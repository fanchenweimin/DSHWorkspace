## 1.4 修行资源分两种：永久的，和临时的

**同样是"资质 +3"，一种是改底子，一种是借来的。** 这一条决定价格，也决定它在人口里值多少。

| 类型 | 定义 | 例子 | 到期 |
| --- | --- | --- | --- |
| **永久** | 改的是这个人的底子，**永远不会掉** | **洗髓**（资质 +3，一次性）、**药浴**（3 年共 +3）、延寿丹（`extraLife`） | 不掉 |
| **临时** | 只在有效期内算，过了就还回去 | **悟道丹**（悟性 +5，一年）、**宝地**（资质 +3，一年）、**固本丹**（破境 +5%，当年）、**喂招**（破境 +8%，当年） | 到期自动掉 |
| **消耗** | 用掉就没了，效果当场结算 | 培元丹（月修为 ×1.10，当月）、疗伤药 | 用完即止 |

**四条规矩**：

1. **永久不可逆**：洗髓只加不减，没有"洗回去"的药。想废掉一个人的根基，只能靠更高阶的手段（灌顶、邪功），那是另一套代价。
2. **临时不叠加**：同类临时药同时只有一份，再吃覆盖不累加（防"连嗑十颗悟道丹"）。
3. **定价按"改变多少次判定"算**：永久 +3 资质会改变此后**每一年**的墙与门，所以洗髓 5 金一颗；临时 +3 只改变当年一次，所以宝地一次 1 金。
4. **战斗与事件默认只认永久**：临时属性不进战斗面板、不进事件门槛，除非那条事件显式声明"可用临时"（避免"吃一颗丹骗过宗门考核"）。

> **在人口里差多少**：洗髓 +3 与宝地 +3，对当年的成功率完全一样；但洗髓那份会让 30 岁前每一次 `q` 与 `b` 都变，按 `设计/15` 的口径，一份永久 +3 大约值 **1.5–2 个百分点**的脱凡率，一份临时 +3 只值当年那一次。

## 2. 赔偿：按对手资产随机比例

```text
赔偿额 = 对手总资产 × 随机比例 × 级别系数

随机比例：1% – 10%（每次战斗现掷）
级别系数：同境界 1.0 / 越级挑战 1.2 / 被碾压 0.8
上限：不超过你现有资产的 80%
```

### 2.1 钱不够时

```text
如果赔偿额 > 你能付的：
  A. 倾家荡产：付光钱 + 卖装备，声望 −10
  B. 白打工：欠债，强制劳役 N 年（N = 欠款/年收入，上限 5 年）
  C. 逃跑：30–50% 成功率，失败即死（生死斗/不死不休）
```

白打工期间：收入全抵债、不能闭关、不能远行、不能离开所在城池。

## 3. 声望（reputation）：到底是干什么用的

你问得对——**没有用途的数值就是噪音**。声望在本作里有 6 个硬用途：

| 用途 | 具体效果 |
| --- | --- |
| **太学直招** | 声望 < 0 → 直接失去直招资格（哪怕四项条件全中） |
| **身份晋升** | 城主需 ≥ 80，将军 ≥ 60，宗主 ≥ 50 |
| **委托报酬** | 每 20 点声望，报酬 +5%，最高 +20% |
| **借传承武器** | 声望不足，城中不借（这是唯一获得传承级武器的途径） |
| **坊市价格** | 声望 < 0 加价 30%；≥ 80 减价 10% |
| **招附庸** | 声望太低，没人来投（影响 `subjects`，进而影响养灵修炼） |

### 3.1 声望怎么变

| 升 | 降 |
| --- | --- |
| 完成委托 +1~3 | 认输（斗法 −5，切磋 −3） |
| 救人 / 守城 +5~15 | 欠债不还 −5 |
| 斩杀祸患 +5 | 滥杀无辜 −15 |
| 世界认可 +30 | 背叛同伴 −20 |

### 3.2 范围

```text
-50 ~ 100
负声望：进城被盘查、不能接高级委托、价格上浮
高声望：可入权力机构、可借宝、可招人
```

## 4. 税收（城主）

```text
城主年税收 = 人口 × 人均税 × 税率
  人均税 = 20 铜/年（基准）
  税率   = 0.3 ~ 0.6（玩家可调，影响民心）

100 万人口 × 20 铜 × 0.4 = 800 万铜 = 800 金/年
```

**但这不是净落袋**，见 §5.6 的开销表。

## 5. 经济循环（钱从哪来，到哪去）

### 5.1 四条收入线

| 来源 | 代表数额 | 说明 |
| --- | --- | --- |
| **打工 / 委托** | 锻体 15–50 银 / 炼气 1–8 金 | 稳定，天花板低 |

### 5.2 家世供给（成年后骤减）

| 家世 | 未成年（7–15） | 成年（16–25） | 25 岁后 |
| --- | --- | --- | --- |
| 大族嫡系 | 每年 **1 金** | 每年 50 银 | 每年 20 银（除非做出贡献） |
| 富商 | 每年 50 银 | 每年 30 银 | 每年 10 银 |
| 小吏 | 每年 20 银 | 每年 10 银 | 3 银 |
| 农户 | 每年 5 银 | 每年 2 银 | 无 |
| 孤儿 | 无 | 无 | 无 |

成年后想继续拿钱，只有三条路：

```text
1. 为家族做贡献（主持族务、联姻、复仇、经商）
   → 一次性奖励 + 恢复较高年供
2. 接过族长之位（成为家主）→ 反过来支配族产
3. 被家族放弃（声望低、走邪路、长期不归）→ 断供，可能被族谱除名
```

### 5.2.1 天赋触发：城主府招募（按阶发放，防卷款跑路）

有百艺天赋的人会**触发一次「去城主府报到」事件**。

金额**不一次性给完**，按你已达的百艺品阶、分期发放：

| 你的百艺品阶 | 一次性安家银 | 此后每年俸禄 |
| --- | --- | --- |
| 1 阶初阶 | 2 金 | 30 银 |
| 1 阶中阶 | 5 金 | 60 银 |
| 1 阶大成 | 10 金 | 1 金 |
| 2 阶 | 30 金 | 3 金 |
| 3 阶 | 80 金 | 8 金 |

**为什么分期**：安家银是「你来了，给你安家」的钱；俸禄是「你干活，给你开工资」的钱。两者分开，人才会长期为城主府服务。

卷款跑路？

```text
拿了安家银就跑：
  → 被列为「逃户」，声望 −30
  → 全国通缉，进城被拿下
  → 原城主府开出悬赏（金额 = 安家银 × 2）
  → 之后任何正经势力都不会再收你
```

所以「跑路」是可行但代价极高的选择，和邪修路线可以接上。

> 谈条件需要交涉判定；失败则安家银减半，声望 −5（不识抬举）。

### 5.6.1 城主摆烂：黑化路线

城主是千挑万选出来的，正常不会摆烂。但**玩家可以选择摆烂**，这会走一条特殊路线：

```text
连续 2 次拒绝「修城墙 / 赈灾 / 上贡」→ 进入「失政」状态
失政状态下继续摆烂 → 民怨沸腾
  → 其他将军联手讨伐（强制战斗，级别：不死不休）
  → 战胜：屠城立威，本性 −20，声望 −40，天下皆知
  → 战败：城破人亡
```

所以摆烂不是「躺平」，是**主动走进一条更凶险的路**。

## 6. 邪修的钱从哪来

被通缉后不能进城，坊市也进不去。但邪修不靠买东西活着：

| 来源 | 说明 |
| --- | --- |
| **杀人掉宝** | 对手身上全部资产（金钱 + 装备 + 材料） |
| **黑市** | 价格比坊市贵 50%，不要声望，不问来历，只在城外的破庙/山洞 |
| **以物易物** | 用抢来的东西换丹药 |

```text
杀一个锻体境散修：可得 20–80 银
杀一个炼气境修士：可得 1–8 金
杀一个养灵境：可得 20–100 金（但打不过）

所以邪修是「高风险高回报」，且越杀越强、越强越敢杀
```

代价：心性崩、本性恶化、被仙司围剿、赏金递增、无法进入正常社会。
