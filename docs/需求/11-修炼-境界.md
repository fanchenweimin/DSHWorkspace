## 1. 一道门，三段判定

```
修为条满了
 ① 墙出不出来？     掷「出现率」
      ├─ 没出现 → 当年破境，境界立成（不吃首次必败，不耗年份）
      └─ 出现   → 看这一品是哪一类
 ② 概率瓶颈 → 每年可以冲一次；第一次必定失败；之后按「成功基数」掷
 ③ 事件瓶颈 → 等那个事件；事件到了
        ├─ 单事件型（品 5）→ 直接过，不掷骰
        └─ 判定型（法相/养灵/修心/品 6）→ 再按「成功基数」掷一次
```

**三条贯穿全局的硬规则**：
1. **失败不扣修为。** 不论是概率瓶颈还是事件瓶颈，失败只损失这一年，修为条、层级都原样保留。
2. **一年只能突破一次。** 全局一次，不分道、不分品。
3. **层级是资格，品是位置。** 层级只增不减，且不能跨大境界攒（每道 Lv1 入门门例外）。

### 2.1 四条独立路线

锻体、炼气、养灵、修心是**四条互相独立的路线**。各修各的条，互不相通：

| 路线 | 修什么 | 吃什么属性 | 独有规则 |
| - | - | - | - |
| **锻体**（1 阶） | 内力 | 资质 | 前 4 品是概率瓶颈；品 5/6 是事件 |
| **炼气**（2 阶） | 法力 | 悟性 | 只认"涨脑子"的东西，除瓶颈类丹药无效 |
| **养灵**（3 阶） | 灵力 | (资质+悟性)/2 × 灵量 | 灵量零和，一个生灵只供一个人 |
| **修心**（4 阶） | 道心 | 心性 | 没有月修为，只由心关事件推进 |

"独立"是**机制层**的：内力不换法力、法力不换灵力（不变量 2）；每个月的修炼**必须明确投给哪一道**。

但"独立"不等于"随便练"——**只练一道的人，四道都走不远**，因为下一节那条带动关系（§8）。

---

### 2.2 螺旋上升：前人摸索出来的那条路

四条路线不互通，但**修高阶时会漏一点给低阶同品号，并把低阶同品号的墙撞开**（§8）。于是自然浮出一条被反复验证的顺序：

```
体魄(锻1) → 脏腑(锻2) → 感气(炼1) → 破胎(炼2) → 驭凡(炼3) → 法相(炼4) → 双 4 品 → 养灵…
```

**这是经验，不是硬编码**：

- 引擎允许你把月份投给任何一道，**没有"必须先修锻体"这条规则**；
- 走螺旋只是因为它**最快**——每破一品，前面同品号的墙自动松一档，修为还会自己涨一点；
- 走偏门有明确代价：只修锻体、炼气一片空白的人，拿不到太学门票，也凑不出"双四品自悟"，只剩师承一条窄路（§5）——**能进，但很难进**。

> 所以人口模型按螺旋算是对的——**不是因为规则强制，是因为别的走法更慢。**

### 2.3 第四小境界才算"有成就"

**背景设定**：前三品只是"摸到了门"，**第四品（朝元 / 法相 / 神游 / 从心而欲）才是一个人在这一道上真正有了成就**。前三品不算什么。

这条不是修辞，它有三个机制后果：

1. **身份与任职看第四品**：军队、宗门、朝廷任事，要的是"某道四品"，不是"某道三品"。
2. **养灵要先打开认知障**（§5）——双四品是"自己悟出来"，太学与师承是"被人提前捅破"；三条都只是入场券，**真正进门看养灵 Lv1**。
3. **锻体比炼气难有出路**：锻体四品（朝元）是**概率瓶颈**，资质 ≤79 墙必现；炼气四品（法相）是**事件瓶颈**，靠太学门票 + 一次判定。所以锻体出身的人更容易停在"三品"这个尴尬位置上——**这是设定的残酷，不是系统的漏洞。**

> **由此撤回上一轮的提议**：不需要为"锻体天才"单开军功 / 武举通道。
>
> 资质 78、悟性 45 的人**不是天才**，是"天生神力、脑子不够"——他 10 岁到脏腑，然后一辈子卡在感气 / 破胎，这是**正常结局**（前三品不算成就）。真正的锻体出路只有一条：把炼气也走到破胎、进太学、再回来到朝元。走不通就是走不通，**这是世界观的一部分**。

### 2.4 难度曲线：小境界之间指数上升

**规则**：同一道内，下一品的修为总量至少是上一品的 `g` 倍，且 `g` 随品号递增。

```text
修为总量(n) = 修为总量(n−1) × g(n)

g(1→2) ≥ 1.6    g(2→3) ≥ 2.0    g(3→4) ≥ 2.2    g(4→5) ≥ 2.4    g(5→6) ≥ 2.6
```

- **不许"差不多"**：相邻两品只差 1.5 倍以内，玩家感觉不到"越往后越难"，前四品会退化成一个连续斜坡。
- **越往后越陡**（`g` 递增）：每一品的跨度都比上一品大。第四品这一格还要**再明显跳一下**——那一格才是成就线。
- **数值表本轮不重算**：§3–§5 的表是 r22 的遗留值（由"10 岁脏腑过半""30 岁脱凡 90%"两个锚点反推），**不满足这条指数规则**（品 3→4 只有 1.56 倍）。r23 按本节的 `g` 重排，同时重跑人口锚点。
- **重排的连带影响**（先记下来）：曲线变陡 → 破境年龄后移 → `b` / `q` 要调松、或者求学与丹药的效率要调高，才能守住"30 岁 90% 脱凡"。**锚点不动，只动曲线形状。**

## 3. 锻体（1 阶）· 资质说话

| 品 | 境界 | 修为总量（**内力**） | 约需年数 | 寿元 | 瓶颈 |
| - | - | - | - | - | - |
| 1 | 体魄 | **140** | 1 年 | 60–85 | 概率 |
| 2 | 脏腑 | **310** | 2 年 | 60–85 | 概率 |
| 3 | 调息 | **1,600** | 12–15 年 | **90–105** | 概率（**第一次换命**） |
| 4 | 朝元 | **2,500** | 18–20 年 | 110–130 | 概率 |
| 5 | 金身 | **3,900** | 30 年 | **300–350** | 事件·单事件：**武名动四方** |
| 6 | 临虚 ★ | **5,700** | 40 年 | **1,000** | 事件·判定：**力破** |

> **修为条快、瓶颈慢，这是故意的。** 前两品加起来只有 450 点——一个资质 57 的孩子从 7 岁入学，**10 岁前后就走完脏腑**（`设计/11` §9 实测：全体 **56.9%** 在 10 岁前到脏腑，资质 65 以上 91%）。真正的时间花在**品 3 之后**：修为条本身要 12–15 年，而调息那道墙平均还要多卡 **3–4 年**，运气差的卡 8–10 年。
>
> **卡住的这些年，玩家不是干等。** 修为条满了，修炼就无事可做——这几个月/几年正好拿去学术法、练百艺，或者进城接委托。**"修为满了但过不去"是这套系统里最正常的状态**，它把时间从"挂机"变成"选择"。

### 2.8 开局四属性是随机出来的（r34）

> **用户口径**：「我发现你这四个隐藏属性（资质、悟性、心性、气运）没有每次开局随机啊，都是一样的。」

| 属性 | 范围 | 取法 |
| --- | --- | --- |
| 资质 / 悟性 / 心性 | **45 – 90** | 各取两次均匀随机再平均（分布集中在 60 附近，天才与废柴都少见） |
| 气运 | **30 – 80** | 单独一段，不做平均——命就是命 |

- 开局纪事也跟着分岔（筋骨单薄 / 不算慢 / 是块练武的料；背书要三遍 / 不快不慢 / 过目不忘）。

### 2.9 阶与品：只用一套刻度（r33）

> **用户口径**：「在一二三阶的 4 品（含）内，高一阶的能影响低一阶高一品的，例如 3 阶 2 品能影响 2 阶 3 品，能影响 1 阶 4 品。超过 4 品的就不用这个规律了。」

- **阶 = 大境界**：1 锻体 · 2 炼气 · 3 养灵 · 4 修心。
- **品 = 小境界 1..6**，名字就是"天地玄黄"那一套：**1 黄下 · 2 黄中 · 3 黄上 · 4 玄 · 5 地 · 6 天**。
  所以「2 阶 1 品 = 2 阶黄下」「黄上 = 3 品」——**品阶名字不是另一套数字，它就是品**。
- **影响等级 `L = 阶 + 品`**（只在品 ≤ 4 时成立）：

| 你 | 够得着 | 够不着 |
| --- | --- | --- |
| 3 阶 2 品（L=5） | 2 阶 3 品（5）、1 阶 4 品（5） | 3 阶 3 品（6） |
| 2 阶 2 品（L=4） | 2 阶 2 品、1 阶 3 品 | **2 阶 3 品** |

- **品 5 / 6（地 / 天）不做这个换算**：只能同阶比品。1 阶天品够不着 2 阶。
- 差一级 → 效果**只剩一成**（威力 −90%）。

### 2.9.1 破境要多久：与属性成反比（r33）

> **用户口径**：「之前设计的突破需要的时间与属性成反比。」

`months = base × 品阶系数 × ref / 属性分`，属性分 = 0.6×资质 + 0.4×悟性（`rules.TIME`）：

| 你的资质+悟性 | 破同一关要 |
| --- | --- |
| 60（基准） | base × 品阶系数 |
| 90 | 约 ⅔ |
| 40 | 约 1.5 倍 |

- 品阶系数：每高一品 +15%（`tierFactor`）；**入门关不加**（"能不能开始"不该比"再进一步"还费时间）。
- 学艺 / 学术法同理，只是吃悟性为主（0.7 / 0.75 权重）。
- 走 `src/model/rules/time.js`；事件若写了 `monthsBy`，耗月也走这条公式。

### 3.0.0.0 一年只能破一次境界，**入门不算**（r32）

> **用户口径**：「之前设定的是每年只能境界突破一次，入门的这种不算（感气入门这种）。」

- **品内突破**（体魄→脏腑、破胎→驭凡…）：**每年只能破一次**，破完 `turn.breakthroughUsed` 置位。
- **入门关**（进一个大境界的第 1 品：体魄 / 感气 / 开视 / 不惑）：**不占这个名额**。
  它问的是"这个人能不能开始"，不是"能不能再进一步"——尤其是"锻体还没练满就想开气"的人，不该被卡一年。
- 事件瓶颈破的也是"品内"，照样占名额；只是它不用掷骰（`force`）。

### 3.0.0 两种瓶颈，两种破法（r30 定稿）

> **用户口径**：「事件类型瓶颈，是一定要由事件去突破瓶颈层级的，没有突破瓶颈的情况下，再怎么尝试都是没用的；反之，一旦事件瓶颈突破了，那么就不需要再重试了。」

| 瓶颈 | 怎么破 | 界面 |
| --- | --- | --- |
| **概率瓶颈**（锻体 1–4、炼气 1–3） | 修为练满 → 点「突破」→ 掷一次门（有墙才掷） | 修为满了就是「突破」按钮 |
| **事件瓶颈**（锻体 5/6、炼气 4/5/6、养灵全部、修心全部） | 修为练满 → 点「突破」→ **把那一件事办掉**（武名动四方 / 立相 / 见众生 / 大心关…），办完直接进品，**不再掷第二次骰** | 同上；点了演的是那一关，不是骰子 |

- **没有那件事，就过不去**：判定层（`judgeBreak`）遇到事件瓶颈直接返回 `need_event`，硬闯无效。
- **办完就是办完了**：事件瓶颈进品不掷骰，`force` 一次到底。
- 修心没有月修为（道心只走心关），所以它那一行**只有「突破」，没有「修炼」**。
### 3.0 入品 = 一道门，不是一条进度条（r28）

> **用户口径**：「角色进来就应该是锻体体魄境界的瓶颈判断，没瓶颈就直接进入锻体体魄了，有门槛就是要突破这个瓶颈，然后进入锻体体魄，根本没有未入门进度条一说。」

所以四道的第 1 品**不是"从 0 攒到 X"**，而是一次瓶颈判定：

| 情况 | 结果 |
| --- | --- |
| 这一品对这个**没有墙**（出现率 `q` 掷空） | 直接站在该品。十岁开局时锻体就走这条路：七岁入蒙学，筋骨已经练开 |
| 有墙 | 停在门口（层级 0），当年只剩这一关；界面写「→ 体魄」，**没有进度条** |

- **修为条从第 1 品才开始有**：`PROF[dao][n-1]` = 站在第 n 品练满所需的修为（体魄 140、脏腑 310…）。
  站在体魄练满 140 才有资格破脏腑；**没入品时没有条**，所以界面上不存在"未入门进度条"。
- 入门关的成功基数有下限 `SUCCESS.openBase`（默认 0.25），而且**不吃"首次必败"**——
  否则资质 40 的人会一辈子站在门外。
- 四道的**入门关各有各的门**（写 `rules.BREAK_GATE.<dao>.1`）：
  锻体无门槛；炼气要 **锻体·脏腑**（气感在筋骨之后）；养灵要**双 80 禀赋 + 一张入场券**；修心要**心性 ≥ 90**。
- 道心是例外：它是**累计制**，`PROF.heart` 的四个值（100/220/370/550）就是四道门槛本身，
  心关给的道心不清零，攒够哪一格就是哪一格。

**锻体的分水岭在"墙出不出现"，不在"门多宽"**：资质 ≤ 60 的人，调息这道墙 **100% 会出现**；资质 90 的人，这道墙根本不存在。资质 ≤ 79 的人，朝元同理。

**品 6 · 力破**：金身圆满 + 在**无法力状态**下与法相以上者死战而不死。**没有额外代价**——不扣寿元、不掉修为，条件本身就是门槛。

## 4. 炼气（2 阶）· 悟性说话，只认「涨脑子」的东西

| 品 | 境界 | 修为总量（**法力**） | 约需年数 | 寿元 | 瓶颈 |
| - | - | - | - | - | - |
| 1 | 感气 | **90** | 1 年 | 60–85 | 概率 |
| 2 | 破胎 | **300** | 2 年 | **60–85（不加）** | 概率 |
| 3 | 驭凡 | **900** | 6–8 年 | **150–180** | 概率（第一次换命） |
| 4 | 法相 | **1,800** | 12–15 年 | 200–240 | 事件·判定：**立相** |
| 5 | 合一 | **2,800** | 20 年 | **350–400** | 事件·单事件：**相与身合** |
| 6 | 化朽 ★ | **4,000** | 30 年 | **1,000** | 事件·判定：**散功** |

**三条与锻体不同的规则**：
1. **"除瓶颈"类丹药无效**（没有"吃药买过关"），但**悟道丹（悟性 +3/+5/+8，一年）有效**——它加的是脑子，提高的是往后十年的修炼基数，不是这一次的骰子；
2. **感气可以反复试、没有年龄上限**——"没有人被永久排除在炼气之外，只有早晚之别"；
3. **太学只招已破胎的人**：16 岁入学时须已进入炼气·破胎（门槛，不是加分）。`设计/11` §9 实测：16 岁已破胎的占全体 **42.6%**，太学在这批人里按资质+悟性取前 8%，**录取者 100% 已破胎、偏科者 0%**。
   **这是唯一的教育通道，不另开"锻体专属通道"**（§2.3）：锻体出身的人想受教育，也得自己把炼气走到破胎。走不通，就是没有——不是系统特判他。

**法相是前四品里唯一的事件瓶颈**：不是概率低，是必须先立相。立相要 `qi.level ≥ 3` + 法力满 + **太学卒业**（这是门票，求学买不到），再按 `0.10 + (悟性−89)×0.01` 掷一次。

**品 6 · 散功**：合一圆满 + **主动散去全部法力**（`qi.bar = 0`、层级保留），再重新聚起来。**这不是代价，是事件本身**——化朽要的是"敢把自己全部法力散掉"这件事，散了之后境界该升还是升，法力照常修回来。

> **炼气为什么比锻体快**：感气 90 + 破胎 300，合计只要 390 法力，悟性 70 的人**不到 4 年就走完破胎**（10 岁前后）。卡点在品 3（驭凡，900 点、约 6–8 年）与品 4（立相，太学门票）。**炼气的时间不是花在"攒"，是花在"等一个人教你"**——这就是太学存在的理由。

## 5. 养灵（3 阶）· 双 80 禀赋 + 三道认知障 + 六道门

**进门分三层，从下往上**：

| 层 | 条件 | 性质 |
| --- | --- | --- |
| **禀赋** | 资质 ≥ 80、悟性 ≥ 80 | 硬（没有就是没有） |
| **认知障** | 下面三条**任一**即可打开 | **软（三选一，等价）** |
| **真正的门** | **养灵 Lv1（见众生）** 那一次判定 | 硬（掷不过就还是没进） |

**打开认知障的三条路**：

```text
① 自悟   锻体 4 品 + 炼气 4 品 —— 到了第四品，你自己就能摸索出「灵」是什么
② 太学   太学卒业 —— 提前帮你把那层认知障打开
③ 师承   一位养灵者引路（师承 / 机缘）
```

**三条都只是入场券，谁都不代替最后那一步**：

- 双四品**不是**"你已经是养灵者"，它只是说**你已经能自己想明白"灵"是什么**——资质悟性够的人，走到那里自然就懂了。
- 太学与师承**不代替你走那两格**，它们做的是另一件事：**提前把那层认知障捅破**。一个只到炼气三品、但太学卒业的人，能听懂"灵"这个概念，**但能不能进门，仍然要看他在养灵那六道门上过不过得去**。
- **所以真正的门槛是「养灵认知」本身**：`spirit.level`。Lv0 = 没进；Lv1（见众生）= 进了。前面三层全部只是"有没有资格去敲这道门"。

> **这也解释了散修为什么进不了养灵**（`需求/02` §2）：国家封锁的不是"灵力"，是**认知障**。没有太学、没有师承，就只能靠双四品自己悟；而双四品要资质 80、悟性 80 的人各走 18–20 年——**野路子走不到那一步，就走不到。**

> 这条同时解释了军队与宗门为什么"破胎起步"（`需求/02` §4.2）：破胎只是**能当兵**，四品才是**能任事**。两个门槛差着整整两品。

| 品 | 境界 | 修为总量（**灵力**） | 寿元 | 门 |
| - | - | - | - | - |
| 1 | 开视 | **5,400** | 不加（靠续命） | 见众生：看见第一个不是自己的生命在死 |
| 2 | 启灵 | **13,500** | 不加 | 见自己：承认自己也是一个会死的生命（**全道最长**） |
| 3 | 真域 | **21,600** | **400** | 见因果 |
| 4 | 神游 | **27,000** | 700–780 | 见天地 |
| 5 | 浑然 | **37,800** | 950–1,000 | **众生念**（单事件，不掷骰） |
| 6 | 回春 ★ | **54,000** | **∞（返老）** | **返本**（判定）：把灵量全还给众生 |

**品 6 · 返本**：浑然圆满 + **把灵量全部还给众生**（个人灵量归零）后不死。成功则返老（年龄回 30），灵量需重新分配——**还出去的是"这一世的份额"，不是"永久损失"**，境界立住之后城还在、人还在，份额可以再争。

> **r18 确认：品 6 没有任何代价。** 三道都只是"事件条件"——力破要求你在没法力时敢死战，散功要求你散掉法力，返本要求你还掉灵量。条件达成 + 一次判定，过了就是过了；失败只损失这一年。

**养灵的修炼速度由「灵量」决定**（见 `15` §2）：一个人的灵量 = 他分到的那一份，而一座城的灵脉 = 治下所有生灵的灵量基数之和（修士 10 / 凡人 1 / 其他生灵 1）；**一个生灵只能供给一个养灵境界**，分出去就是别人的。

## 6. 修心（4 阶）· 心性说话，靠事件推进

| 品 | 境界 | 道心（累计） | 寿元 | 破境方式 |
| - | - | - | - | - |
| 1 | 不惑 ★ | 100 | **1,000** | 大心关（指定事件） |
| 2 | 天命 ★ | 220 | 1,400 | 大心关 |
| 3 | 耳顺 ★ | 370 | 2,000 | 大心关 |
| 4 | 从心而欲 ★ | 550 | 3,000 | 大心关（全游戏终点） |

- **道心没有"月修为"**。它只由**心关事件**推进：成功一次 `+30 × 心性/100`（心性 90 → +27，100 → +30）；**失败不给也不扣**。
- 这就是"修心不能靠打坐"的算术实现——心性再高也不会自己涨道心。
- 门是**心性 ≥ 90**，且**每次心关都要重新满足**；心关每 5–10 年必出一道，不随机等。
- 心性 < 90 时"成功也不给道心"（只减不增）。
- **修心四品全是极境**，没有普通品：拿到不惑，后面三品的寿元自己会长。
- 修心**不参与带动**（它没有品号可比），也不进城市人口账。

## 7. 教育 = 求学（常驻动作，不是静态加成）

**蒙学和府学是义务的，没有"不上学"这一档。** 它们的作用不是给属性、也不是给固定加成，而是**开放"求学"这个动作**——在学籍覆盖的品上、且**正在撞瓶颈时**，玩家可以花月份去求学，提高概率瓶颈的**成功基数**。

| 学籍 | 年龄 | 覆盖哪些品 | 能求学的品 |
| --- | --- | --- | --- |
| **蒙学** | 7–10 | 锻体 1–2（体魄、脏腑） | 品 1–2 |
| **府学** | 11–14 | 锻体 1–3 + 炼气 1–3 | 品 1–3 |
| **太学** | 16–19 | 锻体 1–4 + 炼气 1–4 | 品 1–4 |

**封顶按品，不按学籍**（r21 改）：

| 品 | 封闭顶 | 要几次 | 说明 |
| --- | --- | --- | --- |
| 品 1–3 | **+0.06** | 2 次（1 年） | 再求也没用 |
| 品 4 | **+0.12** | 4 次（2 年） | 品 4 更难，给更多余地 |
| 品 5–6 | — | — | 事件瓶颈，求学无效 |

- 每次求学 **+0.03**，同一品内累积，破境成功后清零；**每次 3 个月、每年最多 2 次**（`需求/20` §7）。
- **它花的是修炼时间**：同一份 12 个月，求学 3 个月就是少练 3 个月。这是它唯一、也是全部的代价。
- **封顶按品，与学籍无关**：学籍只决定"这一品能不能求"（蒙学不覆盖品 3，所以品 3 的求学要等府学）。**同一品封顶 +0.06 封死，读再多书也加不上去。**
- **太学的特殊作用**：炼气 4 品（法相）是事件瓶颈，**只有太学卒业的人才能触发"立相"事件**——太学不是概率加成，它是那道门的门票。

**为什么不是静态加成**：r16 的蒙 +30% 会让"能不能换命"几乎等于"进没进蒙学"。改成可点动作之后，属性重新成为主变量，教育是"多一条路"，不是"唯一的路"；而且**点它要花时间**，玩家不会无脑点满。

## 8. 带动：高境界的修炼，会漏一点给低境界的同品号

**两条，各自独立，不要混成一条**：

```text
① 修为外溢   修 阶 M 的道时，对每一道 阶 < M 的同品号（品 ≥ 2）：
                该品修为条 每月 += 本月所得 × 外溢率（默认 10%）
                该品已满则作废（不结转、不折成别的、不换道）

② 破瓶颈     在 阶 M 达成第 N 品（N ≥ 2）时：
                对所有 阶 < M 的第 N 品：**墙直接拆掉**（若尚未过去）
                即那一道的 q 视为 0，下次冲关不再掷出现率
                但**修为仍要自己修满** —— 带动不给层级、不给免费破境
```

| 达成 | 外溢给 | 顺手拆掉的墙 |
| - | - | - |
| 炼气 2 品（破胎） | 锻体 2 品（脏腑）的修为 | 锻体 2 品的墙 |
| 炼气 3 品（驭凡） | 锻体 3 品（调息）的修为 | 锻体 3 品的墙 |
| 炼气 4 品（法相） | 锻体 4 品（朝元）的修为 | 锻体 4 品的墙 |
| 养灵 3 品（真域） | 炼气 3 品 + 锻体 3 品的修为 | 同上两道的墙 |
| 养灵 4 品（神游） | 炼气 4 品 + 锻体 4 品的修为 | 同上两道的墙 |

**四条边界**：

1. **第一小境界不带**：品 1 没有"更低一阶的同品号"可带，外溢与拆墙都从品 2 起。
2. **只补同品号**：破胎带脏腑，不带调息。
3. **只从高到低**：炼气带锻体，锻体不带炼气；养灵带炼气与锻体，反之不行。
4. **带动不占额度、不掷骰、不清修为**：外溢只是"少修一点"，拆墙只是"不用再赌 q"。

**为什么这样设计**：四条路线独立（§2.1）。如果完全不带动，玩家前 40 年全在补底子；如果带动成"自动补齐"（上一版的写法），低阶境界就彻底没有重量。**外溢 + 拆墙正好卡在中间：低阶要花时间，但不必再赌命。**

> 这就是"高境界的精进主要是破除低境界的瓶颈"的算术版本：**外溢管量，拆墙管质。**
>
> 上一版的「大境界互补」（出现率 ×0.1 / 事件基数 ×10）与"自动补齐"都作废。

## 9. 寿元：一条规则代替一张经验表

```text
寿元 = 境界下限 + 进品时掷一次的区间随机量 + extraLife（延寿丹/宝药/机缘，永久叠加）
```

| 规则 | 内容 |
| --- | --- |
| 前两个小境界不加寿元 | 体魄/脏腑/感气/破胎 都是凡人寿元；开视/启灵 也不加 |
| 第三品起每进一品加一次 | 调息、驭凡、真域 是三道各自的"第一次换命" |
| 第五品大提 | 金身 300–350、合一 350–400、浑然 950–1,000 |
| 第六品统一 1,000 | 临虚 / 化朽 / 不惑 都是 1,000 |
| 两条 ∞ | 养灵·回春（返老，年龄回到 30）、修心·转世（重开一世，心性不重置） |
| 叠加而非覆盖 | `extraLife` 加到哪个底座上都终身有效，不会被新境界覆盖掉 |
| 品 6 **无代价** | 临虚 / 化朽 / 回春 进去是多少就是多少，**不扣寿元、不清修为**（r18 确认） |

**"凡人"的正式定义 = 体魄 / 脏腑 / 感气**（没换过命的人）。破胎虽然不算凡人，但**寿元仍是凡人**——这就是"四成的人停在破胎、却只有 72 年"的来源。

## 10. 圆满

**圆满 = 该小境界的修为条修满。** 只有一个意思，不新增境界、不新增层级。

- "第 4 品圆满"= 朝元的内力条满了（或法相的法力条满了）；
- 品 5 的前置写的是"第 4 品圆满 + 对应事件"，不是"第 5 品"；
- 所以"圆满"是**破境的前置状态**，不是破境的结果。
