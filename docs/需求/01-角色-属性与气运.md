## 1. 四项数值属性 + 两项先天标签，各自只有一个出口

| 属性 | 范围 | 唯一出口 | 不参与 |
| --- | --- | --- | --- |
| **资质** | 45–90（r34 随机） | 锻体（内力速度、锻体出现率/基数） | 炼气、修心 |
| **悟性** | 45–90（r34 随机） | 炼气（法力速度、炼气出现率/基数）＋ 走不走炼气的门槛 | 锻体、修心 |
| **心性** | 0–100 | 修心（道心增量、心关成功基数、心魔）＋ 战斗神志值 | 锻体、炼气 |
| **气运** | 0–100（开局 30–80） | 判定的小幅修正、事件权重 | 不作为任何境界的主属性 |
| **命格**（先天标签） | 枚举 | 起点与上限 | 不改公式 |
| **天赋**（先天标签） | 枚举 | 百艺上限 | 不改公式 |

> **口径**：真正的**数值属性是四项**（资质 / 悟性 / 心性 / 气运）；
> 命格与天赋是**枚举标签**，不参与任何公式的乘法，只改起点、上限与百艺封顶。
> 旧稿把五项并列写成"五项属性"，容易被读成"五个数值"——本版分开写。
>
> ⚠️ **代码现状**：`state.attr` 只有前三项 + 顶层 `luck`，**命格 `fate` 与天赋 `talents[]` 都没落地**
> （`talents.json` 是死配置）。见 `设计/92` A1 / A2。

**"唯一出口"是这套系统的地基**：资质高的人只能靠锻体兑现，想走炼气就是浪费。这就是四道能并立的原因——它们不是四个难度，是**四个互不重叠的属性出口**。

## 2. 属性怎么生成

> **r34 改了口径**（用户原话：「我发现你这四个隐藏属性没有每次开局随机啊，都是一样的」）。
> 现行口径见 `需求/11` §2.8，摘要：

| 属性 | 范围 | 取法 |
| --- | --- | --- |
| 资质 / 悟性 / 心性 | **45 – 90** | 各取**两次均匀随机再平均**（分布集中在 60 附近，天才与废柴都少见） |
| 气运 | **30 – 80** | 单独一段，**不做平均**——命就是命 |

- 开局纪事也跟着分岔（筋骨单薄 / 不算慢 / 是块练武的料；背书要三遍 / 不快不慢 / 过目不忘）。
- 想复现：`demo.initial(name, { rng })` 传确定性 `rng`；测试用 `fresh()` 钉住 66/71/62。

**以下 r22 的旧口径已作废**，只留作对照：

```text
出生：和 S ~ U[110, 130]，分配 r ~ U[0.40, 0.60]
      资质 = round(S × r)      悟性 = round(S × (1 − r))
自然上限 78；均值 60、sd 7.5；范围 44–78
```

> **作废原因**：旧模型把资质与悟性绑成"一条 S 的对偶分配"（和恒定、必然负相关），
> 而 r34 的要求是**四项各自独立随机**。所以"自然上限 78"这条路也一起作废。
> 这条变更的连带后果要记着：`需求/11` §5 的「双 80 才能进养灵」在旧模型里是
> "自然人口命中率 0"的稀有门，**在新模型里双 80 变得可达**（45–90 的均值区间上）。
> 养灵门槛要不要跟着调，见 `设计/92` A4。

### 2.1 属性上限：三层加法，满值可达 200

> **r35 补写。** 之前只写了"出生怎么随机"，没写"一个人最高能到多少、靠什么到"。
> 没有这张表，"上限 200"是一句空话——**必须有路可走，但不能有捷径**。

| 层 | 来源 | 单人上限 | 代价 | 进门槛判定？ |
| --- | --- | --- | --- | --- |
| **出生** | 随机（r34：45–90 两次平均） | 90 | — | ✅（就是底值） |
| **命格** | 天才 / 早慧 这类 | **+30** | 抽不到就是抽不到 | ✅ |
| **事件** | 顿悟 / 传承 / 灌顶 / 大彻大悟 | **+20**（单次封顶） | **一生 1–2 次**，遇不到就是没有 | ✅ |
| **永久资源** | 药浴 / 洗髓 / 宝物 | **合计 +15** | 全买极贵 + 占月数 + 卡品阶窗口 | ✅ |
| **临时** | 悟道丹 / 宝地 | **合计 +10** | 高阶丹 + 高阶宝地同时在场，且只有一年 | ❌ **只进基数，不进门槛** |

```text
单项封顶路径：90 + 30 + 20 + 15 + 10 = 165 → clamp 200（本作按 200 记上限）
永久侧最高：  90 + 30 + 20 + 15      = 155（差 45，靠临时补）
```

- **"200 不是装饰"**：它是"天才 + 最稀有事件 + 全部永久资源 + 顶级临时道具同时成立"的产物。
  四者缺一就到不了。**没有捷径能到 200，但确实存在一条路。**
- **临时加成不进门槛判定**：`需求/11` §5 养灵的双 80、修心的心性 90，**只看永久值**。
  否则一颗悟道丹就能进养灵，全游戏最窄的那道门变成药铺。
- **临时值计入面板显示**：所以"看得见的 200"和"判定用的 155"是两回事——
  **满值从来不是一个稳定状态，是一个瞬间。**
- **资源加成不能破 caps**：药浴、洗髓、宝物、临时加成全部受 100 的硬顶约束。

> **注意**：r34 把出生改成 45–90（均值集中在 60），所以"90 出生"本身就少见；
> 上表那条 165 的封顶路径**是存在的但极窄**。数值待重推（见 `PROGRESS.md` §0）。

## 3. 心性：三条来源，一个定时任务，一个闸门

> **r35 定稿。** 这一节把"心性怎么掉、怎么涨、什么时候招心魔"讲全。
> 旧稿只写了「自然衰减 + 事件回补」，**漏了两条会扣心性的来源**（事件选择、问心关失败），
> 导致"心魔"在机制上不可达。现在补齐。

### 3.1 三条改动线（各自记账，**不互相抵消**）

| # | 线 | 什么时候 | 改多少 | 能不能把心性降到 60 以下 |
| --- | --- | --- | --- | --- |
| ① | **自然衰减**（定时任务） | 每年年初，**未入修心**时 | 在册 −1/年；离校 −2/年 | **不能**——心性 ≤ 60 即停 |
| ② | **事件选择** | 事件结算时 | 由事件自己写（扣或加） | **能** |
| ③ | **心关失败** | 每一次心关失败 | 按下表（r35 新增） | **能** |

**"不互相抵消"的意思**：某年你既被自然衰减扣了 1，又因为一个事件被扣了 8，
那一年就是 **−9**，不是"扣了事件就不扣自然"。

### 3.2 ① 自然衰减：定时任务，且只到 60 为止

```text
每年年初执行一次（角色层 step3）：
  若 已入修心（heart.level ≥ 1）  → 不执行
  若 心性 ≤ 60                    → 不执行
  否则：在册（蒙/府/太）−1；离校（城中/野外/路上/秘境）−2
        扣完若低于 60，钳到 60
```

- **它的作用是"让时间有代价"，不是"把人拖死"。** 所以它停在 60：
  一个什么都不做的人，心性会慢慢凉到 60，然后停在那儿。
- **60 这个数就是"心魔的保险"**：定时任务最多把人压到 60，
  **单靠熬时间是熬不出心魔的**。这条是 r35 明确的设计意图。

### 3.3 ② 事件选择：这才是心性的主要来源

> **r35 补写。** 这条以前在需求里没写，结果"心性"变成一个只降不升、
> 而且降不出后果的死数值。现在把它写实。

事件可以写 `add/sub attr.heart.eff`（走修饰器）或 `clampAdd`（走一次性），常见类型：

| 类型 | 典型幅度 | 例子 |
| --- | --- | --- |
| **目击杀戮 / 亲手杀人** | −5 ~ −12 | 屠村、处决、战场上补刀 |
| **被至亲背叛 / 失去至亲** | −8 ~ −15 | 师门构陷、妻离子散 |
| **破境失败（重挫）** | −3 ~ −5 | 冲关不成、闭关出岔 |
| **作恶（屠戮无辜 / 背叛）** | −5 ~ −10 | 见 `需求/13` §8 三禁 |
| **大彻大悟** | **+15** | 一生 1 次量级 |
| **问心 / 静坐 / 了断因果** | +5 ~ +8 | 稀有事件 |
| **了却心愿** | +3 ~ +5 | 报仇成功、送走故人 |

- **额度没有硬上限**，但要守一条：**"加心性"的事件必须稀有**（一生个位数），
  否则修心的"心性 ≥ 90"这道门就变成"多刷几次"的事。
- 反过来，**"扣心性"的事件可以常见**——那正是这个设计想要的：
  **正常人不会遇心魔，但做了某些事就会。**

### 3.4 ③ 心关失败扣心性

**每一次心关失败**（不管成没成）：

```text
当前品修为 −10 × 基数        （修为的代价，见 需求/11 §6）
30% 概率 心性 −1             （心性的代价，r35 新增）
```

- 这条让"修心"真正变成"会退"的一道：**你不只是没进，你还会被磨薄。**
- 与 ① 的区别：① 停了（60 以下不动），③ 不停——**入了修心也照样扣**。

### 3.5 心魔：心性 0–39 触发

> **r35 定稿，与旧稿方向相反，以本节为准。**

| 项 | 规则 |
| --- | --- |
| **触发区间** | 心性 **0–39**（即 `< 40`），**每年年初掷一次** |
| **存活率** | **与心性成正比**：`p(活) = 0.1 × 心性 / 39` |
| 39 时 | **0.100**（九死一生） |
| 20 时 | 0.051 |
| **0 时** | **0**（必死） |
| **入道要求** | 只找**入道者**（锻体 ≥ 3 品 或 炼气 ≥ 2 品）；凡人只"得心疾"，不掷心魔 |

**活下来**：

```text
心性 = max(0, 心性 − 5)
当前品的修为条清零
境界不掉
当年不能再发起心关
```

**死了**：身死，这一世结束。

> **为什么是"正比"而不是"反比"**：
> 心性越低，说明这个人**越认不清自己**——心魔要夺的就是"自我"，
> 而一个连自我都守不住的人，自然更难活下来。
> 心性 0 的人没有任何抵抗，所以存活率是 0。
>
> 这条与你 r35 的口径一致：「存活率与心性成正比，0 时为 0，39 为 0.1」。

> **数值待重推**：`0.1` 这个斜率是占位值（见 `PROGRESS.md` §0）。
> 逻辑是"线性、过 (0,0) 与 (39,0.1)"，斜率随锚点调整。

### 3.6 为什么这样设计（串起来看）

```text
自然衰减（最多到 60）        →  保证"啥也不干的人"永远不会遇心魔
事件扣心性（能到 0）          →  这才是有后果的那一刀
心关失败扣心性（能到 0）      →  修心的人先天承担更多风险
        ↓
心性跌破 40  →  每年掷一次心魔  →  为正比存活，越接近 0 越必死
        ↓
活下来：心性 −5、修为清零    →  代价重、但不是处决
死     ：这一世结束
```

**一句话**：**时间是温和的，选择是致命的。**

## 4. 气运

| 项 | 规则 |
| --- | --- |
| 字段名 | **气运**（旧写法一律作废，设计侧字段名见 `设计/02`） |
| 范围 | 0–100，**初始钳 20–95** |
| 作用 1 | 判定偏置：`±(气运 − 50) × 0.001`（±5% 封顶），加在掷骰值上 |
| 作用 2 | **进位偏置**：年末修为小数部分进位概率 `0.5 + (气运 − 50) × 0.001`（±5%） |
| 作用 3 | 事件权重：高气运的"机缘"权重 +0.1 档，低气运的"灾祸"权重 +0.1 档 |
| 漂移 | **每年一次**，向 50 回归 `±1`；事件可以一次性 ±5–15 |
| 年度位置 | **寿元检查之后、心性衰减之前** |

**三个入口，一个乘区都没有**：气运改骰子的落点、改小数进位、改抽事件的倾向，但**绝不进任何一条境界公式的乘法**。它也不改资质、不改功法、不改灵量。

> **命名**：气运与命格是两件事——气运是后天运气（会漂移），命格是先天出身（开局定死）。混用这两个词会让"运气好"和"生得好"分不开。

## 5. 命格与天赋（先天，不可练）

- **命格**：开局随机一个，改四属性的起点/上限（天才、好运、早慧、铁骨、道种、凡人、薄命）。
- **天赋**：百艺的布尔 + 强度（无 / 有 / 卓绝），决定职业上限，**不通过修炼获得**。
- **转世保留命格与心性，不保留天赋。**

## 6. 一个角色的年度节拍（角色层）

```
年初（自动，顺序写死）
① 寿元检查     年龄 +1；超过寿元 → 死
② 气运漂移     气运向 50 回归 ±1（+ 事件修正）
③ 心性衰减     在册 −1 / 离校 −0.5；触地板 60 则 0
④ 心魔         心性 < 40 → 掷；< 20 → 必死

月内（玩家驱动，12 个月）
⑤ 主要事件 / 常驻动作   每月一件事，扣它的月
   └ 修炼、突破、求学都在这里——它们不再由年度链自动结算

年末（自动）
⑥ 错过结算 → 剩余月份清零 → 本年额度复位 → 跨年动作推进
```

**顺序不能换**：先衰减再掷心魔，与先掷再衰减，是两个人不同的死法。这是本轮唯一一条被写死的顺序要求。

**为什么修炼与突破从年度链里挪进"月内"**：它们现在要花月（`需求/20` §2）。写进年度链会变成"自动结算"，时间就不再是货币。

**人口回归不在这条链上**——它属于城池层，在年初第⑤步之前跑，见 `20` §10.4。
