# 需求 · 01 角色：属性与气运

> 系统：**0x 全局**（属性是三个系统共用的输入）
> 对应实现：`docs/设计/02-角色-属性与结算.md`、`docs/设计/01-角色-数据模型.md`
> 这一份只回答"人是怎么被算出来的"，不回答"怎么存"。

---

## 1. 五项属性，各自只有一个出口

| 属性 | 范围 | 唯一出口 | 不参与 |
| --- | --- | --- | --- |
| **资质** | 44–78（自然）→ 100（改造后） | 锻体（内力速度、锻体出现率/基数） | 炼气、修心 |
| **悟性** | 同上 | 炼气（法力速度、炼气出现率/基数）＋ 走不走炼气的门槛 | 锻体、修心 |
| **心性** | 0–100 | 修心（道心增量、心关成功基数、心魔）＋ 战斗神志值 | 锻体、炼气 |
| **气运** | 0–100 | 判定的小幅修正、事件权重 | 不作为任何境界的主属性 |
| **命格 / 天赋** | 枚举 | 起点与上限、百艺上限 | 不改公式 |

**"唯一出口"是这套系统的地基**：资质高的人只能靠锻体兑现，想走炼气就是浪费。这就是四道能并立的原因——它们不是四个难度，是**四个互不重叠的属性出口**。

## 2. 属性怎么生成

```text
出生：和 S ~ U[110, 130]
      分配 r ~ U[0.40, 0.60]
      资质 = round(S × r)      悟性 = round(S × (1 − r))
```

- **自然上限 78**（S=130、r=0.60）。所以"自然出生的人单项永远摸不到 80"。
- 均值 60、标准差 7.5、范围 44–78。
- 心性单独生成，均值 70、范围 40–90；**命格可以改起点**。
- 想上 80 只有三条路：命格、天赋、后天资源（药浴/洗髓/宝物）。**教育不给属性**。

> **这条决定的后果**：朝元（资质 80）、法相（悟性 90）、开视（双 80）在"纯自然人口"里命中率是 0。所有高境界都是被"加成"顶上去的。

## 3. 心性：永不关闭的窗口

| 规则 | 内容 |
| --- | --- |
| 自然衰减 | **在学校/在册期间 −1/年**；离校后 −0.5/年 |
| 地板 | 60。触地板后**衰减归零**，但**窗口不关** |
| 上限 | 100 |
| 回补 | 只靠事件（`heart_restore`、静坐、了断因果），**不靠计算** |

**关键：窗口永不关闭。** 心性掉到 60 的人，靠"静坐 +5"这类没有判定的恢复事件，50–100 年能回 90。所以"触地板即永久失去修心资格"这句话是**错的**，r16 已废除。

**修心的推进完全靠事件**：道心不随时间增长，只由心关事件推进（成功 `+30 × 心性/100`，失败不给也不扣）。心性 < 90 时"成功也不给道心"。

**心性 < 40 触发心魔**（独立于修心）：
- 触发线 40，必死线 20；
- 成活率与心性成正比（`0.10 × 心性 / 39`，39 → 10%，20 → 5%）；
- 活下来：心性 −5、**当前品修为条清零**（这是心魔的代价，不是"突破失败"，不受"失败不扣修为"保护）；
- 死：身死。
- 心魔**只找入道者**（锻体 3 品以上 / 炼气 2 品以上），凡人不会心魔。

## 4. 气运

| 项 | 规则 |
| --- | --- |
| 字段名 | **气运**（旧写法一律作废，设计侧字段名见 `设计/02`） |
| 范围 | 0–100，**初始钳 20–95** |
| 作用 1 | 判定偏置：`±(气运 − 50) × 0.001`（±5% 封顶），加在掷骰值上 |
| 作用 2 | **进位偏置**：年末修为小数部分进位概率 `0.5 + (气运 − 50) × 0.001`（±5%） |
| 作用 3 | 事件权重：高气运的"机缘"权重 +0.1 档，低气运的"灾祸"权重 +0.1 档 |
| 漂移 | **每年一次**，向 50 回归 `±1`；事件可以一次性 ±5–15 |
| 年度位置 | **寿元检查之后、心性衰减之前** |

**三个入口，一个乘区都没有**：气运改骰子的落点、改小数进位、改抽事件的倾向，但**绝不进任何一条境界公式的乘法**。它也不改资质、不改功法、不改灵量。

> **命名**：气运与命格是两件事——气运是后天运气（会漂移），命格是先天出身（开局定死）。混用这两个词会让"运气好"和"生得好"分不开。

---

## 5. 命格与天赋（先天，不可练）

- **命格**：开局随机一个，改四属性的起点/上限（天才、好运、早慧、铁骨、道种、凡人、薄命）。
- **天赋**：百艺的布尔 + 强度（无 / 有 / 卓绝），决定职业上限，**不通过修炼获得**。
- **转世保留命格与心性，不保留天赋。**

## 6. 一个角色的年度节拍（角色层）

```
年初（自动，顺序写死）
① 寿元检查     年龄 +1；超过寿元 → 死
② 气运漂移     气运向 50 回归 ±1（+ 事件修正）
③ 心性衰减     在册 −1 / 离校 −0.5；触地板 60 则 0
④ 心魔         心性 < 40 → 掷；< 20 → 必死

月内（玩家驱动，12 个月）
⑤ 主要事件 / 常驻动作   每月一件事，扣它的月
   └ 修炼、突破、求学都在这里——它们不再由年度链自动结算

年末（自动）
⑥ 错过结算 → 剩余月份清零 → 本年额度复位 → 跨年动作推进
```

**顺序不能换**：先衰减再掷心魔，与先掷再衰减，是两个人不同的死法。这是本轮唯一一条被写死的顺序要求。

**为什么修炼与突破从年度链里挪进"月内"**：它们现在要花月（`需求/20` §2）。写进年度链会变成"自动结算"，时间就不再是货币。

**人口回归不在这条链上**——它属于城池层，在年初第⑤步之前跑，见 `20` §10.4。

## 7. 与旧文档的差异（读旧文前先看这张表）

| 旧写法 | 现在 |
| --- | --- |
| 旧稿用 `fortune` 当气运 | **气运**（旧写法作废） |
| 旧稿用 `fate` 当气运 | **命格**才是它的语义；气运与命格分开 |
| 心性触地板 60 后永久关闭 | **永不关闭**，靠事件回补 |
| 心性每 3 年 −1、下限 10 | 每年衰减、地板 60 |
| 气运钳 20–95 且进公式 | 不进境界公式，只做 ±5% 判定修正 |
| 教育给单项 +10/+18/+28 | **教育不给属性**；改成求学（常驻动作，3 月 / +0.03） |
| 修心有月修为 | **没有**；道心只由心关事件推进 |
