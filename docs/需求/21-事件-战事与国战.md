# 需求 · 21 事件：战事与国战

> 系统：**2x 事件系统 · 战事模块**
> 对应实现：`docs/设计/21-事件-战事链.md`
> 相关：`需求/20`（事件总纲）、`需求/30`（战斗）、`需求/02` §1.1（北国与北关）、`需求/15`（身份与义务）
> **r23 新增。** 解决的是一句话：**不能让人一味修炼。**

---

## 1. 一句话

**战事是修炼的"外部截止日期"。**

修炼是长线（几十年磨一个瓶颈），战事是硬点（某一年某个月，你必须出现）。它不需要打败玩家，只需要**占用玩家的月份**——把"再练两年"变成"今年练不成了"。

三条设计意图，按重要性排：

1. **打断**：让"修为满了、就差磨"的人不得不停下来，把月份花在别处。
2. **兑现**：修炼了三十年，得有一次"用在实处"的机会——守城、出征、救人。
3. **筛人**：战事是最诚实的境界检验。**破胎能当兵，四品能任事**（`需求/11` §2.3）。

---

## 2. 修炼不能只进不出（本模块的根）

一个只有"投入"没有"产出"的修炼系统，结局一定是"所有人闭关到死"。所以境界之外必须有**出口**，出口只有三条：

| 出口 | 产出什么 | 换成什么 | 在哪 |
| --- | --- | --- | --- |
| **战功** | 守住 / 打赢 / 救人 | 身份、席位、丹药配额、免役 | 本文件 |
| **百艺** | 丹药、器物、符箓、阵法、治病 | 钱 → 药 → 破境率 | `需求/13` |
| **供职** | 戍守、差役、朝会、教习 | 俸禄、名额、灵量份额 | `需求/15` §5 |

**三条出口都不直接给修为**（不变量：战斗不反哺修炼）。它们绕一圈回来：**战功 → 身份 → 灵量与资源 → 修炼加速**。这一圈必须让玩家看见，否则"打仗"就只是消耗。

---

## 3. 战事的时间是"日历"，不是骰子

**战事不掷骰。** 它在日历上写死，到点就来：

```
大曜历 312 年   北境告急（预警，非强制，优先级 3）
       ↓ 12 个月
大曜历 313 年   城战 · 北关（强制，优先级 1）
       ├─ 守住 → 北境稳；国战推迟 5 年（或不来）
       └─ 城破 → 城战 · 第二城（6 个月后，强制）
                    └─ 再破 → 城战 · 第三城
                              └─ 三城尽失 → **国战开启**（强制，长期）
```

| 规则 | 内容 |
| --- | --- |
| 触发 | **按年份写死**（`calendar`），不参加权重抽取，不看气运 |
| 预警 | 每次战事**必有前置预警**（1 年前），给玩家时间备药、备符、安排闭关 |
| 强制 | 城战与国战都是**强制事件**：上桌即封住常驻模块（`需求/20` §10.2） |
| 连锁 | 城战失败**不重掷**，直接推进到下一座城；这是"链"，不是"随机再来一次" |
| 可推迟 | 只有**预警**阶段可以花钱/人情推迟（例如提前送粮、请援军）；城战与国战不可推迟 |
| 可结束 | 国战有明确终点（打赢一场决战 / 丢三城 / 求和），**不做无限期消耗** |

**为什么写死而不是随机**：随机战事会变成"运气税"——运气差的人一辈子在打仗，运气好的人一辈子在闭关，两种人生都没意思。写死之后，**所有人都要在同一个年份做同一个决定**，差别只在"你那时候几品"。

## 4. 城战：从最北那一座开始

北国有三个方向可以打进来，所以**先打离边境最近的三座城**，一座一座往里推：

| 序 | 城 | 战略含义 | 丢了会怎样 |
| --- | --- | --- | --- |
| 1 | **北关** | 门户。守军最多，也最先被打 | 北境门户洞开，第二城进入战时状态 |
| 2 | **望北城** | 粮道与灵脉节点 | 北境灵脉总量 −20%，养灵者当年份额下降 |
| 3 | **长明城**（起点城） | 最后一道墙 | 三城尽失 → 国战 |

**每场城战是一次"主要事件"，不是一个战斗界面**：

```
城战 · 北关（耗时 4–6 月，强制）
  ├─ 守城      留在城里，按月消耗，胜负看城防 + 守方战力总和
  ├─ 出击      出城迎战，一次战斗结算（高风险，战功翻倍）
  ├─ 驰援      从别处赶去（耗时先扣路程），到得晚就看别人打完
  └─ 弃城      提前撤走（不掉命，扣名声与贡献，可能被追究）
```

- **参战资格**：破胎起步（军队门槛），但**四品以下只能当卒**——领队、守将、决策席位要四品（`MILESTONE`）。
- **不参战是允许的**：你可以弃城、可以躲、可以"那年正好闭死关"。但城市会丢，丢了之后**你所在的城可能就没了**（人口、坊市、席位一起没）。
- **城战不是必输**：城防 + 守方战力 + 援军，按 `需求/30` 的分级结算。守住一次，北境稳五年。

## 5. 国战：城战失败之后的那一场

```
触发：北境三城全部失守（或两城失守 + 一次决战失败）
规模：全国征召，主要事件池里 60% 以上是战事
持续：3–10 年（有明确终点，见 §3）
```

| 项 | 规则 |
| --- | --- |
| **征召** | 破胎以上**全部在册**，每年至少 6 个月在军中（强制事件"军令"，每年年初生成） |
| **战场** | 国战期间新增场景 `battle`：坊市、委托、求学**全部不可用**（城里在打仗） |
| **主线** | 国战有自己的主线链（5–8 步）：初战 → 相持 → 断粮 → 决战 / 求和 |
| **产出** | 战功是平时的 3 倍；但**死亡概率也翻倍**——这是"高回报"的唯一正当来源 |
| **未参战** | 逃役：贡献清零、身份降一档、通缉标记；被抓住按军法 |
| **结束** | 三种结局：**打赢**（北国退兵，北境重建 10 年）、**议和**（割地赔款，灵脉总量 −10%）、**亡国**（本局失败，进入"遗民"结局） |

**国战不是"更大的城战"**，它是**整局游戏的节奏断点**：一个 30 岁破胎的人，打完一场国战可能 40 岁；而这十年，他本可以用来磨朝元那道墙。**这就是取舍。**

## 6. 战斗概率：战事期间必须"高到不能忽视"

| 时期 | 战事类事件占比 | 说明 |
| --- | --- | --- |
| 平时 | 5–10% | 剿匪、护商、边衅，偶尔一次 |
| 城战期（单城） | **40%** | 该城及邻近城的池子被战事占满 |
| 国战期 | **60–70%** | 主要事件区几乎只剩战事与主线 |

**实现口径**（设计侧 `21` §4）：战事期给战事类事件加 `warWeightMul`（平时 1 / 城战 3 / 国战 6），**同时**把优先级提到 1–2。**只改权重不改优先级，战事照样会被日常事件挤掉**——两件事必须一起做。

---

## 7. 战功与贡献

**战功是"贡献"的一种，不是独立货币。** 所有出口都汇进同一个账：`merit`（贡献度）。

| 来源 | 记什么 | 典型量级 |
| --- | --- | --- |
| 守城成功 | `merit.war += 城防系数 × 参战月数` | 20–60 |
| 阵斩同阶 | `merit.war += 10 × 对方品` | 20–50 |
| 救人 / 护民 | `merit.war += 5–20` | 小 |
| 百艺交付 | `merit.craft += 件数 × 品阶` | 常年累加 |
| 供职考绩 | `merit.office += 年数 × 考绩档` | 每年 5–15 |

**贡献能换什么**（`data/merit.json` 配，不写死在代码里）：

| 兑换 | 代价 | 上限 |
| --- | --- | --- |
| 身份升一档 | 100–300 | 每档一次 |
| 席位（城池灵量份额） | 每年结算按贡献排序 | 席位总数固定 |
| 丹药 / 符箓配额 | 20–50 / 件 | 每年 3 件 |
| 免役（跳过一年军令） | 80 | 每年 1 次 |
| 延寿丹购买资格 | 500 | 一生 3 次 |

- **贡献会衰减**：每年 −10%（四舍五入），**不累计成"存款"**。理由是"三十年前救过城"不该换今天的一个席位。
- **贡献不能买境界**：任何兑换都不许直接加修为、加成功率（否则就是"氪金跳过瓶颈"，与 `需求/11` 的"丹药不能让墙消失"冲突）。

## 8. 与其它系统的接口

| 方向 | 内容 |
| --- | --- |
| 战事 → 事件 | 强制事件、封住常驻、占据主要事件池、推进主线链 |
| 战事 → 战斗 | 城战/国战是战斗的"容器"，一次城战内部可能打 1–3 场 |
| 战事 → 城池 | 城破 → 人口 −20~50%、灵脉 −20%、席位减少（`需求/20` §10.4） |
| 战事 → 修炼 | **不直接给修为**；只通过"占月"和"战后伤病"影响 |
| 修炼 → 战事 | 境界决定参战资格与职责；四品才能任事 |
| 贡献 → 身份 | 兑换身份、席位、配额（`需求/15`） |

## 9. 内容最低要求

| 类 | 数量 | 必须带 |
| --- | --- | --- |
| 预警事件 | 每场战事 1 个 | 提前 12 个月、可推迟的选项、明确的"来的是什么" |
| 城战事件 | 每城 3–5 个变体 | 守/击/援/弃 四个选项 + 各自的月数与判定 |
| 国战主线 | 5–8 步 | 每步一个强制事件 + 一个不可逆的世界变化 |
| 战功结算 | 1 套 | 参战月数 × 系数，不许手写数字 |
| 贡献兑换 | 5–8 条 | 每条写清上限与衰减 |

**文案底线**：战事里必须有"你在做什么"的具体动作（守垛口、押粮、抬伤员），不能只有"参战/不参战"两个按钮。
