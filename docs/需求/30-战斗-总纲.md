# 需求 · 30 战斗系统总纲

> 版本：r18
> 对应实现：`设计/30-战斗-结算.md`（数值表、术法 93 条、器物图鉴、极境公式全在那里）
> 这一份只讲"一场仗凭什么这么打"，不讲具体伤害数字。

---

## 1. 定位：战斗是修炼结果的展示

**战斗不产生修为。** 它把"你练成了什么"摊开给人看：

| 你练的 | 战斗里变成 |
| --- | --- |
| 锻体境界 | 血量、攻击力、防御力 |
| 炼气境界 | 法力（矛与盾） |
| 养灵境界 | 灵力（三重伤害）、精神 |
| 心性 | **神志值**（第三血条） |
| 术法熟练 | 招式与被动 |
| 百艺 | 器物、丹药、符箓、阵法、战兽 |

**反哺只有一条窄门**：战后伤病会碰人物心性（神魂震荡、心创）。除此之外，打赢不加修为、不加速度——想靠打架变强，路径是"战功 → 身份 → 灵量/资源 → 修炼加速"，绕一圈，不直连。

---

## 2. 三层结算，顺序不可颠倒

```text
第一层  手段层（规则，不掷骰）
         双方各是什么大境界 → 决定这一仗"是什么性质的战斗"
         ↓
第二层  压制档（规则，不掷骰）
         低阶方的品 → 全压制 / 可对抗 / 镜像
         → 决定这一仗"能不能打、怎么打"
         ↓
第三层  资源对拼（骰子在这里才出现）
         血 / 法力 / 灵力 / 精神 / 神志值 / 攻防 / 架势
```

**一句话**：战斗不是血条蓝条的交换，是"**手段层对不对得上**"的问题；对得上之后，才轮到血蓝条。

## 3. 四道手段：每个大境界的东西都不一样

| 阶 | 道 | 手段层 | 攻 | 防 |
| --- | --- | --- | --- | --- |
| 1 | 锻体 | 物理 | 肉身、兵刃 | 血量厚度、肉身扛 |
| 2 | 炼气 | 法力 | 外放术法（矛） | **法力盾**（盾） |
| 3 | 养灵 | 灵力 | 实体 + 精神双重伤害（更重精神） | **解析**（比炼气多一层盾） |
| 4 | 修心 | 道 | 直攻**神志值** | 只有道能防道 |

**四条硬口径**：

1. **法力既是矛也是盾。** 锻体打炼气打不穿盾——除非法力耗空，所以锻体对炼气的正确打法是**拖**。反过来炼气打品 1–3 的锻体，对方没有法力可挡，**直接吃真实伤害**。
2. **品 4 才开始"挡得住，但挡不干净"**：朝元能抵抗法力攻击，但每次仍会受伤，受伤多少与攻方境界成正比——"可对抗"不是安全区，是从"挨真实伤害"变成"放血"。
3. **灵力是混合力量，炼气只能硬抗**：实体 + 精神双重伤害，炼气对灵力没有任何克制手段，只有精神强的人能挡下几击；反过来养灵的**解析**让法力伤害微乎其微（×0.1）。
4. **修心没有术法**：修心境本身就是对自我的探究，可自创简易招式，直攻神志值。

**手段的解锁点**：

| 手段 | 解锁 |
| --- | --- |
| 法力（外放、盾） | 炼气·**破胎**（感气只是气机入体，放不出来，仍算凡人） |
| 灵力（攻击、解析） | 养灵·**启灵**（压制资格提前到开视） |
| 道（攻心） | 修心·**不惑**（修心第一品就是极境） |

**凡人三境（体魄 / 脏腑 / 感气）低一档**：没有压制资格，也没有防御性压制，碰上修行者只有挨打。**调息以上全部同级**——不存在"低阶不许与高阶交手"的硬墙，高阶的优势由手段层与资源上限自然体现。

## 4. 压制：规则，不是倍率

**判定分工**：**攻方只看大境界**（破胎与法相打朝元，规则上一模一样，区别只在强度）；**防（低阶）方只看小境界**。

| 低阶方品 | 档 | 效果 |
| --- | --- | --- |
| 品 1–3 | **全压制** | 攻方向：高阶手段是**真实伤害**，无减免直扣血；防方向：低阶攻击被完全挡死（肉身对盾 ×0，法力对解析 ×0.1） |
| 品 4 | **可对抗** | 能挡，但**挡不干净，每次仍受伤**，穿透与攻方强度成正比；战斗退化为拼血蓝条 |
| 品 5–6 | **镜像** | 把品 5 的人**视为与对手同境界**，双向规则压制取消，纯能力对拼 |

**三条推论**：

1. **跨阶差也镜像**：金身 vs 神游隔着整整一个炼气，金身照样不受规则压制——实际表现是会被一招秒，但那是**能力差距，不是规则**。
2. **压制取消 ≠ 能力拉平**：规则上平起平坐，手段上照样欠缺——锻体用不了法器和灵器（境界门槛卡死）。
3. **同大境界内无压制**：永远是属性对拼，品差通过战斗属性上限差自然体现，**不再用旧 D 倍率表**。

## 5. 两套资源，三条血条

**角色属性（规则层）与战斗属性（数值层）分开**：资质好不代表血厚，悟性好不代表法力多。唯一接口是**心性 1:1 → 神志值**。

| 战斗属性 | 来源 | 是不是血条 |
| --- | --- | --- |
| 血量 | 锻体境界 | **第一血条** |
| 精神 | 养灵境界（人人 30 底子） | **第二血条** |
| 神志值 | **自身心性 × 1**（进场复制） | **第三血条** |
| 法力 | 炼气境界 | 不是 |
| 灵力 | 养灵境界 | 不是 |
| 攻击力 / 防御力 | 锻体境界 | 不是 |

**任意一条血条归 0，直接死亡**，不看其他两条还剩多少。所以"越往上越难杀"不是血多，是**条数齐**：凡人三条都薄，炼气血量上去了但精神/神志还薄，养灵前两条厚了，修心三条全满。

**非死亡比斗有危险线**：任意一条 ≤10% 可叫停（认输、判负、对手收手）。生死斗没有这条线。

**神志值 ≠ 人物心性**：神志值归 0 当场死；人物心性归 0 不当场死，触发心魔（成活率 0 → 必死）。数值相同，性命不同。

## 6. 四种伤害与反制

| 伤害 | 来源 | 扣什么 | 谁能挡 | 谁能硬扛 |
| --- | --- | --- | --- | --- |
| **物理** | 锻体攻击、凡器、灵力术法的物理段 | 血量 | 防御力；**法力盾也吸**（1 法力挡 2 点） | 所有人 |
| **法术** | 炼气术法、法器、灵力术法的法术段 | 血量 | **法力盾**：纯法力全额挡；灵力法术段只挡一半（解析拆盾） | **防御力无效** |
| **精神** | 灵力术法的精神段、阴险术 | 精神 | **只有灵力对冲** | 只能拿精神池硬吃 |
| **道** | 修心招式 | **神志值** | **只有道** | 常境无解 |

- **灵力术法一发打三段**（物理 + 法术 + 精神），三段抵挡方式各不相同。
- **对冲 = 三段全免**：双方都放灵力术法，两发相撞全抵消，按灵力总量与术法品阶判胜者，**胜者吞掉并反打**。
- **没有灵力的人连对冲的资格都没有**——只有"挨"和"跑"。
- **道伤只扣神志值，不扣人物心性**。

## 7. 战斗分级与战后

| 分级 | 能不能走 | 后果 |
| --- | --- | --- |
| 切磋 / 斗法 | 随时可走 | 有危险线；**不掷伤病** |
| 生死斗 | 认输需代价 | 按战后血量比例掷伤病（完胜 20/5/0 · 惨胜 60/30/2 · 险胜 100/60/5） |
| 不死不休 | 不能走 | 同上，且必得神魂震荡 / 心创 / 断骨之一 |

**战后只回写四样**：生死、伤病、名声、物品。其中只有伤病碰人物心性——这是战斗影响修炼的唯一通道。

### 7.0 游戏里先落两种：切磋 / 死斗（r31）

> **用户口径**：「战斗分死斗和切磋，死斗死了就直接结束游戏了。」

| 分级 | 怎么叫停 | 会不会死 | 掷不掷伤病 |
| --- | --- | --- | --- |
| **切磋** `spar` | 任意一条血条掉到 **10% 危险线**即叫停，判负 | **不会**。血条见底也只是认输 | **不掷** |
| **死斗** `death` | 没有危险线，任一血条归 0 就是死 | **会**。玩家死 → `state.dead`，**这一世当场结束**，不能再做任何事 | 只在死斗里掷（输了才掷） |

- 「斗法 / 不死不休」两级**先不做**：等认输赔偿、遁走判定落地再加，现在只有这两级。
- 入口：`act.spar`（城中演武场，12 岁以上，1 月）、`act.combat`（军职，死斗）、6 处事件的 `judge`（劫匪 / 巡边 / 妖物 / 阵前斗将 / 城战 / 国战，默认死斗）。
- **城战与国战有年龄门**：16 岁以下不上城墙、18 岁以下不在征召册上——只剩「弃城而走 / 逃避征召」两条路。不然一个十四岁的孩子年年被赶上城墙，每一局都死在同一处。

### 7.0.2 法力是油，法力盾是甲（r32 更正）

> **用户口径**：「法力是用来释放法术的，法力盾是挡伤害的，法力盾可以由法器、防御术法一类的生成。你没修炼防御术法，咋个产生防御盾呢。」

- **法力**＝放法术的油：施法扣，每回合回一点。**大修士不会放两个法术就开始肉搏**——回气率 5%/回合、单发消耗 8%–13%，
  一场十来回合打下来，法修靠的是法术，不是拳头。
- **法力盾**＝挡伤害的一层：**只从法器与防御术法来**。以前把它和法力混成一个池子，等于"有法力就有盾"，
  锻体永远打不穿——现在没练防御术法、身上没法器，炼气修士就是光着血条。
- 盾会被打掉；打光了可以再"运功"结一次（`kind: guard` 的术法，一次一拍，放弃这一拍的出手）。
- 开打时先结盾：练过的人进场就是满盾。

### 7.0.3.1 拳头砸得开气墙（r34）

> **用户口径**：「拳头要能破防啊，你打炼气境界的对手，拳头连盾都破不了，还是得用术法，用术法又会回到之前说的那个问题，法术的阶级局限性。」

- **物理伤害穿透护盾 55%**：气墙（法力盾）挡得住法术，挡不住一记砸在脸上的拳。剩下一半直接进血条。
- **反向压制**：凡人三境打炼气，物理系数 **0.55**（法术只有 0.12–0.35）——"以力破法"是真的能打进去，只是慢。
- 于是低阶修士有三条路：拳头磨、术法换、符箓炸（§7.0.3.2）。不会再出现"两头堵"。

### 7.0.3.2 符箓：战前先炸一下（r34）

- 身上有 `kind: "符箓"` 的东西（如雷火符），**开打前自动甩一张**，先造成一次伤害（盾挡一半），然后进正常回合。
- 这是低阶修士打高阶对手的翻盘手：一张雷火符约 45 点，够把"打不动"变成"能磨"。
- 符从囊中扣，用光了就没有；打之前想清楚要不要带。

### 7.0.3.3 认输（r34）

- 死斗不认输（对方不放过你）；**切磋有认输线**：血量跌破 15%（`surrenderAt` 可覆盖）就收手，判负、不死、不掷伤病。
- 战报写「你看了一眼自己的血，收了手：「不打了。」」——输得体面，比被打死好。

### 7.0.4 品阶进伤害公式（r33）

> **用户口径**：「法术的威力也和法术的品阶、修炼进度相关……对上 2 阶 3 品的对手就没有效果了，或者威力减少 90%。你要把这个纳入伤害计算公式里去。」

伤害的乘法链（顺序不能乱）：

```
伤害 = 基数 × 骰子 × 手段层压制(suppressMul) × 品阶够不够得着(grade.reach) × 熟练系数
```

| 乘子 | 看什么 | 值 |
| --- | --- | --- |
| `suppressMul` | 大境界（攻方 rank vs 守方 rank/tier） | 1 / 0.6 / 0.45 / 0.35 / 0.1 |
| `grade.reach` | **术法阶品 vs 对手阶品**（`L = 阶 + 品`） | 够得着 1，差一级 **0.1** |
| 熟练系数 | 小成 0.85 / 大成 1.0 / 圆满 1.15 | |

- 术法的"阶品"= 手段层的阶 + （品阶 ± 熟练偏移）；拳脚**不吃**品阶这一项。
- 反应到战报上：打不动的时候写「品阶不够，只擦破一点皮」，别让玩家以为中了 bug。

### 7.0.5 死斗里的那一次转身就跑（r33）

- 死斗血条见底、本来要死的那一刻，**再掷一次逃跑**：`fleeBase 0.25 + 闪避×0.5`（上限 0.6）。
- 跑成了：`outcome = 'fled'`，`hp = 1`，**必带伤**（一年内修得慢），人还活着。
- 跑不成：照常死。
- 数据可以写 `flee: "never"`（不许跑，比如被困在城里）/ `"always"`（剧情必逃）。

### 7.0.3 闪避（r32 新增）

- 被打中**之前**先掷闪避，闪开了这一下**全部伤害归零**（灵力术法的三段也一样）。
- 渠道：人人 4% 基础 + 身法术法（御风步 +6%/档、游龙步 +10%/档）+ 器物（轻身靴 +5%）；上限 45%。
- **道伤不看闪避**：心念压过来，人躲不开。

### 7.0.1 打得让人看得懂（r31 界面口径）

- 战斗是**独立一屏**，**尺寸写死**（不随内容长高），中间战报自己滚；
- 上方**双方各一排血条**：血 / 法力 / 精神力 / 神志，随每一拍实时跳；
- 每一拍都要写清**谁、用什么招式、掉了什么**（「你欺身进招「罗汉拳」，山贼掉血 10（法力盾挡下 2）」）；
- 可以**自动播完**，也可以「跳过」直接看结果。

### 7.1 城战与国战（r23 新增）

战事不是"更大的斗法"，它是**有月份的容器**（`需求/21`）：

| 层级 | 打几场 | 耗时 | 谁能参加 |
| --- | --- | --- | --- |
| 剿匪 / 护商 | 1 场 | 1–2 月 | 破胎以上 |
| **城战** | 1–3 场（守垛口 → 巷战 → 突围） | 4–6 月 | 破胎当卒，四品任事 |
| **国战** | 3–8 场（分阶段，中间有相持与断粮） | 3–10 年 | 全国征召；逃役有罚 |

- **城战/国战的战斗本身仍按 §2 的三层结算**，不新开一套公式；
- 不同的是**容器**：打之前要行军（扣月）、打之后要收尸（扣月），中间可能一整个季度没有战斗，只是在守；
- **战功按参战月数 × 系数结算**（`21` §7），不是按杀敌数——否则"刷小兵"就变成最优解。

## 8. 极境（一句话，细节在设计）

**极境不是无敌，是一套没有特例的公式**：`伤害 = max(1, (攻 − 防) × 层次系数 × 修正)`，防御力照常参与减甲。层次系数：品 5 ×0.15 / 品 4 ×0.10 / 品 3 以下 ×0.05 / 极境对极境 ×1.0。

- **极境战只能一对一**，围攻彻底无效（层次差把同时到达的攻击折叠成一次）。
- **车轮战只磨血、不磨甲**，价值在"逼极境退场"，不在"杀死极境"。
- **能杀极境的三条路**：另一个极境 / 传承器 / 极境已伤。

## 9. 与其它系统的接口

| 接口 | 内容 |
| --- | --- |
| ← 修炼 | 战斗属性全部按境界查表；术法熟练决定招式；百艺提供器物丹药 |
| ← 事件 | 战斗是事件的一种"选项后果"（斗法、征剿、护城） |
| → 事件 | 战功 → 名声 → 身份事件（优先级 3）；战斗本身是一次事件选项的后果 |
| → 贡献 | 城战/国战产出 `merit.war`；只换身份·席位·配额，**不换修为**（`21` §6） |
| → 修炼 | **只有战后伤病**碰心性 |
| ← 气运 | 只偏置命中/闪避/暴走的骰子；**伤害数字不吃气运**（否则等于吃两遍） |

**气运只进一个口**：一次攻击只有一个气运入口——命中判定。让气运也影响伤害取整，等于高气运的人既容易命中又每次都往上取整。
