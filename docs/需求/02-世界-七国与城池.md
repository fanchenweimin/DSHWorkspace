## 1. 地理：七国、两妖域

### 1.1 大陆格局（r25 改）

大陆是一块被**断天山脉**顶在中间的高原。山脉里住着妖族，七国绕着它排成一圈，国与国之间只有**一条分割线**。

```text
                    玄 朔（北）
              ╱                     ╲
      凉野 ┌─────────────────────┐  大曜
   （西北）│    断 天 山 脉        │（东 · 本作）
      云梁 └─────────────────────┘  苍梧
   （西）        昭武（南）  朱离（南）
```

| 方位 | 国 | 一句话 |
| --- | --- | --- |
| **东（本作）** | **大曜** | 长明城为都，北关南关守两端，底子是"国办学" |
| 北 | 玄朔 | 雪不化，人说话带白气也带刀 |
| 西北 | 凉野 | 风把沙子吹成墙，商队走一趟留下半条命 |
| 西 | 云梁 | 书院比城墙高，松脂与铜锈一个味道 |
| 南 | 朱离 | 稻子一年两熟，雨水淹得死人，也富得养人 |
| 西南 | 昭武 | 铁匠铺的火不熄，孩子先学打铁再学拿剑 |
| 东南 | 苍梧 | 水网密得像掌纹，船家不认路只认水色 |

- **中间是妖域**：断天山脉，跨不过去、也守不住。妖族不是主线敌人，它是**资源与风险**（秘境、山猎）。
- 因此主要冲突仍然是**人与人**：国与国（边境、灵脉、商路）、城与城（水源、灵田、人口）、人与人（夺宝、争道、私仇）。
- 七国之间**不画色块堆叠**，只画**一条分割线**——地图要一眼看出"这是一整块大陆被切成七份"，不是七块拼图。

### 1.2 人类与妖兽

- 这个时代**人类是强势方**，妖族被赶进中间的高原与海外的岛。
- **主要冲突不是人妖，而是人与人**：
  1. 国与国（边境、灵脉、商路）
  2. 城与城（同国之内，争水源、灵田、人口）
  3. 人与人（夺宝、争道、私仇）
- 妖族只在「秘境、山猎」这类事件里出现，是资源与风险，不是主线敌人。

### 1.3 地图（写代码时绘制）

首页就是地图，**明亮、大字号**，与游戏整体视觉一致（浅底、墨线、淡彩）：

- 一整块大陆轮廓 + **断天山脉**（中部高原，山纹 + "妖族之地"标注）
- 七国由**七条分割线**从山脉边缘拉到海岸线，一个国一个扇区
- 大曜在**东侧正中**，高亮（描边 + 淡金底），内部标 4 座城：
  **长明城**（都城 / 起点）、**北关**、**南关**（两端关隘）、**望北城**（重镇，北关与长明之间）
- 其余六国只标都城点与国名
- hover 显示：国名 / 主城 / 特产 / 当前威胁
- 地图不参与玩法计算，纯展示；但事件里可以引用地名，保持一致
- **首页不做顶部菜单栏**：地图是主体，右下或中央只有一个「开始游戏」（以及不显眼的登录入口）

> r25 之前的口径是"大曜在大陆西侧、西横贯山脉、东沧海"，那是旧图。**以本节为准。**

## 2. 国家为什么办修炼

大曜以国办学，用意有四个层次，从浅到深：

| 层次 | 目的 |
| --- | --- |
| 对百姓 | **多一分活命的本事**。锻体境能自保，不至于被邪修抓去炼丹 |
| 对朝廷 | **提升国家认同**。修炼资源由国家发放，学成者为国所用 |
| 对国家 | **搜罗真正的天才**。七岁入蒙学起就在筛选 |
| 对统治 | **保持国家力量 > 混乱力量**。心性好的培养成城主，可用的当将军，**不好的切断养灵知识** |

最后一条是关键设计：**国家会把「养灵是什么、怎么修」的知识对不合格者封锁**。所以野路子修士大多停在炼气，进不了养灵——这解释了为什么「散修难以成长」。

## 3. 学制（已修正）

| 阶段 | 年龄 | 年限 | 内容 |
| --- | --- | --- | --- |
| 蒙学 | 7 岁 | 4 年（7–10） | 识字、锻体根基、通用凡品功法 |
| 府学 | 11 岁 | 4 年（11–14） | 引气、选百艺、准备大考 |
| 大考 | **15 岁** | — | 一生一次 |
| 太学 | **16 岁** | 4 年（16–19） | 养灵知识、权力机构历练 |
| 卒业 | 20 岁 | — | 有培养价值者进入城池权力机构；否则自力更生 |

> 府学（11–14）「选百艺」这一步，选什么、能走多远、赚多少钱，见 [修真百艺](13-修炼-百艺.md)。**这是全作唯一能打破家世的路径**：丹道天才在府学三年可攒 1.5 金，刚好买下破胎用的第一件悟性宝物。

> ✅ **已定**：15 岁放榜、16 岁入学，中间空一年作为"等待与准备"（与 `15-修炼-身份教育与人口.md` §1 一致）。

### 3.1 毕业去向

```text
太学卒业
  ├─ 有培养价值 + 心性优良 → 进城池权力机构历练 → 争取城主
  ├─ 有培养价值 + 心性一般 → 军中任职 → 将军路线
  └─ 无培养价值 / 心性不良 → 不再培养，切断养灵知识，自力更生
```

这条直接对应游戏里的 `心性` 与 `记功` 两个隐藏/半隐藏数值。

## 4. 城池、军队、宗门：养灵的社会学

### 4.1 养灵的「灵」= 生灵

**养灵境界修的是生灵。你治下/身边的生灵越多，修炼越容易。**

由此推出整个社会结构：

| 位置 | 生灵规模 | 修炼效率 | 谁来做 |
| --- | --- | --- | --- |
| **城主** | 一城，百万人口 | 最优 | 国家选拔，心性优良，为国为民 |
| **将军** | 统兵万人 | 次优 | 抢不到城，或心性不足者 |
| **宗门宗主** | 门人数千 | 再次 | 去「乱灵域」自建宗门 |
| **散修** | 无 | 极差 | 破不了瓶颈、被国家放弃者 |

> 「乱灵域」：没有城、没有国家管制的区域，宗门林立，弱肉强食。

### 4.2 为什么军队和宗门都是炼气·破胎起步

> **两道门槛要分清**：**破胎 = 能当兵**（`qi.level ≥ 2`），**四品 = 能任事**（`MILESTONE`，见 `11` §2.3）。军队招人看前者，领兵、守将、宗门执事看后者。中间差着整整两品——这两品的差距就是"当卒"与"当家"的区别。

因为**炼气·破胎的增幅比锻体·朝元还大**。

```text
锻体·朝元（1 阶 4 品）→ 肉身大成，但仍是「人」
炼气·破胎（2 阶 2 品）→ 能外放法力，进入「修士」
```

破胎之后，战斗力是质变，不是量变。所以：

- 军队、宗门的**入门门槛就是炼气·破胎**。
- 锻体境、炼气·感气的人**没有资格参军或入宗门**，只能依附城池生活。

### 4.3 依附城池的底层逻辑

```text
普通炼气破不了瓶颈 → 走邪路
  → 杀人炼丹（人是生灵，可聚法力助破境）
  → 首选猎物：锻体境散修（无靠山、好下手）
  → 所以锻体境必须依附城池（城中有仙司、有阵法、有强者）
```

这是「城池」在玩法上的意义：**不是背景板，是保命设施**。

- 在城内：安全，但要交税、受管制、被抽丁
- 在城外：自由，但随时可能被邪修盯上

### 4.4 邪法：杀人炼丹

炼气境界可以通过灌顶破境，那么**必然存在更邪恶的替代品**：

| 方式 | 效果 | 代价 |
| --- | --- | --- |
| 正统灌顶 | 成功率减半 | 钱、人情、心性 −6、永失世界认可 |
| **杀人炼丹** | 成功率提升（人=生灵=法力） | 心性大幅下降、被仙司通缉、可能入魔 |
| 养灵者杀人 | **不划算**——活人价值更高（可提供持续的生灵） | 所以养灵反而少杀 |

这条给玩法提供了**邪恶路线**：快速破境，但被通缉、被追杀、心性崩坏。
