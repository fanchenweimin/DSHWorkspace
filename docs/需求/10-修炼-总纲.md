# 需求 · 10 修炼系统总纲

> 版本：r18
> 上层：`00-总纲-三系统与气运.md`｜子系统：`11-境界` / `12-法术` / `13-百艺`
> 补充说明：`14-经济与资源`（钱与物）、`15-身份教育与人口`（学籍、席位、灵量）

---

## 1. 一句话

**修炼 = 修炼基数 × 修炼时间 × 乘区；修为满了还要过瓶颈。**
三个子系统（境界、法术、百艺）用的是**同一条式子、同一份月数**，所以"练什么"永远是取舍，不是叠加。

---

## 2. 修为公式

```text
月修为 = 修炼基数 × 0.20 × 乘区
年修为 = 修炼基数 × 2.4   × 乘区
修为   = Σ（每月月修为）        ← 小数保留，年末按气运决定是否进位
```

### 2.1 修炼基数（加权和）

```text
基数 = 0.70 × 属性 + 0.20 × 功法值 + 0.10 × 境界值
```

| 项 | 锻体 | 炼气 | 养灵 | 修心 |
| --- | --- | --- | --- | --- |
| **属性** | 资质 | 悟性 | (资质 + 悟性) / 2 | 心性 |
| **功法值** | 功法品阶查表（黄中 38 / 黄上 46 / 玄 54 / 地 58 / 天 60） | 同左 | **势力档次**（小宗 38 / 大宗 46 / 圣地 54） | 无（心关不带功法） |
| **境界值** | `30 + 10 × 品` | 同左 | 同左 | 无 |

**为什么是加权和而不是"属性 × 系数"**：如果属性独占，功法与境界就没有位置——一个天阶功法的圣地和一个小宗门弟子会练得一样快。加权和让"投胎"与"投师"都算数，且三项的比例可以单独调（0.70 / 0.20 / 0.10 是本轮取值）。

### 2.2 乘区（只有两个）

| 道 | 乘区 | 上限 |
| --- | --- | --- |
| 锻体 | 资源：药浴、丹药、宝地、师承 | 建议合计 ≤ ×2.0 |
| 炼气 | 资源：悟性宝物、师承（**丹药完全无效**） | 建议合计 ≤ ×2.0 |
| 养灵 | **灵量系数**（唯一乘区） | 0.2 – 6.0 |
| 修心 | **没有乘区** | — |

**修心没有乘区，也没有月修为**：道心只由心关事件推进（见 `11` §6）。这是"修心不能靠熬时间"的机制实现。

### 2.3 灵量系数（养灵专有）

```text
灵量基数：凡人 1 / 修士 10 / 其他生灵 1（开智的按修士 10）
城池灵脉 = Σ 治下所有生灵的灵量基数
个人灵量 = 分到的那一份（零和，分出去就是减法）
灵量系数 = clamp(2 × 个人灵量 / 城池灵脉, 0.2, 6)
```

| 情形 | 份额 | 系数 | 说明 |
| --- | --- | --- | --- |
| 城主独占百万人口城 | 100% | **2.0** | 基准 |
| 分出 10% 给别的养灵者 | 90% | **1.8** | 慢 10% |
| 对半分 | 50% | 1.0 | |
| 散修（一城 1.2 万人） | 1.2% | 0.2（钳） | 养灵几乎练不动 |

- **零和**：`自己的 + 分出去的 ≤ 城池灵脉`，一个生灵只能供一个养灵境界。
- **只作用于养灵**，锻体/炼气/修心的任何数值都不吃灵量。
- **用份额而不是绝对值**：份额 ×2 就是系数，所以"分 10% 慢 10%"永远成立，不管这座城是 10 万人还是 300 万人。

## 3. 三个子系统

### 3.1 境界修炼（主线）

| 项 | 内容 |
| --- | --- |
| 攒什么 | 每品一条修为条：**内力 / 法力 / 灵力 / 道心** |
| 时间 | 一生主投入；一年 12 个月 |
| 结果 | 境界、寿元、战斗属性（血/攻/防/法力/灵力/精神） |
| 卡点 | **瓶颈**（概率瓶颈 / 事件瓶颈），见 `11` |

### 3.2 法术修炼（战力）

| 项 | 内容 |
| --- | --- |
| 攒什么 | 每本术法独立的**熟练度 0–100**（入门 40 / 大成 80 / 圆满 100） |
| 时间 | 与修为**抢同一份月数** |
| 结果 | 战斗招式（威力、被动加成） |
| 卡点 | 阶位门槛（黄下→天阶，六档）、相性（错配 ×0.5）、获取渠道 |

见 `12-修炼-法术.md`。

### 3.3 百艺修炼（钱与辅修）

| 项 | 内容 |
| --- | --- |
| 攒什么 | 技艺积累（1→2 累计 600，2→3 累计 1,800） |
| 时间 | 少年期投入为主，成年后靠"做工月"换钱 |
| 结果 | 钱、辅助修炼（丹药/符箓/阵法）、战斗手段（毒/器/傀）、治病 |
| 卡点 | 天赋（无 / 有 / 卓绝）决定上限，**练不出来** |

见 `13-修炼-百艺.md`。

### 3.4 三者抢同一份时间

```text
一年 12 个月 = 境界修炼 + 法术熟练 + 百艺积累 + 行动（游历/为官/办事）

例：资质 60 的锻体 3 品，年修为 132
    若一年拿出 4 个月练一本黄上术法（月熟练 7.5）→ 修为只有 8 个月的量
    → 破境晚 4 个月，术法圆满早 5.3 个月
```

**这就是全部平衡机制**：没有"术法会拖慢修炼"的惩罚规则，时间本身就是惩罚。

## 4. 自我循环（修炼不能只靠挂机）

```text
        ┌──────────── 修为 ────────────┐
        ↓                               │
     境界 → 寿元 / 战力 / 身份            │
        ↓              ↓                │
     灵量           钱 / 势力            │
        ↓              ↓                │
        └──── 资源（丹药·宝物·功法）──────┘
```

| 环节 | 谁提供 | 断了会怎样 |
| --- | --- | --- |
| **钱** | 百艺、委托、俸禄、战利品（`14`） | 买不起药浴与悟性宝物 → 卡在概率瓶颈 → 只能靠年份硬磨 |
| **身份** | 太学卒业、战功、心性（`15`） | 拿不到玄阶术法、分不到灵量 |
| **灵量** | 城池人口与席位（`15`） | 养灵唯一的乘区消失，直接停摆 |
| **寿元** | 境界 + 延寿丹（`11` §9） | 时间不够，术法与境界只能二选一 |

**四条缺一条，修炼就退化成"点下一步等年份"**——所以经济、身份、灵量不是配菜，是修炼系统的四个输入。

### 4.1 三条出口：修炼必须有"用出去"的地方

上面的循环讲的是"怎么变强"，这一节讲**"变强之后干什么"**。只有投入没有产出，结局一定是所有人闭关到死。

| 出口 | 产出 | 换回什么 | 详见 |
| --- | --- | --- | --- |
| **战功** | 守城、出征、救人 | 贡献 → 身份 / 席位 / 丹药配额 | `21` |
| **百艺** | 丹药、器物、符箓、阵法、治病 | 钱 → 药 → 破境率 | `13` |
| **供职** | 戍守、差役、朝会、教习 | 俸禄、名额、灵量份额 | `15` |

**三条出口都不直接给修为**（战斗不反哺修炼）：它们绕一圈——**贡献 → 身份 → 灵量与资源 → 修炼加速**。这一圈必须让玩家看见。

**反向的约束同样重要**：身份带**年度义务**（`20` §6.1），每年要拿出几个月服役；不履行就扣贡献、降身份。**拿了身份不出力，比不拿身份更亏。**

> 这一节的存在，是为了让"闭关三十年"成为**一种选择**，而不是**唯一解**。

## 5. 与其它系统的接口

| 接口 | 方向 | 内容 |
| --- | --- | --- |
| 修炼 → 事件 | 出 | 修为满 / 层级够 → 允许瓶颈事件入池（优先级 2） |
| 事件 → 修炼 | 入 | 求学（常驻动作）、瓶颈放行、资源获取、身份变更、**月份占用** |
| 修炼 → 战斗 | 出 | 战斗属性按境界查表；术法熟练决定招式 |
| 战斗 → 修炼 | 入 | **只有一条**：战后伤病碰人物心性（神魂震荡 / 心创） |
| 气运 → 修炼 | 入 | 判定偏置、年末进位方向 |
| 灵量 → 修炼 | 入 | 只进养灵的乘区 |

> **战斗不直接给修为。** 想靠打架变强，路径是：战功 → 身份 → 灵量/资源 → 修炼加速。绕一圈，但每一环都能被玩家看见。

## 6. 本轮修正（相对 r17）

| 项 | r17 | r18 | 为什么 |
| --- | --- | --- | --- |
| 修炼逻辑 | 分散在属性/境界两份文档 | **收成一条式子**，三个子系统共用 | 本轮总纲要求 |
| 灵量 | 绝对量（50 万 = 系数 1.0） | **基数制 + 份额**（凡人 1 / 修士 10 / 其他 1） | 简化：只需两个数 + 一个其他生灵基数 |
| 灵量系数 | `灵量 / 500,000` | `2 × 份额` | 与"分 10% 慢 10%"完全等价，且不依赖城的大小 |
| 气运入口 | 只有判定修正 | **判定 + 进位 + 事件倾向** | 气运要管"随机数与四舍五入" |
| 时间 | 未明写"共用月数" | **写死：三子系统抢同一份 12 个月** | 这是唯一的平衡机制 |
