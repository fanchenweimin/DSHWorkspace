## 1. 三个主系统，一个穿层属性

```
                    ┌───────────────── 气运 ─────────────────┐
                    │  改随机数的偏置 · 改年末取整的方向 · 改事件倾向  │
                    └───────┬───────────────┬──────────────┬──────┘
                            ↓               ↓              ↓
                    ┌───────────┐   ┌───────────┐   ┌───────────┐
                    │  修炼系统  │←──│  事件系统  │──→│  战斗系统  │
                    │  数值主体  │   │  进程主体  │   │  结果展示  │
                    └───────────┘   └───────────┘   └───────────┘
```

| 系统 | 一句话职责 | 产出 | 读谁 |
| --- | --- | --- | --- |
| **修炼系统** | 一条式子：**修炼基数 × 修炼时间 = 修为**，外加**瓶颈** | 修为条、层级、属性成长 | 属性、功法、灵量 |
| **事件系统** | 游戏的**主进程**，为修炼系统服务 | 瓶颈事件、常驻动作、资源、身份、灾祸 | 修为状态、优先级 |
| **战斗系统** | 修炼系统的**直观结果展示** | 生死、伤、名声、战利品 | 境界、术法、百艺、心性 |
| **气运** | 不属任何系统，**穿三层** | 随机数偏置、取整方向、事件倾向 | 无 |

**三条关系不能反**：

1. **事件系统是驱动，不是装饰。** 修炼只负责"攒数值"，能不能过那道坎由事件系统决定（事件瓶颈）；求学的加成、突破的资源、身份的门票，全从事件里来。
2. **战斗系统不反哺修炼数值。** 打赢不加修为、不加速度。战斗只产出四样东西：**生死、伤病、名声、东西**——名声换身份，身份换灵量与资源，这才是战斗回到修炼的路径（绕了一圈，不是直连）。
3. **气运只做偏置，不做乘区。** 它改骰子的落点、改小数进位、改抽事件的倾向，但**绝不进任何一条境界公式的乘法**。

## 2. 修炼系统：一条式子，三个子系统

### 2.1 统一逻辑

```text
修为 = 修炼基数 × 修炼时间 × 乘区
     （月修为 = 基数 × 0.20；年修为 = 基数 × 2.4）

瓶颈 = 修为满了之后，那道过不去的坎
     （锻体 1–4 / 炼气 1–3 是概率瓶颈，其余是事件瓶颈，见 11）
```

- **四条独立路线**：锻体（内力）/ 炼气（法力）/ 养灵（灵力）/ 修心（道心），**各修各的条，互不相通**。每个月的修炼要指定投给哪一道；"螺旋上升"是前人摸索出的顺序，不是规则（`11` §2.1–§2.2）。
- **修炼基数**：`0.70 × 属性 + 0.20 × 功法值 + 0.10 × 境界值`（加权和，每道属性不同）。
- **修炼时间**：以"月"为最小单位，一年 12 个月。**时间是最硬的资源**——境界、术法、百艺抢的是同一份月数。
- **乘区**：只有两个，锻体/炼气的**资源**（丹药/药浴/宝物/师承）与养灵的**灵量系数**。修心没有乘区。

### 2.2 三个子系统

| 子系统 | 攒什么 | 基数吃什么 | 时间怎么花 | 产出 |
| --- | --- | --- | --- | --- |
| **境界修炼** | 修为条（内力/法力/灵力/道心） | 资质 / 悟性 / (资质+悟性)/2 / 心性 | 主投入，一个人一生的主线 | 境界、寿元、战斗属性 |
| **法术修炼** | 术法熟练度（0–100） | **同一份修炼基数** ÷ 阶位系数 × 相性 | 每本书单独磨，**与修为抢月数** | 战斗手段 |
| **百艺修炼** | 技艺积累（600 / 1,800） | 资质×资质权重 + 悟性×悟性权重 + 0.2×功法值 | 少年期投入，成年后换钱 | 钱、辅助修炼、战斗手段、治病 |

**三者共用一套基数、共用一份时间**：这是"修炼要有取舍"的唯一机制。一个把十五本术法练圆满的人，境界必然落在后面——不需要额外惩罚，时间本身就是惩罚。

### 2.3 修炼要能自我循环

```text
修为 → 境界 → 寿元 / 战力 / 身份
  ↑                        ↓
  └── 资源（丹药·宝物·功法·灵量） ←── 钱 / 身份 / 势力
```

**闭环的四个环节**（缺一个，修炼就变成"挂机等年份"）：

| 环节 | 谁提供 | 断了会怎样 |
| --- | --- | --- |
| 钱 | 百艺、委托、俸禄、战利品 | 买不起药浴与悟性宝物，卡在概率瓶颈 |
| 身份 | 太学卒业、战功、心性 | 拿不到玄阶术法、分不到灵量、养灵练不动 |
| 灵量 | 城池人口、席位分配 | 养灵完全停摆（这是养灵唯一的乘区） |
| 寿元 | 境界、延寿丹 | 时间不够，术法与境界二选一 |

## 3. 气运：唯一穿三层的属性

| 入口 | 作用方式 | 上限 |
| --- | --- | --- |
| **随机数** | 一切判定的掷骰值加偏置 `(气运 − 50) × 0.001` | ±5% |
| **四舍五入** | 年末把修为小数进位时，进位概率 `0.5 + (气运 − 50) × 0.001` | ±5% |
| **事件倾向** | 高气运偏"机缘"，低气运偏"灾祸" | 只改权重，不改池子 |

- **三个入口加起来就是气运的全部**。它不改资质、不改功法、不进乘区（不变量 5）。
- **为什么连四舍五入都要管**：修为是绝对量、要按年累加，小数位年年舍弃就是"慢性扣修为"；让气运决定进位方向，等于让"运气好的人"每年多捡回零点几个点——一年看不出来，三百年就是几十年。
- **漂移**：每年向 50 回归 ±1，事件可以一次性 ±5–15。

## 4. 事件系统：为修炼服务的四件事

| 服务 | 具体形态 | 优先级 |
| --- | --- | --- |
| **开门** | 22 个瓶颈事件（法相、养灵六门、修心四关、品 5/6） | **2** |
| **加码** | 求学（改常驻动作：3 月 / 成功基数 +0.03 / 按学籍封顶） | 常驻模块 |
| **给资源** | 丹药、宝物、功法、师承、秘境 | 3–5 |
| **改身份** | 大考、卒入、任职、婚配、战争 | 1–3 |

### 4.1 界面只有两个模块

| 模块 | 是什么 | 从哪来 |
| --- | --- | --- |
| **主要事件** | 会"找上门"的事，最多 1 强制 + 2 可选 | 事件池筛选（时间窗 → 前置 → 资格 → 出现概率 → 优先级批次） |
| **常驻事件** | 永远在的动作：修炼（境界/术法/百艺）、坊市、委托、求学、摆烂 | 固定清单，按场景解锁 |

**优先级是顺序，不是概率**：数值越小越先被看见；取最小的一批，批里有强制事件就返回强制事件，否则批内按**出现概率（权重）归一化**抽一条。**破境事件必须是优先级 2**——修为满了、层级够了，那一年就该出那道门，不能跟"坊市买药"抢骰子。

**是否强制管"能不能推后"，出现概率（1–10 档）管"这条有多容易被抽中"**——它**不是必出概率**：五条权重 1/2/3/4/5，第一条中签率只有 1/15。**所以不想错过的事，就设成强制事件。**

### 4.2 时间：一年 12 个月

- **月是唯一货币**，任何动作都标价多少月；年末剩余作废，不结转。
- **修炼、突破、求学都是动作**，不再由年度链自动结算——**它们的代价就是"少做别的"**。
- **主要事件可以跨多年**：耗时写多少月就是多少月（立相 12 月、闭死关 36 月），本年装不下就挂起，次年继续扣，期间不能换动作。
- **常驻事件不超过 1 年**：默认最多把当年剩余月用完，不跨年。唯一例外是**修炼**——寿元够长之后，才允许一次投入多年（否则点到手酸）。

### 4.3 年度顺序

```
年初（自动，顺序写死）：寿元 → 气运 → 心性 → 心魔 → 城池层 → 事件掷骰
月内（玩家驱动）：每月一件事，扣它的月
年末（自动）：错过结算 → 月份清零 → 额度复位 → 跨年动作推进
```

- **角色层**：寿元 → 气运 → 心性 → 心魔。这条顺序不能换（先衰减再掷心魔）。
- **城池层**：人口回归 → 灾害修正 → 灵脉重算 → 席位 → 灵量分配。它不参与角色判定，但**必须在事件掷骰之前**——今年的人口决定今年的灵量，今年的灵量决定今年养灵者练多快。

## 5. 战斗系统：只做展示，不做反哺

| 战斗读什么 | 从哪来 |
| --- | --- |
| 血量 / 攻击 / 防御 | 锻体境界（按品查表） |
| 法力 | 炼气境界 |
| 灵力 / 精神 | 养灵境界 |
| **神志值** | **人物心性 × 1**（唯一接口） |
| 手段层 | 大境界（物理 / 法力 / 灵力 / 道） |
| 招式 | 术法熟练度 + 百艺 |

- **角色属性不进战斗面板**：资质、悟性不换算成任何战斗数值，唯一接口是心性 1:1 → 神志值（不变量 1）。
- **结算三层不可颠倒**：手段层（规则）→ 压制档（规则）→ 资源对拼（骰子）。
- **战后只回写四样**：生死、伤病、名声、物品。其中**只有伤病会碰人物心性**（神魂震荡、心创），这也是"战斗能反过来影响修炼"的唯一一条窄门。

## 6. 术语（唯一口径）

| 词 | 含义 | 易错点 |
| --- | --- | --- |
| **阶** | 大境界序号（1–4） | 不是"等级" |
| **品** | 小境界序号（1–6，修心 1–4） | |
| **层级** | 每道一条轨，第几层 = 这一品你"通了" | 层级是破境的资格，品是你站的地方 |
| **修为条** | 每品一条独立进度条 | **内力 / 法力 / 灵力 / 道心** |
| **路线** | 锻体 / 炼气 / 养灵 / 修心，四条**互相独立**的道 | 独立是机制，不是"只能练一条" |
| **螺旋** | 前人摸索出的修炼顺序（体魄→脏腑→感气→…） | 是**经验**，不是规则强制 |
| **成就线** | **第四品**（朝元/法相/神游/从心而欲） | 前三品不算有成就；身份与养灵门槛都看这一格 |
| **带动** | 修高阶时，低阶同品号**涨一点修为**、并**被拆掉墙** | 不给层级、不给免费破境 |
| **战事** | 日历驱动的强制大事（城战 → 国战） | 不掷骰、不看气运，到点必来 |
| **圆满** | **该小境界的修为条已修满** | 是一个状态，不是层级、不是新境界 |
| **瓶颈** | 修为满了却过不去的那道坎 | **旧的"门槛"一词作废**，境界层统一叫瓶颈 |
| **出现率** | 修为满时"这道墙会不会挡在你面前" | **越高越难**；等于 1 是必撞，等于 0 是没墙 |
| **成功基数** | 墙出现后"这道门有多宽" | 与属性成正比；**越高越容易** |
| **概率瓶颈** | 每年可试一次、可无限试、第一次必败 | 锻体 1–4、炼气 1–3 |
| **事件瓶颈** | 必须等一个事件；事件不来，基数再高也没用 | 品 5 / 品 6 / 法相 / 养灵六门 / 修心四关 |
| **灵脉** | 城池的灵总量 = 治下所有生灵的灵量之和 | 城的账 |
| **灵量** | 一个人分到的那一份，**零和** | 人的账；不是修为条 |
| **气运** | 0–100，只做加法偏置 | 不改资质、不进乘区 |
| **命格** | 出生时定下的"天生是什么人" | 与气运是两件事 |
| **出现概率** | 1–10 档，**是批内权重，不是概率** | 五条权重 1/2/3/4/5 时，第一条中签率是 1/15 |
| **强制事件** | 上桌后不能推后，且**封住常驻模块** | 不想让一件事错过，就把它设成强制 |
| **求学事件** | 蒙/府/太开放的事件，提高概率瓶颈的成功基数 | 不是静态加成 |

> **"门槛"这个词只保留在两处**：术法的"入门门槛"（阶位要求）、物品的"使用门槛"（境界要求）。境界的那道坎，一律叫**瓶颈**。

## 7. 三条硬边界（改任何文档前先看）

1. **角色属性不进战斗面板**，唯一接口是心性 1:1 → 神志值。
2. **灵量只作用于养灵**，且是零和：分出去就是减法。
3. **本性与心性零耦合**：本性是"你天生是什么人"，心性是"你被磨成什么人"。
