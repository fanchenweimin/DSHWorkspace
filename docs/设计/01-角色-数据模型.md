# 设计 · 01 角色数据模型

> 系统：**0x 全局**（角色状态是三个系统共用的底座）
> 需求侧：`需求/01` §2–§6、`需求/11` §1–§2、`需求/15` §1–§2、`需求/10` §2
> 原则：**字段只在 `schema.js` 声明一次**；派生值不许存。
> **r22 新增三处**：`path.*.wall`（墙只掷一次，必须入档）、`gateAge`（首次达成年龄）、`mods`（修饰器，永久/临时同一套，见 `设计/03`）。
> **读属性的唯一姿势是 `resolve('attr.aptitude.eff')`**，基础值 `attr.aptitude` 只允许"永久改造"（洗髓/药浴/成长）写。

## 1. 新的单局状态（v5）

```js
{
  version: 5,
  seed, rev, turn,

  age: 7,
  lifespan: { base: 72, roll: 0, extra: 0 },   // 寿元 = base + roll + extra
  alive: true,

  // 先天
  luck: 55,              // 气运（0–100）。r17：luck 就是气运
  fate: 'fanren',        // 命格 key（r17：fate 还给命格）
  talents: [],           // 天赋 key[]
  origin: [],            // 出身三段

  // 四属性（基础值 + 上限）
  attr: {
    aptitude: 55, insight: 55, heart: 70,
    caps: { aptitude: 78, insight: 78, heart: 100 }
  },

  // 四道：一条轨 + 一条条子 + 失败累积
  // bar 名字：内力 / 法力 / 灵力 / 道心
  path: {
    body:   { level: 0, bar: 0, fail: 0, attempts: 0, wall: {} },  // 锻体·内力
    qi:     { level: 0, bar: 0, fail: 0, attempts: 0, wall: {} },  // 炼气·法力
    spirit: { level: 0, bar: 0, fail: 0, attempts: 0, wall: {} },  // 养灵·灵力
    heart:  { level: 0, bar: 0, fail: 0, attempts: 0, wall: {} }   // 修心·道心（累计制）
  },

  // wall 以**品号**为键：{ '1': false, '2': true } —— 本品的墙只掷一次（11 §4.1）
  // 值：未出现键 = 未掷；false = 无墙；true = 墙在。**必须入档**，否则读档能刷墙

  // r22：首次达成某境界的年龄，只写不改（人口统计 / 事件门槛 / 太学判定）
  gateAge: { },        // { body1: 7, body2: 10, qi1: 12, qi2: 17, ... }

  // r22：修饰器（永久/临时同一套，见 设计/03 §3）
  mods: [
    // { id, target:'attr.aptitude.eff', op:'add', value:3,
    //   duration:{kind:'permanent'}, source:'item.xisui', stack:'unique', tags:[] }
  ],
  activePath: 'body',
  breakthroughUsedThisYear: false,      // I9：全局一年一次

  // 求学加成：按道、按品累积，破境成功清零（设计 03 §6）
  study: {
    body: { 1: 0, 2: 0, 3: 0, 4: 0 },
    qi:   { 1: 0, 2: 0, 3: 0, 4: 0 }
  },

  education: {
    stage: 'mengxue',        // mengxue | fuxue | gap | tai | graduate
    stageStartAge: 7,
    examScore: null,
    admission: null,         // direct | special | null
    graduated: false,        // 太学 4 年读完 → true
    spiritKnown: false,      // 知情，不等于解锁
    craft: null
  },

  identity: {
    base: 'citizen',
    org: null,
    title: null,
    seat: null,              // 席位（养灵 100 席）
    subjects: { mortal: 0, body: 0, qi: 0, spirit: 0, other: 0 }   // 按最高档分桶
    // mortal 含体魄/脏腑/感气；body = 锻体·调息以上；other = 未开智的生灵
  },

  // 灵量（r18 改基数制）：份额，零和
  spiritMass: {
    total: 9_100_000,        // 治下生灵的灵量基数之和 = 可支配上限
    own: 9_100_000,          // 自己留多少（练养灵用）
    granted: []              // [{ to: 'npc_17', amount: 900_000 }]
  },

  city: {
    population: 1_000_000,
    base: 1_000_000,
    meridian: 9_100_000,     // 灵脉 = Σ 生灵灵量基数（修士 10 / 凡人 1 / 其他 1）
    seats: { total: 100, used: 0 }
  },

  // 战事（r23）：日历驱动，只读 world；角色层只记"我在不在场"
  war: {
    phase: 'peace',          // peace | warning | city | nation（见 21 §4）
    since: null,             // 进入当前 phase 的年份
    cityLost: [],            // ['beiguan','wangbei']，与 flag.city_lost.* 同步
    monthsServed: 0          // 本年已参战月数（战功按它结算，不按杀敌数）
  },

  // 贡献（r23）：只换身份·席位·配额，不许换修为与成功率（I21）
  merit: {
    war: 0, craft: 0, office: 0,
    spent: 0,                // 已兑换总量（只做展示与上限判断）
    lastDecayYear: null      // 每年年初 ×0.9，不累计成存款
  },

  flags: {},                 // spirit_known / world_recognized / li_xiang ...
  log: []                    // 判定日志（q, p, roll, 结果）
}
```

## 2. 字段改名对照（迁移必读）

| 旧（v3 / v4） | 新（v5） | 说明 |
| --- | --- | --- |
| `fate`（气运数值） | **`luck`** | r17：气运叫 luck |
| `natal`（命格 key） | **`fate`** | r17：命格叫 fate（绕回原名，但含义反了） |
| `hidden.luck` / `baseLuck` | **`luck`** | 气运只有一个字段 |
| `fortune: { body, qi, spirit }` | **`path.*.bar`** | 修为条按道分 |
| `cognition` | **`path.spirit.level`** | 认知 = 养灵层级 |
| `hidden.aptitude/insight/heart` | **`attr.*`** | 去掉 hidden 前缀 |
| `hidden.caps` | **`attr.caps`** | |
| `realms: {}` | **`path` + 派生** | 境界由 `level` 推出 |
| 灵量（旧：城池供给） | **`spiritMass`** + `city.meridian` | 城=灵脉（Σ 基数），人=份额（零和） |
| 灵脉 `= 人口`（r17） | **`= Σ 生灵灵量基数`** | r18 基数制：凡人 1 / 修士 10 / 其他生灵 1 |
| `lifespan: 70` | **`lifespan: {base, roll, extra}`** | 三段式，叠加不覆盖 |
| — | **`study`**、**`breakthroughUsedThisYear`** | r17 新增 |

### 2.1 灵量基数（三个常量，写在 `const.js`）

```js
const SPIRIT_UNIT = { mortal: 1, cultivator: 10, other: 1 };
// other = 未开智的禽畜草木；开智的（灵兽/妖/精怪）按 cultivator 计
// city.meridian = 9.1 × population（修士占比九成时），≈ 人口 × 9
```

## 3. 派生值（不许存）

| 值 | 算法 | 何时重算 |
| --- | --- | --- |
| 修炼基数 | 见 `02` §2（属性 + 功法 + 境界 的加权和） | 破境 / 换功法 / 换宗门 / 属性变化 |
| 月修为 | 基数 × 0.20 × 乘区 | 每年 |
| **出现率 `q`** | 见 `11` §4（**一品只掷一次**，缓存进 `path.wall`） | 首次满条时掷，读档不重掷 |
| **成功基数 `b`** | 见 `11` §5（`max(0,属性−40) × 0.0030`） | 每次尝试现算 |
| **灵量系数** | `clamp(2 × own / total, 0.2, 6)` | 分配变化时 |
| 境界名 | `LEVEL_NAME[dao][level]` | 读时 |
| 战力图 | 见 `设计/30-战斗-结算.md` | 读时（不含角色属性） |
| 城池灵脉 | `= Σ SPIRIT_UNIT × 各档生灵数` | 每年（城池层） |

## 4. 四个不变式（写库前断言）

```js
// 1. 层级单调且不越界
0 <= path[dao].level <= MAX_LEVEL[dao]          // 锻体/炼气/养灵 6，修心 4

// 2. 修为条不越界（修心累计制，其余按品清零）
0 <= path[dao].bar <= PROF[dao][path[dao].level]

// 3. 失败累积有上限，且失败不扣修为
0 <= path[dao].fail <= 0.08
// 断言：失败前后 bar 必须完全相等

// 4. 灵量零和（分出去的 + 自己留的 ≤ 可支配总量）
spiritMass.own + Σ granted.amount <= spiritMass.total
```

**破境成功**：`level += 1; bar = 0; fail = 0; attempts = 0; study[dao][tier] = 0`（修心 `bar` 不清零）。
**破境失败**：`fail = min(0.08, fail + rand(0.01, 0.03)); bar` 不变；`attempts += 1`。

## 5. 存档兼容（v4 → v5）

1. `fate`（气运数值）→ `luck`；`natal` → `fate`；
2. `fortune.body` → `path.body.bar`（其余同理），`cognition` → `path.spirit.level`；
3. 新增 `study`（全 0）、`breakthroughUsedThisYear`（false）、`spiritMass`（按 `identity.subjects` 求和）；
4. r23 新增 `war`（默认 `peace`）与 `merit`（三项全 0）；旧档补默认值，**不要从 `flag` 反推**——`flag.city_lost.*` 是事件链的依据，`war.cityLost` 是统计视图，两边同时写、以 `flag` 为准；
4. `city.meridian` 重算为 `= Σ SPIRIT_UNIT × 各档生灵数`（旧权重表作废）。

**迁移后必须重算 `lifespan`**：旧档只有 `lifespan: 70` 一个数，新模型是三段式，缺 `base` 的按境界补。

## 6. 与现有代码的差异

| 现有 | 缺口 |
| --- | --- |
| `PROF_MAX = 100`（百分制） | 新模型是**每品独立的绝对修为量**（120/260/1600/…，见 `11` §1） |
| 无 `pathLevel` | 四道层级完全没有，破境判定打不到对象上 |
| `attrCoef = 0.35 + a/65` | 换成 `0.70×属性 + 0.20×功法 + 0.10×境界` |
| `fortune` 对象三键 | 需拆成四道，并加 `fail / attempts` |
| `fate` 存气运、`natal` 存命格 | **对调**：`luck` 存气运、`fate` 存命格 |
| 事件只有 `kind`（+ 16%/45% 硬编码） | 需加 `nature / priority / forced / rate` 与 `quota`；**新增 `turn`（月轴与候选）** |
| 无求学派生字段 | 需加 `study`（按道按品）与 `turn.studyUsed` |
| 无灵量分配 | 需加 `spiritMass`（零和断言） |
| 心性 3 年 −1、下限 10 | 改每年衰减、地板 60、窗口不关 |
| 气运钳 20–95 且进公式 | 只做加法修正 |
