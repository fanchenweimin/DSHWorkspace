  只有 `arts[id].talent` 这一个按门走的字符串标签。
- 影响：`需求/01` §5「转世保留命格与心性」、`需求/13` §9 的百艺天赋表全都挂空。

- `docs`（多处一致地）写：成活率 `0.10 × 心性 / 39` —— 心性越高越容易活。
- `.tmp/r14_66.md`（r13 定稿）已明确推翻，理由写得极清楚：
  > 「旧版心魔公式 `p = 0.20 + 0.01×心性`……**方向反了**」

  新式：`p(活) = min(1, 3.9 ÷ 心性)`，心性 39 → 0.100，心性 0 → 1.000。
- 现状：**`docs/需求/01` §3、`docs/需求/20` §11、`docs/设计/02` L155 三处都还是旧式。**
- 按用户给的优先级（docs > 归档 > .tmp），`.tmp` 是第三档、不该压 docs；
  但 `.tmp` 这条带 `[定]` `[r13]` 标记且**明确写了"已删"**，属于「被误删的定稿」。
  → **建议人工确认后回填 docs**，不要擅自改。

**B2 心性衰减速率**

- `docs`：在校 −1/年、离校 −0.5/年、地板 60。

  心性永远到不了 40，**B1 的心魔规则永不触发**——两条规则在 docs 内部就是互斥的。
