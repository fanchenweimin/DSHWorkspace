## 1. 核心规则

> 每个选择造成的后果**只有 sysadmin 账户可以看**，user 账户只能看选项，看不到选项标签。

拆成两条：

### 1.1 后果预览：只有 sysadmin 能看

| 信息 | 访客 | user | sysadmin |
| --- | --- | --- | --- |
| 选项标题 | ✅ | ✅ | ✅ |
| 选项提示（hint） | ✅ | ✅ | ✅ |
| **「约 N 年」时长** | ✅ | ✅ | ✅ |
| **效果标签（tags）** | ❌ | ❌ | ✅ |
| **数值变化预览**（+钱/+修为/−心性） | ❌ | ❌ | ✅ |
| **成功/失败概率描述** | ❌ | ❌ | ✅ |
| **不可用原因** | ✅ 见 §1.1.1 | ✅ | ✅ 具体数额 |
| 结果页的 changes 明细 | ❌ | ❌ | ✅ |
| 结果页的 notes | ✅ | ✅ | ✅ |
| 隐藏属性 / 寿命 / 观己 | ❌ | ❌ | ✅ |

### 1.1.1 「不可用原因」怎么写

- **事件本身写明了价钱的**（「交 1 金过路费」），选项里直接显示金额，所有人可见。
- **事件没写明价钱的**（「买下那部功法」），只显示「钱不够」，不显示具体数额。
- sysadmin 永远看到完整原因（「需 1 金 20 铜」）。

这样既能保留「剧情里的明码标价」，又不会把所有隐藏数值暴露给玩家。

### 1.2 为什么这么设计

- **普通玩家凭剧情做选择**，不知道每个选项的数值，才有「修仙」的不确定性。
- **管理员需要调试**，才能验证配置是否生效。
- 这不是作弊功能，是**调试视图**——和「观己」是同一套权限逻辑。

## 2. 落地方式

### 2.1 后端只发一次，前端按角色过滤？

**不行**。前端过滤等于把数据发给了浏览器，用开发者工具就能看到。

正确做法：

```js
// engine.publicState() 接受一个 options 参数
publicState(state, { viewer: 'guest' | 'user' | 'sysadmin' })

// 按角色裁剪
choice: {
  id, label, hint,
  timeLabel: `约 ${years} 年`,                              // 所有人都能看到
  tags:      viewer === 'sysadmin' ? choice.tags : undefined,
  warning:   viewer === 'sysadmin' ? schoolWarning(...) : undefined,
  available,                                                 // 都返回
  reason: viewer === 'sysadmin' ? 具体原因 : 简短原因
}
```

### 2.2 服务端裁剪

```text
GET /api/runs/:id
  → 根据 Cookie 判断 user 角色
  → engine.publicState(state, { viewer })
  → 返回裁剪后的 JSON
```

- 访客与 user 得到的 JSON 里**根本没有** `tags` / `timeLabel` / `changes` 字段。
- sysadmin 得到的 JSON 是完整版。

### 2.3 结果页

`makeResult()` 里记录的 `changes`（数值变化明细）同样按角色裁剪：

```text
sysadmin → 显示「锻体感悟 +32 · 根骨 微有精进 · 气运 逆风拂面」
user/访客 → 只显示剧情文本与 notes（文字叙述），不显示数值条
```

### 2.4 前端表现

| 角色 | 选项渲染 |
| --- | --- |
| sysadmin | 三行：标题 / 提示 / 标签+年限+数值预览 |
| user / 访客 | 两行：标题 / 提示，右侧只有一个箭头 → |

未登录访客与 user 表现完全一致（都不看数值）。

### 3.2 游戏页：卡片直点，零弹窗

参照 `归档/r24-旧版/proto/turn-proto.html` 的骨架（一年十二月、左人右账、中间卡片），但换成浅底墨线。

```text
┌ 顶栏：天下 ← ｜ 年号 ｜ 岁数 ｜ 学籍 ｜ …… ｜ 重开 ｜ 登录 ┐
├ 左：四道修为条 ─┬ 中：12 月刻度 + 一句提示 + 卡片 ─┬ 右：纪事 ┐
│  资质/悟性/心性  │  [蒙学卒试 主线] 应考1月 再读1月 │  囊中   │
│                 │  [打熬筋骨] 1月（常驻，虚线）    │  局势   │
└─────────────────┴──────────────────────────────────┴─────────┘
```

**为什么没有抽屉**：r24 原型是「点卡 → 开右侧抽屉 → 选选项 → 关抽屉」，一步事变成四次点击。现在**选项直接长在卡片里**，点哪个就走哪条：

| 以前 | 现在 |
| --- | --- |
| 点卡开抽屉 | 卡上直接列全部选项（每个选项带耗时） |
| 抽屉里再点一次 | 一次点击 = 一次 `POST /api/act` |
| toast 提示"已记入月历" | 结果只写进右栏「纪事」，没有浮层 |
| 弹窗确认「重开」 | 「重开」两段式：第一次变「再点一次」，三秒内不点就复原 |
| 月数不够 → 弹提示 | 选项就地置灰，标红剩余月数；被服务端拒绝的原因**贴在卡下面，2.6 秒自消** |
| 卡住时只能关页面 | 今年做不成任何事时，多一张「把这一年过完」（`canWait` → `{kind:'wait'}`），点一下过完，不弹窗 |

**常驻卡与事件卡用形状区分**：事件卡实线 + 左侧色条（强制事件是朱色），常驻卡虚线。有强制事件未处理时，服务端**干脆不发常驻卡**（I15），提示条改口说"手头有非处理不可的事"。

**页面上看不到的东西**（服务端已删，不是 CSS 隐藏）：

```text
weight  priority  judge  quota  luckBias  chain  ttl
source  template  args  window  fromCalendar  order  duty  maxMonths
when    do
```

选项只留 `id / label / hint / months`；事件只留 `id / title / nature / hint / months / forced / choices`。成功率、墙、权重、出处——一概不出服务端。

### 3.3 配置页：表格 / 表单，不是整块 JSON

r24 的配置页是一个 `<textarea>`，改一个数要在两百行 JSON 里找。现在由 `public/js/form.js` 把 JSON **按形状翻译**：

| 数据形状 | 呈现 |
| --- | --- |
| 对象 | 分组（可折叠），标量字段一行一个输入框 |
| 对象数组 | **表格**（一行一条，列名中文化，关键列给足宽度） |
| DSL 数组（每项一个算子键，如 `{eq: [...]}`） | 「算子 / 参数」两列，参数再拆成输入框 |
| 短标量数组（≤4 项，如 `["path.x", 3]`） | 一排小输入框 |
| 长字符串（大陆轮廓、风物） | 多行框 |
| 其余嵌套结构 | 折叠区里的小 JSON 框（唯一保留的"源码位"，但只在那一格） |

14 份按系统分组，与 `需求/` 编号同构：

| 组 | 文件 |
| --- | --- |
| **全局 0x** | `rules` `limits` `ops` `invariants` |
| **世界 0x** | `world` `calendar` |
| **角色 0x** | `talents` `identities` `items` |
| **事件 2x** | `events` `actions` `conditions` `macros` `templates` |

配套三件事：

- **改动计数**：改了 3 个格子就写「改动 3 处，未保存」，`Ctrl+S` 可存；
- **「源码」开关**：真要动结构（加一条事件、删一个国家）切过去手写，改完切回来会**先校 JSON 再渲染**，错就留在源码视图并标红；
- **只读清单**：`ops`（算子表）与 `invariants`（不变量）只读——改它们等于改语义，得发版。

**保存走覆盖层**：`PUT /api/config/<file>` 写进 sqlite 的 `config_overrides`，**不动磁盘 `src/seed/*.json`**；「还原」删掉这一行，回到磁盘原值。运行时一律读 `repository/config.js#get()`（覆盖层优先），所以改完刷新即生效、不用重启。

**点一下之后发生什么**（r26 起）：**数值真的会变**，但变化只体现在三处，不出浮层——
左栏四条进度条、右栏囊中与军功、以及纪事末尾那行「（铜 +2 · 军功 +12）」。
破境成不成，由宏里的 `log` 写成一句白话（"关隘开了一线"），**不给概率、不给骰点**。
