## 0. 一句话概括

**战斗不是血条蓝条的交换，是"手段层对不对得上"的问题；对得上之后，才轮到血蓝条和属性。**

一个锻体·金身面对炼气·破胎，他的问题不是"我血够不够厚"，而是"我根本碰不到对方"——法力盾挡在中间，肉身打不穿。反过来，炼气·破胎面对锻体·金身，法力压制失效，两人就是纯拼属性。**先判手段层，再判压制档，最后才进入资源对拼**——这个顺序是整个战斗系统的骨架。

r4 再补一句：**"资源对拼"拼的不是角色属性，是三根血条。** 血量（锻体）、精神（养灵）、神志值（自身心性）——任何一根清零，人就没了。资质、悟性这些"天赋"只决定你练得多快、术法多狠，**不给你多一滴血**（§4.1）。

## 1. 结算总序：三层，不可颠倒

```text
第一层  手段层判定（规则，不用骰子）
         双方各在什么大境界？各自的手段层是什么？
         → 决定这一仗"是什么性质的战斗"
         ↓
第二层  压制档判定（规则，不用骰子）
         低阶一方的品阶 → 全压制 / 可对抗 / 镜像（§3）
         → 决定这一仗"能不能打、怎么打"
         ↓
第三层  回合制资源对拼（骰子在这里才出现）
         血量 / 法力 / 灵力 / 精神 / 神志值 / 攻防 / 架势（§4）
         术法威力、命中、暴走判定（§6）
```

**判据来自用户原话**：「战斗不是简单的血条蓝条交换，而是按境界、百艺推演而来」。

**r4 追加的铁律**：**战斗资源与角色资源不是同一套** `[定]`——资质好不代表血量高，悟性好不代表法力多。角色属性（资质/悟性/心性/本性）是"规则"，战斗属性（血/法力/灵力/精神/神志值/攻防）是"数值"，两套分开，只通过少数明确的接口相连（§4.1、§5）。

## 2. 四道手段：每个大境界的东西都不一样 `[定]`

| 阶 | 道 | 手段层 | 攻是什么 | 防是什么 |
| - | -- | ----- | ------- | ------- |
| 1 | 锻体 | **physical 物理** | 肉身、兵刃 | 血量厚度、肉身扛 |
| 2 | 炼气 | **mana 法力** | 外放的术法（**矛**） | **法力盾**——用法力构建防御（**盾**） |
| 3 | 养灵 | **spirit 灵力** | 实体与精神的双重伤害（**更重精神**） | **解析**——相当于比炼气又多一层盾 |
| 4 | 修心 | **dao 道** | 直攻**神志值**（第三血条，§7）——不碰人物心性 | 只有道能碰道 |

四个关键点 `[定]`（2026-10-27 深夜修正口径）：

1. **法力既是矛也是盾**。盾：锻体打炼气，法力构建的防御肉身伤不到——**除非法力耗空**，所以锻体对炼气的正确打法是**拖**。矛：炼气打品 1–3 的锻体，**锻体没有法力可以抵挡，直接吃真实伤害（直扣血）**——法力压制首先是打人的，其次才是挡人的。
2. **品 4 才开始"挡得住，但挡不干净"**。朝元能抵挡法力攻击，**但每次仍会受伤**，受伤多少与攻方境界成正比——"可对抗档"不是安全区，是从"挨真实伤害"变成"放血"。
3. **灵力是混合力量，炼气只能硬抗**。实体+精神双重伤害、更重精神。炼气境只有精神强大的才能挡下那么几击（精神池的作用），挡得住几击，挡不住一场——而且**炼气对灵力没有任何克制手段，只有硬抗**；反过来，养灵的**解析**让法力伤害微乎其微（×0.1）——同为防御，养灵比炼气又厚一层。
4. **修心没有术法**。修心境本身就是对自我的探究，不需要术法，**自创一些简易招式**就够了（§6.7）。

### 2.1 手段的解锁点

| 手段 | 解锁 | 说明 |
| --- | --- | --- |
| 法力（外放、盾） | 炼气·**破胎**（2 阶 2 品） | 感气只是气机入体，放不出来，也是凡人 |
| 灵力（攻击、解析） | 养灵·**启灵**（3 阶 2 品） | 但**压制资格**提前到开视，见 §3.4 |
| 道（攻心） | 修心·**不惑**（4 阶 1 品） | 修心第一品就是极境 |

### 2.2 「同级」：凡人三境之外都在同一张桌上 `[定]`

> 用户原话：「除了之前的设定的凡人3境外，其余的境界都属于同级的，例如养灵开视虽然是3阶1品，但是还是养灵阶段。」

- **凡人三境**（锻体·体魄、锻体·脏腑、炼气·感气）低一档：没有压制资格，也没有防御性压制——凡人碰上修行者，只有挨打的份。
- **调息以上全部同级**：不存在"低阶不许与高阶交手"的硬墙，谁都能上桌。高阶的优势不由行政规定，由**手段层压制**（§3）和资源上限（§4）自然体现。
- **开视（3 阶 1 品）是"同级"的最好注脚**：它还是养灵阶段，就压得炼气抬不起头——哪怕它自己还没有灵力手段。

### 2.3 四种伤害与反制 `[定]`（r4 新增，战斗的骨架）

> 用户原话：「用法力施展术法进行的攻击会造成法术伤害（扣血），只有用法力施展法术护盾能抵消（养灵有规则可以压制）。用灵力施展术法进行攻击会造成物理伤害（扣血），法术伤害（扣血），精神伤害（扣精神），只能用灵力施展的法术进行对冲反制。修心使用招式时，对心性进行扣除。」

| 伤害类型 | 来源 | 扣什么 | 谁能抵消 / 反制 | 谁能硬扛 |
| --- | --- | --- | --- | --- |
| **物理伤害 physical** | 锻体攻击力、凡器、灵力术法的物理段 | **血量** | **防御力**（直接减伤）；**法力盾也可吸收**（每 1 法力挡 2 点）——这就是"锻体打不穿炼气" | 所有人 |
| **法术伤害 mana** | 炼气术法、法器、灵力术法的法术段 | **血量** | **法力盾**。分成两种情形：**纯法力攻击**（炼气术法/法器）盾**全额吸收**，养灵解析可压到 ×0.1；**灵力术法的法术段**盾**只能吸收一半**（1 法力只挡 1 点，解析把盾的结构拆了） | **没有任何肉身手段**——防御力对法术无效 |
| **精神伤害 spirit** | 灵力术法的精神段、阴险术（蚀神咒） | **精神** | **只有灵力对冲**（§2.3 之三）；无灵力者无从抵挡 | 只能拿**精神池**硬吃（厚度 = 养灵境界） |
| **道伤 dao** | 修心招式 | **神志值** | **只有道能防道** | 常境无任何手段——只能靠自己的心性厚 |

四条硬口径 `[定]`：

**一、法术伤害不看防御力。** 防御力是"肉身扛打"的能力，只管物理伤害。一个防御力 40 的金身，面对一发法术伤害照样全吃——除非他有法力盾。**"炼气打品 1–3 的锻体是真实伤害"这句话的机制含义就是"对方没有盾，而防御力对法术无效"。**

**二、灵力是三重伤害，而三段的抵挡方式各不相同** `[定]`（2026-10-27 二次拍板）：

```text
灵力术法命中，三段同时打出去：

① 物理段 → 走防御力（正常减伤）
② 法术段 → 法力盾"能挡，但只能挡一部分"
             1 点法力只吸 1 点（不是 2 点），上限也只吸一半
             ——「解析规则压制」在这里生效：盾还在，但被拆薄了
③ 精神段 → 没有任何手段能挡，只能拿精神池硬吃

例外：对方也用灵力术法对冲 → 三段全免（见之三）
```

**三、对冲 = 三段全免；挡不住 = 按段各算。** `[定]`

- **对冲**（双方都有灵力、都放灵力术法）：两发相撞，**三段伤害全部抵消，一点不剩**。按灵力总量与术法品阶判胜者，**胜者吞掉这一发并反打**（反打伤害 = 差值，三段照常）。
- **挡不住**（对方没有灵力，或有灵力但没放术法）：就按之二的三段各算——**物理走防御力、法术段被盾挡掉一部分、精神段硬吃**。
- **没有灵力的人连对冲的资格都没有**——锻体、炼气面对灵力攻击，只有"挨"和"跑"两个选项。这条写死，不给例外。

**四、道伤只扣神志值，不扣人物心性。** 见 §7——神志值是"战斗副本"，归 0 = 道心当场崩碎（死），但活下来的人，人物心性只走战后判定（§11）。

```text
四道伤害的"谁能挡"一句话：
  物理 → 防御力（人人有）；盾也能吸
  法术 → 法力盾：纯法力全额挡、灵力法术段只挡一半
  精神 → 只有灵力对冲；没有灵力就只能用精神池硬吃
  道   → 只有道；常境无解
```

## 3. 境界压制：规则压制，三档 `[定]` `[改]`

### 3.1 总规则

> 用户原话：「高一大境界的手段对低一境界的都有压制效果，这个效果在第五小境界后取消。压制效果取消不代表能力层级相同。」
>
> 2026-10-27 补充拍板：「攻（强）方只看大境界属于哪一层，防（弱）方看小境界，1-3 是无法抵抗，4 是可以抵抗，5 是没有大境界规则压制。」

**判定分工** `[定]`：

- **攻方只看大境界**——他属于哪一层，决定他用什么手段层压人。破胎和法相打朝元，规则上一模一样；区别只在强度：破胎可能弱到被朝元抵抗住，法相可能强到把朝元碾死。**压制档不决定胜负，只决定"这一仗是什么性质"。**
- **防（低阶）方只看小境界**——品 1–3 / 品 4 / 品 5+，三档。

| 低阶方品阶 | 压制档 | 效果 |
| --- | --- | --- |
| **品 1–3** | **全压制（无法抵抗）** | **攻方向**：高阶手段是**真实伤害**，无减免直扣血——法力打品 1–3 锻体直接掉血，灵力再附精神侧。**防方向**：低阶攻击被压制手段完全挡死——肉身对法力盾 ×0（只能等它耗空），法力对解析 ×0.1（微乎其微） |
| **品 4** | **可对抗（可抵抗）** | **攻方向**：能被抵挡，但**挡不干净——每次仍受伤**，穿透多少与攻方境界（强度）成正比；破胎打朝元是放血，法相打朝元是碾死。**防方向**：压制手段磨得动了——战斗退化为**拼"血蓝"条** |
| **品 5–6** | **镜像（视为同境界）** | 把品 5 的人**视为与对手同境界**（§3.2 镜像规则）——双向规则压制取消，纯能力对拼，按各自的属性来 |

`[推]` 三档的具体数值（可调，**按方向分列**）：

| 档 | 高阶 → 低阶（攻） | 低阶 → 高阶（防） |
| --- | --- | --- |
| 全压制 | **真实伤害 ×1.0**，无减免直扣血 | 肉身对盾 **×0**；法力对解析 **×0.1** |
| 可对抗 | 穿透 ∝ 攻方境界：**×0.4 ~ ×1.0**（朝元挡法力仍会受伤） | 盾可磨 **×0.5**；解析 **×0.5** |
| 镜像 | ×1.0 | ×1.0 |

### 3.2 镜像规则：每个大境界的第 5 小境界，单独算 `[定]`

> 用户原话：「每个大境界的第5小境界，你都可以把他看成是和另一方同样境界的。例如锻体金身对战炼气破胎时，境界就相当于炼气破胎，对战炼气法相时就是炼气法相，对战养灵神游时就是养灵神游。但攻击手段上还是没法弥补，比如锻体就是用不了法器和灵器。」

```text
金身（1 阶 5 品）vs 破胎（2 阶 2 品）→ 金身按"炼气破胎"算：同层对拼
金身（1 阶 5 品）vs 法相（2 阶 4 品）→ 金身按"炼气法相"算：同层对拼
金身（1 阶 5 品）vs 神游（3 阶 4 品）→ 金身按"养灵神游"算：同层对拼
```

三条推论 `[定]`：

1. **跨阶差也适用**。金身 vs 神游隔着整整一个炼气，但金身照样不受规则压制——**实际表现是会被一招秒，但那是能力差距，不是规则**。招式打上去该多少伤害就多少伤害，没有"解析 ×0.1"这类规则减免。
2. **压制取消 ≠ 能力拉平**。规则上平起平坐，手段上照样欠缺：锻体就是用不了法器和灵器（法器要法力、灵器要灵力，境界门槛卡死）——金身只能用肉身和凡器去打一个神游。规则的门开了，能力的墙还在。
3. **品 6 同样镜像**（临虚/化朽/回春另有极境层，见 §3.4 之五，两者不冲突：极境规则优先）。

### 3.4 特例与边界

**一、开视（3 阶 1 品）没有灵力手段，但对炼气全程有压制 `[定]`。**

实现口径：**压制资格按"所处大境界"判定，不按"是否已掌握该境界手段"**。开视虽放不出灵力，但"解析"的能力已经有了——开视的本义就是"看见"，法力在他眼里是透明的。所以：

```text
开视 vs 炼气品 1–3：防御性全压制（炼气的法力打不进去）
开视 vs 炼气品 4  ：可对抗
开视 vs 炼气品 5+：镜像
开视自己的攻击    ：只能用炼气/锻体手段（他本来就炼气出身），
                    但带着"料敌先机 / 看破 / 观气"三件套
                    （战斗系统改造计划 §2.2，继续有效）
```

**二、同大境界内无压制。** 永远是属性对拼；品差通过**战斗属性上限差**（血量/法力/灵力/精神随品增长，§4.3）自然体现，**不再用旧 D 倍率表** `[改]`。

**三、凡人三境无压制资格。** 体魄、脏腑、感气是凡人，没有防御性压制（本来就没什么可压的），对上任何修行者都按全压制挨打。

**四、阶差不设特殊规则** `[定]`：镜像规则跨阶差同样适用（金身 vs 神游例，§3.2）。不存在"隔一个大境界就恒为全压制"——被一招秒是能力问题，规则之门对品 5 永远是开的。

**五、极境层单独一套规则** `[改]`——见 §9.5。旧"问道判定（55 开 + 手段广度修正）"**作废**，改为"扁平化 + 大境界系数"。一句话预览：**极境打非极境，走通用公式 + 层次系数（0.05~0.15），防御力照常参与减甲；极境打极境，所有手段抹平，只看裸血/裸攻/裸防乘系数（锻体 1 / 炼气 2 / 养灵 3 / 修心 4）。**

## 4. 战斗属性：与角色属性是两套 `[定]` `[改]`

> 用户原话：「战斗资源与角色资源不用同一套。资质好不代表血量高，悟性好不代表法力多。……血量根据锻体境界来的，精神根据养灵境界来的，心性是继承的自身心性，但这个心性仅仅是战斗用的。法力是根据炼气境界来的，灵力是根据养灵境界来的，攻击力和防御力是根据锻体境界来的。」

### 4.1 两套资源的分工

| | 角色属性（规则层） | 战斗属性（数值层） |
| --- | --- | --- |
| 有哪些 | 资质、悟性、**人物心性**、本性 | 血量、法力、灵力、精神、攻击力、防御力、**神志值** |
| 干什么 | 决定**修炼速度、破境概率、术法威力、相性、心性判定** | 决定**这一仗怎么打** |
| 来源 | 事件/命格/天赋，一辈子缓慢变化 | **只看境界**，进境界就有一份固定面板 |
| 关系 | **不直接换算**。资质 100 的人血量不会比资质 40 的人高——他是"练得快"，不是"血厚" | **唯一例外：神志值 1:1 继承角色心性**（§4.3 末） |

**这条分隔的意义**：把"这个人有没有天赋"和"这个人打不打得过"彻底拆开。一个资质平庸但苦修到金身的武夫，血比一个资质绝顶但卡在脏腑的天才厚一倍——**境界是熬出来的，天赋只决定你熬多快。** 这是这个世界最核心的公平。

### 4.2 七项战斗属性与来源 `[定]`

| 战斗属性 | 来源 | 作用 | 三条血条 |
| --- | --- | --- | --- |
| **血量** | **锻体境界** | 挨物理/法术伤害 | **第一血条** |
| **精神** | **养灵境界** | 挨精神伤害 | **第二血条** |
| **神志值** | **自身心性 × 1**（进场复制） | 挨道伤 | **第三血条** |
| **法力** | **炼气境界** | 放法术、开法力盾 | 不是血条 |
| **灵力** | **养灵境界** | 放神通（三重伤害）、对冲 | 不是血条 |
| **攻击力** | **锻体境界** | **不用法力灵力时**的直接伤害；灵力术法的物理段基数 | 不是血条 |
| **防御力** | **锻体境界** | **不用法力灵力时**的减伤；只对物理伤害有效（§2.3） | 不是血条 |

**三条血条的读法** `[定]`：

```text
血量   = 0 → 死（肉身崩）
精神   = 0 → 死（神魂散）
神志值 = 0 → 死（道心碎，当场「心溃」）
任意一条归 0，直接死亡，不看其他两条还剩多少。
```

所以**高境界的人不是"血更厚"，是"血条更厚、而且条数更齐"**：凡人是"血 100 / 精神 30 / 神志 30"，三条都薄；炼气者血量上去了、精神和神志还是薄的；养灵者前两条厚了；修心者三条全满。**这就是"越往上越难杀"的机制解释——不是血多，是你得同时打穿三条。**

**非死亡比斗的危险线** `[定]`：切磋/斗法这类不打死人的比斗，**任意一条血条掉到 10% 即为"危险线"**，可以叫停结束（认输、判负、或对手收手）。生死斗没有这条线。

> 设计意图：有危险线，切磋才有"点到为止"的操作空间；也解释了为什么城中切磋极少出人命——**不是大家心善，是规则给了台阶**。

#### 4.3.1 神志值 ≠ 人物心性（r12 改名，必须分清）`[定]`

> 用户原话：「心性分人物心性和战斗心性，为了防止混淆，战斗心性改名神志值，归 0 战斗中就死亡。人物心性是掉下去触发心魔。」

| | **神志值**（战斗属性） | **人物心性**（角色属性） |
| --- | --- | --- |
| 是什么 | 第三血条，一条**临时的命** | 修心门槛、本性判定、术法相性的那个数 |
| 从哪里来 | 进场时 `人物心性 × 1` 复制一份 | 出生值 + 事件增减，长期积累 |
| 归 0 会怎样 | **当场死**（心溃） | **不当场死**，触发**心魔**；但心性 0 的心魔成活率为 0 → **必死**（`境界系统总纲.md` §6.6.1） |
| 战斗后 | **弃掉**，不带走任何伤痕 | 只有战后心性判定才碰它（§11） |
| 能不能回 | 战斗内不回（§4.4），打完自动满 | 靠事件，几乎不可恢复 |

> **为什么要分**：一个人可以在战斗里"道心被当场打碎"（神志值归 0，死），也可以在漫长的岁月里"心一点点凉掉"（人物心性归 0，走火入魔）。**前者是一瞬间的事，后者是一辈子的事**——用同一个词会让人误以为"心性 0 就死"，那样修心者反而成了全游戏最脆的人。
>
> **一句话**：**神志值是心性的影子，影子碎了人还在；人物心性碎了，人才真的没了。**

### 4.4 「只取灵力」：手段不叠加，只取最高一层 `[定]`

> 用户原话：「当一个角色有法力和灵力时，只取灵力，法力是比不上灵力的。」

| 角色所处 | 战斗里用哪套 | 法力池 |
| --- | --- | --- |
| 锻体（未入炼气） | **攻击力/防御力**（纯肉身） | 无 |
| 炼气（未入养灵） | **法力**（法术 + 盾） | 用 |
| **养灵及以上** | **灵力**（三重伤害 + 对冲） | **封存，不参与战斗**——面板置灰，标注「已被灵力取代」 |

**为什么只取灵力**：灵力一发打三段（物理+法术+精神），法力一发只打一段还被解析 ×0.1——**留着法力打架等于自废武功**。这不是规则禁止，是**战力上的自然淘汰**：到了养灵，法力就成了"旧工具"，只在炼器、布阵、日常里还用得上。

**这条的实际效果**：战斗中每个人只有"一套手段"，永远不存在"法力灵力双开"的复杂局面。**境界决定你手里是什么牌，牌只有一副。**

**资源回复** `[推]`：

| 资源 | 每回合回复 | 备注 |
| --- | --- | --- |
| 法力 | **+5**（"调息"动作 +15） | 养灵以上封存，不回也不掉 |
| 灵力 | **+3** | 养灵以上唯一回的池 |
| 血量 / 精神 / 神志值 | **0** | 战斗内不回——只能靠丹药、生生诀、归灵造化功 |

**法力盾的账** `[推]`：开盾是一个行动，之后**每回合维持 5 点法力**；每 1 点法力吸收 **2 点伤害**（物理或法术都吃）。所以"锻体打不穿炼气"是有数学的——一个 60 法力的破胎，盾能吸 120 点伤害，外加每回合 5 点的维持费；体魄每回合打 10 点，**10 回合上限内永远磨不穿**。想让盾破，只有两条路：**打到他法力见底，或者拖到他算不过这账**。

#### 4.5.1 天生 / 后天，两个字段

每个天赋在数据里带两个开关：

```js
{ id: 'battle_frenzy', name: '战斗狂',
  innate: true,        // 开局 roll 能不能抽到
  acquired: 'T2:3',    // 后天条件模板（null = 不可后天）
  cost: { spirit: +10, heart: -3 }   // 后天获得时立刻结算的代价
}
```

**后天获取不走独立事件**，只在**战后结算**时检查一次条件——条件够了就"觉醒"，弹一条提示，直接生效。这样 19 个天赋不需要写 19 段事件。

| 模板 | 记法 | 含义 | 常用参数 |

2. **T3（濒死）是唯一能把下品变上品的路径**：一个资质平平的人，靠"差点死过三次"拿到「神凝」，这就是这个世界给凡人的补偿。
3. **代价一律走心性或本性**，不走"再扣血"——因为战斗天赋是**身体记住的东西**，代价应该是"你变成了什么样的人"，不是"你又掉了几点血"。

> `[改]` r8 之前写的是「战斗天赋后天不可得（同百艺天赋），转世重抽」，**本轮作废**。现在一半以上的天赋可以后天养出来，且**代价写进天赋本身**（战斗狂精神 +10 心性 −3）。

### 4.8 战后伤病：什么时候掷 `[定]`

> 数值与效果表在 `角色属性与规则系统.md` §5.11（**权威**），本节只写"战斗在什么条件下留下伤"。

**先划一条界**：**切磋与斗法不留重伤。** 因为"非死亡比斗在危险线 10% 叫停"，人根本没到那个份上。**只有生死斗与不死不休才掷**——这是"切磋安全、拼命危险"的机制保证。

```text
按战后血量比例掷（一场只掷一次）：

  完胜（血量 > 50%）  轻伤 20% / 重伤 5%  / 残 0
  惨胜（血量 ≤ 20%）  轻伤 60% / 重伤 30% / 残 2%
  险胜（血量归 0 被救回） 轻伤 100% / 重伤 60% / 残 5%

三条必得（不掷，符合即得）：
  精神归 0 但被救回  → 神魂震荡（30 天，一个月不能出战）
  神志值归 0 但被叫停  → 心创（人物心性 −3，三个月不能修心）
  单次伤害 > 血量上限 20% → 断骨
```

| 伤 | 谁来治 | 效果 |
| --- | --- | --- |
| 流血 / 内伤 | 自己嗑药，凝血丹 | 战斗内 3 回合止住；内伤 30 天 |
| 断骨 | 医道 1 阶 | 90 天 → **30 天** |
| 神魂震荡 | 医道 3 阶 或 养灵者 | 30 天 → 15 天 |
| 心创 | **没有医生** | 只能靠事件与时间，90 天 |
| 残 | 4 阶丹 / 传承器 | 否则永久 |

> **医道在这里第一次有了战场外的价值**：它不治伤（伤自己会好），它**治时间**。一个队里有医修，等于把"养伤三个月"压成"养伤一个月"——**在寿元以年计的世界里，这是硬通货。**
>
> **"残"只给 2%–5%**：这个数不高，但**它一旦发生就是一辈子的事**，而且它专治"莽夫流"——一个从不认输的人，迟早会带着一条断腿活三百年。

### 6.2 品级：天地玄黄四阶梯 `[定]` `[改]`

> 用户原话：「术法、功法分为四个层级，假如叫天地玄黄四级（实际还是用品阶，那个更准）。天阶对应第6小境界，地阶对应第5小境界，玄阶对应第4小境界，黄阶对应第1-3小境界。每个品级由上往下兼容。」

数据结构仍是 `grade{min, best, max}`（物品三重境界），但取值不再自由，**由梯子写死**。术法/功法不跨大境界——梯子在自己的道内走（mana 术法打养灵反正被解析，跨阶没有意义）：

| 阶位 | 对应品 | 最低入门门槛（min） | 最适合（best） | 最高有效（max） |
| --- | --- | --- | --- | --- |
| **天阶** | 品 6 | 品 5 | 品 6 | 品 6 |
| **地阶** | 品 5 | 品 4 | 品 5 | 品 5 |
| **玄阶** | 品 4 | 品 1–3 | 品 4 | 品 4 |
| **黄上** | 品 3 | 品 1 | 品 3 | 品 3 |
| **黄中** | 品 2 | 品 1 | 品 2 | 品 2 |
| **黄下** | 品 1 | 品 1 | 品 1 | 品 1 |

**由上往下兼容**：天阶的门槛落在地阶的适用位（品 5），地阶的门槛落在玄阶的适用位（品 4）——想提前摸高档术法，必须先站上下一档的位置。**第 4 小境界（朝元）想入门天阶，门都没有。**

`[定]` **黄下是流通的知识**：「第一个小境界基本没有什么特殊能力，所以黄下的是可以流通的，也就是所谓的知识。」罗汉拳、基础桩功这类东西太普通、太常识——坊市白送、蒙学必教。

**`[定]` 往上每一档的获取方式都不一样，一条线卡死**（用户原话：「坊市最高黄阶上品，玄阶就需要走身份，例如去城主府获取，宗门，家族获取（也会走事件，但是必定触发）。天阶地阶属于传说中的了，也通过事件来，机缘事件之类的。」）：

| 阶位 | 从哪拿 | 触发方式 | 多少钱 |
| --- | --- | --- | --- |
| **黄下** | 坊市白送 / 蒙学必教 | 无门槛 | 0 |
| **黄中** | **坊市买** | 进店即可 | 1–5 银（术法）/ 20–80 银（功法） |
| **黄上** | **坊市顶格**——这就是坊市的货架上限 | 进店即可，但常缺货 | 5–30 银 |
| **玄阶** | **不走坊市**：城主府 / 宗门 / 家族 | **身份事件，必定触发**（有身份就一定有门路，只是迟早） | 不要钱，要人情与功劳 |
| **地阶** | **机缘事件** | 概率，稀有 | 不可购买 |
| **天阶** | **机缘事件** | 概率，极稀有，一生可能一次 | 不可购买 |

> **这条线的意义**：**散修的天花板就是黄上。** 不是买不起，是**货架上没有**——玄阶以上根本不进坊市，它们走的是"人"而不是"钱"。所以「一个有宗门的普通弟子」在术法资源上永远强过「一个有钱的散修」，这与境界系统里"养灵靠身份"是同一个世界的同一条逻辑。
>
> **"必定触发"这四个字很值钱**：它意味着**玄阶不是运气，是身份的兑现**。你投了谁、认了谁、替谁办过事，都会变成某一天有人把你叫进后堂，给你一本册子。**这是本作里"效忠"这件事唯一的直接回报。**

**玄阶是"陪跑术"**：门槛品 1 就能入门，品 4 才满威力——一本玄阶术法可以从品 1 一直修到品 4 圆满，陪你走完整个上升期。这正是它的珍贵之处，也是"品 1 入门、品 4 圆满"这条长坡存在的意义。效果曲线沿用三重境界原规则：`min` 之下不能修，`min→best` 威力 40%→100%，`best~max` 满威力；因为 `best = max`，升过档就是 ×0.5 的废术——**换代需求由此而来**。

  40–79   大成 ×1.4

  阶位系数   黄下 1 / 黄中 1.5 / 黄上 2 / 玄 3 / 地 5 / 天 8
  相性系数   相符（含中性）1.0 / 错配 0.5

| 黄中 | 7.6 | 5.3 月 | **13.2 月** |
| 黄上 | 5.7 | 7.0 月 | **17.5 月** |
| 玄 | 3.8 | 10.5 月 | **26.3 月** |

### 6.5 术法相性与副作用 `[定]` `[改]`

> 用户原话：「好人和纯粹的坏人是难得的，更多的是中间混混沌沌不好不坏的。只有不断地做坏事，才能算坏人。杀人不是判断标准，而是做事的逻辑，用恶术杀坏人算好事啊。」

**总纲：心性和本性是在事件选择里定的，判定的是"做事的逻辑"，不是"杀没杀人"。**

- 切磋到最后选择把人打死——存心作恶，本性向恶偏移。
- 用《大魔手》宰了一个采生折割的邪修——行的是善的逻辑，不偏恶，甚至向善。
- 本性是连续谱：中间大、两端少（初始 35–65 为主），**只有不断做坏事才配叫坏人**。

所以战斗系统里**没有"恶术杀人"的战后判定** `[改]`——刀是中性的，逻辑才分善恶。术法的影响写进每本书的**简介**里：注明性质（阴险/刚猛/慈悲），写明**有下限、有后果**的副作用。玩家学之前就看得见全部代价，选了就是认了。

**相性对修炼的影响** `[定]`：

| 情形 | 修炼进度 | 威力 | 心性代价 |
| --- | --- | --- | --- |
| 相性相符（含中性） | 100% | ×1.0 | 无 |
| **相性错配** | **×0.5** | ×0.8 | 熟练里程碑：**入门 −3 / 大成 −10 / 圆满 −20**（合计 −33） |

## 7. 修心战斗：攻神志值 `[定]` `[改]`

> 用户原话：「修心境界对于其他境界（除极境）都是直接对'心性'进行攻击，然后产生类似心魔，但是这是战斗中，所以与实际心魔有区别。」
>
> r4 补充：「心性是第三血条……修心使用招式时，对心性进行扣除，进而引发后续阶段。」

**关键口径：神志值是"第三血条"，1:1 复制角色心性，战斗结束即弃。**

旧版"心防 = 心性 × 2"作废 `[改]`——现在不乘 2，**心性多少，神志值就是多少**。修心者心性 95，第三血条就是 95；凡人 **60–77**（卒业 67–77，上了年纪触地板 60），就薄薄几十点（`角色属性与规则系统.md` §5.7.1：出生 **80–90**、衰减地板 **60**，r14）。

> **`[定]` r12 的分寸**：神志值与人物心性**数值相同、性命不同**。前者是这一场里被打碎的道心（死了就死了，没死就出战斗即消）；后者是这个人一辈子的心。**所以"心性 95 的人第三条命也是 95"只是"影子有多长"的问题，不代表他的道心只有 95 点血。** 详见 §4.3.1。

```text
神志值 = 角色心性（进场复制，战斗结束即弃）

道伤命中 → 神志值 −X
  > 50%   正常
  ≤ 50%   「心乱」：每回合 20% 行动作废
  ≤ 20%   「心破」：术法/神通全部失效，每回合 50% 攻击自己（自伤 = 对方最后一击）
  = 0     「心溃」：道心崩碎，当场死亡（生死斗死；比斗=判负，战后走心性判定）
```

**三条血条的统一口径**：血量 0 死、精神 0 死、**神志值 0 死**。修心者的杀法就是**绕过前两条，直接打第三条**——所以对**神志值低**的敌人（凡人 60–77）几乎是几指的事，对**神志值厚**的敌人（同为修心，95+）只能一点点磨。**修心的强度不吃境界，吃对手的心。**

| | 战斗心魔（心乱/心破/心溃，只看**神志值**） | 真心魔（境界总纲 §6.3，只看**人物心性**） |
| --- | --- | --- |
| 触发 | 神志值被打穿阈值 | **人物心性归 0**，或修心修为被扣穿 |
| 影响 | 只在本场，结束即消 | 修为归零、`心性 = max(10, 心性−5)`；成活率 `0.10 × 心性 ÷ 39`（**越低越必死**，心性 0 时必死） |
| 恢复 | 出战斗就恢复（神志值自动回满） | 人物心性几乎不可恢复 |
| 联动 | 心溃 = 当场死 / 判负 → 战后心性判定（可能 −3） | 无 |

**修心 vs 非极境**：修心四品全是极境，所以这一仗走极境规则（§9.5）——**对方打不穿你，你几指打碎他的道心**。这不是"攻神志值"和"极境必胜"两条规则打架，是同一件事的两种说法：**修心杀人的方式，就是把第三条血条清零。**

**修心 vs 修心**：双方都是极境、同一大境界。`[推]` `[待]` 按"同门走本道规则"处理——扁平化会把系数拉平到 4:4，等于没有规则（§9.5.5）。所以修心内战走攻神志值：谁的神志先被打穿谁死。**修心打修心，比的是谁更想得明白。**

**两条铁律** `[定]`：
1. **器物把人的手段层往上顶，但顶不过境界压制**。锻体·金身拿法器，能打出法力伤害，但面对养灵照样被解析——**器给的是攻击层，不是豁免权**。
2. **坏了就是坏了** `[定]`。器物战斗中判定损耗，损毁后不可复原，只能回收部分材料弥补损失。器物的"死亡"和宠物一样永久——这是百艺换代需求的根源，也是"器有寿"的世界观。

**定价公式** `[推]`（炼器师报价用）：
```text
凡器·粗制 = 材料 × 1.2 + 工费（约 8 成是材料）
凡器·精制 = 粗制 × 2.5 ~ 4
法器     = 精制 × 1.5（2 阶主材贵 5 倍，但成品溢价更高）× 阶差 4
灵器     = 法器 × 3 ~ 4（自带术，卖的是"术"不是"铁"）
传承器   = 无价（不流通，只赠予）
```

**损耗判定** `[定]`（"坏了就是坏了"的落地）：每场战斗结束时掷一次，**只在"格挡致命一击 / 被破甲 / 对撞同阶法器"三种情形下触发**：

| 档 | 单次损耗率 | 说明 |
| --- | --- | --- |
| 凡器·粗制 | 15% | 钝了、崩口了，修（原价 20%）或扔 |
| 凡器·精制 | 10% | 可修（原价 30%） |
| 法器 | 12% | 可修但贵（原价 40%），修两次后不可再修 |
| 灵器 | 18% | **不可修**，损毁即报废，回收 10–20% |
| 传承器 | 0% | 不坏 |

> 灵器损耗率最高却最贵——这不是 bug，是**炼器师的生意模型**：灵器卖的是"术"，术会过时，器会坏，所以养灵修士每几十年就得换一把。**换代需求的根，在这里。**

## 9. 战斗分级与战后结算（全部沿用旧定）

战斗系统改造计划 §4 的四条**不动**：切磋/斗法/生死斗/不死不休；认输赔偿 = 对手资产 ×10%（倾家荡产/白打工/逃跑三选）；遁走判定；**战后心性判定表**（必胜而败 −3、以弱胜强 +3、连续败绩累积）。战斗系统总纲只补充一条衔接：

- **战后心性判定是真实心性的唯一战斗入口**。战斗内的一切（心乱、心破）都是临时的；只有"预期 vs 结果"的战后判定才碰真实心性。这条保证修心玩家不会因为被人打了一场就心性崩盘——**心性只能被自己的怀疑打碎，不能被别人的拳头打碎**，除非那一拳真的把第三血条清零了（§7）。

## 9.5 极境战斗：一套公式，两个层次系数 `[定]` `[改]`

> 用户原话：「对于包含极境的战斗，如果一边是非极境，基本可以认为其血量是很多很多的……极境战斗时，将所有手段扁平化处理，例如修心对战锻体临虚，只用基础血量和攻击力，防御力，临虚攻击时，乘以修正系数1，修心攻击时，乘以修正系数4（第四个大境界）。」
>
> 追加：「极境对上非极境并不是真正的无敌，你要根据其具体战斗性质进行合理数值化。」
>
> 三轮追加：① 基础血量按实际境界；② 养灵/极境围杀无用，只能单挑，车轮战有一点用但不多；③ 防御力照常参与计算，最低 1 点就是 1 点。

**核心改进：两套算法合并成一条公式，只有系数不同。**

```text
伤害 = max( 1, (攻方攻击力 − 守方防御力) × 系数 × 修正 )

极境 vs 非极境：  攻方攻击力不放大，系数 = 层次系数（0.05 ~ 0.15）
极境 vs 极境：    攻方攻击力先 × 大境界系数（1/2/3/4），系数 = 1.0
```

| 对局 | 攻方攻击力 | 系数 | 详见 |
| --- | --- | --- | --- |
| **极境 vs 非极境** | 原值 | 层次系数 ×0.05 ~ 0.15 | §9.5.2 |
| **极境 vs 极境** | 先 × 大境界系数（1/2/3/4） | ×1.0 | §9.5.3 |

> 合并的理由：上一版"极境减伤不用防御力"是**给极境开特例**，而用户第三轮明确要求"按计算规则来算甲"。开了特例，极境的防御力就变成了装饰品；现在它就是一个实实在在的 40 点甲——**想打得进去，先把攻击力堆到 40 以上。** 这条门槛本身就是极境最强的一道墙。

| 大境界 | 极境 | 旧"极境 7 个"的对应 |
| --- | --- | --- |
| 锻体 | **临虚**（1 阶 6 品） | 1 |
| 炼气 | **化朽**（2 阶 6 品） | 2 |

| 修心 | **不惑 / 天命 / 耳顺 / 从心而欲**（4 阶 1–4 品，四品全是极境） | 4–7 |

### 9.5.2 极境 vs 非极境：一套没有特例的公式 `[定]` `[改]`

> 用户原话：「极境对上非极境并不是真正的无敌，你要根据其具体战斗性质进行合理数值化。」
>
> 追加（2026-10-27 第三轮）：① 极境基础血量**按各自实际境界取**；② 「养灵境界和极境修士围杀无用，只能一对一单挑，车轮战或许有一点用，但不多」；③ 「肯定要按计算规则来算甲的啊，最低 1 点就是 1 点」。

**上一版"极境减伤不参与防御力计算"作废** `[改]`。极境不开任何特例，**走的就是全书的通用结算**：

```text
单次伤害 = max( 1, (攻方攻击力 − 极境防御力) × 层次系数 × 修正 )

· 减甲在前、系数在后，与普通战斗同一个顺序
· 最低 1 点：是"最终伤害"的保底，不是"减甲后"的保底
· 攻方攻击力 < 极境防御力 → 减甲为负 → 系数也救不回来 → 恒 1 点/次
```

**一、层次系数** `[推]`（只看攻方的品阶，攻方是极境则为 1.0）

| 攻方 | 层次系数 | 对临虚（血 1,200 / 防 40）的实际表现 |
| --- | --- | --- |
| **极境** | **×1.0**（攻先 × 大境界系数） | 见 §9.5.3，不与本表混用 |
| 品 5（金身 / 合一 / 浑然） | **×0.15** | 攻 58 − 40 = 18 → **2.7/回合**，444 回合 |
| 品 4（朝元 / 法相 / 神游） | **×0.10** | 攻 38 − 40 = **负数 → 恒 1 点**，1,200 回合 |
| 品 3 及以下 | **×0.05** | 攻 25 − 40 = 负数 → **恒 1 点**，1,200 回合 |

**这就是"最低 1 点就是 1 点"的全部含义**：朝元的拳头砸在临虚身上，一辈子打 1,200 下，临虚的皮都没破。**不是打不动，是"不够格"——减甲减完已经是负的，系数只是把负数变得更小。**

**二、防御力就是防御力，没有"层次豁免"** `[定]`

| 关键推论 | 说明 |
| --- | --- |
| **攻 < 防 = 永远 1 点** | 朝元 38、金身 58，对上临虚 40：前者恒 1 点，后者 2.7 点。**品 5 是"能磨出痕"的最低门槛，品 4 及以下根本进不了这门** |
| **攻击力差距比系数重要** | 系数只差 1.5 倍（0.10 vs 0.15），但 38 和 58 差 20 点甲——**低境界想打极境，先想办法把攻堆到 40 以上**（器、符、术法被动） |
| **极境打非极境正常结算** | 临虚 88 − 朝元防 17 = 71/回合，480 血 **6.8 回合杀**；打金身 62/回合，750 血 **12 回合杀** |

**三、极境战只能一对一，围攻彻底无效** `[定]`

> 用户原话：「养灵境界和极境修士围杀无用，只能一对一单挑，车轮战或许有一点用，但不多。」

**这是硬规则，不是加成折扣**：

| 情形 | 规则 |
| --- | --- |
| **极境参与的战斗** | **同时只能有 1 人出手**。二十个人站在场上，每回合也只有一个人打得到他——其余人"挤不进去" |
| **为什么** | 极境的防御不是"皮"，是**层次**。层次差把同时到达的攻击**折叠成一次**——二十拳打在同一时刻，等于一拳打二十次 |
| **车轮战** | **唯一的例外**：不是同时打，是**轮流打**。一个接一个上，能持续消耗极境的血量与资源 |

```text
20 个朝元"围攻"临虚，实际发生的不是围攻，是排队：

  第 1 回合  朝元 A 打 1 点 → 临虚一击杀 A
  第 2 回合  朝元 B 打 1 点 → 被杀
  ……
  第 20 回合 朝元 T 打 1 点 → 被杀
  累计 20 点 → 1,200 血的 1.7%

  → 二十条人命换走他 1.7% 的血。围杀不成立，连"磨"都算不上 ✓
```

> **设计意图**：这条规则把"人海战术"从战争逻辑里彻底删掉了。**在极境面前，人多不是力量，是"送人头的顺序"。** 想靠人命填，得填到"车轮战"那种尺度——而车轮战消耗的是血与资源，不是防御（§9.5.2 之四）。

**通用围攻规则（非极境战斗）** `[推]`：锻体、炼气之间的战斗**可以围攻**——每人系数 +0.05×（人数−1），封顶 ×0.30。这是"十把刀就是十把刀"的常识。但**只要任一方是养灵及以上，围攻同样不成立**（灵力与道是规则层，多人的"理"互相排斥，十打一 = 一对一）。

| 战斗双方 | 围攻是否成立 |
| --- | --- |
| 锻体 vs 锻体 / 炼气 vs 锻体 / 炼气 vs 炼气 | **成立**（+0.05/人，封顶 0.30） |
| 任一方为**养灵 / 修心 / 极境** | **不成立**，只能一对一 |

**四、车轮战：有一点用，但不多** `[定]`

> 用户原话：「车轮战或许有一点用，但不多。」

极境真正的弱点不是"打不穿"，是**"架不住一直打"**：

| 机制 | 数值 |
| --- | --- |
| **气血不复原** | 同一场战役内，每接一场，极境气血**上限** −10%（累加到 −50% 为止），且**不回满**（只回 20%） |
| **资源见底** | 法力/灵力每场只回 30%；每追加一场，回复比例再 −10% |
| **恢复代价** | 要完全恢复，极境必须**静养一月**（这一个月他不在场上） |

```text
20 个金身车轮战临虚（一次一人上，金身 2.7 点/回合）

  第 1 场  20 回合 × 2.7 = 54 点；临虚 62/回合，12 回合杀 1 个金身 → 本场死 1.6 人
  第 2 场  临虚血 1,146，上限跌到 1,080，只回 20% → 实到 1,057
  第 3 场  ……
  第 5 场  临虚累计掉 270 点（1,200 → 930），上限已跌到 600，回不满
  金身阵亡 8 人，剩 12 人

  → 结论：车轮战能把他从"满血"磨成"半血且回不满"，
    但磨不掉防御，也磨不死他 —— 有用，但不多 ✓
  → 真正的用法是"逼他退场静养一月"，不是"在此地杀他"
```

> **这条设计的关键**：车轮战消耗的是**血与资源**，不是**防御力**。防御力不随疲劳下降（那是"境界"带来的，不是"体力"带来的），所以低境界永远打不穿。**车轮战的价值在"逼极境退场"，不在"杀死极境"——它换的是一个月的空档，不是一条命。**

**五、修正项（"不是无敌"落在哪）** `[推]`

| 情形 | 修正 | 说明 |
| --- | --- | --- |
| **极境已伤** | 血量 <50% 时，**防御力 = 原值 × 血量比例**（剩 30% 血 → 防 40 → 12） | 这是唯一能让低境界"打进去"的路径。朝元打重伤临虚：38 − 12 = 26 × 0.10 = **2.6/回合**，从 1 点变成 2.6 点 |
| **传承器** | **攻击力取极境级（88），且层次系数按 ×1.0 结算** | 不是"×3"，是"把你拉到极境的攻击力再算"。朝元持传承器：88 − 40 = 48/**回合**，1,200 血 **25 回合**——30 回合内能杀 |
| **极境级手段**（同境极境的术法、阵法） | 同上，按极境攻击力与 ×1.0 结算 | 只有极境的手段能碰到极境 |

```text
四条路，按可行性排序（只有前三条能"杀"）：

① 另一个极境          → 扁平化对拼（§9.5.3），正常胜负
② 传承器              → 把攻击力拉到 88，25 回合杀临虚
③ 重伤的极境          → 防御随血量比例下降，朝元从 1 点变 2.6 点；配传承器 4.7 回合
④ 车轮战              → 磨不掉防御，只能逼他退场，杀不死

低境界单挑完好的极境：1,200 回合，30 回合上限内打掉 2.5%。不成立。
```

**六、按战斗性质分别表现** `[定]`

| 性质 | 表现 |
| --- | --- |
| **切磋 / 斗法** | 极境几击破危险线，判非极境负；极境可主动认输（体面，不掉价）。非极境也可在 10% 危险线叫停——反正打不动 |
| **生死斗** | 极境几击杀；非极境杀极境只有①②③三条路（传承器、对方已伤、极境对极境），**车轮战不算** |
| **不死不休** | 唯一可能翻车的场：极境已伤 + 传承器 + 对方是另一个极境。三样凑齐才谈得上"杀" |

> **设计意图**：极境的"无敌"不是免疫，是**三层壁垒叠出来的结果**——血厚（1,200）、甲硬（防 40 卡死所有品 4 以下的攻击）、层次系数再削一刀。想撬开它，得先从这三层里找缝：**撬甲靠传承器，撬血靠极境已伤，撬层次靠另一个极境。** 靠人多是不行的——这个世界里，人多的力量只到炼气为止。

> 旧"0.0001% 翻车"作废 `[改]`：现在有真实数值路径，不需要叙事补丁。**极境能不能被杀，是一道算得出来的题（25 回合 / 1,200 回合），不是一个掷得出来的骰子。**

### 9.5.3 极境 vs 极境：抹平手段，只比裸值 × 系数

**扁平化清单** `[定]`：

| 抹掉 | 留下的 |
| --- | --- |
| 术法、神通、招式、道伤的**特殊效果** | **血量**（按**各自实际的锻体境界**查 §4.3，不乘系数） |
| 手段层、压制档、解析、法力盾、灵力三重 | **攻击力**（按各自实际锻体境界查，**乘大境界系数**） |
| 熟练度、相性、丹药、符箓、阵法、器物加成 | **防御力**（按各自实际锻体境界查，不乘系数） |

> **"按各自实际境界"已定** `[定]`（第三轮拍板）：不是统一按临虚满值，是各人**练到哪一品就是哪一品**。一个锻体只到金身就转炼气、最后修到化朽的人，极境账面是"血 750、防 26"；一个锻体走满临虚的化朽，是"血 1,200、防 40"。**极境不是"到了就行"，是"你上来时带着多少底子"。**

**大境界系数** `[定]`：

| 大境界 | 极境 | 攻击系数 |
| --- | --- | --- |
| 锻体 | 临虚 | **×1** |
| 炼气 | 化朽 | **×2** |
| 养灵 | 回春 | **×3** |
| 修心 | 四品 | **×4** |

```text
每回合伤害 = max( 1, (己方攻击力 × 大境界系数 − 对方防御力) × 1.0 )
            与 §9.5.2 同一套公式，只是层次系数固定为 1.0、攻击力先乘境界系数
回合上限：极境战 30 回合（普通战 10 回合）——25 回合杀临虚需要这个上限
```

**这个规则最重要的一个后果** `[推]`：**极境战奖励"四条腿都走满"的人**。一个锻体只到金身就转修炼气、最后修到化朽的人，账面是"攻 58×2=116、血 750"；一个锻体走满临虚的人，账面是"攻 88×2=176、血 1,200"。**同样是化朽，前者会被后者按在地上打。** 极境不是"到了就行"，是"你上来时带着多少底子"。

### 9.5.5 修心内战：系数相同，走回本道 `[定]`

> 用户原话：「按心性攻击是对的。」

修心四品系数都是 ×4，扁平化之后双方完全对称——等于没有规则。所以：

```text
修心 vs 修心（同大境界极境） → 不走扁平化，走攻神志值（§7）
修心 vs 其他极境（跨大境界） → 走扁平化 + 系数
```

否则"修心四品怎么分胜负"这个问题无解（基础血/攻/防都取自锻体，通常都是临虚满值）。**已定。**

**修心内战的实际画面**：两个人站着不动，互相一指一指地问。**神志值不是攻击力，是耐力**——先被问穿的人死。所以修心四品之间的强弱，不看谁境界高，看谁的心性厚、谁的招式多（不惑 2 招、天命 3 招、耳顺 4 招、从心而欲 5 招）。**低品修心打赢高品修心，靠的是招式组合，不是境界压人**——2 招对 5 招，同一发道伤，变化差了一倍。

### 9.5.6 极境战为什么"没有术法"

不是禁用，是**没有意义**：到了极境，术法的高低差已经被"道"的层次盖过去了。一个临虚用天阶拳意打另一个临虚，和一个化朽随手一挥，在扁平化里是同一件事——**只看你这一身底子有多厚，乘上你站在第几层。** 这也是"极境之间是大道之争，不是术法之争"的机制写法。

## 10. 回合流程（结算管线）`[推]` `[改]`

```text
每回合：
  ① 意图（开视以上可见对方意图）
  ② 行动（一次一行动；一心二用天赋可 2 个，第二个 ×0.7）
  ③ 命中/闪避（悟性 vs 悟性 + 架势修正 + 战斗天赋，**骰子按气运偏置**——`气运系统.md` §4）
  ④ 伤害分型（§2.3）——这一击打的是物理 / 法术 / 精神 / 道，还是灵力的三段
  ⑤ 手段层结算（压制档减免，§3；极境对局改走 §9.5——对非极境用层次差系数、对极境用扁平化系数）
  ⑥ 扣血条（§4.2）：
        物理 → 血量（先减防御力）
        法术 → 血量（先扣法力盾）
        精神 → 精神
        道   → 神志值
  ⑦ 状态检查（心乱 / 心破 / 三条血条是否有一归 0 / 架势 / 持续效果）
  ⑧ 危险线检查（非死亡比斗：任一条 ≤10% → 可叫停）

回合上限 10（**极境战 30**）；超时按剩余血量比例判胜（三条血条加权：血 60% / 精神 30% / **神志值** 10%）。

> **气运只进 ③，不进 ⑥** `[定]`：一次攻击 = 一个结算单元，气运只修正命中那颗骰子，伤害数字的取整走普通四舍五入。否则气运高的人既更容易命中、又每次都往上取整，等于吃两遍（`气运系统.md` §4.3）。
```

**围攻在流程里的位置** `[定]`（§9.5.2 之三）：

```text
同一回合有 n 人在场时：
  双方都是锻体 / 炼气 → 围攻成立，每人的攻击单独结算，
                        系数 +0.05×(人数−1)，封顶 0.30
  任一方为养灵 / 修心 / 极境 → 围攻不成立，本回合只有 1 人出手
```

**三条血条的归零是最高优先级**：任何一条归 0 立即结束战斗，不再结算本回合后续——**先死的人没有下一个动作**。

对手数据结构（沿用战斗系统改造计划 §6 的 rank/tier/layers/intentPool/combatLevel）需要加字段：

  combatStats: {
    hp, hpMax,              // ← 锻体境界查表
    atk, def,               // ← 锻体境界查表
    mana, manaMax,          // ← 炼气境界查表（养灵以上置 null）
    spirit, spiritMax,      // ← 养灵境界查表（未入养灵仍给 30）
    will, willMax,          // ← 角色心性 1:1（战斗副本）
    talent: [],             // ← 战斗天赋
  },

}
