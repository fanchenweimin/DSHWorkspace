# 气运系统

> 建立：2026-10-28 ｜ **r2：同日，用户三条大改（会变、优先级、档位边界）**
> 定位：**气运的唯一权威文档**。随机结果修正、结果取整、事件门槛、年度漂移，全部收在这一份里。
> 标注约定：`[定]` = 用户原话；`[推]` = 按体系外推；`[待]` = 需拍板；`[改]` = 本轮推翻旧规则。

---

## 0. 一句话

**气运不改"你能不能"，只改"结果落在哪"。**

它不进任何属性公式（不是 +N 的加值），只做三件事：偏随机骰、定取整方向、开事件池子。

但 **r2 的重要修正**：气运**本身是会变的**——每年随机漂移 ±1~30 点。所以它不是一个出生就写死的标签，而是一条**会被这一辈子推着走的曲线**。命好的人越活越顺，命差的人一路下坡，除非有命格把它按住。

## 1. 定义与档位

### 1.1 区间与硬边界 `[改]`

**0–100，50 为中性。实战范围被钳在 10–90。**

| 层 | 范围 | 谁管 |
| --- | --- | --- |
| **绝对边界** | **10 ≤ 气运 ≤ 90** | 年度漂移的钳位，谁都不能越（`[定]`「不可超过 10-90」） |
| **例外通道** | 0–9 与 90–100 | **只有命格能开**。`好运`/`薄命`/`逆风命`/`血手` 这类东西给的初始值或偏移可以出界，普通漂移不行 |

旧口径（`属性档位与境界分布.md` §5）的「20–95、不成长、不做门槛」**全部作废**。

### 1.2 六档 `[定]` `[改]`

> 用户原话：「气运0的能活着都是个奇迹了，开局判死很正常。气运[1-10)是倒霉，[10,20)是差，[20,80]正常，(80,90]好，(90,100]强运。」

| 档 | 区间 | 系数 k | 一句话 |
| --- | --- | --- | --- |
| **绝境** | **= 0** | 0 | **不是倒霉，是活不下来**。`存活判定`会先过一遍（§4.4） |
| **倒霉** | [1, 10) | 0.02 – 0.20 | 好事永远轮不到他；坏事的池子对他开着 |
| **差** | [10, 20) | 0.20 – 0.40 | 不是灾星，是"总差一口气" |
| **正常** | **[20, 80]** | 0.40 – 1.60 | **占绝大多数人**。数值上有波动，但**不进任何事件门槛** |
| **好** | (80, 90] | 1.60 – 1.80 | 手气好，但还没到"命"的程度 |
| **强运** | (90, 100] | 1.80 – 2.00 | 好运事件池对他打开 |

**边界全用左闭右开，只有两端闭合**：`{0} / [1,10) / [10,20) / [20,80] / (80,90] / (90,100]`。

> **r1 的边界写错了**：我原来写成 `[20,80) / [80,90) / [90,100]`，与用户原话差一格。现在按原话：**80 属于"正常"**（`[20,80]` 闭合），**90 属于"好"**（`(80,90]` 闭合）。这条差别在实现上很实在——`气运 == 80` 的人不该被算成"好运"，`气运 == 90` 的人不该被算成"强运"。

### 1.3 「绝境」档为什么单列

用户原话把它从"倒霉"里拎出来了：**倒霉是运气差，绝境是活不下去。**

- 倒霉（1–9）：活得很难看，但能活。
- 绝境（0）：**出生就要过一道存活判定**，`P(活到 7 岁) = 35%`（§4.4 公式）。活下来的，是真的命硬；活不下来的，是这个世界每年少掉的那批人。

这条不是惩罚玩家，是**给"气运"这个词定分量**——如果一个气运 0 的人也能安安稳稳长大，那气运就不叫命，只叫手感。

### 1.4 中间 60 点才是大多数人

**气运 20–80 的人，一辈子不会因为气运"遇见"任何事。** 他只会发现"炼丹总少出一颗""突破总差一点""这一趟出门没碰上那个人"。

气运 92 的人不一样：他会**撞见**别人一辈子撞不见的事。

这也解释了为什么命格值钱：**它们不给你加数值，它们把你从中间推到两端去。** 中间是安全的，但中间什么也不会发生。

## 2. 三条作用线 + 一条优先级 `[改]`

| 线 | 作用于 | 形态 | 谁读它 |
| --- | --- | --- | --- |
| **① 骰子** | **白名单内**的随机结果 | 连续偏移（§4） | 寿元、资质悟性、破境、奇遇、战斗命中……（清单见 §4.5） |
| **② 取整** | **全部**非整数计算结果 | 离散定向（§5） | 一切要走五段链的数值 |
| **③ 门槛** | 事件池子 | 开关（§6） | 好运 `>90`、特别倒霉 `<10` |
| **④ 漂移** | 气运自己 | 年度随机游走（§7） | 每年一次，钳 10–90 |

### 2.1 优先级：① > ② `[定]`

> 用户原话：「因为气运只参与计算一次，所以规则1比规则2优先级高。」

落成硬规则（这比 r1 的"二选一"更明确——**不是互斥，是有先后**）：

```text
一个结算单元里，气运只能出现一次。
  该结果带骰子（且在 §4.5 白名单内）→ 气运用在骰子上，取整走普通四舍五入
  该结果不带骰子（或骰子不在白名单）  → 气运用在取整上

判据只看「这一趟有没有吃到骰子」，不看"我想不想让它吃"。
```

**为什么必须这样**：如果两道都吃，气运 100 的人既"更容易命中"又"每次都往上取整"，等于一份气运花两次——而用户要的是"只参与一次"。

### 2.2 气运不进五层链

它不是一个 `[+5]` 条目，而是挂在**结算动作**上的一次读取。这与 `角色属性与规则系统.md` §1.8「概率修正不进链」是同一条原则，也解释了为什么气运永远不写在属性区间里。

## 3. 气运系数 k

```text
k = 气运终值 / 50        # 严格正比，50 为中性
```

| 气运 | 0 | 5 | 10 | 20 | 50 | 80 | 90 | 100 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **k** | 0 | 0.1 | 0.2 | 0.4 | **1.0** | 1.6 | 1.8 | 2.0 |

`[定]` 用户给了两个锚点：「正比，区间【0-2】」「气运为 50 时修正为 1」——这两条只对应一个函数，就是 `k = 气运 / 50`。

**k 是唯一的气运旋钮。** 全系统只有这一个系数，不允许各系统自己定义"气运 × 0.1"之类的新斜率。

## 4. 线①：骰子修正（连续）

### 4.1 口径

```text
原骰 = 下限 + random() × (上限 − 下限)
修正 = (气运 − 50) × 0.002 × (上限 − 下限)      # 区间幅度的 ±10%
结果 = clamp(原骰 + 修正, 下限, 上限)
取整 = 普通四舍五入（**不走 §5**，见 §2.1）
```

`0.002` 的来历：`(100−50) × 0.002 = 0.10`，即**气运拉满只挪动区间幅度的 10%**。气运 50 时修正为 0。

### 4.2 强度实算

| 随机量 | 区间 | 气运 0 | 气运 50 | 气运 100 |
| --- | --- | --- | --- | --- |
| 寿元 roll | 60–100（幅 40） | −4 年 | ±0 | +4 年 |
| 资质 + 悟性总和 | 100–140（幅 40） | −4 点 | ±0 | +4 点 |
| 破境判定（掷 1–100） | 1–100（幅 99） | −9.9 | ±0 | +9.9 |

> **改口径**：r1 写的"资质 roll 30–100（幅 70）"已废——资质和悟性**不再各自 roll**，改为"先定总和再分配"（`角色属性与规则系统.md` §5.5），所以气运作用在这个"总和"上。

**这组数不负责"让气运 0 的人活不成"。** 气运 0 的死活由 §4.4 的存活判定管，不由这 ±4 点管。骰子修正只负责"落点偏一点"，别让它承担叙事。

### 4.3 一次结算只有一个气运入口

见 §2.1。**最典型的是战斗**：一次攻击 = 一个结算单元，气运只进**命中判定**，伤害数字的取整走普通四舍五入。

### 4.4 存活判定：气运 0 的门 `[推]`

> 用户原话：「气运0的能活着都是个奇迹了，开局判死很正常。」

出生时判一次，**只判一次**，过了就一辈子不再判：

```text
m = min(资质, 悟性)
P(活到 7 岁) = 0.95
             − 0.03 × max(0, 30 − m)        # 单项太低的，先天就撑不住
             − 0.03 × max(0, 20 − 气运)      # 气运低的人，意外多

下限 0.10（真有人活下来，但那不叫运气，叫命硬）
```

| 气运 | 单项 50 | 单项 40 | 单项 25 | 单项 15 |
| --- | --- | --- | --- | --- |
| **0（绝境）** | **35%** | **35%** | **20%** | **10%** |
| 5（倒霉） | 50% | 50% | 35% | 20% |
| 10（差） | 65% | 65% | 50% | 35% |
| 15（差） | 80% | 80% | 65% | 50% |
| **20+（正常起）** | **95%** | **95%** | **80%** | **65%** |

**读法**：气运 20 以上、单项 40 以上 = 95%，跟"必然活下来"没区别；气运 0 = 三个人里死两个。**"活下来是奇迹"这句话，在这里是 35%。**

> 这条判定的位置很关键：它**不是开局判死玩家**，而是**给"这个世界有很多人没长大"这件事一个数值**。玩家抽到气运 0 就是抽到了那 35%——**如果他活下来了，那他就是这个世界里最不该活的一个，后面的每一件事都是赚的。**

### 4.5 白名单：哪些随机数吃气运 `[定]` `[改]`

> 用户原话：「一是一些随机数生成，不用全部随机数，具体哪些你可以设定，也可以设定成可配置的，最后人工配置，然后由气运修正。」

**做成配置表**（配置文件里一行一个开关，默认值如下）：

| 随机事件 | 默认 | 理由 |
| --- | --- | --- |
| 寿元 roll | ✅ 吃 | 这是最该被"命"影响的一件事 |
| 资质 / 悟性总和 | ✅ 吃 | 同上 |
| 存活判定（§4.4） | ✅ 吃 | 气运低的人本来就该多死 |
| 破境成功率判定 | ✅ 吃 | 玩家最能感知的"差一点" |
| 奇遇 / 事件抽取 | ✅ 吃 | 气运叙事的主战场 |
| 战斗命中 / 闪避 | ✅ 吃 | 战斗是随机最密集处，不吃等于气运在战斗里消失 |
| 暴击 / 特殊效果触发 | ✅ 吃 | 同属战斗骰 |
| 战利品掉落 | ✅ 吃 | "他总能捡到东西" |
| **炼丹成丹率** | ❌ **不吃** | 丹道靠技艺，不靠天；出丹数走取整（§5）已经吃了一次 |
| **百艺判定（养宝/画符/布阵）** | ❌ **不吃** | 同上，技艺术不该被气运抹平 |
| **敌方 AI 决策 / 意图抽取** | ❌ **不吃** | 那是世界的逻辑，不是你的命 |
| **地图生成 / 天气 / 每日杂项** | ❌ 不吃 | 吃不起，也没意义 |

> **白名单的意义**：气运能改的东西必须**玩家看得见、且和他有关**。炼丹成丹率故意排除在外——如果气运能改炼丹成功率，那"丹道天才"这个身份就失效了（`修真百艺.md` 开篇那条铁律：丹道天才必须能靠炼丹赚钱）。

## 5. 线②：结果取整（离散）

### 5.1 规则 `[定]`

> 用户原话：「当计算结果不为整数时，例如炼丹计算结果为12.5时，根据气运计算修正（正比）【0-2】，当气运为50时，修正为1，此时0.5×1=0.5，再按照四舍五入，结果为13。」

```text
m = |值|,  sign = 值的符号
n = floor(m),  f = m − n          # f ∈ [0,1) 是"多出来的那一截"

收益类（越大越好）  进位 if  f × k ≥ 0.5
损失类（越小越好）  进位 if  (1 − f) × k ≤ 0.5

结果 = sign × (n + 进位)
```

**两条分支在 k = 1 时都退化成普通四舍五入**——这是这套规则唯一的正确性锚点。

### 5.2 为什么必须分"收益 / 损失"两类 `[推]`

用户原话只给了收益侧（出丹数 12.5 → 13）。但同一个函数也会吃到**损失侧**：

| 场景 | 值 | 好运的人应该 |
| --- | --- | --- |
| 炼丹出丹数 | 12.5 颗 | 得 13 颗（往上进） |
| 修炼耗时 | 4.75 月 | 用 4 月（往下舍） |
| 被人打伤的伤害 | 12.5 点 | 只吃 12 点（往下舍） |
| 一笔支出 | 12.5 银 | 只付 12 银（往下舍） |

如果一律"往上进"，气运高的人反而**多花钱、多挨打、多花时间**——那就成了诅咒。所以每个结算点必须声明 `favor`：`high`（收益）或 `low`（损失）。

### 5.3 完整算例

**收益：出丹 12.5 颗**

| 气运 | k | f × k | 进位 | 结果 |
| --- | --- | --- | --- | --- |
| 0（绝境） | 0 | 0 | 否 | **12** |
| 25（差） | 0.5 | 0.25 | 否 | **12** |
| **50（正常）** | 1.0 | 0.50 | **是** | **13** ← 用户原例 |
| 75（正常） | 1.5 | 0.75 | 是 | **13** |
| 100（强运） | 2.0 | 1.00 | 是 | **13** |

**损失：修炼耗时 4.6 月 / 4.75 月（两个对照）**

| 耗时 | 气运 | k | (1−f)×k | 进位 | 结果 |
| --- | --- | --- | --- | --- | --- |
| 4.6（f=0.6） | 0 | 0 | 0.4×0 = 0 ≤ 0.5 | **是** | **5 月** |
| 4.6 | 50 | 1.0 | 0.40 ≤ 0.5 | 是 | **5 月** |
| 4.6 | 75 | 1.5 | 0.60 > 0.5 | 否 | **4 月** ← 气运在这里才生效 |
| 4.6 | 100 | 2.0 | 0.80 > 0.5 | 否 | **4 月** |
| 4.75（f=0.75） | 0 ~ 100 | 0 ~ 2 | 0.25×k ≤ 0.5 恒成立 | **恒是** | **恒 5 月** |

> **4.75 这一行是本节的要点**：`(1−f)×k ≤ 0.5` 要翻成"舍"，需要 `k > 2`——而 k 的上限就是 2。**气运 100 也救不回 4.75。** 想快，只能让耗时本身降到 4.5 以下。这就是"气运治不了硬差距"：它能推一格门槛，推不动两格。

**整数不受影响**：结果本身就是整数时 f = 0，气运不参与。

### 5.4 三条边界

| 情形 | 处理 |
| --- | --- |
| 结果为负数 | 取绝对值走两条分支，最后补符号（`sign`） |
| 结果超出一格 | **不可能**——`n + 进位` 天然落在 `{floor, ceil}` 之间 |
| 连续多次取整 | **禁止**。只能对"最终结果"取整一次 |

## 6. 线③：事件门槛 `[定]` `[改]`

> 用户原话：「在一些特定事件判定中，可能会需要气运值，例如好运的事件时，可能需要气运>90。特别倒霉的事件需要气运<10。」

| 门槛 | 条件 | 谁的门 |
| --- | --- | --- |
| **好运事件** | `气运 > 90` | 传承、宝药、贵人、天降机缘 |
| **特别倒霉事件** | `气运 < 10` | 无妄之灾、被人惦记、走火入魔的引子 |
| **无门槛** | `20 ≤ 气运 ≤ 80` | 一切常规事件——**这才是大多数人的人生** |

**这是硬开关，不是加权。** 气运 90 的人把事件表翻烂也看不到"好运事件"那一格；气运 10 的人永远遇不上"特别倒霉"。

### 6.1 三段缝隙（改后仍然保留）

| 缝隙 | 说明 |
| --- | --- |
| **90–90** | 强运档是 `(90,100]`、好运事件是 `>90`——**两者现在对齐了**（r1 里 90 既是"强运"又够不上"好运事件"，是个 bug，已修） |
| **80** | `80` 属于"正常"，不是"好"。差一格的手气，纯数值 |
| **20** | `20` 属于"正常"，不是"差"。**这是最容易被误写的边界** |

## 7. 线④：年度漂移 `[定]` `[改]` —— r2 新增

> 用户原话：「气运是会变动的，每年随机1-30点增减变动，不可超过10-90，更极端的命运需要命格给。」

### 7.1 规则

```text
每年结算一次：
  方向  = 50/50 随机（好/坏各半）      ← 见 §7.2 的修正
  幅度  = 1 + random() × 29            # 1–30 点，均匀
  delta = 方向 × round(幅度)
  新值  = clamp(旧值 + delta, 10, 90)   # 硬钳
```

**为什么是 1–30 这么大的步长**：因为气运是"一辈子的走势"，不是"一次的心情"。一年挪 30 点，十年就能从 50 挪到 90——**一个平民用二十年爬到"强运"，是这个世界里最励志也最罕见的事**。

### 7.2 让漂移"有方向" `[推]`

纯 50/50 随机游走的结果是：**每个人都必然回归 50**，气运就成了一个假变量。所以加两条修正：

| 修正 | 效果 |
| --- | --- |
| **向心力 ∝ 距离** | 漂移方向不是 50/50：`P(变好) = 0.5 + (50 − 当前气运) × 0.004`<br>气运 10 的人每年 66% 概率变好；气运 90 的人 66% 概率变差 |
| **命格按住** | 带 `好运` 的只往上漂（`P(变好)=0.85`）、带 `薄命` 的只往下漂（P=0.15）；**它们同时是"允许越过 10/90"的唯一通道** |

> **这条修正的后果很有意思**：气运 50 的人稳定在 50 附近晃；气运 20 的人有 62% 每年往上走，慢慢回到中段；**气运 90 的人每年 66% 往下掉**。
>
> 所以"强运"不是一个能守住的状态——它是**一道坎，你冲过去，然后被世界慢慢拉回来**。只有命格能把它钉住。

### 7.3 极端值只有命格能给

| 值域 | 谁能给 |
| --- | --- |
| 10–90 | 年度漂移够得着 |
| 1–9 / 91–100 | **只有命格**（初始值或偏移） |
| 0 或 100 | **只有绝品命格**，且应极度罕见 |

这条把"0 和 100"变成了传说——**气运 0 的人不是"运气差"，是"生来就不该活"，而且这个状态一辈子改不掉**（漂移钳在 10，他连爬回 10 都做不到，除非有命格）。

## 9. 实现口径

```js
const luckK = (luck) => clamp(luck, 0, 100) / 50;         // [0, 2]

// 线②：定向取整
function luckRound(v, { luck, favor = 'high' }) {
  const k = luckK(luck);
  const sign = v < 0 ? -1 : 1;
  const m = Math.abs(v);
  const n = Math.floor(m);
  const f = m - n;
  const up = favor === 'high' ? f * k >= 0.5 : (1 - f) * k <= 0.5;
  return sign * (n + (up ? 1 : 0));
}

// 线①：骰子修正（取整用普通四舍五入）
function luckRoll(lo, hi, luck) {
  if (!CONFIG.luckDice.includes(key)) return Math.round(lo + Math.random() * (hi - lo));
  const shift = (luck - 50) * 0.002 * (hi - lo);
  return Math.round(clamp(lo + Math.random() * (hi - lo) + shift, lo, hi));
}

// 线④：年度漂移
function driftLuck(luck, fate) {
  const pUp = fate === '好运' ? 0.85
            : fate === '薄命' ? 0.15
            : 0.5 + (50 - luck) * 0.004;
  const dir = Math.random() < pUp ? 1 : -1;
  const mag = 1 + Math.random() * 29;
  return clamp(luck + dir * Math.round(mag), 10, 90);
}
```

### 9.1 四条反例（每一条都会真实发生）

| 反例 | 后果 |
| --- | --- |
| **每步取整** | 月修为 11.4 取整成 11，再 ×12 = 132，实际应为 136.8 → 137。**误差逐年累积，且气运每月生效一次** |
| **嵌套调用** | `luckRound(luckRound(x))` 让气运吃两遍；`luckRoll` 的结果再 `luckRound` 同样是两遍 |
| **读时取整** | 在 `render()` 里调取整函数，界面每刷新一次数值就漂一次——违反「中间值禁止读时计算」 |
| **把 k 直接乘结果** | `v × k` 会让气运 0 的人一切归零（钱、修为、寿元全变 0），这是最常见的误读 |

**正确顺序永远是**：算完 → 取整一次 → clamp 一次 → 回写或展示。

### 9.2 漂移的一个坑

**别每年重掷"方向"。** 如果每年独立掷 50/50，气运的方差会随年龄爆炸，八十岁的人气运必然在 10 或 90。加了 §7.2 的向心力之后才稳。**这条在实现时要写单测：模拟 10,000 个角色各活 80 年，看气运的分布是否仍以 50 为中心。**
