# 需求 · 00 总纲与术语

> 版本：r17（2026-10-30）
> 这一份只写「要什么」，不写「怎么做」。**实现细节一律在 `docs/设计/`**。
> 收口原则：一个概念只在一处定义，其他地方只引用编号。

---

## 1. 一句话

一个人从 7 岁进蒙学（**必须进**），靠资质/悟性/心性在四条道上各自爬 22 个小境界；**每个小境界 = 攒满一条独立的修为条 + 过一次瓶颈**；瓶颈分「概率」「事件」两种，玩家的全部策略都在「怎么让那道墙别出现」和「怎么让那道门出现」上。

---

## 2. 四道 · 22 品

| 阶 | 道 | 吃什么 | 修为条名字 | 品 1–6（修心 1–4） |
| - | - | - | - | - |
| 1 | **锻体** | 资质 | **内力** | 体魄 / 脏腑 / 调息 / 朝元 / 金身 / 临虚 ★ |
| 2 | **炼气** | 悟性 | **法力** | 感气 / 破胎 / 驭凡 / 法相 / 合一 / 化朽 ★ |
| 3 | **养灵** | 资质 + 悟性 + 灵量 | **灵力** | 开视 / 启灵 / 真域 / 神游 / 浑然 / 回春 ★ |
| 4 | **修心** | 心性 | **道心** | 不惑 ★ / 天命 ★ / 耳顺 ★ / 从心而欲 ★ |

★ = 极境（寿元 1,000 起；回春为 ∞）。

**四条修为条互相独立**：锻体的内力不喂炼气，炼气的法力不喂养灵。换道不是"转职"，是从零再开一条条子。

> **r17 改名**：血气→**内力**、真气→**法力**、灵量→**灵力**。改名是为了把"灵量"这个词腾出来——**灵量现在是资源，灵力才是修为条**（见 §3）。

## 3. 术语（唯一口径）

| 词 | 含义 | 易错点 |
| --- | --- | --- |
| **阶** | 大境界序号（1–4） | 不是"等级" |
| **品** | 小境界序号（1–6 / 修心 1–4） | |
| **层级** | 每道一条轨，LvN = 这一品你"通了" | 层级 ≠ 品；层级是破境的**资格**，品是你**站的地方** |
| **修为条** | 每品一条独立进度条，攒满才有资格破下一品 | 四道各有名字：**内力 / 法力 / 灵力 / 道心** |
| **圆满** | **该小境界的修为条已修满** | 是一个**状态**，不是层级、不是新境界 |
| **瓶颈** | 修为满了却过不去的那道坎 | 分两类，但落成**三种**（见 §4） |
| **出现率** | 修为满时，"这道墙会不会挡在你面前"的概率 | **越高越难**；= 1 − 旧成功率 |
| **成功基数** | 墙出现之后，"这道门有多宽" | 与属性成正比；**越高越容易** |
| **概率瓶颈** | 每年可试一次、可无限试、第一次必败 | 锻体 1–4 品、炼气 1–3 品 |
| **事件瓶颈** | 必须等一个**事件**；事件不来，基数再高也没用 | 品 5 / 品 6 / 法相 / 养灵六门 / 修心四关 |
| **单事件型** | 事件一到就过，**不掷骰** | 三个品 5 专属 |
| **priority** | 事件的**层级**属性，**数值越小越优先** | 不是"概率"，不是"权重" |
| **灵脉** | 城池层面的灵总量（= 人口） | 是**流量/总量** |
| **灵量** | 一个人能调动的灵，= 治下生灵之和 | **零和**：分给别人就是减法；不是修为条 |
| **luck** | 气运的字段名 | 不再用 `fortune` / `fate` |
| **fate** | **命格**的字段名 | r17 把 `fate` 还给命格，气运改 `luck` |
| **求学事件** | 蒙学/府学/太学开放的事件，提高概率瓶颈成功率 | **不是静态加成**，是事件 |

## 4. 瓶颈：这一版最核心的一条

```
修为条满了
  ├─ ① 掷「出现率」
  │     ├─ 没出现 → 当年破境（境界立成）
  │     └─ 出现   → 进入 ②
  ├─ ② 概率瓶颈 → 每年一次；第一次必败；之后按「成功基数」掷
  └─ ③ 事件瓶颈 → 等事件；事件到了
        ├─ 单事件型（品 5）→ 直接过
        └─ 判定型 → 再按「成功基数」掷一次
```

| 道 | 品 | 瓶颈类型 |
| - | - | - |
| 锻体 | 1–4（体魄/脏腑/调息/朝元） | **概率瓶颈** |
| 锻体 | 5（金身） | **事件 · 单事件**（武名动四方） |
| 锻体 | 6（临虚） | **事件 · 判定**（力破） |
| 炼气 | 1–3（感气/破胎/驭凡） | **概率瓶颈** |
| 炼气 | 4（法相） | **事件 · 判定**（立相） |
| 炼气 | 5（合一） | **事件 · 单事件**（相与身合） |
| 炼气 | 6（化朽） | **事件 · 判定**（散功） |
| 养灵 | 1–4 | **事件 · 判定**（见众生→见自己→见因果→见天地） |
| 养灵 | 5（浑然） | **事件 · 单事件**（众生念） |
| 养灵 | 6（回春） | **事件 · 判定**（返本） |
| 修心 | 1–4 | **事件 · 判定**（四道心关） |

**第 5 品只需要一次事件就够，不掷骰。第 6 品的三个大境界瓶颈各不相同**（力破 / 散功 / 返本）——它们共用结构，不共用内容。

---

## 5. 概率瓶颈的三条硬规则

1. **无限尝试。** 不设次数上限、不设年龄上限，修为条满之后每年可以冲一次。
2. **第一次必败。** 每一品的第一次尝试必定失败，第二次起才按基数算。**没有一次就成的。**
3. **失败会涨基数，但涨幅随机。** 每次失败加 `1%–3%` 的随机值，同一品内累计，上限 `+8%`；破境成功后清零。

另有两条全局规则：
- **失败不扣修为**（任何瓶颈都不扣，只损失这一年）；
- **一年只能突破一次**（全局一次，不分道、不分品）。

## 6. 教育 = 求学事件

**蒙学和府学是义务的，没有"不上学"这一档。** 它们不给属性、不给固定加成，只**开放求学事件**：

| 学籍 | 覆盖哪些品的求学 | 加成封顶 |
| --- | --- | --- |
| 蒙学（7–10） | 锻体 1–2 | +0.06 |
| 府学（11–14） | 锻体 1–3 + 炼气 1–3 | +0.09 |
| 太学（16–19） | 锻体 1–4 + 炼气 1–4 | +0.15 |

- 每次 **+0.03**，同品内累积，破境清零；每年最多一次。
- **太学额外的作用**：炼气 4 品（法相）是事件瓶颈，**只有太学卒业的人才能触发"立相"事件**。

> **教育是"多一条路"，不是"唯一的路"**：改事件之后，属性重新变成主变量，能不能换命主要看你自己的资质，而不是你上没上学（因为**人人都上学**）。

## 7. 大境界互补

```
达成「第 M 阶的第 N 品」（M ≤ 3，N ≤ 4）
  → 对本人所有「阶 < M 的第 N 品」：
        概率瓶颈：出现率 × 0.1
        事件瓶颈：成功基数 × 10
```

- **同品号才生效**（炼气 2 品帮锻体 2 品，不帮 3 品）；
- **只前 3 阶、只前 4 品**（修心、品 5、品 6 都不参与）；
- **单向**（低阶不给高阶加成）。

---

## 8. 灵量：一个人的灵，是所有生灵之和

| 规则 | 内容 |
| --- | --- |
| **个人灵量** | = 他治下所有生灵的灵量之和（1 个生灵 = 1 点） |
| **零和** | **一个生灵的灵量只能供给一个养灵境界**。城主 100 万人口，分 10 万给别的养灵者，自己就只剩 90 万 |
| **不共享** | 分出去的灵量，自己练不了；收回来，对方就掉 |
| **只作用于养灵** | 锻体/炼气/修心的任何数值都不吃灵量 |
| **席位** | 一城 100 席 = 灵量分配权，不是均分 |

---

## 9. 三条硬边界

1. **角色属性不进战斗面板。** 唯一接口是**心性 1:1 → 神志值**。
2. **灵量只作用于养灵**，不改锻体/炼气/修心的任何数值。
3. **本性与心性零耦合。** 本性是"你天生是什么人"，心性是"你被磨成什么人"，两条线永不相交。
