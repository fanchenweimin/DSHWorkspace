## 0. 两套维度，必须分开

事件有两个**正交**的维度。混在一起是 v2 最大的问题——它会让人写出"这个强制事件为什么在坊市触发"这种没法回答的问题。

| 维度 | 问什么 | 值域 | 作用 |
| --- | --- | --- | --- |
| **内容类型** `kind` | 这是个**什么**事件 | 八类（§1） | 决定呈现方式、能否不出、走哪条抽取支路 |
| **触发类型** `trigger` | 它**什么时候有资格**进池 | 五类（§2） | 只决定"进不进候选池"，不决定落不落 |

**举例**：`school_exam`（大考）——内容类型是 `forced`（强制，必须应考），触发类型是 `time`（15 岁）。它既不是"强制类"也不是"时间类"，**它是"在 15 岁有资格进池的强制事件"**。

再加一个**优先级** `priority`（§3），决定"同一个池子里谁压谁"。

```text
┌──────────────────────────────────────────────────────┐
│  trigger  →  能不能进池（地域？时间？境界？前置？）      │
│  priority →  进了池之后，压不压得住别人（1 强制 / 2 优先）│
│  kind     →  抽中了之后，怎么呈现、走哪条支路           │
│  rate     →  同一支路里，它的相对出现率（手调）          │
└──────────────────────────────────────────────────────┘
```

## 1. 维度一：内容类型（`kind`，八类）

沿用 v2 定稿，只补一条"是否占槽位"。

### 1.1 槽位事件（互斥，一轮只出一个）

| 代号 | 名称 | 需要选择 | 默认优先级 | 说明 |
| --- | --- | --- | --- | --- |
| `ambient` | 氛围事件 | ❌ | 4 | 纯展示，不占决策 |
| `normal` | 普通事件 | ✅ | 3 | 主要剧情 |
| `encounter` | 奇遇事件 | ✅ | 3 | 机缘、陷阱、传承 |
| `threshold` | 门槛事件 | ✅ | 2 | 入场资格链（"能不能去试"） |
| `breakthrough` | 破境事件 | ✅ | 2 | 修为满时的过关抉择（"要不要试"） |
| `forced` | 强制事件 | ✅ | **1** | 身份/处境压下来的事 |

**互斥**：六者一轮只出一个。

### 1.2 常驻行动（不占槽位，永远可选）

| 代号 | 名称 | 说明 |
| --- | --- | --- |
| `cultivate` | 修炼 | 功法、术法、兵器、百艺 |
| `commission` | 委托 | 按年刷新的任务 |

> 常驻行动**不走抽取流水线**，永远挂在界面下方。强制事件出现时它们仍然可见，但点下去会被拒（理由见 v2 §2.2）。

## 2. 维度二：触发类型（`trigger`，五类）

### 2.1 总表

| 代号 | 名称 | 进池条件 | 典型用途 |
| --- | --- | --- | --- |
| `plain` | 普通事件 | 无额外条件，只过 `when` | 日常剧情，占内容量 70% |
| `region` | 地域事件 | 角色**当前所在地**在 `region` 白名单内 | 坊市只在城内；宝地只在城外 |
| `time` | 时间事件 | 年龄/年份/学籍阶段命中 `time` 窗口 | **主线回归**：14 岁百艺、15 岁大考 |
| `realm` | 境界事件 | 某道**品阶达到并要求圆满** | 世界认可、悟道、飞升 |
| `prereq` | 前置事件 | `prereq` 列表里的事件**全部已发生** | 事件链、后续剧情、复仇 |

### 2.2 地域事件 `region`

**地域枚举**（与 `身份系统.md` 的位置/身份对齐）：

| 值 | 含义 | 谁在这儿 |
| --- | --- | --- |
| `city` | 城内（街巷、衙门、宅邸） | 居民、官吏、家主 |
| `market` | 坊市 | 商人、散修、百艺匠人 |
| `academy` | 学府（蒙学/府学/太学） | 学生、教习 |
| `outskirts` | 城外（田地、驿道、村镇） | 农户、行商、镖队 |
| `wild` | 荒野（山野、密林、乱葬岗） | 散修、猎户、邪修 |
| `sect` | 宗门山门 | 弟子、长老 |
| `battlefield` | 战场 | 军士、将军 |
| `secret` | 秘境 / 洞天 | 探险者 |

```js
trigger: 'region',
region: ['market', 'city'],   // 二者之一即可
```

> **地域是硬门槛，不做模糊匹配。** 在城外的人永远不会遇到"坊市拍卖会"——**这条比任何概率都重要**，因为它让"回城"这个动作第一次有了战略价值。

### 2.3 时间事件 `time`

三种写法，可组合：

```js
// ① 岁数窗口（主线用，必出）
trigger: 'time', time: { age: 14, span: 0 }

// ② 学籍阶段（学府线用）
trigger: 'time', time: { school: 'prefecture', phase: 'final_year' }

// ③ 年份周期（朝会、季考、缴税用）
trigger: 'time', time: { every: 3, offset: 1 }
```

**"时间"这一维的语义是"日历到了"，不是"必须发生"。** 要不要强制出现，由 `priority` 决定——`school_exam` 是 `time + priority 1`，所以必出；"城中换了季节"是 `time + priority 4`，出不出都行。

### 2.4 境界事件 `realm`

```js
trigger: 'realm',
realm: {
  path: ['body', 'qi'],      // 锻体或炼气（1–3 阶）
  tier: 4,                    // 第 4 品
  state: 'complete'           // 该品修为圆满
}
```

**两条铁规**：

| 事件 | 触发点 | 为什么 |
| --- | --- | --- |
| **世界认可** | 1–3 阶 · **第 4 品圆满** | 4 品是"人"的极限，再往上要世界点头 |
| **悟道** | 1–3 阶 · **第 5 品圆满** | 5 品是"世界点头"，6 品要"自己想通" |

```text
锻体：朝元(4) 圆满 ──世界认可──▶ 金身(5) 圆满 ──悟道──▶ 临虚(6)
炼气：法相(4) 圆满 ──世界认可──▶ 合一(5) 圆满 ──悟道──▶ 化朽(6)
```

> **境界事件只在 1–3 阶生效**。养灵和修心有自己的层级门（见 `境界系统总纲.md` §5.4 / §6），不走这一套——它们的门是"见众生""见自己"，不是"世界认可"。

### 2.5 前置事件 `prereq`

```js
trigger: 'prereq',
prereq: ['life_chain', 'great_awakening']   // 两者都发生过
```

- **"发生过"= 存档里有这条事件的记录**，不要求选的是哪个选项；
- 需要"选了某个选项才算"时，用 `flags`：
  ```js
  prereq: ['great_awakening'],
  when: { flags: { heart_open: true } }
  ```
- **前置事件不消耗、不过期**：它可以被后续多个事件引用。

### 2.6 组合

一个事件只能有一个 `trigger`（互斥），但 `when` 可以与任何 `trigger` 叠加：

```js
{
  id: 'treasure_land',
  trigger: 'region', region: ['outskirts', 'wild'],
  when: { fate: { min: 80 } },     // 气运 > 80
  ...
}
```

> **为什么 trigger 互斥**：五种触发类型的"进池语义"不同，同时命中会产生"到底因为哪个进的池"的歧义。**互斥之后，每个事件只有一条进池理由，日志可读。**

## 3. 优先级 `priority`

```text
1  强制     出了就必须处理（出征、大考、缴税）
2  优先     有条件必出（破境、门槛链、境界事件）
3  普通     与别的普通事件同池竞争
4  氛围     纯展示，垫底
```

**规则只有一条**：

> **池子里取"最小优先级"那一层，其余层全部丢弃，不参与本轮抽取。**

```text
池子 = [A(pri 3), B(pri 3), C(pri 1), D(pri 2)]
→ 只剩 C，直接出
```

这条替代了 v2 §1.5 的"有 forced 就出 forced"，但更通用：**任何一层都可以压住下面所有层**，不需要为每种情况写特判。

> **代价要知道**：优先级 1 的事件一多，普通事件就永远轮不到。所以 **`priority: 1` 是稀缺资源**，全库建议不超过 25 条（出征、大考、百艺择业、缴税、驱逐这类"人生节点"才配）。

## 4. 抽取流水线（六步）

### 4.1 完整流程

```text
每回合（一"年"）开始：

① 收集    遍历事件库 → 五类 trigger 判定 → 过 when 条件 → 过"本年不可重复" → 进池
② 截断    取最小 priority 那一层，其余丢弃
③ 强制    该层里有 kind = forced 的 → 按 rate 加权抽一个 → 直接返回
④ 抽类型  没有强制 → 按当前状态的类型权重表（§4.3）掷一个 kind
⑤ 抽事件  在该 kind 的子池里，按 rate 加权抽一个
⑥ 返回    渲染选项（show 过滤 / enable 置灰）→ 玩家选 → 执行 result
```

### 4.2 伪代码

```js
function drawEvent(ch) {
  // ① 收集
  let pool = EVENTS.filter(e =>
    e.enabled &&
    matchTrigger(e, ch) &&          // 五类触发，互斥
    evalWhen(e.when, ch) &&         // 年龄/属性/身份/flag/气运
    !isCoolingDown(e, ch) &&        // 冷却：once / every_n_years
    !e.onceOnly || !ch.done[e.id]
  );
  if (!pool.length) return ambientFallback(ch);

  // ② 优先级截断
  const top = Math.min(...pool.map(e => e.priority));
  pool = pool.filter(e => e.priority === top);

  // ③ 强制直返
  const forced = pool.filter(e => e.kind === 'forced');
  if (forced.length) return weightedPick(forced, e => e.rate);

  // ④ 按状态抽类型
  const w = KIND_WEIGHTS[stateKey(ch)];
  let kind = weightedPick(Object.keys(w), k => w[k]);
  let cand = pool.filter(e => e.kind === kind);
  if (!cand.length) {                     // 该类型空池 → 降级到 normal
    cand = pool.filter(e => e.kind === 'normal');
    if (!cand.length) return ambientFallback(ch);
  }

  // ⑤ 按出现率抽事件
  return weightedPick(cand, e => e.rate);
}
```

### 4.3 类型权重表（随状态变化）

| 状态 | ambient | encounter | normal | threshold |
| --- | --- | --- | --- | --- |
| 蒙学（7–10） | 8–12% | 3–6% | 余下 | 5% |
| 府学（11–14） | 8–12% | 3–6% | 余下 | 8% |
| 太学（16–19） | 12–18% | 8–12% | 余下 | 12% |
| 有身份（城主/将军/宗主/家主） | 12–18% | 8–12% | 余下 | 15% |
| 无身份散修（20+） | 25–35% | 15–25% | 余下 | 12% |
| 养灵（开视以上） | 35–45% | 15–25% | 余下 | 10% |
| 修心（不惑以上） | 30–40% | 20–30% | 余下 | 10% |

> `breakthrough` **不进这张表**——它是"修为满 + 优先级 2"直接进池的，靠状态表抽它会把"该破境"变成"看运气"。

### 4.4 一次实跑（14 岁，府学生，该学百艺了）

```text
① 收集
   school_baiji      trigger=time(age 14)  ✓
   school_exam       trigger=time(age 15)  ✗ 还没到
   market_auction    trigger=region(market) ✗ 在学府
   treasure_land     trigger=region(wild)  ✗ 不在地
   normal_* (37 条)  trigger=plain         ✓

② 截断   priority: school_baiji = 1，其余 = 3
   → 池子只剩 school_baiji

③ 强制   kind = forced → 直接返回

⑥ 渲染   "府学四年，该择一门手艺了。"
   选项 12 门正艺（show 条件过滤：禁·血丹需本性≤40，不满足则根本不出现）
   选「丹道」→ result: flags.craft.dan = true、解锁炼丹修炼与使用
```

**注意第 ③ 步**：`school_baiji` 之所以必出，不是因为"时间到了"，而是因为它的 `priority = 1`。**时间只负责把它放进池子。**

## 5. 事件 schema

```js
{
  // ── 身份
  id: 'school_baiji',                 // 全局唯一，snake_case
  title: '择一门手艺',
  icon: 'book',
  kicker: '府学 · 十四岁',

  // ── 两套维度
  kind: 'forced',                     // 八类
  trigger: 'time',                    // 五类
  priority: 1,
  rate: 100,                          // 出现率（0–100，手调）

  // ── 触发参数（按 trigger 填其一）
  region: null,
  time:  { age: 14, span: 0 },
  realm: null,
  prereq: null,

  // ── 通用条件
  when: {                             // 进池前判定
    school: 'prefecture',
    flags: { expelled: false }
  },

  // ── 冷却 / 一次性
  once: true,                         // 一生一次
  cooldown: 0,                        // 或：N 年内不再出现

  // ── 呈现
  body: '……',
  years: 1,
  choices: [ /* 见 §6 */ ],

  // ── 元数据
  enabled: true,
  source: 'builtin'
}
```

**`rate` 的语义**：同一支路内的**相对权重**，不是绝对概率。三条 `normal` 事件 rate 分别是 30 / 30 / 40，就按 3 : 3 : 4 抽。要让某条更常见，把它调大即可。

## 6. 选项：三件事

### 6.1 显示条件 `show` —— 不满足就不出现

```js
show: {
  nature: { max: 40 },              // 本性恶（不是心性！）
  attribute: { aptitude: { min: 80 } },
  fate: ['villain'],
  flags: { craft: { dan: true } },
  realm: { path: 'qi', tier: { min: 2 } },
  identity: ['general', 'sect']
}
```

> **`show` 不满足 = 这个选项在玩家眼里不存在。** 恶人专属选项，好人一辈子看不到——这是"世界观可信"的基础。
>
> ⚠️ **r16 修正**：v2 的宏 `goodOnly: heart >= 70` 与 `evilOnly: heart <= 40` **作废**。善恶看 `nature`（本性），不看 `heart`（心性）。心性低只会触发心魔，不解锁任何选项。

### 6.2 可用条件 `enable` —— 出现但灰掉

```js
enable: {
  money: 10000,                     // 铜钱
  items: { peiyuan_pill: 1 },
  stage: { qi: 2 }
}
```

灰掉时必须给理由（`"需 1 万钱，你还差 6 千"`），**看得见、摸不着**比"看不见"更痛。

### 6.3 结果 `result` —— 配置化修正

结果是一组**字段 → 增量**的映射，按顺序执行：

```js
result: {
  attribute: { aptitude: 5 },        // 资质 +5
  heart: 30,                          // 心性 +30
  nature: -10,
  money: 100,                         // +100 铜
  moneyGold: 1,                       // +1 金（1 金 = 1000 铜）
  years: 2,                           // 耗时 2 年
  flags: { craft: { dan: true } },
  items: { lingzhi: 3 },
  realm: { path: 'qi', exp: 50 },
  log: '你在丹房守了三年火。'
}
```

**结果的四种形态**：

| 形态 | 写法 | 用于 |
| --- | --- | --- |
| **直接修正** | `result` | 无判定的选项（+5 就是 +5） |
| **判定** | `check` + `success` / `failure` | 有成功率的（破境、偷袭） |
| **随机** | `roll: [{ p, result }]` | 有几种等概率走向的 |
| **计算** | `compute: 'exam_score'` | 由公式算出的（大考成绩） |

```js
// 判定式
{
  label: '强行突破',
  check: { base: 0.35, attr: 'aptitude', scale: 0.01, offset: -0.81 },
  success: { realm: { tier: 1 } },
  failure: { realm: { expPct: -0.10 }, heart: -5 }
}
```

### 6.4 条件字段全表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `age` | `{min,max}` | 年龄 |
| `aptitude` / `insight` | `{min,max}` | 资质 / 悟性 |
| `heart` | `{min,max}` | 心性（0–100，地板 60） |
| `nature` | `{min,max}` | 本性（0–100，初始 60–80） |
| `fate` | `{min,max}` | **气运**（0–100），注意与"命格"区分 |
| `fortune` | `string[]` | **命格** key 列表 |
| `talent` | `string[]` | 天赋 key 列表 |
| `realm` | `{path,tier,state}` | 境界 |
| `school` | `'none'\|'primary'\|'prefecture'\|'academy'` | 学籍 |
| `identity` | `string[]` | 身份 |
| `region` | `string[]` | 所在地 |
| `flags` | `object` | 布尔标记（可嵌套） |
| `money` | `number` | 铜钱 |
| `items` | `object` | 物品数量 |

> ⚠️ **`fate` 与 `fortune` 必须分开命名**：前者是 0–100 的气运数值，后者是"命格"（天纵奇才、恶人）。旧稿两处混用，是错的。

## 7. 学府线（具体事件）

### 7.1 时间轴

| 年龄 | 阶段 | 年限 | 事件 |
| --- | --- | --- | --- |
| 7–10 | 蒙学 | 4 年 | 入学（7）、`school_dropout`（可退学） |
| 11–14 | 府学 | 4 年 | 入学（11）、**`school_baiji` 百艺择业（14，强制）** |
| **15** | 大考年 | 1 年 | **`school_exam` 大考（强制，唯一选项）** |
| 15 | 空窗 | — | 最后的破胎窗口 |
| 16 | 入学判定 | — | `school_admit` 放榜 |
| 16–19 | 太学 | 4 年 | 季考、`taixue_expel`（本性<70）、`taixue_return`（入养灵后） |
| 20 | 卒业 | — | `school_graduation` 分配 |

> **三级学府都是 4 年**（`身份系统.md` §4.1 已定）。百艺放在 14 岁，是府学最后一年——**学完就毕业，带着一门手艺走**。

### 7.2 `school_baiji` · 百艺择业（14 岁，强制）

```js
{
  id: 'school_baiji',
  kind: 'forced', trigger: 'time', priority: 1, rate: 100, once: true,
  time: { age: 14 },
  when: { school: 'prefecture' },
  body: '府学四年，教习把你的名册翻到最后一页。该择一门手艺了——这门手艺，往后要养你一辈子。',
  choices: [
    { label: '丹道', result: { flags: { craft: { dan: true } } } },
    { label: '器道', result: { flags: { craft: { qi: true } } } },
    { label: '符道', show: { realm: { path: 'qi', tier: { min: 2 } } },
      enable: { /* — */ }, result: { flags: { craft: { fu: true } } } },
    { label: '阵道', show: { realm: { path: 'qi', tier: { min: 2 } } },
      result: { flags: { craft: { zhen: true } } } },
    { label: '灵植', result: { flags: { craft: { zhi: true } } } },
    { label: '御兽', result: { flags: { craft: { shou: true } } } },
    { label: '傀儡', show: { realm: { path: 'qi', tier: { min: 2 } } },
      result: { flags: { craft: { kui: true } } } },
    { label: '医道', result: { flags: { craft: { yi: true } } } },
    { label: '灵膳', result: { flags: { craft: { shan: true } } } },
    { label: '堪舆', show: { realm: { path: 'qi', tier: { min: 2 } } },
      result: { flags: { craft: { kan: true } } } },
    { label: '鉴宝', result: { flags: { craft: { jian: true } } } },
    { label: '灵酿', result: { flags: { craft: { niang: true } } } },

    // 三禁：不满足 show 条件则根本不出现
    { label: '血丹（禁）', show: { nature: { max: 40 } },
      result: { flags: { craft: { blood: true }, evil_path: true }, nature: -10 } },
    { label: '炼魂（禁）', show: { nature: { max: 30 } },
      result: { flags: { craft: { soul: true }, evil_path: true }, nature: -15 } },
    { label: '蛊（禁）', show: { nature: { max: 30 } },
      result: { flags: { craft: { gu: true }, evil_path: true }, nature: -15 } }
  ]
}
```

**三条硬规则**：

1. **百艺是"开关"，不是"数值"**。`craft.dan = true` 之后，`cultivate` 里才出现"炼丹"，炼出的丹才能用。
   → **没学过就永远不能用，哪怕捡到丹方。**
2. **符道/阵道/傀儡/堪舆 需要炼气·破胎**（`修真百艺.md` §2.2）。14 岁没破胎的人看不到这四个选项——**这是设计的筛选，不是 bug**。
3. **三禁的 `show` 用 `nature`，不用 `heart`**。作恶看本性，不看心性。

### 7.3 `school_exam` · 大考（15 岁，强制，**只有一个选项**）

```js
{
  id: 'school_exam',
  kind: 'forced', trigger: 'time', priority: 1, rate: 100, once: true,
  time: { age: 15 },
  body: '州府大考。三千人取三百，榜上有名，就还有一条路。',
  choices: [
    { label: '应考', years: 1, compute: 'exam_score' }
  ]
}
```

**只有一个选项，但结果由公式算**：

```text
卷面分 W = 0.30 × 资质 + 0.30 × 悟性 + 0.15 × 境界分 + 0.10 × 本性 + 0.15 × 临场

  境界分 = 当前品阶 × 20        （体魄 20 … 朝元 80 … 法相 80，超过 100 截）
  临场   = clamp(50 + (气运−50) × 0.5 + N(0,12), 5, 95)

总分 = W × 1.296
```

**为什么乘 1.296**：它把"**双 80 + 破胎 + 临场一般**"的考生**正好顶到 90 分**。于是"90 分 "不再是虚无缥缈的绝对线，而是**一个可以翻译成属性的话**：

> **考到 90 分 = 你的资质悟性到了双 80 的水平。**
> 太学门口那道线，是用"天纵奇才"四个字刻的。

**实测标定（12 万局蒙特卡洛）**：

```text
总分  均值 73.4、标准差 6.2
90 分 → 超过 99.66% 的人 → 每届 1 万考生约 34 人过线
```

| 考生（临场 50） | 总分 | 位置 |
| --- | --- | --- |
| 资质 70 + 悟性 70 + 破胎 | 77.9 | 前 24% |
| 资质 75 + 悟性 75 + 破胎 | 85.5 | 前 2.5% |
| **资质 80 + 悟性 80 + 破胎** | **90.2** | **前 0.3% ← 过线** |
| 资质 85 + 悟性 85 + 破胎 | 93.7 | 前 0.05% |
| 资质 80 + 悟性 80 + 朝元 | 95.7 | 前 0.01% |

> **每年约 34 人过线，名额只有 5–10 个。** 这就是"千军万马"的物理来源。
>
> 而这 34 人里，**真双 80 的只有 6 个左右**，其余二十几个是双 70–79 但临场超常——**科场就是这样，运气也是分。** 一个 75/75 的考生，撞上气运 95 的一天，就能挤掉一个 80/80 的倒霉蛋。
>
> 这条让"再考一次"变成真的有意义：**不是"我不够格"，是"我那天病了"。**

**结果分档**：

| 总分 | 结果 | 后续 |
| --- | --- | --- |
| ≥ 90 | **过线**（约 34 人/届） | 进 `school_admit` 判定，抢 5–10 个名额 |
| 80–89 | 中榜（县学补录） | 无太学资格，可当吏员、教习、账房 |
| < 80 | 落榜 | `school_graduation` 走普通分配 |

### 7.4 `school_admit` · 放榜（16 岁）

```js
{
  id: 'school_admit',
  kind: 'forced', trigger: 'time', priority: 1, rate: 100, once: true,
  time: { age: 16 },
  when: { flags: { exam_pass: true } },
  body: '……'
}
```

三条录取线（`身份系统.md` §4.2）：

| 通道 | 条件 | 名额 |
| --- | --- | --- |
| **直招** | 总分 ≥ 90 + 炼气·破胎 + 资质 > 80 + 悟性 > 80 | 无硬名额，**自然约 6 人/届**（真双 80） |
| **特招** | 总分 ≥ 90 + 炼气·破胎 | **每城 5–10 人**（从剩下的 ~28 人里取） |
| 落榜 | 以上不满足 | 转入普通分配 |

> **直招靠属性，特招靠名额。** 特招的存在，是为了让"悟性够、资质差一点"的人也有路——否则太学就只收天纵奇才，国家养不出第二种人才。

### 7.5 `taixue_expel` · 驱逐（太学在读，本性 < 70）

```js
{
  id: 'taixue_expel',
  kind: 'forced', trigger: 'plain', priority: 1, rate: 100,
  when: { school: 'academy', nature: { max: 69 } },
  body: '司业把你的名帖从墙上揭下来，当着全班的面。',
  choices: [
    { label: '认了', result: { flags: { expelled: true }, school: 'none' } },
    { label: '求情',
      check: { base: 0.15, attr: 'fate', scale: 0.005 },
      success: { result: { /* 留校，但记过 */ }, flags: { probation: true } },
      failure: { result: { flags: { expelled: true }, school: 'none' }, nature: -5 } }
  ]
}
```

- **只看本性，不看心性**。心性低不下逐客令；
- 一旦 `expelled = true`，**`school_admit` 永久不再触发**；
- 求情成功率上限 65%（气运 100 时），**本性越低越难求**——可再加 `offset`。

### 7.6 `taixue_return` · 再入太学（**仅限已入养灵**）

```js
{
  id: 'taixue_return',
  kind: 'forced', trigger: 'realm', priority: 2, rate: 100, once: true,
  realm: { path: 'spirit', tier: { min: 1 } },   // 养灵·开视

    { label: '进去', result: { school: 'academy', flags: { expelled: false } } }

}
```

> **这是本设计里最有味道的一条**：被太学赶出去的人，只有一条路能回去——**自己走到养灵**。  
> 而养灵要靠灵量、灵量要靠席位、席位要靠太学出身——**这是一个闭环，也是一道墙**。破墙的人，故事就有了。

## 8. 境界事件

### 8.1 `world_recognition` · 世界认可（第 4 品圆满）

```js
{
  id: 'world_recognition',
  kind: 'threshold', trigger: 'realm', priority: 2, rate: 100, once: true,
  realm: { path: ['body', 'qi'], tier: 4, state: 'complete' },
  when: { age: { min: 30 } },
  choices: [
    { label: '受之', result: { realm: { tier: 1 }, log: '……' } },
    { label: '辞之', result: { heart: 5, flags: { refused_recognition: true } } }
  ]
}
```

- **只对 1–3 阶生效**（锻体、炼气）。养灵的"世界认可"是层级 Lv5，走自己的门；
- 触发条件写的是"第 4 品圆满"，**不是"修为满"**——圆满是"练到这一品的顶"，修为满是"可以突破"。两者差一个 `complete` 状态；
- **给"辞之"一个选项**：拒绝世界认可，换 5 点心性。这是修心者的路——**不入 5 品，反而心性更足**。

### 8.2 `dao_insight` · 悟道（第 5 品圆满）

```js
{
  id: 'dao_insight',
  kind: 'threshold', trigger: 'realm', priority: 2, rate: 100, once: true,
  realm: { path: ['body', 'qi'], tier: 5, state: 'complete' },
  choices: [
    { label: '闭关三年', years: 3,
      check: { base: 0.20, attr: 'insight', scale: 0.012, offset: -1.2 },
      success: { result: { realm: { tier: 1 } } },
      failure: { result: { heart: -10, realm: { expPct: -0.15 } } } },
    { label: '入世十年', years: 10,
      check: { base: 0.35, attr: 'nature', scale: 0.008, offset: -0.4 },
      success: { result: { realm: { tier: 1 } } },
      failure: { result: { heart: -5 } } }
  ]
}
```

**两条路**：闭关看悟性，入世看本性。**悟性高的人闭门，本性厚的人出门**——这是四道里唯一一个"两条属性都通向同一扇门"的地方。

## 9. 环境事件

### 9.1 `treasure_land` · 宝地（气运 > 80，城外）

```js
{
  id: 'treasure_land',
  kind: 'encounter', trigger: 'region', priority: 3, rate: 12, cooldown: 10,
  region: ['outskirts', 'wild'],
  when: { fate: { min: 80 } },
  body: '山雾散了半刻。你看见崖下有一片光，不像是日月照下来的。',
  choices: [
    { label: '打坐参悟', years: 3,
      result: { attribute: { insight: 3 }, log: '你在崖下坐了三年。' } },
    { label: '采集灵材', years: 1,
      result: { items: { lingcai: 3 }, money: 500 } },
    { label: '记下地脉', years: 1, show: { flags: { craft: { kan: true } } },
      result: { attribute: { insight: 1 }, flags: { vein_known: true } } },
    { label: '转身就走', result: { fate: -2 } }
  ]
}
```

**为什么是"气运 > 80 + 城外"**：

- **气运 > 80** 把触发率压到约 8% 的人口——宝地是"运气好的人才遇得到"的，不是"勤快的人"；
- **城外**是硬门槛。在城里一辈子的人，遇不到宝地——**这条让"出城"第一次有代价也有回报**。

> 宝地是 `修真百艺.md` §4.3"养宝"的入口：炼气破境不吃丹药，只吃宝物和宝地。**所以这个事件是炼气路线的命门**，`rate` 不能调太低。

### 9.2 `heart_restore` · 心性补足（境界越高越常见）

```js
{
  id: 'heart_restore',
  kind: 'normal', trigger: 'plain', priority: 3,
  rate: 6,                       // 由 §9.2 的表动态覆盖
  when: { heart: { max: 92 } },
  choices: [
    { label: '静坐', years: 1, result: { heart: 5 } },      // 顿悟 +5
    { label: '问心', years: 2,
      check: { base: 0.5, attr: 'nature', scale: 0.005 },
      success: { result: { heart: 8 } },                     // 问心 +8
      failure: { result: { heart: -3 } } },
    { label: '大彻大悟', years: 5, show: { heart: { max: 70 } },
      check: { base: 0.2, attr: 'insight', scale: 0.008 },
      success: { result: { heart: 15 } },                    // 大彻大悟 +15
      failure: { result: { heart: -10 } } }
  ]
}
```

**出现率随境界递增**（`rate` 由状态表覆盖，不是写死的）：

| 境界 | rate | 理由 |
| --- | --- | --- |
| 凡人 / 锻体 1–2 | 2 | 还没开始想这些 |
| 锻体 3–4 / 炼气 1–2 | 4 | 开始感觉到"活得久"这件事 |
| 炼气 3–4 | 6 | 同龄人开始死 |
| 炼气 5–6 | 9 | 活得比孙子的孙子还久 |
| 养灵 | 12 | 见过太多生死，反而更容易想通 |
| 修心 | 15 | 本来就在这条路上 |

> **这一条直接回答了 r14 那个"修心窗口永久关闭"的死结**：心性地板 60、门槛 90，一旦触底就再也补不回来。**但只要高境界的心性事件足够密，触底的人还有机会靠"大彻大悟 +15"翻回来。**
>
> 所以 `rate` 从 2 涨到 15 不是数值调整，是**给这个世界留一条后路**：**越老越容易想通，虽然大多数人都没等到。**

### 9.3 气运阈值事件

气运（`fate`，0–100，均值 50）在三个位置开不同的池子：

| 气运 | 解锁 | 说明 |
| --- | --- | --- |
| **> 80** | 宝地、秘境、贵人 | 约 8% 的人 |
| 20–80 | 普通池 | 大多数 |
| **< 20** | 灾祸、横死、被劫 | 约 8%，且**资质分配区间放宽到 [0.12, 0.88]**（`角色属性与规则系统.md` §5.5.1.1） |

> **气运低不只是"运气差"，是"分配更极端"**——命薄的人更容易偏科，偏科的人更容易双 80 失败。两个惩罚叠在一起，才是"命薄"。

## 10. 与既有系统的接口

| 系统 | 接口点 | 事件侧怎么写 |
| --- | --- | --- |
| **境界** | 破境四步（瓶颈→层级→其余条件→突破） | `breakthrough` 事件只负责"这一步要不要走"，层级判定在 `境界系统总纲.md` §2.4 |
| **境界** | 瓶颈事件（22 个） | 全部是 `threshold`（7 个事件链）+ `breakthrough`（15 个单次） |
| **百艺** | `craft.*` 开关 | `school_baiji` 一次性点亮；**没点亮就不能在 `cultivate` 里出现** |
| **学府** | `school` 字段 | `none / primary / prefecture / academy` 四态 |
| **心性** | `heart` 0–100、地板 60 | 事件可以突破地板（`heartShift`），自然衰减不行 |
| **本性** | `nature` 0–100 | 只被事件改，**不被心性事件连带** |
| **灵量 / 身份** | `identity` 字段 | 身份事件（出征、朝会）用 `forced` + `plain` |
| **战斗** | 战斗后置事件 | `prereq` 挂 `battle_*` 记录 |

## 12. 与 v2 的差异（谁作废了谁）

| 项 | v2（事件系统重构.md） | v3（本文） |
| --- | --- | --- |
| 维度 | 只有内容类型八类 | **内容类型 × 触发类型 双维度** |
| 优先级 | 只有"forced 最高" | **1/2/3/4 四级，池内最小者胜** |
| 抽取 | 按状态比例掷类型 | 收集 → 截断 → 强制 → 抽类型 → 抽事件（**六步**） |
| 地域 | 无 | **`region` 五类触发之一，硬门槛** |
| 时间 | 隐含在 `when.age` | **`time` 五类触发之一，主线回归靠它** |
| 境界 | 无 | **`realm` 五类触发之一，世界认可=4 品圆满、悟道=5 品圆满** |
| 前置 | 无 | **`prereq` 五类触发之一** |
| 出现率 | `weight` | **`rate`（0–100，手调，相对权重）** |
| 选项条件 | `show` / `enable` | 沿用，**但修掉 `heart`/`nature` 混用的错误** |
| 结果 | `effects` | **`result` 四种形态**：直接/判定/随机/计算 |
| 表结构 | §5.1 | **沿用，需加 `trigger` / `priority` / `rate` / `region` / `time` / `realm` / `prereq` 七列** |
