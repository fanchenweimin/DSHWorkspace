## 0. 定位

这一份解决三件互相牵连的事：

1. **统一坐标**：境界、物品、职业都用「x 阶 x 品」说话，不再混用「品级/等级/境界」。
2. **先天差异**：命格（影响四隐藏属性）与天赋（百艺布尔值），让「芸芸众生」真的各有不同。
3. **时间尺度**：高境界延寿后，游戏不能靠「点修炼」耗时间，必须用事件与战斗填满。

| 2 | 1 | 炼气·感气 |

> 已确认：锻体第三重定名「**调息**」（原「周天」是未改完的旧名）。

### 1.2 物品三重境界

每个物品（丹药 / 兵器 / 符箓 / 阵法 / 功法 / 法术）都带三个境界值：

```js
grade: {
  rank: 1, tier: 3,        // 品阶本身：1 阶 3 品
  min:  { rank: 1, tier: 1 },   // 最低使用境界
  best: { rank: 1, tier: 3 },   // 最适合使用境界
  max:  { rank: 1, tier: 3 }    // 最高影响境界
}
```

示例：蒙学《锻体诀》= **1 阶 3 品**，最低 1 阶 1 品，最适合 1 阶 3 品，最高影响 1 阶 3 品。

**效果曲线**（替代现在写死的 `power`）：

```text
用户境界 < min        → 无法使用（按钮置灰，说明「境界不足」）
min ≤ 用户 < best     → 效果按比例从 40% 线性升到 100%
用户 = best           → 100%
best < 用户 ≤ max     → 保持 100%（成熟期）
用户 > max            → 效果 × 0.5，并标注「此物已不合你用」
```

> **2026-10-27 更新**：**功法/术法**的 `grade{min,best,max}` 取值不再自由，按「天地玄黄」四阶梯写死——天阶=品 6（门槛品 5）、地阶=品 5（门槛品 4）、玄阶=品 4（门槛品 1–3）、黄上/中/下=品 3/2/1（门槛品 1），且**不跨大境界**；黄下是流通知识。详见 [`战斗系统总纲`](战斗系统总纲.md) §6.2。丹药/兵器/符箓/阵法等**物品**仍用本节的绝对阶品，不受此梯约束。

这样「法器比凡器强太多」不是靠写死数值，而是靠品阶差直接体现：
- 凡兵 1 阶 2 品 → 锻体脏腑可用，2 阶修士用它只发挥 50%
- 法器 2 阶 2 品 → 炼气破胎可用，对锻体天然占优

### 1.3 职业品阶

| 职业 | 起步阶 | 说明 |
| --- | --- | --- |
| 炼丹 | **1 阶** | 锻体期就能学，产品可以是 1 阶 |
| 炼器 | **1 阶** | 同上 |
| 符箓 | **2 阶** | 需炼气破胎（2 阶 2 品）才能入门 |
| 阵法 | **2 阶** | 同上 |

但**产品**都可以是 1 阶：一个 2 阶符箓师仍能画 1 阶符卖钱。

职业品阶与个人品阶的关系：

```text
职业等级 = 你的百艺水准（1..5，对应 1阶初阶 → 玄品）
可炼制物品最高品阶 = min(职业等级对应阶, 你自身境界阶)
```

即：炼气期（2 阶）的炼丹师，最高能炼 2 阶丹；但若他只是凡品初阶（1 阶），只能炼 1 阶。

> 职业档位、十二门清单、天赋与年收入见 [修真百艺](修真百艺.md)。本节只定"坐标"，那份定"内容"。

### 1.4 改造范围

| 现有字段 | 改为 |
| --- | --- |
| `ITEMS[x].power` | `grade` 三重境界 + `powerAtBest` |
| `ITEMS[x].requirement` | `grade.min`（统一替代） |
| `ARTS[x].power` | `grade` + `powerAtBest` |
| `ARTS[x].grade: 'fan'` | `grade.rank/tier` |
| `METHODS[x].grade: 'fan'` | 同上，并用于修炼倍率 |
| `RECIPES[x].rank` | 按产物品阶推导 |
| `CRAFT_SKILLS[x].ranks` | 改为「1 阶初阶 / 1 阶中阶 / … / 2 阶」 |

## 2. 命格与天赋

### 2.1 命格（先天命运）

开局随机一个，**影响四隐藏属性的起点与上限**。

| 命格 | 效果 |
| --- | --- |
| 天才 | 资质/悟性/心性 各 +12，上限 +10 |
| 好运 | 气运恒定 ≥ 60，且气运下限 +10 |
| 早慧 | 悟性 +15，但心性 −8 |
| 铁骨 | 资质 +18，悟性 −6 |
| 道种 | 心性 +15，资质 −8 |
| 凡人 | 无加成，四属性随机（默认档） |
| 薄命 | 四属性各 −6，但气运 +8、寿元 −10（补偿型） |

命格与现有「出身 / 幼年 / 命兆」三段不冲突：命格是**第四段**，权重更高、影响更大。

> ❓**待确认**：命格是否可后天改变？建议**不可**，但可在特定事件里「认命」或「逆命」，给一次性小修正。

### 2.2 天赋（百艺）

现有 `craftTalents` 是 18–94 的数值。改为**布尔 + 强度**：

```js
craftTalent: {
  alchemy:  'none' | 'minor' | 'major',   // 无 / 有 / 卓绝
  forging:  ...,
  talisman: ...,
  formation: ...
}
```

| 天赋 | 可达到的职业上限 |
| --- | --- |
| 无 | 1 阶初阶（能入门，但一辈子停在这里） |
| 有 | 与自身境界同步（最高 3 阶） |
| 卓绝 | 可越一阶（炼气期就能炼 3 阶物） |

「有就是有，没有就是没有」——天赋不通过修炼获得，只在开局与极少数机缘事件里确定。

## 3. 寿元

### 3.1 境界对应寿元

> ⚠️ **本节已改口径（2026-10-26 夜）**。权威表在 [`境界系统总纲`](境界系统总纲.md) §9，此处只留结论。

规则一句话：**前三个大境界的前两个小境界不加寿元，第三个小境界起，每进一品加一次。** 修心四品全加。

| 境界 | 寿元 | 说明 |
| --- | --- | --- |
| **凡人（锻体·体魄 / 脏腑 · 炼气·感气）** | 60–85 | **没换过命**。也是"安生活法"的天花板 |
| 锻体·调息（1 阶 3 品） | 90–105 | **第一次跃升** |
| 锻体·朝元 | 110–130 | |
| 锻体·金身 | 300–350 | 第五品，够站满一两百年 |
| 锻体·临虚 ★ | **1,000** | 极境统一值 |
| 炼气·感气 / 破胎 | 不加 | 结胎不算改命 |
| 炼气·驭凡（2 阶 3 品） | 150–180 | 炼气第一次跃升 |
| 炼气·法相 | 200–240 | |
| 炼气·合一 | 350–400 | 第五品 |
| 炼气·化朽 ★ | **1,000** | 极境统一值 |
| 养灵·开视 / 启灵 | 不加 | 前段 70 年靠续命（城主缺 46 年，三丹够） |
| 养灵·真域（3 阶 3 品） | **400** | |
| 养灵·神游 | 700–780 | 210 岁到达（100 年到真域口径） |
| 养灵·浑然 | 950–1,000 | 360 岁到达 |
| 养灵·回春（3 阶 6 品） | **∞（返老）** | 年龄重置回 30 岁，可反复；代价 灵量减半 + 心性 −2 |
| 修心·不惑 ★ | 1,000 | 极境 |
| 修心·天命 ★ | 1400 | |
| 修心·耳顺 ★ | 2000 | |
| 修心·从心而欲 ★ | 3000 | |
| 转世重修 | 重置（**心性不重置**） | 见 §3.3 |

> 旧说法「养灵回春理论上无限，但没修心也就 1000」本轮作废：**回春现在就是 ∞**（靠返老重置年龄），转世重修是另一条 ∞（换身体重来）。1,000 变成**极境的门槛值**（临虚 / 化朽 / 不惑 都是 1,000），不再是硬顶。
>
> 另：原文"凡人 = 未入锻体·朝元"的口径已作废（调息就该跳，不该等到朝元）。现在的"凡人"＝**体魄 / 脏腑 / 感气**，是"没换过命的人"，也是安生活法的上限。85–400 岁这一段靠**续命**填（延寿丹 +80 年已够城主，见 总纲 §9.5）。

### 3.2 落地方式

```js
// 不再用「每升一重 +2 年」的线性叠加，也不再用「取 max」的覆盖写法
// 已定：境界给底子，额外寿元（延寿丹/宝药/机缘）永久叠加
// 权威写法见 境界系统总纲.md §9.6
lifespan = 境界下限 + 已掷好的区间随机量 + extraLife;
// 随机量进品时掷一次并存下，不要每次重算（否则读档能刷）
// extraLife 是角色卡字段：延寿丹三档各限一次（+10/+20/+50，上限 80）+ 宝药 + 机缘
```

> **为什么不再用 `max(当前, 下限 + rand)`**：那个写法下，凡阶段吃的延寿丹在你踏进真域那天会被 400 覆盖掉——白吃了 75 年的命。叠加口径下，同一份 `extraLife` 加在不同底座上（400+80 / 700+80 / 950+80），**终身有效、不被覆盖**。这条决定的连锁后果是：将军缺 21 年、宗主缺 44、家主缺 78、城卫缺 116，**补上就通顶**，不再是"补了也死"。

同时保留「芸芸众生」的体感：

- 绝大多数人走不到调息，实际游戏长度仍集中在 60–120 年。
- 寿元跳到 300 以上需要进第五品；跳到 1,000 是极境（三道第六品 + 修心不惑）；**∞ 只有两条路：养灵·回春返老、修心转世**。
- **每次寿元跃升都会触发一次「寿元暴涨事件」**（亲友老去、城池变样、旧人成土），用来体现时间跨度。

### 3.3 转修（转世重修）

修心任意重之后可以「转修」——**转世重修，重开一世**。

| 项 | 规则 |
| --- | --- |
| 触发 | 修心任意重（不惑起） |
| 保留 | **命格 + 心性** —— 因为「自己还是自己」，只是换了一具身体 |
| 不保留 | **天赋**（重新随机）、境界、寿元、物品、金钱、身份、记功 |
| 重置 | 年龄回到 7 岁，从蒙学开始 |
| 性质 | **二周目**，不是新局——继承同一条命途记录，标记 `reincarnation: N` |
| 次数 | 无上限 |

> ⚠️ **心性不重置（2026-10-26 定）**。这条比"命格保留"更重要：
>
> - 心性练到 95 的人，转世后还是 95，下一世能直接再修心、再转世 → 真正无限；
> - **心性跌破 90 的人，转世一百次也进不了修心**——因为修心的门是心性 90，而他带过去的就是崩掉的那个自己。
>
> 所以修心是唯一一条**不可回滚**的进度条：死只是结束一世，心性崩了是永久失去入口。心性只能靠极稀少的「回心」事件抬回来。

界面上表现为：旧一世进入「前世录」，新一世带着命格与少量「前世余韵」（可选：一次提升初始某属性的机会）。

> 这样「无限活」的设定就成立了：修心 → 寿尽 → 转修 → 再来一世，且命格与心性不变、自己仍是自己。

### 3.4 另一条无限：养灵·回春的「返老」

回春（3 阶 6 品）不靠转世，靠**在同一具身体里重置年龄**：

```text
效果：年龄 = 30 岁，境界 / 修为 / 养灵层级 / 记忆 / 物品 全部保留
冷却：100 年一次
代价：灵量减半（治下生灵枯竭一批，须重新经营）、心性 −2
```

> 结果同样是无限寿元，但性质完全不同：**转世是放弃一切重来，返老是抱住一切不放**。所以回春者必然是最不肯交权的人——每一次返老，都要重新把势力攒回来。

## 4. 战斗事件密度

养灵之后静修无效，如果没有足够战斗，玩家会「点几百年」。

### 4.1 事件配比目标

| 阶段 | 战斗类事件占比 | 说明 |
| --- | --- | --- |
| 蒙学（7–11） | 10% | 以学业为主 |
| 府学（11–15） | 10% | 保证太学大考 |
| 太学（15–20） | 25% | 开始接触斗法 |
| 卒业后（20–80） | 40% | 江湖与秘境 |
| 养灵后（80+） | **60%** | 不战斗就没事做 |
| 修心后 | 50% | 心关 + 战斗 |

### 4.2 新增战斗事件（暂定 8 个）

| 事件 | 适合境界 | 激烈级别 |
| --- | --- | --- |
| 同门切磋 | 1–2 阶 | 切磋（可认输） |
| 坊市争宝 | 1–3 阶 | 斗法（可遁走） |
| 秘境夺宝 | 2–3 阶 | 生死斗 |
| 护道之战 | 2–3 阶 | 生死斗 |
| 宗门试炼 | 2–3 阶 | 斗法 |
| 北关再战 | 2–4 阶 | 生死斗 |
| 老怪拦路 | 3 阶 | 生死斗（可能被碾压） |
| 大道之争 | 3–4 阶 | 不死不休 |

每条都带一个「认输 / 遁走」的可用性判断，见 [战斗系统改造计划](战斗系统改造计划.md) §4。

### 4.3 长寿的时间感（已定方案）

寿元跳到 500 年，如果每年只是「修炼一年」，玩家要点上千次。用两个机制解决：

**方案 A：长跨度事件**
某些选择本身就是「十年八年」：
- 顿悟 = 8–12 年
- 闭关 = 20–50 年
- 云游 = 15–30 年
- 养灵后的常规事件，单位默认 5–10 年

**方案 B：无选择的轮播事件**
不打断玩家，直接在时间轴上「快进」：
- 系统连续生成 3–8 条「这些年」短叙事（故人成土、城中换了三任城主、灵田荒了又开）
- 每条不带选项，只展示
- 遇到需要抉择的事才停下

两者结合：

```text
玩家做出「闭关 20 年」的选择
  → 结算修为与机缘
  → 插入 2–3 条轮播事件（不打断）
  → 停在下一个需要选择的事件
```

轮播事件数据结构（无 choices）：

```js
{
  id, icon, title, body,
  years: 5,           // 这一条代表多少年
  passive: true,      // 无选项，自动播放
  effects: {...}      // 可选，自动结算
}
```

前端用「时间流」样式逐条淡入，可逐条推进或一键跳过。
