## 0. 为什么必须重构

现有 40 个事件写死在 `content.js`，是**扁平数组 + 权重随机**。六个问题：

1. 所有事件平等竞争，不分类型。
2. 选项静态：只能置灰，**做不到「命格恶人才出现恶选项」**。
3. 修炼与委托在「事件之外」的抽屉里，不是一套模型。
4. 年限与年龄脱节。
5. 内容量不够，40 个事件跑 80 年明显重复。
6. 全在代码里，管理员改不了。

## 1. 八类事件（定稿）

### 1.1 槽位事件（互斥，一轮只出一个）

| # | 代号 | 名称 | 需要选择 | 优先级 | 说明 |
| --- | --- | --- | --- | --- | --- |
| ① | `ambient` | 默认事件 | ❌ | 低 | 纯展示，不需要选择 |
| ② | `normal` | 普通事件 | ✅ | 低 | 主要剧情 |
| ③ | `encounter` | 奇遇事件 | ✅ | 低 | 机缘、陷阱、传承 |
| ⑦ | `threshold` | 门槛事件 | ✅ | 中 | 突破瓶颈、迈入门槛的**事件链** |
| ⑧ | **`breakthrough`** | **破境事件** | ✅ | 中 | 修为满时的**破境抉择** |
| ⑤ | `forced` | 强制事件 | ✅ | **最高** | 由身份/处境触发，压制一切 |

**互斥**：① ② ③ ⑦ ⑧ 五者互斥，一轮只出一个。
**优先级**：⑤ 强制 > ⑦ ⑧ 条件必出 > ①②③ 掷骰。

### 1.2 常驻行动（不占槽位，永远可选）

| # | 代号 | 名称 | 说明 |
| --- | --- | --- | --- |
| ④ | `cultivate` | 修炼 | 功法、术法、兵器、百艺 |
| ⑥ | `commission` | 委托 | 按年份刷新的任务 |

### 1.3 ⑦ 门槛事件 vs ⑧ 破境事件

两者现在都是独立事件类，但作用不同：

| | **⑦ 门槛事件** | **⑧ 破境事件** |
| --- | --- | --- |
| 触发时机 | 事件链上下一步条件满足 | **修为攒满、卡在关口** |
| 解决什么 | **入场资格**（能不能进这一道） | **过关判定**（这一关过不过） |
| 例子 | 病榻边 → 荒寺石壁 → 大彻大悟 | 炼气·破胎满了 → 服宝物 / 去宝地 / 请灌顶 |
| 概率 | **正常概率**，不手动调高 | 修为满时**必出**（条件必出） |
| 错过后果 | 就错过了，没有后悔药 | 修为一直留着，可以下次再出 |

**关键修正**：⑦ 门槛事件的概率**保持正常水平**，不因为是门槛就调高。
错过了就是错过了——这是设计意图，不是 bug。

**一句话**：⑦ 决定「你有没有资格去试」，⑧ 是「你现在要不要试」。

### 1.4 门槛事件链（⑦）

| 门槛 | 事件链 | 解决 |
| --- | --- | --- |
| 修心 | `life_chain` → `great_awakening` → `awakening_complete` | 拿 `life_and_death` + `great_awakening` + `heart_open` |
| 养灵 | `spirit_comprehend` | 拿 `life_understanding`（需双四重 或 太学+资质80+悟性80） |
| 世界认可 | `save_city` / `legacy` | 拿 `worldRecognition`（需该道第四重修为圆满） |
| 悟道 | `dao_insight` / `heart_demon` | 拿 `trueDao` |
| 炼气灌顶 | `borrow_insight` | 开启 ⑧ 破境事件（成功率减半） |

### 1.5 触发规则

```text
每次抽取槽位事件时：
  1. 有 forced？                  → 出 forced
  2. 修为满且未在闭关/战斗中？      → 出 ⑧ 破境事件
  3. 否则 ①②③⑦ 按正常概率掷骰

⑦ 的权重与其他普通事件同级别，不额外加权。
玩家这次没抽到，就只能等下一次。
```

## 2. 抽取流程

```text
每回合开始：
  1. 有 forced（⑤）？                → 出 forced
  2. 修为满且可破境？                 → 出 ⑧ 破境事件（必出）
  3. 否则掷 r ∈ [0,1)，按当前状态取比例区间：
       ① ambient   p1
       ③ encounter p2
       其余 = ② normal + ⑦ threshold（两者同池，按各自权重）
  4. 无论出哪类，页面下方永远同时展示：
       ④ 修炼   ⑥ 委托
```

> ⑧ 破境事件是「条件必出」，不参与概率掷骰。修为满了就一定会问你要不要破。

### 2.1 比例随状态变化

先按角色状态取一个**区间**，区间内随机一个比例，再归一化，最后掷骰定类。

| 状态 | ambient | encounter | normal |
| --- | --- | --- | --- |
| 蒙学（7–10） | 8–12% | 3–6% | 余下 |
| 府学（11–14） | 8–12% | 3–6% | 余下 |
| 太学（16–19） | 12–18% | 8–12% | 余下 |
| 有身份（将军/城主/宗主） | 12–18% | 8–12% | 余下 |
| 无身份散修（20+） | 25–35% | 15–25% | 余下 |
| 养灵以后 | 35–45% | 15–25% | 余下 |
| 修心以后 | 30–40% | 20–30% | 余下 |

> 范围而不是定值，是为了「同一状态下不同回合节奏也不同」。

### 2.2 强制事件的交互（已定）

强制事件出现时，页面**仍显示** ③修炼 ④委托 ⑤破境，但点击会被拒绝并给出理由：

```text
「将军召你出征，此刻不能闭关。」
「衙门催税，先缴了再说。」
「宗门令牌已下，不得延误。」
```

这样玩家能看到「我本来可以做什么」，压力更具体，也不会觉得界面抽风。

## 3. 选项条件系统（重构核心）

### 3.1 两类条件，行为不同

```js
choice: {
  id, label, hint, tags,
  years: 1,

  // 不满足 → 选项根本不出现
  show: {
    fate: ['villain'],              // 命格含恶人
    nature: { max: 40 },            // 本性恶（不是心性！心性低不解锁任何选项）
    identity: ['general', 'sect'],  // 身份
    flags: { evil_path: true },
    attribute: { insight: { min: 80 } },
    realm: { key: 'qi', tier: { min: 2 } }
  },

  // 不满足 → 出现但置灰，附理由
  enable: {
    money: 10000,
    items: { peiyuan_pill: 1 },
    stage: { qi: 2 }
  },

  effects | check, success, failure
}
```

- `show` 不满足 → **压根不出现**（恶人专属选项，好人永远看不到）。
- `enable` 不满足 → **出现但灰掉**，写明缺什么。

### 3.2 条件宏

| 宏 | 等价 |
| --- | --- |
| `goodOnly` | `heart >= 70 且 fate 不含 villain` |
| `evilOnly` | `heart <= 40 或 fate 含 villain` |
| `bodyOnly` / `qiOnly` / `spiritOnly` | 对应境界已解锁且品阶达标 |
| `inCity` / `inArmy` / `inSect` / `inClan` | 身份判定 |

## 4. 年限与年龄（全局唯一时间源）

### 4.1 规则

```text
1. 每个选项只声明 years。
2. advanceAge 严格执行 years，不允许调用方传默认值。
3. state.age 是全局唯一时间源，所有判定读它。
4. 年限可跨越年龄门槛，但跨越后必须重新检查：大考、学籍、寿元、身份事件。
```

### 4.2 闭关 / 长跨度选择（已定）

```text
玩家选「闭关」，手动输入年限
  上限 = min(50, 寿元剩余 - 1)
  → 系统一年一判定
  → 每年检查：钱够不够、有没有强制事件、修为涨多少、有没有走火入魔
  → 第 5 年钱花光 → 第 6 年插入强制事件「欠税劳役」→ 闭关中断
  → 最后汇总：共闭关 5 年，修为 +X，遭遇 2 件事
```

这要求 `advanceAge` 支持**逐年回调**，而不是一次性加。

## 5. 事件入库

### 5.1 表结构

```sql
CREATE TABLE events (
  id TEXT PRIMARY KEY,
  kind TEXT NOT NULL,        -- ambient|normal|encounter|threshold|breakthrough|forced|cultivate|commission
  title, icon, kicker, body,
  years INTEGER DEFAULT 1,
  weight INTEGER DEFAULT 10,
  when_json TEXT,            -- 触发条件
  choices_json TEXT,         -- 选项数组
  enabled INTEGER DEFAULT 1,
  source TEXT,               -- builtin|custom
  created_at, updated_at
);
```

- 启动时把 `content.js` 内置事件同步进表（`source='builtin'`）。
- 管理员改内置事件：**覆盖正文与数值，保留 id**；「恢复默认」回到代码版本。
- 新增事件 `source='custom'`，不被同步覆盖。
- 存档只存事件 id + 选项 id，事件内容变更不影响旧档。

### 5.2 缓存

内存 Map，保存后热更新，无需重启。

## 7. 内容规划

### 7.1 数量目标

| 类 | 现有 | 目标 |
| --- | --- | --- |
| ① ambient | 0 | 40 |
| ② normal | 35 | 120 |
| ③ encounter | 5 | 60 |
| ⑤ forced | 6 | 40 |
| ⑦ threshold | 6（已合并在现有） | 25 |
| ⑧ breakthrough | 0 | 12（按道 × 重数） |
| ④ cultivate | 0 | 15 |
| ⑥ commission | 生成器 | 20 模板 |
| 合计 | 40 | **332** |

### 7.2 样例题材（贴合背景）

**ambient（无选项，纯展示）**
- 城中又换了季节，灵田里的稻子熟了第三茬
- 你听说北关又起战事，与你无关
- 幼时玩伴的儿子，如今也进蒙学了
- 五十年过去，长明城的城墙翻修了两次
- 你手下的东城门换了三任总管，你只记得第一任的名字

**normal（普通）**
- 同门请你帮忙（帮 / 拒 / 收钱帮）
- 城里有人卖来历不明的丹药（买 / 查 / 报官）
- 老友的儿子求你收留
- 账房催税（交 / 拖 / 理论）
- 下属请求调职（准 / 拒 / 亲自去谈）

**encounter（奇遇）**
- 山中遇古洞（进 / 绕路 / 留记号）
- 路边垂死修士托付（听 / 走 / 夺宝——夺宝需恶人）
- 老人卖一部残缺功法（买 / 不买 / 抢——抢需恶人）
- 有人告诉你「杀人可以炼丹」（**邪恶路线告知入口**，仅恶人命格/低心性出现）

**forced（强制，按身份）**
- 将军：开战了，必须出征
- 宗主：长老派下事务
- 城主：朝会 / 赈灾 / 政敌弹劾
- 居民：缴税日，没钱强制劳役
- 太学生：季考
- 邪修：仙司上门

**cultivate（修炼，常驻）**
- 修炼当前功法
- 参悟新术法
- 练兵器
- 炼丹 / 炼器 / 画符 / 刻阵（需百艺）
- 打坐（低效但不花钱）
- **闭关**（手动输入年限，逐年判定）

**threshold（门槛事件链，⑦）**
- 病榻边 → 荒寺石壁 → 大彻大悟（修心）
- 感悟生命（养灵）
- 洪水围城 / 衣钵（世界认可）
- 问心 / 心魔（悟道）

**breakthrough（破境事件，⑧，修为满时必出）**
- 锻体：服丹 / 药浴 / 洗髓 / 找机缘 / 灌顶
- 炼气：宝物 / 宝地 / 明悟 / 灌顶（丹药无效）
- 养灵：认知事件 / 机缘（静修无效）
- 修心：心关事件（可能跌落或身死）

## 8. 邪恶路线（隐藏）

三个入口任一成立才解锁：

```text
1. 命格含「恶人」
2. **本性 ≤ 40**（`[改]` r13：旧稿写"心性 ≤ 40"，与"心性不是道德"冲突，已改）
3. 奇遇被告知（获得 flag: knows_blood_alchemy）
```

| 选项 | 效果 | 代价 |
| --- | --- | --- |
| 杀人取丹 | 破境成功率 +40% | 心性 −10、`wanted`、仙司追 |
| 掠夺法器 | 直接得装备 | 心性 −5、声望 −3 |
| 以人养灵 | 养灵修为 +20 | 心性 −15、全城通缉 |

普通人**永远看不到这些选项**。

## 9. 界面改造（不换行）

### 9.1 原则

```text
一行一件事：
  第一行  标题（超长才折行，折在标签之前）
  第二行  提示 + 标签 + 年限 + 不可用原因，全部横排，不折行
  宽度不够：整体横向滚动，不换行
```

### 9.2 具体

- `.story-choice` 改 `grid-template-columns: 34px minmax(0,1fr)`，内部两行。
- 第二行 `display:flex; flex-wrap:nowrap; overflow-x:auto;`。
- 标签 `white-space:nowrap`。
- 「约 N 年」固定右侧。
- 战斗行动按钮同样。
- `change-chips` 单行横向滚动。

### 9.3 ambient 轮播

一年一年展示：第一年 3 秒、之后 2 秒、最后停 5 秒。
**提供「加速观看」按钮**（只是变快，不是跳过）。
