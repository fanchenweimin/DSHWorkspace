## 1. 四道总纲

### 1.1 锻体 —— 资质决定一切

| 规则 | 落地 |
| --- | --- |
| 资质越高，每次修炼收益越高 | 锻体系数跨度最大：资质 30 → ×0.60，资质 95 → ×1.85 |
| 事件收益同样吃资质 | 事件 `prof` 与修炼共用 `applyTraining`，自动继承 |
| 前三重可服丹药、珍贵药材、外力冲刷 | 保留并扩充：丹药 / 药浴 / 洗髓 / 喂招 |
| 资质越高越不易瓶颈 | 前三重自然突破率直接由资质线性决定 |
| 资质越低越易瓶颈 | 资质 40 以下常年卡在一、二重 |
| 第四重人人有瓶颈，难易随资质 | 改为「机缘」制：所需机缘点数按资质递减（1–4） |
| 第四重不能靠重试 | 机缘不足时，闭关/苦修按钮置灰，只留「出门寻找机缘」 |

### 1.2 炼气 —— 气之掌握，丹药无效

| 规则 | 落地 |
| --- | --- |
| 修炼与判定主看悟性 | 炼气系数由悟性决定 |
| **普通丹药不能破境** | `policy = 'treasure'`：破境列表**不出现**任何丹药；战斗中回气丹仍可用 |
| 短暂提升悟性的宝物有用 | 新增「悟性宝物」，给 `insightBuff`（持续 N 年），修炼、破境、事件判定全部吃这个 buff |
| 可去历练、追寻偶然出现的宝地 | 新增「宝地」事件，有出现窗口；三处地点各有属性门槛，成功给大量气悟 + 宝物/机缘 |
| 第四重需自身努力 + 一点明悟 | `type = 'insight'`：机缘 + 明悟双判定（悟性 + 心性） |
| 资质不够可请高人灌顶 | 见 §3，灌顶必付代价且**永久失去认可资格** |

### 1.3 养灵 —— 只认认知，不认外力

| 规则 | 落地 |
| --- | --- |
| 寻生命本质，不能靠外力 | `policy = 'opportunity'`：丹药、药浴、灌顶、静修**全部不给修为** |
| 没有机缘一辈子止步很正常 | 修为只能通过「认知类事件」获得，不给保底、不给年限累积 |
| 太学只教「养灵是什么」 | 太学给 `spirit_known` 标记 + 功法，**不解锁境界** |
| 门槛是对生命本质有认识 | 解锁需 `life_understanding`（由「感悟生命」判定获得） |
| 锻体+炼气均第四重才有资格感悟 | 「感悟生命」资格 = `body.stageIndex >= 3 且 qi.stageIndex >= 3`，或已在太学且经历过生死 |

**关键改动**：`applyTraining` 对养灵直接返回 0（静修无效），修为只能由事件 `prof: { spirit: N }` 且事件被标记为 `cognition: true` 时给。

### 1.4 修心 —— 最难，且会倒退

| 规则 | 落地 |
| --- | --- |
| 非大彻大悟、明心见性不可入 | 保留三段链（经历生死 → 大彻大悟 → 心关），心性门槛提到 **90** |
| 每进一步都是自我认知的升华 | 每一重单独写「心关事件」，不套通用概率 |
| 化凡不一定提升，可能跌落/走火入魔 | 化凡改四分支：升华 / 白费 / **跌落一重** / **走火入魔（终局）** |
| 心魔九死一生 | 心魔失败有明确致死概率 |

## 2. 步入门槛

### 2.1 感气：进府学 ≠ 能感气

现状：11 岁 `applyMilestones` 直接解锁炼气并发功法。**必须移除。**

新流程：

```text
11 岁入府学 → 获得「引气篇」读本（qi_known），炼气仍 locked
每年一次「感气」判定（qiSense）：
  概率 = 20 + (悟性 - 50) × 0.9 + 气运 × 0.1 + 已读年数 × 3
  成功 → 解锁炼气（感气），获得功法
  失败 → 这一年白过，qiYears + 1，悟性 +1（屡败略有体感）
一生最多判定 (15 - 11) + 若干年，可能一辈子感不成
```

配套：`applySchoolPassive` 不再给府学白送炼气修为（否则必成）。

### 2.2 养灵：太学只是知情

```text
通过太学大考 → education.stage = 太学
             → flags.spirit_known = true（知道养灵是什么、怎么修）
             → 给《太学观灵经》，但 realm.spirit.unlocked 仍为 false

感悟生命（comprehendLife）：
  资格：生活过（有 near_death / life_and_death 之一），且
        (body.stageIndex >= 3 且 qi.stageIndex >= 3)  或  (太学在读且 life_understanding)
  判定：25 + (悟性-50) × 0.7 + (资质-50) × 0.3 + 生死经历加成
  成功 → life_understanding = true → 解锁养灵
  失败 → 这一年白过，可再来（每年一次）
```

### 2.3 世界认可：必须先有一道修为圆满

```text
canSeekRecognition(state) =
  存在某一大境界：stageIndex === 4 且 prof === 100（即「金身/合一/浑然」修为已满，正卡在圆满关）
  且 !state.flags.borrowed_insight（灌顶者永久失格）
```

未达标时，事件里的 `worldRecognition` 被 `applyEffects` 拦下，降级为「记功 +5」，并提示：
「这一份认可太重，你现在的境界还承不住。」

同时：`processProgression` 里 `world` 型关卡只在满足上式时才允许挂起等待；否则根本不进入 `awaiting`，而是提示「还不到谈认可的时候」。

## 3. 灌顶（借他人之悟）

### 3.1 核心：灌顶不是「替你破关」，是「让你有机会试」

你的原话：炼气·感气进不了破胎，找大佬灌顶，**灌顶后自己进入破胎的概率只有正常的 50%**。

所以灌顶的语义是：

```text
灌顶 = 大佬把「境界的门」给你推开一条缝
     → 你自己仍然要突破
     → 但成功率只有正常的一半（50%）
     → 每次额外灌顶，这个比例再降
```

### 3.2 数值

```text
第 1 次灌顶：突破成功率 = 正常值 × 0.50
第 2 次灌顶：          × 0.35
第 3 次灌顶：          × 0.25
第 4 次起：            × 0.15
（只在同一道、同一品上叠加；换品重新计数）

跨大境界（炼气·法相 → 养灵·开视）：
  固定 0.001%，且不受灌顶次数加成
  这就是「传说能实现，实际几乎不实现」
```

### 3.3 代价（每次灌顶都付，成功与否都付）

| 代价 | 数值 |
| --- | --- |
| 心性 | −6（自认走了捷径，与「对自我的确信」直接冲突） |
| 钱财 | 大量铜钱，或一件法器/材料 |
| 人情 | `flags.owe_favor = true`，后续可能被讨债 |
| **世界认可** | 灌顶过的人**永久失去世界认可资格**（这是「上限拉得很低」的落地） |
| 明悟 | 之后该道的明悟判定 −30% |

> 所以灌顶是一条「能过，但过完就废了上限」的路。它存在的意义不是主流玩法，而是给卡死的人一个「聊胜于无」的出口，以及给剧情提供「借他人之道」的悲剧感。

### 3.4 什么时候能用

- 只在 `bottleneck` 阶段出现，作为「破境手段」之一。
- 需要找得到高人：太学在读 / 有 `master_lu` / 有宗门 / 花钱请散修（钱要够多）。
- 每一品独立计数，`borrowed[realmKey][stageIndex]` 记录灌顶次数。

### 3.5 与「第六重」的关系

灌顶出来的人照样能修到第六重（极境），只是**永远拿不到世界认可**，因此卡在第五重（`awaiting: 'world'` 永不满足）。这是设计上的「天花板」，不是死锁——玩家仍可继续修其他三道。

## 4. 心性与本性（两个概念）

**这是本轮最重要的拆分。**

| 字段 | 名称 | 是什么 | 影响 |
| --- | --- | --- | --- |
| `hidden.heart` | **心性** | 心性**坚韧程度**，对自我的确信 | **只影响修心境界的门槛（90）与突破** |
| `hidden.nature` | **本性** | 善恶倾向（0–100） | 恶选项、NPC 态度、事件分支 |

### 4.1 两者互不干涉

你的原话：

> 心性 95，但本性是坏的，是个大恶人。这不影响他进入修心境界，也不影响他屠城。

所以：

```text
心性 95 + 本性恶 → 可入修心（心性够）
                → 可屠城（本性恶，恶选项开放）
                → 屠城本身不降心性
                → 只有「屠完开始怀疑自己」才降心性
```

### 4.2 心性的升降（与善恶脱钩）

| 升 | 降 |
| --- | --- |
| 大彻大悟 | 自我怀疑 |
| 战胜心魔 | 被否定后动摇 |
| 直面本心、承担不可逆抉择 | 反复改换道路 |
| 天下反对仍不改其道 | 借他人之悟（灌顶 −6） |
| 以弱胜强、确立自信 | 以为必胜却惨败 |

**救人与屠城本身都不动心性。** 只有「这件事让你更信自己 / 更怀疑自己」才动。

- 衰减：`heart_open` 前每 3 年 −1；`heart_open` 后每 6 年 −1。
- 门槛：**90**。
- 意象：`心湖易澜 / 心有定见 / 澄如止水 / 万劫不疑`。

### 4.3 本性的偏移

```text
初始：按命格给定（恶人命格 10–25，赤子 70–90），否则随机 35–65
偏移：每次善恶选择 ±1~5
区间：0–100（0–20 大恶 / 21–40 恶 / 41–60 中性 / 61–80 善 / 81–100 大善）
```

本性只影响「能选什么」「别人怎么看你」，不影响修心。

详见 [本性心性命格天赋](本性心性命格天赋.md)。

## 5. 数值方案

### 5.1 修炼收益

```js
attrCoef(realm) =
  锻体: clamp(0.35 + 资质 / 65, 0.55, 1.90)     // 30→0.81  50→1.12  80→1.58  95→1.81
  炼气: clamp(0.35 + 悟性 / 65, 0.55, 1.90)     // 计入 insightBuff
  养灵: 0                                        // 静修无效，只认事件
  修心: clamp(0.30 + 心性 / 80, 0.45, 1.60)

gain = base × 主修权重 × 功法系数 × attrCoef × 随机(0.90~1.10)
```

> 养灵为 0 是硬规则，需在 `applyTraining` 里对 `policy === 'opportunity'` 直接短路，避免被通用加成绕过。

### 5.2 前三重自然突破率

```js
锻体: 32 + (资质-50) × 1.15 + 气运 × 0.10      // 30→11%  50→32%  80→67%  95→84%
炼气: 22 + (悟性-50) × 0.95 + 悟性buff × 0.85   // 丹药不参与
养灵:  6 + 认知层数 × 4 + (悟性-50) × 0.3       // 极低，靠认知事件堆
```

失败 → 进瓶颈页；瓶颈页给的手段**每种资源只结算一次**，不再「重试 +6%」。

### 5.3 第四重（大成）

```js
所需机缘 need：
  锻体: 资质≥85→1  ≥65→2  ≥45→3  else→4
  炼气: 悟性≥85→1  ≥65→2  ≥45→3  else→4   且需明悟判定（悟性+心性）
  养灵: 固定 3                             不减免
  修心: 心性≥85→1  ≥70→2  else→3

判定 = 45 + (主属性-50) × 0.6 + 机缘 × 5 + 明悟加成
失败：机缘减半（向下取整），需重新积累
```

无机缘 → 闭关/苦修/服丹全部置灰，只留「出门寻找机缘」（1 年，按属性判定获得 1 点机缘）。

### 5.4 第五重（圆满）

满足 §2.3 资格后，`awaiting = 'world'`，等待「世界认可」事件。三个大境界共用一次认可。

### 5.5 第六重（大圆满）

需 `trueDao`；灌顶者不受影响（他们本来就卡在第五重）。

## 7. 配置真正联动（你特别强调的一条）

现在配置的 `difficulty` / `type` / `allowPills` 只影响极少数分支，`note` 完全只是文字。改造后每个配置项都必须落到判定里：

| 配置项 | 现在的效果 | 改造后必须影响 |
| --- | --- | --- |
| `difficulty` | 只进 `naturalChance` 与瓶颈概率 | 同时进 `breakthroughChance`、第四重判定、战斗压制换算 |
| `allowPills` | 只有锻体在读它 | 由 `policy` 统一裁决，且**同一 policy 下所有大境界一致** |
| `policy` | 无 | 决定瓶颈手段池、静修是否有效、能否灌顶 |
| `type` | 决定是否挂起/开瓶颈 | 新增 `fortune`/`insight` 的独立流程 |
| `allowEmpower`（新） | 无 | 该重是否出现「灌顶」选项 |
| `attribute` | 影响修炼系数 | 同时影响**事件判定**与**战斗中的属性加成** |
| `combatRank`（新） | 无 | 战斗压制等级 |
| `suppressionWeight`（新） | 无 | 压制强度 |

## 9. 与其他文档的关系

- **品阶**：境界现在有统一的 `rank/tier`（阶/品）坐标，物品按「最低 / 最适合 / 最高影响」三档折算。见 [品阶命格寿元](品阶命格寿元.md)。
- **战斗**：境界不只是修炼速度，还是**手段代差**（锻体拦不住法力、炼气拦不住灵力）。见 [战斗系统改造计划](战斗系统改造计划.md)。

- **心性/本性**：已拆成两个字段，见 [本性心性命格天赋](本性心性命格天赋.md)。
- **身份**：养灵修炼只看「灵量 = Σ人数×境界权重」，见 [身份系统](身份系统.md)。
