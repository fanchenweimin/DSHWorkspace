## 0. 核心结论（你的定稿）

1. **境界提升不是六边形变强，而是手段变多。**
   属性本身涨得有限，真正拉开差距的是：能不能外放法力、能不能御器、能不能用灵器、能不能看破。
2. **某些手段低境界根本无法抵抗。** 炼气破胎外放法力，锻体就是拦不住；养灵启灵的灵力，炼体和炼气都拦不住。
3. **两套独立的高位层**：
   - 锻体·临虚 / 炼气·化朽 / 养灵·回春（三个第六重）
   - 修心四重（不惑 / 天命 / 耳顺 / 从心而欲）
   这 **7 个境界单列一层**，对其它所有小境界**全胜无败**；只有这 7 个互相打才有胜负。
4. **法器/法术都是行动回合**，没有「一心二用」天赋就只能一个一个来。
5. **战斗分级**：切磋 / 斗法 / 生死斗 / 不死不休，决定能否认输、能否遁走。
6. **0.001% 保留**：传说可以发生，实际几乎不发生。

## 1. 境界压制：两层制

### 1.1 第一层：常境（普通小境界之间）

```text
阶 = 大境界序号（锻体1 / 炼气2 / 养灵3）
品 = 小境界序号（1..6）

D = (atk.阶 - def.阶) × 6 + (atk.品 - def.品) + 修为微差
```

| D | 档位 | 输出 | 受伤 |
| --- | --- | --- | --- |
| ≥12 | 天堑 | ×2.6 | ×0.35 |
| 9~11 | 碾压 | ×2.1 | ×0.45 |
| 6~8 | 强压 | ×1.6 | ×0.62 |
| 3~5 | 略优 | ×1.25 | ×0.82 |
| −2~2 | 持平 | ×1.00 | ×1.00 |
| −5~−3 | 略劣 | ×0.85 | ×1.18 |
| −8~−6 | 被压 | ×0.65 | ×1.45 |
| −11~−9 | 被碾压 | ×0.48 | ×1.75 |
| ≤−12 | 必败 | ×0.32 | ×2.10 |

效果校验：
- 炼气·感气(2,1) vs 锻体·体魄(1,1)：D=+6 → 强压
- 炼气·感气(2,1) vs 锻体·周天(1,3)：D=+4 → **只是略优**（压制力下降，符合你的要求）
- 炼气·驭凡(2,3) vs 锻体·金身(1,5)：D=−1 → 持平偏劣（高品锻体能咬住低品炼气）

### 1.2 第二层：极境（7 个特殊境界）

```text
极境 = { 锻体·临虚(1,6), 炼气·化朽(2,6), 养灵·回春(3,6),
         修心·不惑(4,1), 修心·天命(4,2), 修心·耳顺(4,3), 修心·从心而欲(4,4) }
```

规则：

| 对局 | 结果 |
| --- | --- |
| 极境 vs 常境 | **极境必胜**，但保留 **0.0001%** 的翻车可能（万事无绝对） |
| 极境 vs 极境 | 进入「问道」判定，只有这 7 个之间才有胜负变数 |

「问道」判定（极境互殴）：

**基础胜率 55 : 45**，再由「手段广度」修正。

```text
胜率 = 50% + 手段广度差 × 4%

手段广度（各道掌握的手段类别数）：
  锻体·临虚     4   （拳脚、兵刃、肉身抗性、气血）
  炼气·化朽     6   （拳脚、兵刃、气术、符箓、阵法、御器）
  养灵·回春     8   （+ 神通、灵器）
  修心·不惑    10   （+ 心术、道意，且对前三道的手段都有理解）
  修心·天命    11
  修心·耳顺    12
  修心·从心而欲 13
```

效果：修心·从心而欲（13）vs 锻体·临虚（4）→ 50 + 9×4 = **86%**。
修心·不惑（10）vs 养灵·回春（8）→ 50 + 2×4 = **58%**。
极境内部仍是「互有胜负」，但修心明显更强——因为**它对下三道都有了解，手段更多**；锻体临虚只有一身肉身。

> 这是你说的「55 开，但修心的手段更多」的落地：基础五五，靠手段数量拉开。

## 2. 手段代差：低境界无法抵抗

这是本版最核心的机制，**独立于伤害倍率**，用「抗性」实现。

### 2.1 法力 / 灵力 / 道意的抗性表

每个进攻手段都有 `layer`：

| layer | 获得条件 | 被谁抵抗 |
| --- | --- | --- |
| `physical` | 锻体 | 锻体、炼气都能抗 |
| `mana` | 炼气·**破胎**（2 阶 2 品） | 需炼气·破胎以上才能抗；**锻体完全无法抵抗** |
| `spirit` | 养灵·**启灵**（3 阶 2 品） | 需养灵·启灵以上才能抗；炼气、锻体**都无法抵抗** |
| `dao` | 极境 / 传承级武器 | 只有极境能抗 |

落地：

```text
若 攻方.layer > 守方.defenseLayer:
    伤害 × 1.8，且附加「无法抵抗」标签
    部分手段直接跳过防御/架势结算
```

**具体表现**：
- 炼气·破胎 用《流云掌》外放法力打 锻体·金身：锻体金身再硬，也拦不住法力，只能硬吃。
- 养灵·启灵 用灵力打 炼气·合一：炼气合一再强，灵力照样穿透。
- 修心 / 极境 用道意：只有同为极境者能抗。

### 2.2 看破与料敌先机

养灵·开视（3 阶 1 品）起拥有：

| 能力 | 效果 |
| --- | --- |
| 料敌先机 | **提前看到对手下一回合意图**（现在所有境界都看得到，改造后只有开视以上能看） |
| 看破 | 有概率识破对手的「蓄势」并打断 |
| 观气 | 战斗中看到对手剩余气血的精确百分比（低境界只看到「气息平稳」这类模糊描述） |

这套能力是**境界特性**，不是数值加成，低境界再怎么堆属性也拿不到。

### 2.3 传承级武器

极境与修心可使用的最高级武器。**不随身携带**——它们通常被供奉在城中，用来**镇压一城气运**，需要时去借、去取。

| 武器 | 供奉地 | 特效 | 破解方式 |
| --- | --- | --- | --- |
| 定海珠 | 长明城 · 镇海楼 | 每 2 回合强制「定身」，跳过对手一次行动 | 需极境 + 悟性判定 |
| 落魂钟 | 北关 · 镇北祠 | 直接削减对手气机上限 | 需养灵·回春以上 |
| 缚龙索 | 南关 · 锁龙井 | 锁住对手兵器/法器，使其无法使用 | 需锻体·临虚肉身挣脱 |
| 照妖镜 | 太学 · 观星台 | 看破一切幻术与伪装，并使对手闪避失效 | 极境道意对冲 |

**获取方式**：

```text
城主 / 将军 / 太学祭酒 → 有资格借用
借用需要：记功达到门槛 + 心性达标 + 归还期限
归还失败 → 通缉、失去身份
```

**没有对应破解手段，就是没办法**——这正是你要的「没有手段抵抗就是没办法」。

> ❓**待确认**：传承级武器是「一件只能借一次」，还是「可反复借，但要付代价」？推荐后者。

## 3. 行动回合：一次只能做一件事

### 3.1 基础规则

```text
每回合 1 个行动。
法器 = 1 个行动（占用整个回合）
法术 = 1 个行动（占用整个回合）
兵刃术 = 1 个行动
符箓 = 1 个行动
丹药 = 1 个行动
拳脚 = 1 个行动
```

**不能同时用法器和法术**，除非拥有天赋：

| 天赋 | 效果 |
| --- | --- |
| 一心二用 | 每回合可执行 2 个行动（第二个效果 ×0.7） |
| 分神 | 可让法器/法术在后台持续 1 回合 |

### 3.2 资源

| 资源 | 上限 | 回复 | 用途 |
| --- | --- | --- | --- |
| 气血 | 100（+境界加成） | 丹药/法术 | 归零即败 |
| 气机 | 20 + 炼气品 × 4 | 每回合 +3，调息 +8 | 法力类手段 |
| 灵力 | 只在养灵·启灵后开启 | 每回合 +2 | 灵力类手段、御灵器 |
| 架势 | 0~3 | 防御/游斗获得 | 强化下一击或减伤 |

### 3.3 回合上限

6 → **10 回合**（手段多了，要给得起回合）。

## 4. 战斗分级：能不能走

| 级别 | 触发场景 | 可认输 | 可遁走 | 失败结果 |
| --- | --- | --- | --- | --- |
| **切磋** | 同门、演武 | ✅ 随时 | ✅ | 轻伤、掉面子、扣钱 |
| **斗法** | 争宝、比试 | ✅ | ✅（需身法/境界判定） | 重伤、掉宝 |
| **生死斗** | 秘境、护道、北关 | ❌ | ✅（低概率，失败即死） | 大概率战死 |
| **不死不休** | 大道之争、杀人夺宝 | ❌ | ❌ | 必有一方死 |

### 4.2 认输与遁走的代价

认输是**破财保命**。赔偿不是死值，按**对手资产**算，详见 [经济与物价](经济与物价.md)。

```text
赔偿额 = 对手总资产 × 10% × 级别系数（同境界 1.0 / 越级 1.2 / 被碾压 0.8）
上限：不超过你现有资产的 80%
```

| 级别 | 认输代价 | 遁走代价 |
| --- | --- | --- |
| 切磋 | 声望 −3（不赔钱） | 声望 −1 |
| 斗法 | 按上式赔钱，声望 −5 | 成功脱身，仍赔 5% |
| 生死斗 | 不能认输 | 30–50% 成功率，失败即死 |
| 不死不休 | 不能认输 | 不能遁走 |

**钱不够的三个选择**（这才是重点）：

| 选项 | 后果 |
| --- | --- |
| A 倾家荡产 | 付光所有钱 + 卖装备，声望 −10 |
| B 白打工 | 欠债，强制劳役 N 年（N = 欠款 / 年收入，上限 5 年） |
| C 逃跑 | 30–50% 成功率，失败即死（生死斗/不死不休） |

白打工期间：收入全抵债、不能闭关、不能远行、不能离开所在城池。

**声望（reputation）的用途**：

| 用途 | 效果 |
| --- | --- |
| 太学直招 | 声望 < 0 失去资格 |
| 身份晋升 | 城主 ≥ 80，将军 ≥ 60 |
| 委托报酬 | 每 20 点 +5%，最高 +20% |
| 借传承武器 | 声望不足不借 |
| 坊市价格 | < 0 加价 30%，≥ 80 减价 10% |
| 招附庸 | 声望太低没人来投 |

**心性的随机扣除**（你的要求：以为必胜结果输了，肯定打击大）：

```text
战斗结束，按「预期 vs 结果」判定心性变化：

  本以为必胜（战力评估优势 ≥ 1 档），结果输了   → 心性 −3（重挫）
  势均力敌，输了                              → 心性 −1（略有动摇）
  明知不敌仍战，且战得漂亮                    → 心性 +1（虽败不疑）
  以弱胜强                                    → 心性 +3（确立自信）
  认输 / 遁走（非不死不休）                    → 心性不变
  不死不休里遁走                              → 心性 −2

连续失败累积：连续 3 场败绩后，每多败一场额外 −1（最多额外 −2）
```

这符合你对心性的定义：**心性看的是「对自己的确信」**，输得莫名其妙才伤自信，明知不敌虽败犹荣。

> ❓**待确认**：赔 1 金是否够重？大曜物价里，凡品铁剑 2 银 20 铜，1 金 = 100 银，相当于 45 把铁剑。

## 5. 招式体系

### 5.1 分类与层

| 类 | layer | 依赖 |
| --- | --- | --- |
| 拳脚 | physical | 锻体 |
| 兵刃术 | physical（凡兵）/ mana（法器）/ spirit（灵器）/ dao（传承级） | 兵器类型 + 对应术法 |
| 气术 | mana | 炼气·破胎 |
| 符箓 | mana | 破胎 + 符箓百艺 |
| 阵法 | mana | 破胎 + 阵法百艺，战前一次 |
| 神通 | spirit | 养灵·启灵 |
| 心术 | dao | 修心 |

### 5.2 兵器与克制

**兵器多多益善**，先做六类：

| 类型 | 特点 | 克制 |
| --- | --- | --- |
| 剑 | 均衡，招式最多 | 克短兵（匕首/奇门） |
| 刀 | 爆发高，出手慢 | 克长兵（枪/棍） |
| 枪 | 距离长，先手 | 克剑 |
| 棍 | 范围大，破架势 | 克刀 |
| 弓 | 远程，蓄力 | 克轻甲/无甲 |
| 奇门 | 特效多，伤害低 | 克重甲 |

**克制只加 1% 伤害**——影响很小，是「锦上添花」，不是「必须遵守」。

```text
克制命中：伤害 × 1.01，并在战斗日志里给一句描述
被克制：无惩罚
```

> 这样既满足「兵器多多益善、有克制」，又不会让玩家为了 1% 去查表。

### 5.3 兵器必须配术

```text
兵器类型：剑 / 刀 / 枪 / 棍 / 弓 / 奇门
未习得对应兵刃术：
  只能「凡俗劈砍」——伤害 = 兵器基础 × 0.45，无克制、无连招、无特效
  法器/灵器则完全无法驱动（连凡俗劈砍都不行，因为需要法力/灵力）
```

这条让「买了剑要学剑术」「买了法器要能外放法力」都成立。

### 5.4 品阶与招式

见 [品阶命格寿元](品阶命格寿元.md) §1.2。招式的 `min/best/max` 决定它在不同境界的发挥：

- 1 阶 3 品《蒙学拳脚》在锻体周天最强，炼气期用只有 50%
- 2 阶 2 品《流云掌》在炼气破胎解锁，锻体期根本用不了（layer 不够）

  id, name,
