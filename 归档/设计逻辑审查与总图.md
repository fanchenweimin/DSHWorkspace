**三条硬边界（三份权威文档一致，可写死）**：

1. **角色属性不进战斗面板**，唯一接口是 `心性 1:1 → 神志值`。

3. **`本性` 与 `心性` 零耦合**，任何把它们连起来的实线都是把"心魔"变回"报应"。

## 5. 代码与文档的代差（只列结论）

`src/` 共 6,819 行，实现的是 **r5 之前的模型**。文档三轮（r11–r16）的改动基本没落进代码。

| 项 | 文档（现行） | 代码（`src/`） |
| - | --- | --- |
| 修为 | 绝对值（锻体 470 → 养灵 54,000） | `PROF_MAX = 100` 百分制 |
| 四道层级 | `pathLevel` Lv0–6，破境的唯一门槛 | **不存在**，用 `stageIndex` |
| 属性生成 | 定和 110–130 + 分配 r，双 80 概率可算 | `aptitude/insight` 直接随机，`attrCoef = 0.35 + a/65` |
| 心性 | 每年 −1/−2，地板 60，心魔 <40 | 每 **3 年** −1（开修心后 6 年），下限 **10**，无心魔 |
| 气运 | 0–100，年度漂移，钳 10–90，参与取整 | `luck` 钳 20–95，无漂移、无取整规则 |
| 灵量 | `Σ(人数×权重)`，唯一乘区 | 有 `identity.subjects` 骨架，但加成走 `attrCoef` |
| 事件 | 8 kind × 5 trigger × 4 priority × `rate` | 只有 kind；强制闸硬编码 16%、门槛闸 45% |
| 战斗 | 三档压制 + 四伤害 + 三血条 | 有 `suppression.rule` / `layer.rule`，未按三档重建 |

**结论**：不是"补几个字段"，是 **`training / realm / event` 三个 system + `attribute.rule` 要重写**。建议顺序：`G7 schema` → `D3/D4 数值` → `pathLevel` → `事件流水线` → `心性/心魔` → `战斗`。

## 6. 公式速查（本图采用的一套）

```text
【属性生成】
k        = 气运 / 50
S₀       = 110 + (k−1)×10 + rand×20                  气运 50 → 110–130
S        = S₀ + 命格(+30) + 天赋(+15) + 事件(≤+20) + 永久资源(≤+15)
r_lo     = 0.40 − 0.014×max(0, 20−气运)              气运 0 → 0.12
r        = r_lo + rand×(1 − 2·r_lo)
资质     = round(S×r)      悟性 = S − 资质
caps     单项 ≤100，和 ≤200
P(双80)  = clamp((1 − 160/S) / 0.20, 0, 1)           S=160 → 0%

【五层链】
v = base
for layer in [事件, 扩展, 身份, 天赋, 命格]:
    v = v × (1 + Σpct) + Σflat
终值 = clamp(v)；气运只在"取整"或"骰子"上出现一次

【修行】
锻/炼基数 = 主属性 × (0.70 + 0.15×功法品阶) + 境界品×2
月修为    = 锻/炼基数 × 0.2 × 乘区
养灵 B    = 0.10 + 0.90 × clamp((资质+悟性−160)/40, 0, 1)
养灵月修为 = B × 20 × 灵量增益
修心 B    = 0.10 + 0.90 × clamp((心性−90)/10, 0, 1)   心性<90 → 0
百艺基数  = 资质×w资 + 悟性×w悟        月 +基数×0.2
术法月熟练 = 锻/炼基数 × 0.2 ÷ 阶位系数 × 相性
            阶位系数 1/1.5/2/3/5/8   相性 1.0 / 0.5

【灵量】
灵量  = Σ(人数 × 权重)       凡人 0.2 / 锻体 1 / 炼气 2 / 养灵 5
增益  = 1 + log10(灵量+1)/2
人口  += clamp(基线 − 人口, −1万, +1万)

【层级判定 p】
锻体 Lv1  0.80 + (资质−40)×0.02        Lv2 0.90 + (资质−60)×0.01
     Lv3  (资质−60)×0.05               Lv4 (资质−79)×0.10
     Lv5  世界认可（不掷）              Lv6 悟道（不掷）
```
