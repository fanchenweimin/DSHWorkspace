## 0. 一句话概括

四道不是四个平行职业，是**四条难度递增、入口互斥、天花板递增的路**：锻体靠资质（50 是分水岭），炼气靠悟性（60 才及格），养灵靠资质+悟性双 80 且只能靠事件开每一扇门，修心靠心性 90 且**会倒退、会死**。

**但门票不等于能走**，这是本项目定下来的最重要一句：

| 道  | 门票      | 真正能走的 | 差在哪                    |
| -- | ------- | ----- | ---------------------- |
| 锻体 | 资质 50   | 55    | 470 修为在蒙学四年里差 17 点    |
| 炼气 | 悟性 60   | 62+   | 破胎 30% 要试很多次           |
| 养灵 | 双 80     | **双 90 + 城主级灵量** | 双 80 到真域要 355 岁（续命 270 年，三丹只够 30%）；双 90 城主 **160 岁**（续命 75 年，三丹余 5） |
| 修心 | 心性 90   | **心性 92 + 进场时剩 446 年** | 90 要 3,750 年、91 要 987 年，哪条路都进不来；92 从神游进、94 从真域就能进 |

它们的共同结构是：

```text
每月 12 个月，产出修为 → 修为满 → 破境判定 → 进品
                    ↓
             突破判定的类型，决定了这条道是"熬"还是"等"
               熬（锻体、炼气）→ 通层级 + 攒修为
               等（养灵、修心、第四重起）→ 事件门，没有骰子
             ↓
        第四层：寿元。前三道前两品不加寿元 → 前段要"买时间"，但已从 218 年降到 75 年
```

## 2. 统一坐标与手段层

### 2.1 阶 / 品

```text
阶 = 大境界序号   锻体 1 / 炼气 2 / 养灵 3 / 修心 4
品 = 小境界序号   1..6（修心 1..4）
```

一切数值都用「x 阶 x 品」说话，物品也带三重境界（`min` / `best` / `max`），见 `品阶命格寿元.md` §1.2。本文不重复。

### 2.2 手段层（决定战斗压制，不是数值加成）

| 阶 | 道  | 手段层             | 谁能拦住它      |
| - | -- | --------------- | ---------- |
| 1 | 锻体 | **physical** 物理 | 都能拦，但很难    |
| 2 | 炼气 | **mana** 法力     | 锻体的拳脚拦不住法力 |
| 3 | 养灵 | **spirit** 灵力   | 法力的火焰烧不动灵体 |
| 4 | 修心 | **dao** 道       | 只有道能碰道     |

压制公式：`D = 阶差 × 6 + 品差`，再乘手段代差系数。详见 `战斗系统改造计划.md`。

### 2.3 每个大境界吃什么属性（本节是索引，详解在各道章节）

| 道  | 主属性                         | 次属性                    | 完全不吃       |
| -- | --------------------------- | ---------------------- | ---------- |
| 锻体 | **资质**（修炼、入门耗时、门时间，全部）       | 气运（判定小幅修正）             | 悟性、心性      |
| 炼气 | **悟性**（修炼、感气耗时、破境成功率）       | 心性（明悟判定）、气运            | 资质、身份      |
| 养灵 | **资质 + 悟性之和**（修炼基数）         | **身份 → 灵量 → 增益**（唯一乘区） | 心性、气运、钱、丹药 |
| 修心 | **心性**（门槛、基数、心关成功率、失败扣除，全部） | 无                      | 其余一切       |

**这张表的真正含义**：四道是**四个互不重叠的属性出口**。资质只有锻体一条路兑现，悟性只有炼气，心性只有修心，而养灵是唯一一个「两个属性都要、且还要社会地位」的道——这就是它最难进的原因，也是它增益最高的原因。

### 2.4 四道层级：破境的唯一门槛 `[定]` `[改]`

> 用户原话：「锻体就是锻体层级，炼气就是炼气层级，例如法相有门槛，那就是改成炼气层级到4后才能进入法相。境界突破都先突破对应的层级，然后层级和资质够了，突破就必定成功。」

**每个大境界一条自己的层级轨，LvN 就代表"这一品你通了"。**

| 轨道 | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 | Lv6 |
| --- | --- | --- | --- | --- | --- | --- |
| **锻体层级** | 体魄 | 脏腑 | 调息 | 朝元 | 金身 | 临虚 ★ |
| **炼气层级** | 感气 | 破胎 | 驭凡 | **法相** | 合一 | 化朽 ★ |
| **养灵层级** | 开视 | 启灵 | 真域 | 神游 | 浑然 | 回春 ★ |
| **修心层级** | 不惑 | 天命 | 耳顺 | 从心而欲 | — | — |

**四条规则**：

1. **层级 = 破境的资格。** 破第 N 品要该道层级 ≥ N。**法相 = 炼气层级 Lv4**（原"机缘"布尔，本轮废除）。
2. **层级靠"一次瓶颈判定"拿。** 每品一次事件、一次掷骰，命中即 +1，**没有事件链、没有进度点**（`角色属性与规则系统.md` §5.8.2）。法相这类门槛品，**一个"立相"事件就够**。
3. **判定命中 → 再看其余条件**（养灵双 80 / 修心心性 90）→ 都满足则**突破必定成功，不再掷骰**。任何一步失败，结果都是"不突破"。
4. **层级可以超前攒，但不能跨大境界攒**（唯一例外是每道的 Lv1 入门链，可在前一道走）。

**属性门槛只有两道有**：养灵（双 80）、修心（心性 90，且每次心关都要重新满足）。锻体、炼气**不设属性门槛**——资质/悟性只决定走多快，不决定能不能走。

| 道 | 层级 | 属性门槛 | 属性在哪起作用 |
| --- | --- | --- | --- |
| 锻体 | 六品全要 | 无 | 修炼基数（走多快） |
| 炼气 | 六品全要 | 无 | 修炼基数（走多快） |
| 养灵 | 六品全要 | **双 80** | 修炼基数（**决定性**：55 年 vs 10 年） |
| 修心 | 四品全要 | **心性 ≥90（每次）** | 基数 + 心关成功率 + **心魔触发（<40）与成活（越低越必死）** |

> ⚠️ **这条改动把"破境难度"的来源换了两次，r11 是最终版**：
>
> | | 旧（r5 及以前） | r6–r10（事件链） | **r11（本文）** |
> | --- | --- | --- | --- |
> | 判定对象 | **境界**过不过 | 链条走到哪一环 | **层级**涨不涨 |
> | 难度来源 | 瓶颈率 + 手段（丹药/硬冲） | 3 环事件链 | **单次判定 p（旧成功率公式）** |
> | 失败形态 | 掷骰失败，明年再来 | 卡在某一环，不知道还差什么 | **这次没抓住，下次再来** |
> | 一次破境要几个事件 | 0 | **3** | **1** |
> | 丹药的作用 | 破境（除瓶颈） | 只加属性 | **只加属性**（不变） |
>
> **r11 的取舍**：r6 为了"破境不是老虎机"，把随机性搬进了 66 个环——结果**内容量炸了，玩家反而更不知道差什么**（"我卡在第二环"没有信息量）。现在回到单次判定：**一个骰子、一个明确的 p、失败只说"这次没成"**。随机性回到手上，但判定对象已经从"境界"换成了"层级"——**境界本身仍然是一次过，只要层级到手**。
>
> **代价**：22 个瓶颈事件要写（原来 66 个环）。`[定]` 这是 r11 最大的一笔减法。

## 3. 锻体（1 阶）· 资质说话

### 3.1 属性影响 `[定]`

| 作用点   | 怎么吃资质                                   |
| ----- | --------------------------------------- |
| 修炼速度  | 月修为 = 资质 × 0.2（即 `基数 × 20`，基数 = 资质/100） |
| 入门耗时  | 资质越高越快，40 → 3 月，80 → 1.7 月，100 → 1 月    |
| 破境耗时  | 同上，且品级越高跨度越大                            |
| 门时间 | 资质越高，门来得越快，到锚点当年即过（旧称"瓶颈"） |
| 事件收益  | 与静修共用同一条 `applyTraining`，自动继承资质系数       |

**资质是锻体唯一的属性出口。** 一个资质 50 的锻体修士，无论怎么努力，他的月修为永远是 10；资质 90 的人永远是 18。这 80% 的差距不是靠时间能追的。

### 3.2 小境界表

| 品 | 境界   | 修为总量     | 突破耗时（月，资质 40–100）                   | **层级判定 p**              | 门（瓶颈事件）              |
| - | ---- | -------- | ----------------------------------- | ---------------- | --------------- |
| 1 | 体魄   | **470**  | 入体魄 `3 − (资质−40)×2/60` ∈[1,3]       | 资质 50 起 0        | 开筋骨 |
| 2 | 脏腑   | **720**  | `3 − (资质−40)×2/60` ∈[1,3]           | 60 → 10%，70 → 0% | 通脏腑      |
| 3 | 调息   | **1050** | `6 − (资质−40)×5/60` ∈[1,6]           | 70 → 50%，80 → 0% | 调气息      |
| 4 | 朝元   | **1500** | `12 − (资质−40)×8/60` ∈[4,12]         | 80 → 90%，90 → 0% | 归元 |
| 5 | 金身   | **2100** | `24 − (资质−40)×16/60` ∈[8,24] `[推]`  | **世界认可**（事件）     | 不坏 |
| 6 | 临虚 ★ | **3000** | `48 − (资质−40)×32/60` ∈[16,48] `[推]` | **悟道**（事件）       | 临虚（+悟道） |

> **「修为总量」的定义**：站在该品所需积累的修为，练满才有资格破下一品。所以「体魄 470」= 从入体魄练到可以破脏腑。
>
> **`[改]` r11：第三、四列怎么读**：「层级判定 p」就是**锻体层级 LvN 那一次判定的成功率**（公式见 §3.3）。"资质 50 起 0"的意思是——**这一品对资质 50 的人没有瓶颈，p ≥ 100%，层级直取**；"80 → 90%"的意思是**掷一次，九成命中，一成这次没抓住**。
>
> 失败**不扣修为**（锻体的失败只是"这次没通"），所以 p 低不等于卡死，只等于**要试很多次**——而试的次数由修为恢复和事件间隔决定。
>
> **`[改]` 「手段」那一列删了**：旧写法是"丹药 / 药浴 / 硬冲 5%"，那是绕开骰子的手段，现在的手段只有一种——**等下一次瓶颈事件**。丹药和药浴回归本职：加属性（`角色属性与规则系统.md` §5.6）。

### 3.4 阈值 470 的来历（这是全表唯一"算出来的数"）

```text
蒙学四年 = 48 月
资质 55 入体魄耗 2.5 月 → 可修炼 45.5 月 × 11 = 500  ✓ 过线 30
资质 50 入体魄耗 2.7 月 → 可修炼 45.3 月 × 10 = 453  ✗ 差 17
资质 60 入体魄耗 2.3 月 → 可修炼 45.7 月 × 12 = 548  ✓ 过线 78
```

**470 正好卡在 50 与 55 之间。** 这就是「50 是分水岭」在月制下的复现：资质 50 的人在蒙学四年里永远练不满体魄，必须等府学；资质 55 的人刚好在 10 岁末撞线。

## 5. 养灵（3 阶）· 双 80 门票 + 养灵层级开门 · 本版新增

### 5.1 进门条件 `[定]`

| 条件     | 值              | 说明                                     |
| ------ | -------------- | -------------------------------------- |
| 资质     | **≥ 80**       | 肉身得先承载得住灵                              |
| 悟性     | **≥ 80**       | 得看得懂"生命是什么"                            |
| 养灵层级 | **Lv1**        | 过一次「见众生」瓶颈判定（`0.35 + (和−160)×0.01 + 生死0.10`）。**这道门在炼气期就能碰**，太学只是知情（`spirit_known`），**不解锁** |

三者缺一不可。**这是全游戏最窄的门**：双 80 意味着 90% 以上的角色终其一生碰不到它。

> **`[推]` 养灵不要求炼气层级**：没有"必须先到化朽"这条。现实里大多数养灵者是在**炼气第 4–5 品**转过去的——因为双 80 的人本来就少，等练到化朽，寿元已经不多了。这条同时解释了为什么"化朽"这个极境反而比"真域"更少见。

> **r11 改口径：养灵门票的"难"，现在是"打不打得开"而不是"够不够格"。**
>
> 双 80 的人从"几乎没有"变成"极难但存在"，但**难在"分得匀"，不在"总分够"**（`角色属性与规则系统.md` §5.5.1.1）：
>
> | 路径 | 和 S | 双 80 概率 |
> | --- | --- | --- |
> | 普通人吃满事件 + 资源 | 145–165 | 0–15% |
> | 普通人 + 天赋·宿慧（+15） | 160–180 | 0–56% |
> | 天纵奇才 + 宿慧 + 事件 + 资源 | 190–210 | 79–100% |
>
> 所以"进得去"这件事，本质上由**命格与天赋**决定，资源和事件只是补最后一段。**但进去了也只有 0.10–0.55 的基数**——门开了，走到真域要几十年到两百多年，多数人寿元不够。
>
> 养灵仍然是"进得去走不动"，只是这道坎从 **门槛** 挪到了 **速度** 上。这比"双 80 根本不可能"更健康：**玩家看得见希望，也算得出绝望。**
>
> **r6 改名**：旧口径叫"认知 ≥0 已达成"（布尔），再叫"生命层级 Lv1"，现在统一为**养灵层级 Lv1**——因为用户把层级改成了**四道各一条轨**（锻体/炼气/养灵/修心），见 `角色属性与规则系统.md` §5.8。

> 旧规则"锻体与炼气均第四重才有资格感悟生命"降级为**可选路径之一**：另一条路径是太学在读 + 经历过生死。太学不再是唯一入口，但它是给"属性够、经历不够"的人准备的。

### 5.2 属性影响 `[定]`

| 作用点          | 怎么吃                                                        |
| ------------ | ---------------------------------------------------------- |
| 修炼基数         | **基数 = 0.10 + 0.90 × 进度**，`进度 = (资质+悟性−160)/40` ∈ [0,1] → `B ∈ [0.10, 1.00]` |
| 月修为          | 月修为 = 基数 × 20 **× 灵量增益**                                   |

> **`[定]` r11 的公式口径钉死**：`0.10 + 0.90 × 进度` 里，**0.90 只乘进度，不乘 0.10**。曾有一版误写成 `0.90 × (0.10 + 和 − 160)/40`，那会在门槛处给出 0.00225——**双 80 的人一品要 2445 年，等于"进得去但永远出不来"**，比"走不动"更死。两条基数（养灵、修心）都用同一个骨架：

>   养灵：进度 = (资质 + 悟性 − 160) / 40     和 160→0，200→1
>   修心：进度 = (心性 − 90) / 10              心性 90→0，100→1

> **本轮改判定口径：养灵的门槛不再由"能不能活到"决定，由"修为够不够快"决定。**
>
> 因为 100 年到真域这个锚点一立，续命需求从 218 年降到 75 年（§5.5），**寿元不再是主要矛盾，修为速度成了唯一的分水岭**：

| 5 | 世界认可 | **50 年** | 90 年 | 265 年 | **不是等，是求**——得让一整个体系承认你 |
| 6 | 悟道 | **66 年** | 120 年 | 353 年 | 最后一扇门，多数人死在这 120 年里 |

> **为什么本轮不给公式**：上一版用了 `245 ÷ 增益`、再上一版用 `8 × 2^(品−1) ÷ 增益`，两次都是先有公式再硬套叙事，结果是"启灵的门算出来比真域长"这种别扭。这次反过来——**先想清楚每一层养灵层级在故事里该有多稀有，再写间隔**。玄门的东西应该是手调出来的，不是指数函数算出来的。
>
> **"门时间 = 间隔 ÷ 成功率"是唯一的算法**：间隔是"这件事多久出现一次"，成功率是"你抓不抓得住"。所以双 80 的人在同一扇门前要等更久（0.35 vs 0.55，慢 1.57 倍）。
>
> **间隔仍挂在灵量上**（散修 ×2.94、城主 ×1.00，沿用你上轮"保留、以后到事件时再调"的意见）。理由没变：养灵层级事件叫「见众生」——**你治下生灵少，众生就少**。
>
> ⚠️ **启灵的 45 年是全道最长的一段，这是有意设计的**：「见自己」是四道里唯一一个"你必须承认自己会死"的门槛。养灵的残酷全在这里——**能看见别人在死的修士很多，能承认自己也会死的人很少**。所以它比真域还长，也比真域还难。如果你觉得这样太狠，把它砍到 25 年，100 年就会变成 80 年。

> 口径已定（§9.6）：`lifespan = 境界下限 + 额外寿元`。**凡阶段吃的延寿丹，进真域后不会被 400 覆盖掉，而是终身叠加。** 所以表里"补齐续命后"那一列才有意义。

> ✅ **叠加口径把这张表从"漏斗"改成了"两根线"，而且这个改动比原方案更好。**
>
> | | 覆盖口径（旧） | **叠加口径（本轮定）** |
> | --- | --- | --- |
> | 续命需求的算法 | 到真域年龄 − 85，但要和境界值重判 | 到真域年龄 − 85，**且一旦满足，后面全通过** |
> | 家主 | 补了 158 年，仍差 7 年死 | **补上就通顶**（1,320 岁回春） |
> | 城卫 | 补了 196 年，仍差 80 年死 | **补上就通顶**（1,585 岁回春） |
> | 散修 | 补了也死 | 补了也**卡在浑然**（差 3 年） |
>
> **这是叠加口径带来的第一个结构性好处：需求变成单一的、可读的一个数。** 覆盖口径下"能不能过"要看四个不同的差值（真域、神游、浑然、回春各算一遍），玩家永远算不清自己死在哪；叠加口径下只需一句话——**"你要多活 N 年，N = 到真域那年减 85"**。
>
> **第二个好处：散修成了唯一的例外，而它的死法很讲究。** 散修即使拿到 269 年续命（本来就拿不到），进浑然要 972 岁，而浑然寿元是 950 + 269 = **969**，**差 3 年**。也就是说：**散修的问题不是"活不到真域"，是"活到真域之后还是太慢"**——他的年修为只有城主的 1/3，每品要磨一百多年，磨到后面连境界寿元都追不上他。这比"被丹药线挡在门外"更狠，因为它说明**给散修续命也没用**。

**这张表解释了整个世界观的支点**：养灵不是"你修得多好"，是"你手下有多少生灵"。所以国家必须对不合格者封锁养灵知识，所以散修永远长不大，所以锻体必须依附城池。

> ✅ **这张表本轮重算过两次，纠正了两个错误**：
>
> **错误一：把寿元当成了加法。** 寿元是"活到几岁"的绝对值，不是"还能再活几年"。所以"400 年寿元"＝活到 400 岁，不是 160 岁再活 400 年。修正后每道门都要用 `到达年龄 < 当前寿元` 判。
>
> **错误二（已随叠加口径解决）：有一版我以为"过了真域还要逐品闯寿元关"。** 那是覆盖口径下的产物——续命在进真域时被 400 吃掉，所以后面每一品都要重新拼寿元。叠加口径下**过了真域就一劳永逸**（额外寿元跟着走），全表只剩散修一个例外。所以"逐品漏斗"这个说法本轮作废，正确的说法是**"一道门 + 一条线"**：真域是唯一的门，续命需求是唯一的线。
>
> **这张表读起来是一条很干净的阶梯，只有散修掉队**：
>
> ```text
> 160 岁 城主顶  → 需 75 年  → 三丹（80）就够（余 5）  → 通顶 750 岁
> 164 岁 城主中  → 需 79 年  → 三丹（80）就够（余 1）  → 通顶 776 岁
> 186 岁 将军    → 需 101 年 → 缺 21，一次记功         → 通顶 931 岁
> 209 岁 宗主    → 需 124 年 → 缺 44，一次救命之恩     → 通顶 1,090 岁
> 243 岁 家主    → 需 158 年 → 缺 78，一次大机缘       → 通顶 1,320 岁
> 281 岁 城卫    → 需 196 年 → 缺 116，两次大机缘      → 通顶 1,585 岁
> 354 岁 散修    → 需 269 年 → 拿不到                 → 补了也卡在浑然（差 3 年）
> ```
>
> **"补上就通顶"这四个字，是叠加口径给这张表带来的最大变化。** 上一版（覆盖口径）里，家主补了 158 年还差 7 年会死、城卫补了 196 年还差 80 年会死——那些"努力无用"的位置现在全没了。**这不是损失，是把惩罚从"努力也白费"改成了"你还得求到"**：
>
> | | 覆盖口径 | 叠加口径 |
> | --- | --- | --- |
> | 惩罚落在 | **拿到之后**（补了也死） | **拿到之前**（求不求得到） |
> | 玩家的感受 | "我做了所有该做的，还是死" | "我知道该做什么，但我求不到那个人" |
> | 设计上的对应 | 数值羞辱 | **社会关系** |
>
> 后一种才是这个游戏该有的味道：**养灵的墙不在数值里，在人情里。** 家主和城卫的问题从来不是"资质不够"，而是"你认识几个能给你续命的人"。
>
> **"补上就通顶"也让第 ② 层终于有了明确的价值**：它不是"让你多活一品"，而是**"给你一整条道"**。将军缺 21 年就能换 931 岁通顶——**21 年换 800 年，这是全游戏最划算的一笔交易**。所以第 ② 层不该做成"稀有的施舍"，该做成"一次记功就兑现的承诺"，否则玩家会觉得这 21 年遥不可及。

**逐品的寿元能不能接住（城主双 90，60 岁入门，三丹已吃 → 额外寿元 80）**：

```text
160 岁 进真域（寿元 400 + 80 = 480 → 能活到 480）  余 320 年
250 岁 进神游（寿元 700 + 80 = 780 → 能活到 780）  余 530 年
370 岁 进浑然（寿元 950 + 80 = 1,030 → 能活到 1,030）余 660 年
530 岁 进回春（寿元 ∞）
```

> **叠加之后，城主的时间余量从"刚好"变成"宽裕"**：进神游余 530 年、进浑然余 660 年。这不是数值膨胀，是**叠加口径必然的结果**——境界给底子（400/700/950），延寿丹给增量（+80），两个来源互不覆盖。上一版按覆盖算，所以城主到神游只剩 450 年余量、到家主那一档就变成负的；现在这条线整体上抬了 80 年。
>
> ⚠️ **但要注意：这 80 年是"终身资产"，不是"每品重发一次"。** 它是加在每一个境界值上的同一个 `extra`，不是每进一品就再吃一遍。写法见 §9.6。

**前三品的这 100 年全靠续命撑（75 年缺口），进了真域之后境界自己的寿元就接得住**——400 + 80 = 480 要覆盖到 250 岁进神游（余 230），700 + 80 = 780 要覆盖到 370 岁进浑然（余 410）。

> 而"余量"只对城主级成立——城卫、家主、散修连**进真域前**都活不到，需要的是 116–269 年，境界寿元一点忙也帮不上。所以 400 → 700 → 950 → ∞ 这组数本轮不动是对的：**它管的是"过门之后"，而过门之前只能靠买和求**。
>
> 这组寿元在覆盖口径下（上一版）看起来像"筛子"，因为城主余 450/580、家主差 7 年；在叠加口径下（本轮）它更像"底座"——**它保证所有过了真域的人都有 400 年可用，至于够不够走完，取决于你买了多少年。**

### 5.7 与旧规则的三处冲突（必须记账）

| 项 | 旧规则 | 新规则 | 影响 |
| --- | --- | --- | --- |
| **静修** | 养灵静修**恒为 0**，只认养灵层级事件 `[改]` | **静修有效**，月修为 = 基数 × 20 × 增益 | 养灵从"纯事件流"变回"可修炼"，玩家有稳定的日常动作 |
| **养灵层级的作用** | 养灵层级只影响突破率（`6 + 养灵层级×4`） | 养灵层级是**硬门槛**（Lv N 才能进 N 品） | 养灵层级从"概率加成"升级为"资格" |
| **时间花在哪** | 修为 288,000 磨修为 → 一轮砍到 104,000 全给门 → **本轮 159,300，修为 43% / 门 57%** | 修为是主体，门是另一半（20–120 年） | 玩家永远有"下一件事"：练快些、攒灵量、出门等机缘 |

第一条推翻了 `境界改造计划.md` §1.3 的核心机制。**理由是自洽的**：如果没有静修，那"修炼基数"这个东西根本无处施加；你给了基数，就等于给了静修。

**第三条走过两个来回，这个来回本身值得记下来**：

| 版本 | 修为总量 | 修为占比 | 到真域 | 玩家卡住的感受 |
| --- | --- | --- | --- | --- |
| 初版 | 288,000 | 100% | 303 岁 | "我资质不够，磨得老死" |
| 上一版 | 104,000 | 23% | 303 岁（等门 243 年） | "门什么时候来" —— 无事可做 |
| **本轮** | **159,300** | **43%** | **160 岁（100 年）** | **"我可以练快点，可以多攒灵量，也可以出门等那场机缘"** |

**上一版的错误在于把"等"做成了玩法主体**。等没有决策，只有消耗；而修为有决策（投几个月、要不要去赚钱、要不要换身份）、门也有决策（去哪历劫、跟谁混、要不要赌一次生死经历）。**所以本轮把配比调成一半一半——不是为了缩短时间，是为了让玩家永远有"下一件事"可做**。时间缩短只是副产品。

#### 6.1.1 一次判定拿修心层级 `[定]` `[改]`

> 用户原话（r11）：「像法相这种突破，事件一个就够了，不需要设置事件链。」

```text
心性 ≥ 90        →  解锁「我是谁」这道门
过一次判定 p      →  p = 0.30 + 0.05 × (心性 − 90)      心性 90 → 30%，100 → 80%
  ├─ 命中        →  修心层级 0 → 1，★ 此后自然衰减归零

```

**没有"自省链 3 环"了。** 这是 r11 的减法：修心的门槛不再是"走完三问"，而是**"在窗口关闭前掷中一次"**。

| --- | --- | --- | --- |
| **Lv1** | 修心·不惑 | 我是谁 | `0.30 + 0.05×(心性−90)` |
| Lv2 | 天命 | 我怕什么 | 同上 |
| Lv3 | 耳顺 | 我要什么 | 同上 |
| Lv4 | 从心而欲 | 我放下什么 | 同上 |

#### 6.1.2 修心：一次开门，之后不再被时间磨损 `[定]` `[改]`

> 用户原话（r11）：「进入修心境界后，心性就不会随着时间自然下落了，我记得这个之前设定过。」
> 用户原话（r10）：「修心本来就是两道关卡，心性和自我层级……不然为啥修心那么难呢。」

**两句话并不冲突，它们说的是修心的前后两段。**

```text
入门前（Lv0）—— 窗口游戏
  心性 ≥90 才触发「我是谁」
  p = 0.30 + 0.05×(心性−90)
  失败 → 心性继续 −1/−2 每年掉；掉回 90 以下 → 窗口关闭，等下一次事件
        ↓ 命中一次
入门后（Lv1+）—— 封存，但不是免疫
  自然衰减 = 0        ← r11 恢复的一条旧设定
  心性仍会掉，只有两个入口：
    ① 心关失败 → 30% 概率 −1
    ② 事件     → 目击杀戮 −5 / 被至亲背叛 −8 / 破境失败 −3 …
  掉回 90 以下 → 修心修为停滞（§6.2 硬闸），直到事件把它重新推回 90
```

> **`[定]` r11 补一条用户原话**：「心性在进入修心不惑境界后，心性不再随时间变化，但还是会被事件变化，掉到 90 后还是会修为不进。」
>
> 所以"封存"封的是**时间**，不是**因果**。这个人不再因为日子一天天过而变淡，但他还会因为"自己做了什么、看见了什么"而变。**不惑不是免疫，是免疫岁月。**
>
> **这比"一劳永逸"更狠**：入门不是拿到永久通行证，是**拿到一条不再自动下滑的线**——线还在，风还在吹，只是不再有重力。心性 92 的人一次目击杀戮（−5）就回到 87，修为立刻停摆，得等下一次「问心」把它推回去。

```text
心性像潮水，但只淹到门口为止

心性 100 ─┐                    ┌──── 100 ──── 入门后：线是平的
          │  −2/年，3–7 年窗口  │
心性  90 ─┴──── 窗口关 ────────┘
          （<90：层级判定打不开，只能等下一次事件）
                            ↑
                        这一刀之后，日子再也磨不动他
```

**为什么这条值得恢复**：r6 废除它，是为了保住"两道关卡同时成立"的紧张感；但代价是**修心者永远在往下滑，拿到不惑也没有任何回报**。用户这句话点出了缺的那一半——**"不惑"在数值上的意思，就是"不再被磨损"**。

**代价也要认**：门票只剩一次。心性 92 的人 p=0.40，**六成概率这一次就废了**，然后要等下一次「问心」（一生数列）。但进门之后**不是躺平**——事件还在往外抽，抽破了 90 就停摆。所以修心的难度从"长期维持"变成"**一次搏命 + 之后随时可能被一件事打回原形**"：

| 阶段 | 卡在什么上 | 失败代价 |
| --- | --- | --- |
| 入门前 | 心性 ≥90 **且** 掷中一次 | 窗口可能就此关闭 |
| 入门后四品 | 心关判定 + 修为累积 | 修为 −10×基数，30% 再扣 1 点心性 |

> **`[待]` 一条要拍板**：心性提升事件的频率与幅度（现写"一生 4–8 次、每次 +5~+15"）。入门只需要"一次 +8 以上事件 + 一次判定"，所以 4–8 次是**偏宽**的。若要更狠，降到一生 2–3 次；若要更稳，保持。见 `角色属性与规则系统.md` §5.7.4。

### 6.2 属性影响 `[定]`

| 作用点     | 怎么吃心性                                              |
| ------- | -------------------------------------------------- |
| 修炼基数    | **分段**：心性 ≥90 → `B = 0.10 + 0.90 × 进度`，`进度 = (心性−90)/10` ∈ [0,1] → `B ∈ [0.10, 1.00]`；**心性 <90 → `B = 0`**（修为不进，不是负数） |
| 单关心关成功率 | `0.30 + 0.05 × (心性 − 90)` → 90: 30%，95: 55%，100: 80% |
| 成功收益    | `+30 × 基数`                                          |
| 失败损失    | `−10 × 基数`                                          |
| **心性 < 90** | **基数归 0 → 成功收益 0；但心关照出、失败照扣**（硬闸，见 §6.6）。所以"掉到 90 以下"不是平安，是**只减不增的消耗战** |
| 心魔触发    | **<40 起**：每年 `p = 0.03 × (40 − 心性)`；**≤20 必触发**（§6.6.1） |
| 心魔成活    | **`p(活) = 0.10 × 心性 ÷ 39`** → 39: 10%，30: 7.7%，20: 5.1%，**0: 0%**（越低越必死） |

### 6.3 一次心关的完整流程 `[定]` —— 本轮的核心

旧版把修心写成"进度只由事件增加、失败扣进度"，太软。现在它是**一条会往下滑的链**：

```text
① 触发        每 5–10 年（均 7.5）必出一道心关（走 ⑧ 事件槽，不随机等）
                 ↓
② 选择        2–3 个选项。选的不是成功率，是"这一关问的是什么"
                 （硬扛 / 逃避 / 认错 / 把责任推给别人）
                 ↓
③ 判定        random < p(心性)
                 │
                 ├─ 成功 ─→ 修为 += 30 × 基数
                 │            └─ 若 心性 < 90 → 修为 += 0（成功也不给）
                 │
                 └─ 失败 ─→ 修为 −= 10 × 基数
                              └─→ ④ 再判一次：30% 概率 心性 −1
                                        └─→ 心性 −1 后若 < 90，此后只减不增
                 ↓
⑤ 心魔        该次扣除 > 现有修为（修为会被扣穿）
                 → 不扣修为，改触发「心魔事件」（立刻，不掷触发骰）
                 → 存活 p(活) = 0.10 × 心性 ÷ 39       ← 39 → 10%，20 → 5.1%，0 → 0
                       活：心性 = max(10, 心性 − 5)，修为归零，当年不可再发起心关
                       死：身死。这是修心唯一的死法，也是全游戏唯一"死在内部"的死法
                 ↓
⑥ 破境        修为 ≥ 本 品门槛 → 该品的「大心关」（指定事件，不可跳过、不可代劳）
                 成功：进品（品级不可逆，永不失去）
                 失败：累计修为 −10%，心性 −1，明年可再发起
```

**四句话记住它**：成功加修为，失败扣修为；失败可能扣心性；扣穿修为就是心魔；心性跌破 90 就再也加不上。

### 6.6 两条线：心性跌破 90 = 硬闸；心性跌破 40 = 心魔 `[定]` `[改]` `[r14]`

```text
心性 ≥ 90：成功 +30×基数   失败 −10×基数        ← 有涨有跌，随机游走带正漂移
心性 < 90：成功 +0          失败 −10×基数        ← 只减不增（硬闸）
              ↓
        修为一路扣到 0
              ↓
        再失败 → 修为被扣穿 → 心魔（立刻触发，不掷骰）
              ↓
        心魔  ┌─ 活 → 心性 = max(10, 心性−5)，修为归零，境界不掉
              └─ 死 → 身死
```

**这条规则让"修心的死因是动摇，不是失败"从一句文学描写变成了机制**：一次心关失败不致命，一次心魔也不一定致命，但**心性掉到 89 的那一刻，倒计时就开始了**，除非找到把心性抬回去的路（§6.8）。

#### 6.6.1 心魔：触发线 40 / 必死线 20 / 成活率成正比 `[定]` `[改]` `[r14]`

> 用户原话（r13）：「作恶和心魔没关系，本性值和心性值是两个东西……正常心性基线是 60，低于 40 概率触发心魔，20 以下必定触发。心魔成活率和心性成反比，39 活下来为 0.1。」

> 用户原话（r14，校正上句）：「越低越必死，基线 60 意思是掉到 60 就不会随时间掉了。」——**所以"成反比"指的是"心性越低、死得越死"**，公式按 `p(活) ∝ 心性` 落地，不是 `∝ 1/心性`。
>
> 用户原话（r12）：「心性分人物心性和战斗心性……战斗心性改名神志值，归 0 战斗中就死亡。人物心性是掉下去触发心魔。」

**先把三件容易混的事分开**（这是本节的全部意义）：

| | 神志值（战斗） | 人物心性（角色） | 本性（角色） |
| --- | --- | --- | --- |

| 与心魔的关系 | 无关（只在本场） | **唯一致因** | **完全无关。作恶不生心魔，行善不免疫** |

```text
本性 10 的魔头 + 心性 95  →  一辈子没遇过心魔
本性 90 的善人 + 心性 30  →  年年被咬
```

**触发线（三条入口）**：

| 入口 | 条件 | 是否掷骰 |

| **自然跌破** | 心性 **21–39**，每年 `p = 0.03 × (40 − 心性)`（39 → 3%／年，30 → 30%／年） | 掷 |
| **必触发** | 心性 **≤20**，每年一次 | 不掷 |
| **修为扣穿 / 心性归 0** | 心关失败扣穿累计修为；或任何扣减压到 0 | **不掷，立刻** |

```text
活下来：心性 = max(10, 心性 − 5)、修为归零、境界不掉、当年不可再发起心关
```

| 心性 | 触发 | 成活 | 死亡率 |

> **`[定]` r14 校正方向：越低越必死。** 用户原话：「越低越必死。」
>
> r13 曾按字面"反比"做成"越低越易活"（`3.9 ÷ 心性`），理由是"自我越厚越难夺"——**那是一句听起来聪明、算起来荒谬的话**：它推出"心性 0 的人心魔伤不到他、心性 39 的人九死一生"，等于**心越碎越安全**。现在改成正比。
>
> **心性在这个机制里身兼两职**：既是心魔找上门的**频率**（越低越常来），又是扛住它的**力气**（越低越扛不住）。**掉十个点，来年次数翻几倍，而活下来的概率还在往下掉——这是一条双杀的线。**
>
> 所以"心性 40"这道线可怕的地方不在那一刻，而在**从那一年起，每一次遭遇都比上一次更接近死亡**。心性 39 的人还有一成机会，可他每活一年就掉两个点——**他在一条下坡的传送带上赌命。**

**心魔只找入道者**（`[推]`，r13 补）：

| 心性跌破 40 的人 | 遇到什么 | 后果 |
| --- | --- | --- |
| **入道者**（锻体 ≥1 品） | **心魔** | 按上表掷触发与成活 |
| **凡人**（锻体 0 品） | **心疾** | 健忘、固执、认不得故人；心性 0 = **心枯而终**，寿元按寿元表正常走 |

> **`[改]` r14：这条从"算术必需"降级为"叙事口径"。**
>
> r13 补它时，前提是"基线 60 = 出生值"——那样凡人 24 岁就自然跌破 40、三十岁以上活不下来一半，不补世界会崩。**但 r14 查明"基线 60"是衰减地板**：自然衰减停在 60，凡人根本不会因为变老而走进心魔区，那个洞自己就没了。
>
> 所以它现在只承担一件事，而且这件事值得留：**心魔咬的是修出来的那个自我，凡人心里没有那根桩，也就没有可拔的东西。**
>
> **代价是**：凡人不会因心魔暴毙，只会**越老越糊涂**。修行者死于道心动摇，凡人死于记性。
>
> **但凡人不是安全**：事件照样能把他的 60 压到 0，只是那个死法叫"**心枯**"，不叫"心魔"——**心枯是安静的死，心魔是挣扎的死，两条路通到同一个地方。**

> **`[改]` r14 又删掉 r13 自己的一句**：r13 写"心性 0 的成活率是 1.000，所以心性归 0 不是死、是坠落到 10 点重来"——方向反了，已作废。现在 **心性归 0 必死**。

> **`[改]` r13 删掉的两句旧话**：① 旧版心魔公式 `p = 0.20 + 0.01×心性`（心性越高越容易活，方向反了，且 0 时只有 20% 存活）；② 旧版"若你要作恶多了必死，改成 0.05+0.005×心性"——**这句话本身就是把心魔当报应，与"本性 ≠ 心性"直接冲突，已删。**

### 6.8 心性恢复：可以，但极少 `[定]`

用户定：**心性能恢复，但这类事件很少；转世重修不会恢复心性**（因为还是同一个人）。

```text
恢复途径 ：「回心」类大事件 —— 长期闭关、师友点醒、大悲大喜、生死之际
每次幅度 ：+1 ~ +3
数量     ：全游戏 3–5 个，且各有前置条件（有的要散尽家财，有的要亲手葬友）
上限     ：不超过该角色历史最高值（崩过一次的心，修不回更亮）
转世     ：不恢复。心性跟着"我"走，不跟着身体走
```

**这条让"心性崩了"成了真正的死刑缓期**：不是当场死，而是**再没有下一次机会**。所以修心玩家最怕的不是心关失败，而是发现自己只剩 89。

> **`[改]` r13 分清两个入口**：心性**上行**的主力不是「回心」，是 §6.8 上面那张表之外的**心性事件三档**（顿悟 +5 / 问心 +8 / 大彻大悟 +15，见 `角色属性与规则系统.md` §5.7.1 ②）。「回心」只是其中"修复已经崩掉的那一块"的稀有子类——它的 +1~+3 是**缝补**，不是**增长**。
>
> 所以"心性 89 的人再没有下一次机会"这句话要收窄：**他还有机会，只是得等一次大事件。** 真正没有机会的是"心性 20、年年心魔、修为年年归零"的那一类——**不是没有心性，是没有时间。**

**还剩两个待确认**：

1. **心关事件的触发源**：需要 20–30 个「我是谁 / 我为何修 / 我能不能放手」类事件，每个 2–3 选项且选项要真的改变判定条件，不是换个文案。
2. **心魔的触发频率（`0.03` 这个系数）**：成活率已按你的口径定死（**正比即越低越必死**，39 → 0.10、0 → 0）；剩下的是"多久来一次"。现在 39 的人 33 年遇一次、30 的人 3 年一次。要不要更密（0.05）/更疏（0.02）。

## 7. 破境：一条轨，四种门

> **`[改]` r11：概率不是消失了，是换了打点。** r6 说"层级和资质够了，突破必定成功"，于是把骰子整个删掉——但 r11 用户又把它请回来了，**只是改挂到"层级"上**：「锻体和炼气前面的境界还是走之前的判断，只是改了结果对象。」
>
> 所以现在是一条轨两段判定：**瓶颈段掷骰（决定层级涨不涨）+ 守卫段必成（决定境界突不突）**。旧的成功率表全部保留，一字未改。

### 7.1 单轨流程 `[定]` `[改]`

```text
① 瓶颈段（可超前，可后补）
   ├─ 无瓶颈（p ≥ 1.00）        → 层级直取 LvN
   ├─ 判定型（0 ≤ p < 1）       → 掷一次 p：命中 +1；未命中 → **不突破**，下次再来
   └─ 资格型（世界认可 / 悟道） → 有则过，无则卡死
        ↓ 层级 ≥ N
② 攒修为到该品的修为总量
        ↓
③ 其余条件：养灵双 80 / 修心心性 ≥90（只有这两道有）
        ↓
④ 全满足 → **突破必定成功**（一次过，不掷骰）
```

| 检查项 | 不满足时显示 |
| --- | --- |
| 层级 < N | 「此境的关窍你还没通」（灰） |
| 修为 < 总量 | 显示进度条（不灰，可以继续练） |
| 属性门槛（仅养灵/修心） | 「资质/悟性不足 80」或「心性不足 90」（灰） |

**失败只可能发生在两处**：**瓶颈段的骰子**（锻体 §3.3 / 炼气 §4.3 / 养灵 §5.4 / 修心 §6.1.1），以及**修心的倒退与心魔**。破境这个动作本身，仍然没有失败——**层级到手、修为够、属性够，就是一次过。**

> **一句话记住四道的手感**：锻体和炼气"**试很多次也不心疼**"（失败不扣修为），养灵"**试错很贵**"（−10% 修为），修心"**试错会伤人**"（−10×基数 + 30% 掉 1 点心性）。同一个骰子，四种痛感。
### 7.2 四道同一条轨，门的形态不同

| 道 | 层级 | 属性门槛 | 门是什么 | 时间主要花在哪 |
| --- | --- | --- | --- | --- |
| 锻体 | 锻体层级 Lv1–6 | 无 | 一次瓶颈判定（开筋骨→…→临虚） | **修为 + 判定次数** |
| 炼气 | 炼气层级 Lv1–6 | 无 | 同上（感气→…→化朽）；**法相要 Lv4** | 修为 + 判定次数 |
| 养灵 | 养灵层级 Lv1–6 | 双 80 | 六次「见 X」事件 | **门占 57%**（395/690 年） |
| 修心 | 修心层级 Lv1–4 | 心性 ≥90（入门前） | 四次判定 + 心关 | **进门那一次**（之后不再被时间磨损） |

**四道的差别不在"轨"，在"门有多贵"**：锻体的门是体力活（一年一次，失败不疼），养灵的门是命（几十年一次，失败 −10% 修为），修心的门是运气（一次搏命，之后长跑）。

> **`[定]` 一条必须补的规则：同一道门，每年最多触发一次。** 没有这条，锻体"失败不扣修为"就等于可以无限重试——p=0.1 刷十次也就到手了。
>
> 加上这条之后，`门时间 ≈ 1 ÷ p` 那套折算**依然成立**（它是期望等待年数），而 p 也**依然是判定成功率**（它是每年的命中率）。**r6 和 r11 说的是同一件事的两面，不冲突。**

### 7.3 手段池重做：从"除瓶颈"到"改概率 / 改属性" `[定]` `[改]`

旧表里那些手段（硬冲、丹药除瓶颈、灌顶）作用对象都是**"掷骰失败"**。r11 骰子回来了，但**打点从"境界"变成"层级"**，所以手段的定位要重排：

| 手段 | 旧作用（作废） | 新作用 |
| --- | --- | --- |
| 硬冲 5% | 绕开瓶颈 | **删除**——"每年一次判定"本身就是硬冲，再给一个 5% 是重复 |
| 普通丹药（除瓶颈） | 100% / 降瓶颈一级 | **删除**——丹药只加属性、只回资源 |
| 药浴 / 洗髓 | 突破判定 +10% | **只加资质**（+1/年、+3、+6，`角色属性与规则系统.md` §5.6） |
| 悟性宝物 | 按新悟性重判 | **只加悟性**（+1~+3），进而拉高修炼基数与判定 p |
| 静修 | 突破判定 +8% / 稳定修炼 | **静修保留**（月修为照常）；喂招改为"心境平稳，本年心性不衰减"（入修心后本就不衰减，所以喂招只对未入门者有意义） |
| **灌顶** | 突破成功率 ×0.5 | **下一次瓶颈判定 p +0.25**（绝对值，钳到 0.95），代价不变（§7.4） |

> **这个改动让百艺的定位更清楚了**：丹药和宝物不再是"破境道具"，而是**属性道具**。它们卖的不是"过这一关"，是"让你这一辈子走得快一点、判定高一点"——**这是更健康的经济模型**，因为它不随境界过期（属性一直在用），只随品阶过期（§5.6 的适用品阶）。

### 7.4 灌顶（借他人之悟）`[定]` `[改]`

```text
作用：该道当前品的**下一次瓶颈判定 p +0.25**（钳到 0.95，只一次，不叠加）
      → 也就是"别人替你想通了一部分"
代价（成功与否都付）：
      心性 −6 / 大量钱财 / owe_favor
      / 永久失去世界认可资格 / 该道下一扇门 p −0.30
```

> **灌顶从"作弊"变成了"借贷"**：它不让你跳过门，只让你更容易掷中——而"下一扇门 −30%"就是利息。**借来的悟，是要还的。**
>
> "永久失去世界认可"这条代价没变——**因为世界认可（养灵 Lv5）是唯一一个"必须是别人给的"层级，借来的道换不到它。**
>
> 这也顺手解释了 §7.2 里养灵"门占 57%"的设计意图：**灌顶只改判定概率，而养灵的门是全部成本的大头**——所以灌顶对养灵最有诱惑力，也最贵。**给卡死的人一个出口，和一段"借他人之道"的悲剧感。**

## 8. 跨境界压制：高阶道把低阶墙削成坎

不是减百分点，是**把失败率压到十分之一**。

```text
p' = 1 − (1 − p) × 0.1
```

| 已达成     | 压制对象      | 原 p | 压制后 p' |
| ------- | --------- | --- | ------- |
| 炼气 · 破胎 | 锻体「调气息」门（进调息） | 0（资质 60） | **0.90** |
| | | 0.50（资质 70） | 0.95 |
| 炼气 · 法相 | 锻体「归元」门（进朝元）  | 0（资质 79） | **0.90** |

> `[改]` 这是**乘在"失败率"上，不是乘在成功率上**：p=0 被压成 0.90，p=0.50 只被压成 0.95。**所以它救的是"完全没有门"的人，对本来就有门的人几乎无用**——这正是"跨境界压制"该有的样子：**削墙，不加翼。**

**这是"优先修后面的大境界"的全部收益。**

对资质 50–60 的人，这两扇门原本 p=0（一辈子等不到），被压制后 **p=0.90，平均 1.1 年就过**。所以中期唯一解法是：

```text
锻体卡在调息 → 转炼气推到破胎 → 回头过调息（p 0→0.9，约一年）
             → 再卡朝元 → 推到法相 → 回头过朝元（同上）
             → 再卡金身 → 这次没有压制了，必须去拿世界认可
```

这条链路把「资质」「悟性」「跨境压制」「认可」四件事串成了一条主线，而不是四个独立的数值表。

#### 「凡人」的正式定义 `[定]`

> 用户原话：「凡人指锻体的体魄和脏腑，炼气的感气。」

```text
凡人 ＝ 锻体 · 体魄 / 脏腑
     或 炼气 · 感气
     或 什么都没修
```

**这条定义有三个用处，都不小**：

1. **它是"安生活法"的天花板**。`修真百艺.md` §10.5 的安生玩家可以修，但上限就到这里——**体魄、脏腑、感气都能练，调息、破胎一步都不能迈**。这一步不是行政规定，是生理事实：**没换过命的人，只有 60–85 年。**
2. **它统一了寿元表的零点**。旧表把"凡人"写成"未入朝元"（＝炼气才算），新表写成"体魄/脏腑"，现在再补上"感气"——**三段说法其实是同一件事：还没换命**。调息是第一次换气、驭凡是第一次拿气改身，从那里起才叫修行者。
3. **它给了"灵量权重"一个自然的下界**。`身份系统.md` 里凡人权重 0.2，锻体 1、炼气 2。**一个脏腑练满的人，灵量仍然是 0.2**——因为他没换命，对灵量的贡献和一个农户一样。这也解释了为什么城主不会去招一堆脏腑满的人来凑灵量。

> 注意 **感气为什么算凡人，而破胎不算**：感气只是"气机入体"，能感觉到灵气、能辨宝物真假，但**身体还是那具身体**；破胎是"结胎"，是把灵气凝成自己的根，那是第一次质变。所以感气 60–85 年，破胎之后才有变化（§9.1 的"前两品不加寿元"与此一致）。

### 9.3 为什么五品大提、六品统一 1,000

**一、第六品统一 1,000，是"极境"的定义，不是数值巧合。**

| 极境      | 寿元        | 说明                        |
| ------- | --------- | ------------------------- |
| 锻体 · 临虚 | **1,000** | 悟道，对常境必胜                  |
| 炼气 · 化朽 | **1,000** | 悟道，对常境必胜                  |
| 养灵 · 回春 | **∞**     | 悟道 + 养灵层级 Lv6，且能返老           |
| 修心 · 不惑 | **1,000** | 修心的第一品就是极境，所以也是 1,000      |

三条道的极境同寿，因为**极境是"跳出常规阶梯"**：到这一步的人已经不是在按品级活着了。修心例外——它第一品起步就是极境，所以 1,000 从第一品就给。回春再往上走一层，所以是 ∞。

**二、第五品提幅很大，因为旧值根本装不下第五品本身。**

```text
旧表：金身 130–150 —— 但锻体练到金身普遍要 60–100 岁，等你到了，寿元只剩 50 年
      合一 240–280 —— 同理，到了就快死了
```

第五品是"极境前的最后一步"，玩家在这里要停很久（锻体金身要世界认可，炼气合一要悟道前置）。**给 130 年等于告诉玩家"第五品只是死后追认"**。所以金身 130 → 300，合一 240 → 350，都按"够你在第五品站满 100–200 年"来定。

### 9.4 两条无限寿元：返老与转世 `[定]`

用户定：**养灵·回春不断重置年龄，修心·转世重修重开一世，两者理论上都是无限寿元。** 但两条路的代价完全不同：

**一、回春 → 返老（同一具身体，反复重置）**

```text
触发：进入 养灵·回春（养灵层级 Lv6 + 悟道）后可主动发起
效果：年龄 = 30 岁。境界 / 修为 / 养灵层级 / 记忆 / 物品 全部保留
冷却：100 年一次
代价：① 灵量减半（治下生灵枯竭一批，必须重新经营）
      ② 心性 −2（每次）
```

> **这不是免费的永生**。灵量减半意味着每 100 年要重新把势力攒回来一次——所以回春者必然是**最不愿意放手权力的人**，也必然是**最容易被夺城的人**。这条比"寿元 ∞"本身有意思得多。

**二、转世重修（换一具身体，重开一世）**

| 项   | 规则                                   |
| --- | ------------------------------------ |
| 触发  | 修心·不惑 起                             |
| 保留  | **命格 + 心性**（同一个人，只是换了身体）              |
| 不保留 | 天赋（重新随机）、境界、寿元、物品、金钱、身份、记功           |
| 重置  | 年龄回 7 岁，从蒙学开始                        |

> **心性不重置是本轮的关键决定**：因为"还是同一个人"。所以——
>
> - 心性被自己练到 95 的人，转世后依然是 95，下一世能直接再修心；
> - **心性跌破 90 的人，转世一百次也进不了修心**。
>
> 这条把"修心"变成了唯一一个**不可回滚**的进度条。它比"会死"更狠：死只是结束，心性崩了是**永远失去入口**。

>
> "不成立了"是好事，理由有三条：
>
> 1. **养灵不再依赖一个尚未设计的系统**。它现在可以独立上线，续命只是让路走得舒服一点。
> 2. **续命从"生死"变成"经济"**：75 年 ≈ 一条命的价格（`修真百艺.md` 三档丹 620–1,250 金，约城主一年收入）。玩家感受到的是"我花了一年收入买时间"，而不是"我在等一个人施舍我两百年"。
> 3. **它顺手造出了一条清晰的丹药线**（见下表）——**只有城主这一档能靠市场解决，而且余量只有 1–5 年**。这个临界点比任何"势力专属"的设定都自然。
>
> 唯一还靠续命才能成立的是**双 80**：缺 190 年，怎么都补不上。但那本来就是"进得去、走不动"，不靠续命也该走不动。

#### 续命的三层（`修真百艺.md` §4.7 定的口径）

延寿丹已定三档：**+10 / +20 / +50 年，每种只能吃一次，合计 +80 年**，药材只能出自养灵·回春境界。**叠加（§9.6），不吃亏、终身有效。**

| 层 | 手段 | 增量 | 门槛 | 谁能拿到 |
| - | --- | --- | --- | --- |
| ① 市场 | 延寿丹 ×3 | **+80 年** | 620–1,250 金 | 有钱就行，但买完就没了 |
| ② 势力 | 宝药 / 机缘 | +100~300 年 | 身份、记功、人情 | **将军到城卫**，一次记功即兑现 |
| ③ 境界 | 回春返老 | 无限 | 3 阶 6 品 | 极境者 |

**三档丹把身份切成两段，而且第二段的尽头只有一个例外**：

| 身份 | 续命需求 | ① 市场（+80） | 还需要 ② 多少 | 补上之后 |
| --- | --- | --- | --- | --- |
| **城主（顶）** | **75 年** | ✅ **余 5** | 0 | 走完六品（750 岁回春） |
| **城主（中）** | **79 年** | ✅ **余 1** | 0 | 走完六品（776 岁回春） |
| 将军 | 101 年 | ❌ 缺 21 | 21 年（一次记功） | **通顶**（931 岁回春） |
| 宗主 | 124 年 | ❌ 缺 44 | 44 年（一次救命之恩） | **通顶**（1,090 岁回春） |
| 家主 | 158 年 | ❌ 缺 78 | 78 年（一次大机缘） | **通顶**（1,320 岁回春） |
| 城卫 | 196 年 | ❌ 缺 116 | 116 年（两次大机缘） | **通顶**（1,585 岁回春） |
| 散修 | 269 年 | ❌ 缺 189 | 拿不到 | **补了也卡在浑然**（972 > 969） |

> **这条线比"身份过滤器"好用得多**。它不靠文案说"散修低人一等"，而是让玩家自己算出来：**我差 189 年，市场上最多卖我 80 年。** 剩下的 109 年不是钱能解决的，那才是身份。
>
> **而且线画得极准**：市场能解决的只有城主两档，**余量分别是 5 年和 1 年——差一颗丹就死**。将军和宗主各缺 21/44 年，**正好是一次人情能补的额度，而补上就是通顶**。
>
> **叠加口径让"补上就通顶"成立，这条比原来的"补了也死"有价值**。原方案里家主补 158 年仍差 7 年、城卫补 196 年仍差 80 年——那等于告诉玩家"你不该努力"。现在反过来：**你缺的只是那个能给你续命的人，不缺别的**。把惩罚从数值挪到关系上，是这个设定最该有的样子。
>
> 这个阶梯比上一版好，因为上一版的缺口是 218–691 年（全员求施舍，看着像设定漏洞），现在缺口是 21–78 年（**人人差一口气，但气数不同**）。

### 9.6 落地方式（口径已定：**叠加**）`[定]`

```js
// 额外寿元：延寿丹 / 宝药 / 机缘，一次写入角色卡，终身有效
const PILL_LIFE = { '续命丹': 10, '驻世丹': 20, '夺年丹': 50 };  // 三档各限一次

function calcExtraLife(c) {
  let y = 0;
  for (const [id, yrs] of Object.entries(PILL_LIFE)) if (c.eaten[id]) y += yrs;  // 上限 +80
  for (const b of c.baoyao) y += b.years;   // 宝药/机缘（势力专属，见 §9.5 第②层）
  return y;
}

// 寿元 = 境界给底子 + 继承下来的额外寿元（互不覆盖）
c.extraLife = calcExtraLife(c);
c.lifespan  = 境界下限 + c.lifespanRoll + c.extraLife;

// 回春·返老：只改 age，不清 extraLife
if (realm === '养灵·回春' && c.cooldown <= 0) {
  c.age = 30;
  c.lingliang *= 0.5;      // 灵量减半，须重新经营
  c.xinxing   -= 2;
  c.cooldown   = 100;
}
```

> ✅ **口径已定：叠加。** 三处必须守住的实现细节：
>
> 1. **`extraLife` 是角色卡上的一个字段，不是"每次进品重新发一次"**。城主顶吃满三丹 80 年，进真域是 480（400+80），进神游是 780（700+80），进浑然是 1,030（950+80）——**同一个 80，加在不同底座上**。写成"进品时 `lifespan += 80`"就错了，那是每品都加一次，会变成 400/480/560/640 的累加。
> 2. **境界下限的随机量只掷一次**（`lifespanRoll`），进品时记住。否则玩家读档能刷寿元上限，这是最容易出的 bug。旧写法 `max(当前寿元, 境界下限 + rand)` 之所以没这个问题，是因为它每次重掷也只会取 max、不会更高；改成加法后必须显式记住随机量。
> 3. **返老不清 `extraLife`**。返老只把 `age` 拨回 30，额外寿元是"这一世买来的寿命"，跟年龄无关。但如果不清，会不会"一次买断、永久有效"？**是的，设计上就是永久有效**——所以延寿丹的稀缺性必须靠"每种只能吃一次 + 药材只出自回春者"来守，不能靠"返老清空"来守。
>
> **为什么必须叠加**：覆盖口径会让"凡阶段吃的延寿丹"在你踏进真域那天被 400 吃掉——**玩家会觉得被骗**，而且这一骗是 75 年的命。更重要的是，叠加把整个 §5.6 的漏斗简化成一句话：**"你要多活 N 年，N = 到真域那年减 85。"** 覆盖口径下得算四个差值，玩家永远不知道自己死在哪儿。

每次寿元跃升触发一次「寿元暴涨事件」（亲友老去、城池换主、旧人成土），用来体现时间跨度。

**寿元是四段式，不是一条曲线**：

| 段        | 靠什么活                 | 玩家感受               |
| -------- | -------------------- | ------------------ |
| 0–85 岁   | 命格给的底子（薄命 −10）       | 一辈子在赶时间            |
| 85–400 岁 | **续命事件**（丹药 / 宝药 / 机缘） | 开始学会"买时间"，也是养灵的入场费 |
| 400–1,000 岁 | 境界自带（真域 / 神游 / 浑然）   | 时间变成资源，但还不够花       |
| 1,000 岁以上 | 极境（临虚 / 化朽 / 不惑）或 **∞** | 时间不再是威胁，开始担心别的东西   |

### 9.7 长寿的时间感

养灵之后一次闭关就是几十年，不能让玩家点上千次。两套机制并用：

- **长跨度事件**：顿悟 8–12 年 / 闭关 20–50 年 / 云游 15–30 年
- **轮播事件**：无选项，直接快进，连续 3–8 条短叙事，遇到抉择才停
