## 1. 结算规则：条目列表 + 层内聚合 + 层间定序

每个数值属性都按同一条公式算。**公式永远不变，变的是填进去的条目。**

### 1.1 唯一公式

```text
v = 基础值
for 层 in [事件, 扩展, 身份, 天赋, 命格]:     # 层间顺序固定
    mul = 1 + Σ(该层所有百分比)
    add = Σ(该层所有固定值)
    v = v × mul + add
终值 = clamp(v)
```

| 规则 | 内容 |
|---|---|
| 层间 | 五层顺序固定，不可调换 |
| 层内 | 先求和再应用，**与条目顺序无关** |
| 百分比 | 相加不相乘：两个 +10% 是 +20% |
| 固定值 | 只加在自己那一层，不被同层百分比放大 |

### 1.2 记法：区间是聚合结果，不是存储单位

```text
80[*0.9][][][][+20]
```

五段位置固定，`[]` 表示该层无条目。每段写的是**这一层所有条目聚合后的结果**：

```text
[*1.1 +1]   读作   v × 1.1 + 1
```

对应存储是两条独立条目：

| id | 层 | 来源 | 类型 | 值 |
|---|---|---|---|---|
| `t-alchemy-master` | 天赋 | 炼丹达人（丹药数量 +10%） | pct | +0.10 |
| `t-alchemy-hand` | 天赋 | 炼丹妙手（每次多 1 颗） | flat | +1 |

一次炼丹 10 颗：`10[*1.1 +1] = 10×1.1+1 = 12`。
若两个天赋都是 +10%，聚合为 `*1.2`，不写 `*1.1 *1.1`。

**扩展层是列表，但结算前要压平。** 列表项数不改变公式形状。

### 1.3 为什么层内必须先聚合

若把列表逐项串联，`A=[*1.1 +1]`、`B=[*1.2]`：

```text
A 先：(v×1.1 + 1) × 1.2 = 1.32v + 1.2
B 先：v×1.2 × 1.1 + 1   = 1.32v + 1
```

同一组规则，只因列表顺序不同就差 0.2。聚合后 pct 合计 +30%、flat 合计 +1，得 `1.3v + 1`，与顺序无关。

### 1.4 顺序不是排版，是权重

层内聚合之后逐层折叠，**越靠右的层，作用范围越大**——它作用在前面所有结果的累积值上。

| 段 | 区间 | 时间性 | 作用范围 |
|---|---|---|---|
| 第 1 段 | 事件 | 此刻发生 | 只作用于基础值 |
| 第 2 段 | 扩展 | 外物与环境 | 包含事件结果 |
| 第 3 段 | 身份 | 社会位置 | 包含事件、外物 |
| 第 4 段 | 天赋 | 与生俱来的能力 | 包含前三层 |
| 第 5 段 | 命格 | 命 | **作用于全部** |

一句话：**越根本的东西越靠右，越不会被左边打折。**

这就是「长寿 +20」不怕「折损 10%」的原因——它在最外层，前面的乘法够不到它。

### 1.5 每层放什么

| 层 | 放什么 | 不放什么 |
|---|---|---|
| 事件 | 本次选择产生的数值效果、一次性遭遇 | 概率与开关（不进链） |
| 扩展 | 装备、丹药、宝地、环境、伤病、他人助力 | 身份与天赋（各有专层） |
| 身份 | 出身、家庭状态、社会地位、学籍、职业 | 家世数值本身（走身份效果） |
| 天赋 | 天赋的数值效果 | 天赋的解锁与开关（不进链） |
| 命格 | 命格的数值效果 | 命格的特殊规则（如「必死时留一命」） |

**一个属性一条链。** 一次事件同时改钱和寿命，是两条独立的链，互不干扰。

### 1.6 抵消：删除条目，或让条目失效

断腿 -5 资质被治好、寒门 +1 银被丧失双亲抵消——这两件事形似，机制不同：

| 机制 | 语义 | 能否自动恢复 | 实现 |
|---|---|---|---|
| **移除** | 事实消失（腿好了） | 不能。再断一次是新的一笔伤 | 删除条目 |
| **失效** | 条件不成立（家没了） | 能。条件回来就自动生效 | `guard` 求值为 false |

不能合并成一种的理由：断腿治好后再次断腿，必须是**新实例**，与旧伤无关；而「被逐出家门后重新归族」，寒门的 +1 银应当自动回来，不需要重新施加一次。

所以条目带 `guard` 字段：

```text
{ id, layer, source, target, kind, value, guard }
```

- `guard` 缺省 → 恒生效
- `guard` 存在 → 每次结算前求值，false 则跳过（条目保留，随时可回来）
- 永久消失 → 由事件删除条目

### 1.7 验证：长寿

```text
80[*0.9][][][][+20] = 80 × 0.9 + 20 = 92
```

若按「先加后乘」写成 `(80+20)×0.9`，得 90。差的这 2 年，就是定序存在的理由。

### 1.8 不在链上的三类东西

| 类型 | 为什么不在链上 | 去哪 |
|---|---|---|
| 概率修正 | 不改属性值，只改某次判定的骰子 | 判定时读取，用完即弃 |
| 开关 / 解锁 | 改的是「能不能」，不是「多少」 | 直接读标签，不参与计算 |
| 上限 caps | 约束成长，不参与求值 | 最后 clamp 时使用 |

### 1.9 三种值：基础值 / 表现值 / 中间值（已定）

| 概念 | 存在哪 | 链的输入 | 链的输出去向 | 重复计算 |
|---|---|---|---|---|
| **基础值** | 存档 | —（它就是输入） | — | — |
| **表现值** | 不存，读时算 | 存档里的基础值 | 展示 / 判定，用完丢弃 | **幂等**，算一万次结果一样 |
| **中间值** | 存档 | 它自己上一次的值 | **覆盖自己** | **非幂等**，每算一次就变一次 |

三者不是三种属性，是同一个属性的三种**用法**，每个属性只能固定一种。判据只有一条：

> **今天改了规则，过去的历史要不要跟着变？**
> 要变 → 表现值。抽到「长寿」，寿元立刻从 72 变 92。
> 不该变 → 中间值。今天抽到「来财」，去年赚的 1000 铜不该变成 1200。

```text
表现值（寿元）
存：base 80
读：链(80) = 92 → 显示 92，base 仍是 80
日后规则变了：链(80) = 95 → 显示自动跟着变 95

中间值（钱）
存：1000
事件「失窃 −10%」：链(1000) = 900 → 回写，存档变 900
再失窃一次：链(900) = 810
```

同一套链，两种用法，差别只在**产物是否回写**。

#### 由此推出的三条硬约束

1. **中间值禁止在「读」时计算。** 读必须是无副作用的查询，否则每刷新一次界面钱就少 10%。
2. **中间值挂不住「持续生效」的规则。** 它不会自动重算。表现值的持续效果写在链上就永久带着；中间值的持续效果只能做成**定期事件**（每年俸禄、每年生息）。
3. **中间值回写时统一取整 + clamp 一次**，不能每步取整，否则误差累积。**取整走气运规则**（`气运系统.md` §5），不是 `Math.round`——气运在这里定"进还是舍"。

#### 「来财」放哪：条目的作用对象

中间值既然挂不住持久 pct，「每次获得金钱 +20%」就只剩一个位置——**变化量**。所以条目多一个字段：

| target | 作用对象 | 例子 |
|---|---|---|
| `value` | 整个值，进五层链 | 命格·长寿 +20 年；失窃 ×0.9 |
| `delta` | 该值本次的变化量 | 命格·来财：收入 Δ ×1.2 |

```text
余额 1000，卖符 +50
Δ 结算：50 →「来财 target:delta ×1.2」→ 60
余额 = 1000 + 60 = 1060

支出：Δ = −200，来财 when:'gain' 不触发 → 余额 860
```

若把「来财」写成 `target:value`，支出会被放大、余额还会在每次事件里复利，两处都错。

## 2. 三类修正，不能混成一种

| 类型 | 形态 | 例子 | 结算方式 |
|---|---|---|---|
| **数值修正** | `+20 年` / `+30 点` / `*0.9` | 命格·长寿、天赋·天才 | 写成条目，进入五层链 |
| **概率修正** | `失败率 −50%` / `成功率 +15%` | 天赋·炼丹达人 | 只在该次判定时生效，不进链 |
| **开关修正** | 解锁选项 / 让某条规则不生效 | 丧失双亲 → 寒门停发年银 | 体现为条目的 `guard`（§1.6），不进链 |

**为什么必须分开**：如果用「+0」表示禁用、用「×0」表示关闭，很快就会分不清「这条规则不存在」和「这条规则被压制」。开关是规则层的引用关系，不是数值。

### 2.1 四条铁律

1. **guard 只读标签与状态，不读任何终值** → 否则规则之间会成环（A 的生效依赖 B 的值，B 又依赖 A）。
2. **只允许 pct / flat 两种 op，不设 set / override** → 层内才可交换、可排序、可缓存。
3. **同类百分比相加** → 避免复利膨胀。
4. **规则不写状态** → 只有事件能产生或删除条目。

## 3. 规则源

规则不是凭空存在的，每条都挂在某个来源上。来源分两类：

### 3.1 纯规则（不占属性位）

| 来源 | 数量 | 性质 | 例子 |
|---|---|---|---|
| **命格** | 28 选 1 | 一生不改，转世保留 | 长寿：寿命 +20；天才：五维 +30；来财：金钱收益 +20% |
| **天赋** | 2–3 个 | 开局生成，极少数可觉醒 | 悟性惊人：炼气收益 +10%；炼丹达人：炼丹失败率 −50% |
| **身份** | 多标签 | 可增可减，有槽位 | 寒门：年收入 +1 银；城主：灵量增益、俸禄、强制支出 |

### 3.2 带规则的实体（本身也是属性）

装备、功法、丹药带来的临时状态——它们**同时是资产和规则源**。这类要额外记「规则是否已生效」，否则会出现「装备在身上但加成没算」。

### 3.3 规则卡

每条规则是一张卡，字段固定：

| 字段 | 含义 |
|---|---|
| `id` | 唯一标识 |
| `source` | 来源：命格 / 天赋 / 身份 / 装备 / 临时 |
| `scope` | 作用对象：寿命、资质、修炼收益、炼丹失败率…… |
| `type` | `flat` 固定值 / `pct` 百分比 / `prob` 概率 / `flag` 开关 / `unlock` 解锁 |
| `value` | 数值，或开关的布尔 |
| `condition` | 什么情况下生效；为空表示常驻 |
| `suppressedBy` | 被哪些规则压制；压制后标签仍在，效果关闭 |
| `desc` | 给玩家看的一句话 |

**关键设计**：`suppressedBy` 而不是「删除规则」。丧失双亲不会抹掉「寒门」这个身份，只是让它的现金流效果停摆——标签还在，效果关了。

## 4. 身份系统

身份不是枚举单选，是**标签集合**；每个标签属于一个槽位。

### 4.1 槽位

| 槽位 | 说明 | 例子 |
|---|---|---|
| 出身 | 家世档位 | 大族嫡系、寒门、孤儿 |
| 家庭状态 | 双亲与家庭变故 | 父母健在、丧失双亲、被逐出家门 |
| 社会地位 | 权力与责任 | 凡人、散修、家主、宗主、将军、城主 |
| 学籍 | 在读状态 | 蒙学、府学、太学、卒业、肄业 |
| 职业 | 谋生手段 | 炼丹师、铁匠、符师 |

**同槽互斥，跨槽并存。** 一个人不能同时是城主和将军（同槽），但可以是「寒门 + 丧失双亲 + 城主」（跨槽）。

### 4.2 三种关系

| 关系 | 含义 | 例子 |
|---|---|---|
| 叠加 | 不同槽的效果同时生效 | 寒门 +1 银/年，城主另有俸禄 |
| 压制 | 一条规则让另一条失效 | 丧失双亲 → 寒门的现金流停摆 |
| 互斥 | 两个标签不能共存 | 城主与将军 |

### 4.3 灵量只认社会地位

已有定稿：养灵增益按**社会地位槽里最高的那个**算，不叠加。城主 ×4.08、将军 ×3.64、宗主 ×3.14、家主 ×2.24、散修 ×1.19。
所以「身份不叠加」只针对灵量；收入、事件权限等其他效果仍可跨槽叠加。

### 4.4 家世放哪里

**结论：家世并入身份，作为「出身」槽，不单独建一套系统。**

理由：家世要的全部能力——给年供、开事件白名单、成年后衰减、被家庭变故压制——身份系统全都有。单独建一套只会得到两份几乎相同的规则引擎。

如果仍觉得「出身」和「社会地位」混在一起别扭，做法是**在界面上分组展示**，数据仍是一套：出身、家庭状态归「家世」页签，社会地位、学籍、职业归「身份」页签。

## 5. 角色属性总表

按新口径，命格、天赋、出身、家世**已移出属性表**（它们是规则）。剩下的按 §1.9 的三种值归类，加约束与标记共四类。

### 5.1 表现值（不存，读时走链）

| 表现值 | 基础值从哪来 | 修正举例 |
|---|---|---|
| 资质终值 | 存档的资质底值 | 命格·天纵奇才 +30；天赋·宿慧 +15；断腿 −5 |
| 悟性终值 | 存档的悟性底值 | 天赋·悟性惊人 ×1.1 |

### 5.5 资质与悟性的生成 `[定]` `[推]`

> 用户原话：「资质，悟性两者之和正常人是110-130，具体值用气运计算，然后再随机分给资质，悟性。要注意悟性、资质单项特别低的人是活不下来的。为了游戏正常进行，应该要有基线。」

**资质和悟性不再各自 roll。** 先定**总和**（由气运决定），再**随机分配**——因为"和"才是命，怎么分是天赋的偏科。

```text
k = 气运 / 50                                    # 见 气运系统.md §3
基础和 S₀ = 110 + (k − 1) × 10 + random() × 20   # 气运 50 → 110–130（普通人）
总和   S = S₀ + 命格 + 事件 + 资源               # 加法，不是撑上限

r = 分配比例
  r_lo = 0.40 − 0.014 × max(0, 20 − 气运)        # 气运 20 → 0.40；气运 0 → 0.12
  r    = r_lo + random() × (1 − 2 × r_lo)        # 气运 20 → [0.40,0.60]；气运 0 → [0.12,0.88]

资质 = round(S × r)
悟性 = S − 资质
```

**`[定]`「110–130」是出生落点，加的东西全部直接叠在原值上**（用户原话：「普通人出生范围就是110-130，然后命格可以加，例如天才+30（直接再130上限加）」）。所以 130 不是天花板，它是**大多数人的出生上限**；带天才命格的身体，一出娘胎就是 130–160 那一档。

| 层 | 来源 | 加多少 | 性质 |
| --- | --- | --- | --- |
| **出生** | 气运定和 | 110–130（气运 50） | 永久 |
| **命格** | 天纵奇才（天才） | **+30**（直接加在 130 上面） | 永久 |
| **天赋** | 宿慧 | **+15**（可分配到资质/悟性） | 永久 |
| **事件** | 顿悟 / 传承 / 灌顶 | 单次最多 **+20**（一生 1–2 次） | 永久 |
| **资源** | 药浴 / 洗髓 / 宝物 | **合计最多 +15** | 永久 |
| **临时** | 悟道丹 / 宝地 | **合计最多 +10** | **临时，不进永久值**（§5.6.1） |

**基线仍在 `r_lo` 里。** 气运 ≥20 的人 `r ∈ [0.40, 0.60]`，而 S 最低 110 → **单项最低 44**。这就是"为了游戏正常进行"的基线：**正常人的偏科最多偏到 44:66**，不会出现"资质 15、悟性 115"的废号。

气运 <20 的人 `r` 的区间被逐步放开——**命差的人连"偏科"都偏得更极端**。

| 气运 | S 范围 | 分配比例 | 单项范围 | 会不会夭折 |
| --- | --- | --- | --- | --- |
| 0（绝境） | 100–120 | [0.12, 0.88] | **12–106** | **大概率**（见 §5.5.2，约七成） |
| 10（差） | 102–122 | [0.26, 0.74] | 27–90 | 有时（35%） |
| **20–80（正常）** | **110–130** | **[0.40, 0.60]** | **44–78** | 几乎不会（5%） |
| 90（好） | 118–138 | [0.40, 0.60] | 47–83 | 不会 |

#### 5.5.1.1 冗余是算术需求，不是保险 `[定]` `[改]`

> 用户原话：「因为你随机的时候不一定是平分的，肯定要有冗余才行。」

**先看分配是怎么来的**（§5.5）：`资质 = round(S × r)`，`悟性 = S − 资质`，而 `r ∈ [0.40, 0.60]`（气运 ≥20 的正常人）。

> **`[定]` r12：`r` 按均匀分布算。** 用户原话：「r 先按平均算。」
>
> 所以下面的概率是"均匀口径"，`P = clamp((1 − 160/S) / (r_hi − r_lo), 0, 1)`。若日后让 r 向 0.5 聚拢，概率会整体上移——**但那样"冗余"的必要性就被削弱了，所以均匀是保守的基准，不是临时方案。**

**双 80 的成立条件**：

```text
S × r ≥ 80   且   S × (1 − r) ≥ 80
→  r ∈ [ 80/S , 1 − 80/S ]
→  容错宽度 W = 1 − 160/S
```

| 和 S | 能双 80 的 r 区间 | 容错宽度 W | 在 [0.40,0.60] 里命中的概率 |
| --- | --- | --- | --- |
| **160** | 恰好 0.500 | **0** | **0%** ← 必须精确平分，连续分布下不可能 |
| 165 | [0.485, 0.515] | 3.0% | 15% |
| 175 | [0.457, 0.543] | 8.6% | 43% |
| 180 | [0.444, 0.556] | 11.1% | 56% |
| 190 | [0.421, 0.579] | 15.8% | 79% |
| 195 | [0.410, 0.590] | 17.9% | 90% |
| **200+** | 覆盖整个 [0.40,0.60] | ≥20% | **100%** |

**这张表推翻了上一版的一个隐含错误。** 上一版写"165 → 双 82/83，过线"，那是**假设完美平分**——但平分本身是概率为 0 的事件。真实的 165 只有 **15%** 的人能双 80。剩下 85% 落在容错区间之外——比如 `r=0.47` 时是 **78 / 87**，一边过线、一边差 2 点，养灵的门就打不开。

**所以"和 200"不是给完美主义者准备的，它是唯一的稳健解**：只有 S ≥ 200，无论 r 怎么偏（在 0.40–0.60 内），都必然双 80。

> **`[定]` 超过 200 那 10 点不是浪费。** S=210 时 caps 会把它砍回 200（资质/悟性各封顶 100），看起来白给。但**它买的是"偏了也有 100"**：S=210、r=0.55 的实际落点是 `100 / 94`（资质 115 被钳到 100），S=200、r=0.55 是 `100 / 90`。多出来的 10 点全部用来**垫高被钳那一侧的对侧**——这就是保险金的本义：**不是为了让平均值更高，是为了让最坏情况不破线。**

**这也是为什么天赋那 +15 是必须的**——它把 S 从 165 抬到 180，把 15% 提到 56%，把"碰运气"变成"多半能成"。

**而"命薄的人少一截"在这里变成了一条可算的硬话**：

| 出生 S₀ | 吃满（+15 天赋 +20 事件 +15 资源） | S | 双 80 概率 |
| --- | --- | --- | --- |
| **110**（气运 20 的下限） | +15 +20 +15 = **+50** | **160** | **0%** |
| 120 | +50 | 170 | 29% |
| 130 | +50 | 180 | 56% |
| 110 + 天才 +30 | +80 | 190 | 79% |
| **130 + 天才 +30** | +80 | **210** | **100%** |

> **`[定]` 所以"命薄的人连用力气换的资格都少一截"是对的，而且比上一版更硬**：出生 110 的人把一辈子榨干（事件 + 资源 + 天赋全拿），**和正好 160，双 80 概率为零**——他差的那 10 点，不是运气，是**必须在分配的那一刻正好劈成两半**，而这在连续分布里不发生。
>
> 气运 <20 的人更惨：r 区间被放宽到 `[0.12, 0.88]`（§5.5），**分母从 0.20 变成 0.76**，同样 210 的和，概率从 100% 掉到 **31%**。**命越薄，越难"分得匀"。**

> 它不再问"你总和多少"，而问"**你的和够不够宽，宽到即使分歪了也不塌**"。这就是为什么命格（+30）和天赋（+15）比事件（+20）和资源（+15）值钱——**它们加在最前面，抬高了 S 本身，也就抬高了整个容错区间**。
>
> 而资源那 +15 之所以仍然重要：它是**唯一能用钱买的**。锻体者 49 年收入换 15 点，把 160 变 175——**从 0% 变 43%**。这是全游戏最贵的一次"从不可能到可能"。
>
> **出生 110–120 且没抽到宿慧的人，仍然进不去**（145–155，概率 0%）。这条和气运设定一致，不修。

**`[定]` 一条必须补的分配规则（否则上面那张表的"均匀分配"没有依据）**：

| 来源 | 能不能选加在哪一项 |
| --- | --- |
| 命格（天纵奇才 +30） | **可分配**——天才不是一个方向，是整个人 |
| 天赋（宿慧 +15） | **可分配**——建号时就能指定，这是它对"冗余"起作用的前提 |
| 事件（+20） | **可分配**——"传承/灌顶"补的往往是短板 |
| 药浴 / 洗髓 / 大洗髓 | **只加资质**，不可挪 |
| 悟性宝物 | **只加悟性**，不可挪 |

**所以永久资源的 15 点是"半固定"的：资质侧最多 9（药浴 3 + 大洗髓 6）、悟性侧最多 6（宝物）**。想双 80 的人，必须靠**事件那 20 点和天赋那 15 点去补另一侧**——前者是命，后者是命格之外唯一的"建号红利"。

> **另一件事也解释清了**：为什么洗髓这么贵还有人买（5–20 金 ≈ 锻体者一年收入）。因为**它是唯一一样"钱能直接买到和"的东西**——命格你抽不到，事件你等不来，只有洗髓是明码标价的。而"差 5 点"的人，往往就是靠它补上最后一段的。
>
> 但钱买不到"容错"。**洗髓把 S 从 160 抬到 175（0% → 43%），却永远抬不到 200（100%）**——因为资金侧总共只有 15 点额度。**最后那 25 点，只能靠命格和天赋。**

#### 5.5.2 存活判定

走 `气运系统.md` §4.4：`P(活到 7 岁) = 0.95 − 0.03×max(0, 30−min) − 0.03×max(0, 20−气运)`。

> **这张表回答了一个旧问题**：为什么旧设定里"资质 30–40 = 很弱"这一档几乎见不到？因为**这个档位的人大多没活到能被测出来的年纪**。游戏里出现的所有角色，都已经通过了那道 95% 的筛子；剩下那 5% 是"你听说过的、别人家的、没养大的孩子"。

### 5.6 资质 / 悟性的成长：资源按品阶卡死 `[定]` `[改]`

> 用户原话：「药浴、洗髓、宝物这些属于百艺和资源一类，只要严格限制其适用品阶就行。此外还需要注意，作业和价值正相关。例如药浴一年增加1点资质，花费1金，上限3点。」

**核心口径：这些资源不是"钱能买属性"，是"钱能买一次机会"。** 每一样都带**适用品阶**，出了那个品阶就是废纸。

| 资源 | 适用品阶 | 效果 | 价格 | 上限 | 由谁做 |
| --- | --- | --- | --- | --- | --- |
| **药浴** | **锻体 1–3 品** | 资质 **+1/年** | **1 金/年** | **+3（共 3 年）** | 丹道 + 灵植 |
| **洗髓** | **锻体 1–4 品** | 资质 **+3**，一次性 | 5 金 | 一生一次（与大洗髓**互斥**） | 丹道 + 医道 |
| **大洗髓** | **锻体 1–4 品** | 资质 **+6**，一次性 | 20 金 | 一生一次（**取代**洗髓，不叠加） | 丹道 + 医道（需 4 品丹师） |
| **悟性宝物** | **按宝物阶：1 阶止于炼气 2 品 / 2 阶止于 3 品 / 3 阶止于 4 品** | 悟性 **+1 / +2 / +3** | 3 / 8 / 15 金 | 每人最多 3 件，**合计上限 +6** | 天生地养，器道只能"养"（百艺 §4.3.1） |
| **养宝** | 炼气 1–4 品 | 宝物加成 ×1.3–1.8 | 工费 2 金 | 每件 3 次 | 器道 |

> **`[定]` 一行硬规则：永久资源合计封顶 +15，按取得顺序先到先算。** 分项加起来正好 15（药浴 3 + 大洗髓 6 + 宝物 6）——**这是刻意的"刚好够"，不是"略有富余"**。任何一项缺席，就再也补不回来：洗髓和大洗髓互斥、宝物只能三件、药浴只开到锻体 3 品。**这就是"代价大"的落地方式——不是贵，是不可逆的排他。**

**价格与效果正相关，但边际递减**——这是刻意设计的：

| 投入 | 得到 | 单价 |
| --- | --- | --- |
| 3 金（药浴 3 年） | 资质 +3 | **1.0 金/点** ← 最划算 |
| 5 金（洗髓） | 资质 +3 | 1.67 金/点 |
| 20 金（大洗髓） | 资质 +6 | 3.33 金/点 |
| 26 金（宝物三件 +1/+2/+3） | 悟性 +6 | **4.33 金/点** ← 全表最贵 |
| **49 金（全买）** | **和 +15** | **3.27 金/点** |

**分项是不对称的，这一点必须写死**：三条路（药浴 / 洗髓 / 宝物）里，前两条只加**资质**，只有宝物加**悟性**。所以永久资源的天花板是**资质 +9、悟性 +6**——**偏科的人靠钱修不回来**，只能靠出生时的分配比例（§5.5 的 `r`）补。这也是"和 15"里唯一一处不可调的地方。

为什么最划算的排在最前：**药浴买的是"时间"，不是"资质"**——它要你连续三年每年泡一次，你在这三年里不能远行、不能闭关、不能出城。**它便宜是因为它占你的位置**（§5.7）。

**适用品阶的意义**（每一条都是世界观）：

| 为什么卡在这里 | 说明 |
| --- | --- |
| 药浴卡在锻体 3 品 | 调息之后，肉身是"劲"在养，不是"血"在养——泡药只能改血，改不了劲 |
| 洗髓卡在锻体 4 品 | 朝元之后骨髓已成，"洗"不动了。金身的人去洗髓 = 拿水冲石头 |
| 宝物卡在炼气 4 品 | 法相之后悟性已经"定形"，外物只能锦上添花，不能改底子 |

> **这条约束同时解决了三件事**：① 防止"氪金堆属性"——钱最多买到 +15 的和，而且买不到命格的 +30、也买不到事件的 +20；② 让百艺有稳定的客户（每到一新境界，全套资源换一茬）；③ 解释了为什么"寒门天才"能翻身：药浴 3 金，一个府学丹徒三年攒得下来（`修真百艺.md` §4.2）。

#### 5.6.1 临时加成：悟道丹与宝地 `[定]` `[改]`

上面那张表是**永久值**（写进角色卡，一生有效）。还有一类是**临时值**——不写进属性，只在"当前生效"里加。

| 来源 | 加成 | 时长 | 按品级调整 |
| --- | --- | --- | --- |
| **悟道丹** | 悟性 **+5** | **1 年** | 1 阶 +3 / 2 阶 +5 / 3 阶 +8 |
| **宝地** | 资质 **+5**、悟性 **+5** | **在宝地内** | 1 阶 +3 / 2 阶 +5 / 3 阶 +8 |
| 宝物 | 悟性 +1 ~ +3 | 持有时 | 已在上面表里，算永久 |

三条规则，必须写死：

1. **临时加成进"修炼基数"和"百艺基数"，但不进门槛判定。** 两个基数都吃主属性，所以"在 2 阶宝地里修炼"月修为能快 8~11%——**这就是宝地的全部价值，也是最诚实的一种加成**（它不给你修为，它给你更快的脑子）。但养灵的双 80、修心的心性 90 只看**永久值**：否则一颗悟道丹就能进养灵，全游戏最窄的那道门变成药铺。`[推]`
2. **同一来源不叠加，不同来源相加。** 宝地 +5 和悟道丹 +5 可以同时生效（+10 悟性），但两座宝地不能叠（你只能在其中一座里坐着）。
3. **临时加成合计封顶 +10**（`[定]` r11）。所以 3 阶丹（+8）+ 3 阶宝地（+8）= 16，**实际按 10 算**——"推到 10"是上限，不是"随便叠"。

> **临时值计入属性显示，所以 200 是"看得见的 200"。** 门槛判定用永久值（最高 210，已封顶），但角色面板上，一个带着 3 阶悟道丹、坐在 3 阶宝地里的双 95 修士，资质与悟性都会显示 **100/100**——**这就是这个世界里"满值"的样子：它从来不是一个稳定状态，是一个瞬间。**

**`[定]` 资源加成不能破 caps（资质/悟性 各 100）。** 药浴、洗髓、宝物全部受 §5.3 的上限约束；临时加成同样受 caps 约束（不能把 100 顶到 105）。

#### 5.6.2 `+5` 点到底值多少：公式与核算 `[定]` `[改]`

> 用户原话：「资质、悟性 +5 点哪有那么高的收益，你的计算公式列出来看看。」

**先给完整算式，一条不漏**：

```text
① 养灵修炼基数   B = 0.10 + 0.90 × 进度                        ∈ [0.10, 1.00]
                   进度 = (资质 + 悟性 − 160) / 40   和 160→0，200→1
                 = 0.10 + 0.0225 × (和 − 160)      ← 线性，无递减；0.90 只乘进度
② 每点"和"的边际   ΔB / Δ和 = 0.0225
③ 月修为        月修为 = B × 20 × 增益（身份→灵量，城主顶 ×4.09）
④ 耗时          耗时 = 修为总量 ÷ 月修为        ← 时间是基数的倒数，不是正比

锻体/炼气另走一条：
⑤ 修炼基数 = 主属性 × (0.70 + 0.15 × 功法品阶) + 境界品 × 2
   锻体 资 60 / 黄上(3) / 品 3：60×1.15 + 6 = 75.0 → 加 5 点 = 80.75（+7.7%）
   炼气 悟 70 / 玄(4) / 品 3： 70×1.30 + 6 = 97.0 → 加 5 点 = 103.5（+6.7%）
```

**把"和 +10"（宝地 +5/+5 或悟道丹 +5 加宝物 +5）代入 ①**：

| 起点 | B | +10 点后 | ΔB | 相对增幅 | 养灵 1 品耗时（城主，5,400） |
| --- | --- | --- | --- | --- | --- |
| 双 80（门槛） | 0.100 | 0.325 | +0.225 | **+225%** | 55.1 年 → **16.9 年** |
| 双 85 | 0.325 | 0.550 | +0.225 | +69% | 16.9 年 → 10.0 年 |
| **双 90** | **0.550** | **0.775** | **+0.225** | **+41%** | 10.0 年 → 7.1 年 |
| 双 95 | 0.775 | 1.000 | +0.225 | +29% | 7.1 年 → 5.5 年 |
| 双 100 | 1.000 | 1.000 | 0 | 0% | 5.5 年 → 5.5 年 |

**三个结论，逐条认账**：

1. **"+5 点"本身不等于 41%。** 它恒定给 **+0.225 基数**，也就是全域跨度（0.10→1.00）的 **22.5%**——这个数是固定的，和你在哪一档无关。**41% 只是"双 90 这个点"的相对值**，是低基数处的放大效应：同样的 +0.225，在 0.55 上是 +41%，在 1.00 上是 +0%（已经封顶）。
2. **上一版把"双 90 处的局部比值"写成了普遍规律，这是表述错误。** 已改：`修真百艺.md` §4.1 与本表统一按"ΔB = +0.225"表述，不再单写 +41%。
3. **"养灵必须禁外物"的结论不变，但理由换了。** 不是"+41% 比城主还猛"，而是：**在门槛点（双 80）上，+10 点把 55.1 年压到 16.9 年**——它直接把"进得去走不动"改成"走得动"。**一颗丹药不该有资格改写一个境界的判据。** 这才是禁外物的真正理由，比比值更硬。

> **顺带解释"为什么锻体炼气吃宝地只有 7%"**：它们的基数是 `主属性 × 系数` 的线性式，+5 点就是 +5%×系数 ≈ +6~8%，没有低基数放大。**同一件宝地，在锻体是"锦上添花"，在养灵是"改命"**——差别不在宝地，在那条基数曲线是不是从 0.10 起步。

### 5.7 心性：自然衰减 · 事件 · 位置 `[定]` `[改]`

> 用户原话：「心性在学校里时每年减少1点，离开学校后每年减少2点（这里就要求能标定用户位置，由此还会有其他作用，例如只有在城里才有坊市，才能买东西），另外还有事件额外扣减，这两者单独计算。」

#### 5.7.1 四条线，各走各的 `[定]` `[改]`

```text
出生               心性 80–90（少数 95+）
                   命格/天赋加在其上：道心天成 +18、澄心 +10、钝根 +10…
区间               0 – 100            ← 上限 100 不可破
  ★ 修心层级 ≥ Lv1（不惑）之后 → 自然衰减归零，此生不再随时间下落   ← r11

① 自然衰减（每年一次，自动）
  在校（蒙学 / 府学 / 太学）  →  心性 −1
  离校（城中 / 野外 / 路上 / 秘境）→  心性 −2
  7 岁前不衰减（赤子之心，未被世事磨损）
  ★ 地板 60 —— 掉到 60 就停，此后不再随时间下落（r14）
  ⚠️ 地板只拦自然衰减，拦不住事件——事件可以把它一路压到 0

② 事件（两个方向，各自记账）
  扣减：目击杀戮 −5 / 被至亲背叛 −8 / 破境失败 −3
  提升：大彻大悟 +15 / 问心 +8 / 顿悟 +5    ← 一生只有数列，极稀有
  两者都不占自然衰减的额度，也不受"每年一次"限制

③ 心关（修心后才有）
  失败 → 30% 概率 心性 −1（`境界系统总纲.md` §6.3 ④）
  这条线入修心之后仍然生效——衰减停了，磨损没停

④ 心魔（心性掉进危险区之后才有，见 §5.7.1.1）
  40 – 100   安全区
  21 – 39    每年 p(触发) = 0.03 × (40 − 心性)     39 → 3%／年，30 → 30%／年
  ≤ 20       必定触发（每年一次，不掷触发骰）
  = 0        必定触发，且成活率为 0（道心尽碎）
```

**"单独计算"的落地含义**：一个 25 岁在城里的人，某年遭遇背叛（−8），那年他的心性是 `−2（自然）−8（事件）= −10`，而不是"扣了 8 就不扣 2 了"。**两者是加法，不是取大。**

> **`[定]` r14：「基线 60」是衰减地板，不是出生值。**
>
> 用户原话：「基线 60 意思是掉到 60 就不会随时间掉了。」
>
> 所以 60 的位置，和旧的"下限 50"是同一个位置——**它是自然衰减的下限，只是往上挪了 10 点**。出生值仍是 80–90。
>
> 这个位移的后果是决定性的：**60 高于 40 的触发线**，于是
>
> ```text
> 岁月杀不死人：自然衰减永远停在地板上，一个人不会因为"活得久"而走进心魔区
> 只有事件能：把所有心性事件按最坏的方向打满，才可能把人压到 40 以下
> ```
>
> 这条比 r13 那版"无下限"更合本作的世界观：**变老不会让人疯，遭遇才会。** 一个八十岁的老卒心性仍是 60，他一辈子没看过不该看的东西；一个三十岁的修士心性 25，因为他三年里看着师门被屠。
>
> **它也顺手解掉了 r13 一个自己造出来的麻烦**：那时把基线当出生值，凡人在 24 岁就自然跌破 40、三十岁以上活不下来一半，只好补一条"心魔只找入道者"去堵。地板一落地，那个洞自己就没了（§5.7.1.2 保留该条，但降级为叙事口径）。

#### 5.7.1.1 心魔：触发线 40 / 必死线 20 / 成活率成正比 `[定]` `[新]`

> 用户原话（r13）：「作恶和心魔没关系，本性值和心性值是两个东西……正常心性基线是 60，低于 40 概率触发心魔，20 以下必定触发。心魔成活率和心性成反比，39 活下来为 0.1。」
>
> 用户原话（r14，校正上句）：「越低越必死，基线 60 意思是掉到 60 就不会随时间掉了。」
>
> **所以"反比"要按"越低越必死"落地**，公式是 `p(活) ∝ 心性`（不是 `∝ 1/心性`）。r13 曾按字面理解成 `3.9 ÷ 心性`，推出"心性 0 反而必活"这种荒谬结论，已作废。

**先把一条最容易混的东西钉死：心魔不是报应。**

| | 本性 | 心性 |
| --- | --- | --- |
| 是什么 | 这个人是善是恶（**道德坐标**） | 这个人信不信自己（**自我确信**） |
| 谁改它 | 做事逻辑，长期累积 | 事件（怀疑 / 大彻大悟）、自然衰减 |
| 会不会招心魔 | **不会。屠城一百座，心性一点不掉** | **会。掉进 40 以下就是心魔开始咬你** |

```text
本性 10 的魔头 + 心性 95  →  心魔永远找不到他（他从没怀疑过自己）
本性 90 的善人 + 心性 30  →  年年被咬（他做尽好事，却一辈子在问"我配吗"）
```

> **这就是"心魔"这个词的本来意思**：它不是天罚，不是业报，是**自我确信崩塌之后，从里面长出来的东西**。所以吃药没用（`修真百艺.md` §5.1：醒神丹对心魔无效）、请人代悟没用（§374）、善恶也换不来豁免。

**两条线**：

```text
触发线 40   心性 ≥40 → 不会有心魔
            心性 21–39 → 每年掷一次：p = 0.03 × (40 − 心性)
            心性 ≤20 → 必定触发，每年一次（不再掷触发骰）
            心性 = 0 → 必定触发，且"道心尽碎"（成活 0）

成活线       p(活) = 0.10 × 心性 ÷ 39          ← 与心性成正比，心性 39 → 0.100
```

| 心性 | 触发 | 成活率 p(活) | 活下来的后果 |
| --- | --- | --- | --- |
| 45 | 不会 | — | — |
| **39** | 3%／年 | **0.100** | 心性 → **34**、修为归零 |
| 35 | 15%／年 | 0.090 | 心性 → 30 |
| 30 | 30%／年 | 0.077 | 心性 → 25 |
| **20** | **必触发** | **0.051** | 心性 → 15（次年仍必触发） |
| 15 | 必触发 | 0.038 | 心性 → 10（保底） |
| 10 | 必触发 | 0.026 | 心性 → 10（保底） |
| 5 | 必触发 | 0.013 | 心性 → 10（保底） |
| **0** | 必触发 | **0** | **必死**（道心尽碎） |

> **`[定]` 活下来 = `心性 = max(10, 心性 − 5)`，修为归零，境界不掉，当年不可再发起心关。**
>
> 保底 10 是必须的：否则心性 3 的人活下来变成 −2，下一年照样必触发，第三次就是死循环。**心魔可以连续来，但不能把人钉死在负数上。**

**为什么要成正比（越低越必死）：**

```text
心性 39 的人刚跌破线 —— 自我还厚，还能扛住一次，十成里活一成。
心性 10 的人已经薄如纸 —— 心魔一碰就穿。
心性 0 的人已经没有自我可守 —— 一个都活不下来。
```

> **心性在这里身兼两职**：它既是"心魔找上门的**频率**"（越低越常来），又是"扛住它的**力气**"（越低越扛不住）。所以它是一条**双杀的线**——掉十个点，来年的次数翻好几倍，而活下来的概率还在往下掉。
>
> 这就是"心性 40"这道线为什么可怕：不是因为那一刻危险，而是因为**从那一年起，每一次遭遇都比上一次更接近死亡。** 心性 39 的人还有一成机会，可他自己每活一年就掉两个点——**他在一条下坡的传送带上赌命。**

**心魔从哪来（触发源的枚举）**：

| 源 | 什么时候 | 强度 |
| --- | --- | --- |
| **自然跌破** | 心性掉进 21–39 之后的每年 | 按上表掷触发骰 |
| **修为扣穿** | 心关失败扣穿累计修为（`境界系统总纲.md` §6.3 ⑤） | **立刻触发，不掷骰** |
| **心性归 0** | 任何扣减把它压到 0 | **立刻触发，不掷骰** |

> **注意第三行**：心性归 0 触发的心魔，成活率 `0.10 × 0 ÷ 39 = 0`。所以**"心性归 0"在本作里就是死**——只是它走的是心魔这道手续，不是当场暴毙。
>
> 换成一句话：**心性是一条单调的死亡线，越薄越活不过去。** 39 活一成、20 活半成、0 一个都活不了。r13 那版"心性 0 反而必活"的写法已作废（那是把"自我越厚越难夺"推到了它的反面）。

#### 5.7.1.2 心魔只找入道者（叙事口径，不再是算术必需）`[推]` `[改]`

> **r14 降级说明**：r13 写这一条时，理由是"不补世界会崩"——那时基线被当成出生值 60，凡人 24 岁就自然跌破 40，三十岁以上活不下来一半。**地板 60 落地之后，那个洞自己就没了**：自然衰减永远停在 60，凡人不会因为变老而走进心魔区。
>
> 那这条还留不留？**留，但理由从"算术"变成"设定"**：

| 心性跌到 40 以下的人 | 会遇到什么 | 后果 |
| --- | --- | --- |
| **入道者**（锻体 1 品及以上） | **心魔** | 按 §5.7.1.1 掷触发与成活 |
| **凡人**（锻体 0 品） | **心疾** | 健忘、固执、认不得故人，**悟性临时 −10**（书读不进了）；心性到 0 是**心枯而终**，当年身死 |

> **理由不是"照顾凡人"，是"心魔要夺的东西凡人没有"。** 心魔咬的是修出来的那个"自我"——一个凡人从来没有把自己从天地里拔出来过，他心里没有那根桩，也就没有可拔的东西。
>
> **代价**：凡人不会因心魔暴毙，只会**越老越糊涂**。这反而是本作里最真实的一段：修行者死于道心动摇，凡人死于记性。
>
> **但凡人不是安全**：事件照样能把他的 60 压到 0，只是那个死法叫"**心枯**"，不叫"心魔"。**心枯是安静的死，心魔是挣扎的死**——两条路都通到同一个地方。

> **`[定]` 心性不是道德，所以这一整套没有任何"善恶加成"。** 一个恶人不会因为作恶而更容易心魔，一个善人也不会因为行善而免疫——他只会因为**自己开始不信自己**而掉进 40 以下。这条和 `本性心性命格天赋.md` §1「不因善恶升降」是同一条规则的两个截面。

> **`[定]` r11 恢复一条旧设定：入修心，心性不再自然下落。**
>
> 用户原话：「进入修心境界后，心性就不会随着时间自然下落了，我记得这个之前设定过。」
>
> 是的——r5 曾写过"修心层级 Lv1 衰减减半、Lv2 归零"，r6 为了保住"窗口游戏"把它整条废了。**现在按用户口径恢复，但只恢复"归零"这一档，且门槛放在 Lv1（不惑）**：不是减半，不是 Lv2，是**一进不惑就彻底停**。
>
> 这条的世界观解释很顺：**不惑的意思是"世事再也磨不动你了"**。心性在此之前是会被日子磨掉的，在此之后只由你自己的选择决定（事件、心关）。
>
> **但"封存"封的是时间，不是因果**（r11 补，用户原话：「还是会被事件变化，掉到 90 后还是会修为不进」）：
>
> ```text
> 归零的只有 ① 自然衰减
> 仍然生效的： ② 事件（目击杀戮 −5 / 背叛 −8 / 破境失败 −3）
>              ③ 心关失败 30% 抽 −1
> → 心性跌破 90 → 修心修炼基数归 0（`境界系统总纲.md` §6.2），修为停摆
> ```
>
> 所以修心不是"入门即通关"。**不惑不是免疫，是免疫岁月**——一个 92 心性的人，一次目击杀戮就回到 87，从此只减不增，得等下一次「问心」把它推回去。**两道关卡里，心性那道改成了"低频但致命"，层级那道改成了"一次搏命"。**
>
> 代价是修心的重心整体移到**事件与心关**上——这不是削弱，是**把随机性从"时间"换成"遭遇"**。

#### 5.7.2 位置系统 `[定]`

> 用户原话：「这里就要求能标定用户位置，由此还会有其他作用，例如只有在城里才有坊市，才能买东西。」

**位置是一个枚举字段，不是坐标。** 它决定"你现在能做什么"，而**不能做的事直接置灰**，不给替代方案。

| 位置 | 心性/年 | 能做 | 不能做 |
| --- | --- | --- | --- |
| **蒙学**（7–12） | −1 | 读书、同窗、启蒙事件 | 坊市、远行、打工 |
| **府学**（12–17） | −1 | 课业事件、师承、同窗比试 | 坊市（校内无市） |
| **太学**（17–20） | −1 | 高阶课业、藏书、结社、**知情**（`spirit_known`） | 坊市 |
| **城中** | −2 | **坊市（唯一买卖点）**、百艺工坊、任务榜、官府、雇佣、**灵量生效** | 采集、秘境、奇遇 |
| **野外** | −2 | 采集、狩猎、奇遇、遭遇战 | **坊市**（买不到东西） |
| **路上** | −2 | 移动（消耗月数） | 一切生产与交易 |
| **秘境** | −2 | 高价值资源、高风险奇遇 | 坊市、官府 |

> **本表的"心性/年"只对未入修心的人生效。** 修心层级 ≥Lv1 之后，这一列全部按 **0** 算（§5.7.1）。位置仍然决定你能做什么，但**不再决定你掉多少**。

**三条硬规则**：

1. **坊市只在城中。** 野外打到一张符、挖到一株灵草，**卖不出去也买不回来**——必须先回城。这一条让"出门"成为有成本的决策，而不是传送门。
2. **灵量只在城中/领地生效。** 养灵的 `万灵朝宗` 明写"须在城中打"（`战斗系统总纲.md` §6.6），同一个道理：**你的势，在你的人在哪才有多大**。
3. **在校是"低衰减 + 低自由"的交易。** 心性掉得慢（−1），但什么也做不了；离校自由了，心性掉得快（−2）。**学校是这个世界唯一在替你按着心性的地方。**

#### 5.7.3 心性的完整一生（三种人）`[推]` `[改]`

> **这一节按 r14 的地板 60 重写。** 出生仍是 80–90，自然衰减到 60 停，所以**每个人最后都停在 60，只是走得快慢不同**。旧稿（r13）把出生写成 60，三个人的曲线全部错位，已作废。

**① 一个普通人**（出生 85，无命格加成，未入道）：

```text
0 岁       85
7 岁前     不衰减（赤子之心）
7–20 岁    −13（在校 −1/年）
20 岁卒业  72
26 岁      60   ← 触地板，此后一生不动
```

> **他的晚年不是"心凉"，是"心定"。** 一个种了一辈子地的老农，心性停在 60：不惑、不疑、也不想。**这是本作给凡人的底线——他们不会被岁月磨穿，只会停在"够用"的地方。**
>
> **注意 60 这个数比门槛 90 低 30 点**：凡人一辈子都到不了修心的门口，不是因为他弱，是因为**他的人生里没有任何一件事把他推向"我是谁"**。

**② 一个心性命格很好的人**（出生 90 + 道心天成 +18 = 108 → clamp 100）：

```text
0 岁      100
20 岁     87      ← 差 3 点
30 岁     67
33 岁     60      ← 触地板
```

> **他天生就离门口只有 3 点**，但 20 岁那年没遇上事，就一路滑到 60，一辈子再没靠近过。**这就是"命格是门票，事件是那一脚"。**

**③ 一个真正走进修心的人**（同上，且年轻时就撞上了事件）：

```text
0 岁      100
20 岁     87
20 岁     +15（大彻大悟）→ 102 → clamp 100
100 → 每年 −2 → 到 90 有 5 年，共 6 次判定
p 从 0.80 滑到 0.30（0.30+0.05×(心性−90)）
6 次全失败 = 0.20×0.30×0.40×0.50×0.60×0.70 ≈ 0.5%
```

**三种事件额度，三种命运**（起点都是 20 岁 87）：

| 拿到什么 | 峰值 | 判定次数 | p 的走势 | 累计成功率 |
| --- | --- | --- | --- | --- |
| **只有一次顿悟 +5** | 92 | **2 次**（92 / 90） | 0.40 → 0.30 | **58%** |
| **只有一次问心 +8** | 95 | 3 次（95 / 93 / 91） | 0.55 → 0.35 | **84%** |
| **一次大彻大悟 +15** | **100**（clamp） | **6 次**（100 → 90） | 0.80 → 0.30 | **99.5%** |
| 什么都没遇上 | 87 | **0** | — | **0%** |

> **`[定]` r14：门槛 90 不降，靠事件补。** 用户原话：「门槛那个会通过事件补，不管。」
>
> 所以 r13 列的三条修法（A 降门槛 / B 减衰减 / C 加额度）**全部作废**——它们是在"出生 60"这个错误前提下推出来的。地板 60 一落地，天赋最高的人 20 岁就有 87，**差 3 点，一次事件就跨过去**。门不是走不通，是**必须命好又有机遇**。

**而一个出生 80 的普通人想修心**（这是分水岭）：

```text
20 岁     67      差 23 点
67 +15 → 82
21 岁 −2 → 80 +8 → 88
22 岁 −2 → 86 +5 → 91      ← 三次事件全打满，才刚过线
23 岁 −2 → 89             ← 窗口关了，只开了 1 年
```

> **他一生只有一次机会，而且这一次机会的成功率是 35%（p=0.35），且必须三件事在三年内接连发生。** 这就是"命薄的人连用力气换的资格都少一截"在心性上的版本——**不是不给他门，是门只开一条缝，缝还很快就合上。**

**`[定]` 于是"修心者为什么总是老人"这个说法要改。**

旧稿写"心性只有熬到那个岁数才可能够"——**那是 r13 的错误推论**（出生 60 才有"熬"这回事）。真实机制是反的：

> **修心者的窗口在年轻时，而且会永久关闭。** 20 岁 87 是最高点，此后每年 −2，到 60 触地板——**大约 33 岁以后，就算再给他十次大彻大悟，也只是从 60 顶到 75，再也够不到 90。**
>
> 所以修心的人不是"老而成道"，是"**年轻时撞上过一次，撞上了就进去了；没撞上就一辈子没撞上**"。进门之后自然衰减归零，他才开始变老——**你看到的那个白发的修心者，是二十几岁就进了门，然后活到了现在。**

#### 5.7.4 修心：一次开门，四次心关 `[定]` `[改]`

> 用户原话（r11）：「进入修心境界后，心性就不会随着时间自然下落了。」
> 用户原话（r10）：「修心本来就是两道关卡，心性和自我层级。心性会有事件提升的，但是提升后还是会递减……不然为啥修心那么难呢。」

> **r14 补一句前提**：出生 80–90、衰减到 60 停，所以"心性 ≥90"这件事**只在年轻时成立**。20 岁卒业 67–77，此后每年 −2、到 60 触地板——**窗口是一只合上就不再打开的抽屉**。
>
> 因为地板 60 **低于**门槛 90，所以存在一条硬账：到 60 之后，**再给多少次事件也补不回 90**（除非一次 +30 级别的奇遇）。这就是修心最残酷的地方——**它不是"越老越有希望"，是"越老越没戏"。**

**两句话合起来，修心变成一个前后两段的东西**：

```text
入门前（修心层级 Lv0）—— 窗口游戏
  心性必须 ≥90 才能触发"我是谁"层级事件
  每次尝试 p = 0.30 + 0.05 × (心性 − 90)      ← 90 → 30%，100 → 80%
  失败 → 层级不涨，心性继续按 −1/−2 每年掉
  心性掉回 90 以下 → 窗口关闭，等下一次事件把它顶上来
                     ★ 但如果已经触了地板 60，这个窗口就永久关闭（r14）
        ↓ 成功一次
入门后（修心层级 ≥Lv1）—— 封存
  自然衰减 = 0（r11 恢复）
  心性只由"心关失败 −1"和"事件"改变
  层级每推一品 = 过一次对应主题的心关（同样 p 公式）
```

**所以门槛只有一道，在门口。** 一旦进门，心性不会再自己往下掉——**但"心性 ≥90 才能推得动"这条依然有效**（`境界系统总纲.md` §6.2：心性 <90 时心关成功收益为 0）。区别只在于：**入门后它不会自己掉出去，除非你自己在心关里输。**

| 阶段 | 卡在什么上 | 单次代价 |
| --- | --- | --- |
| **入门前（Lv0 → Lv1）** | 心性 ≥90 **且** 层级事件判定成功 | 失败一次，可能就掉出窗口 |
| 不惑 → 天命（Lv1 → Lv2） | 心关判定 + 修为累积 | 失败 −10×基数 修为，30% 再扣 1 点心性 |
| 天命 → 耳顺（Lv2 → Lv3） | 同上，耗时更长 | 同上 |
| 耳顺 → 从心而欲（Lv3 → Lv4） | 同上 | 同上 |

> **`[定]` 这次改动的净效果：修心从"一辈子在等风"变成"一次搏命 + 三次长跑"。**
>
> - **好处**：修心终于有"回报"了。之前的设计里，拿到不惑之后心性还在掉，玩家会觉得"我修这个到底图什么"。现在不惑本身就是回报——**你从此不再被日子磨损**。
> - **代价**：入门那道门的权重被放大到极致。心性 92 的人 p=0.40，**六成的概率这一次就废了**，然后要再等一次"问心"（一生数列）。所以修心者的第一道坎不是境界，是**运气**。
> - **保留的东西**：心关照旧会磨人（失败 −10×基数修为、30% 扣 1 点心性）。所以"入门后不衰减"不等于"入门后安全"——**你只是不再被时间杀死，还是会被自己杀死。**

> **时间线**（出生 100 / 出生 85 两种起点，对比着看）：

```text
出生 100（道心天成）          出生 85（无命格）
20 岁   87   差 3 点          20 岁   72   差 18 点
+15 → 100（clamp）            22 岁   三次事件全打满，勉强 91
100 → 90 有 5 年（6 次判定）    只开 1 年（p=0.35）
累计成功 99.5%                        35%
同年    判定命中 → Lv1 ★ 此后自然衰减归零
此后    只做一件事：一次一次地过心关
```

> **`[定]` 这条路只有一条分叉：起点 + 遇不遇得上。** 左边那个人**只要撞上一次大彻大悟就进去了**；右边那个人要把一生所有的心性事件在三年内连打出来，才有四成机会。
>
> **而两条路有同一个天花板**：33 岁（左）/ 26 岁（右）触地板 60 之后，**再给多少次事件也补不回 90**。所以修心的窗口不是"越大越有希望"，是"**越年轻越有希望**"。

> **和更早版本最大的差别**：旧稿是"22 岁拿到 Lv1、27 岁窗口关闭，之后修为冻结"。现在没有"修为冻结"这回事了——**进了门，他每一天都有资格练，直到他自己搞砸。**
>
> 这也把境界总纲 §6.5 那道"446 年"的坎改写了：修心者不再是"大部分年头没资格练"，而是"**入门极难，入门后可以一直练**"。**难在门口，不在路上**——和养灵正好相反。

> **`[待]` 仍然待拍板的一件事**：心性提升事件的频率与幅度。r14 把"基线"还原成地板之后，结论**回到 r10 的判断**——出生 100 的人 20 岁 87、缺 3 点，**一次大彻大悟（+15）就够开门**。所以旧建议「一生 4–8 次」是**偏宽**的：它让"命格好 + 等得到事件"的人几乎必然入道。要拍的是：收紧到一生 1–3 次（修心极稀有），还是保持 4–8 次（修心是"少数人的路"）。**这条直接决定一个城里有一个修心者还是一百个。**

### 5.8 四道层级：锻体 / 炼气 / 养灵 / 修心 `[定]` `[改]`

| 轨道 | Lv 范围 | LvN 对应 | 谁读它 |
| --- | --- | --- | --- |
| **锻体层级** | Lv1–6 | 体魄 / 脏腑 / 调息 / 朝元 / 金身 / 临虚 | 锻体六品突破 |
| **炼气层级** | Lv1–6 | 感气 / 破胎 / 驭凡 / 法相 / 合一 / 化朽 | 炼气六品突破；**法相 = 炼气层级 Lv4** |
| **养灵层级** | Lv1–6 | 开视 / 启灵 / 真域 / 神游 / 浑然 / 回春 | 养灵六品突破（入养灵要 Lv1） |
| **修心层级** | Lv1–4 | 不惑 / 天命 / 耳顺 / 从心而欲 | 修心四品突破 |

**旧的三个标签全部并进来**：认知 → 生命层级 → **养灵层级**；明悟 → 自我层级 → **修心层级**；**「机缘」布尔废除**，法相的门槛改写为"炼气层级 Lv4"。

#### 5.8.1 破境判定：一条四步流程 `[定]` `[改]`

> 用户原话（r11）：「现在的境界破境判定是：先判定破境需要瓶颈不，不需要，直接对应层级；需要，检查本次是否能修改对应层级。修改成功——判定其余条件（如有），成功则突破，否则都是不突破。所以锻体和炼气前面的境界还是走之前的判断，只是改了结果对象。」
>
> **"改了结果对象"** 是全节的关键：**旧的成功率判定的是"境界"，现在判定的是"层级"。** 公式一个没改，改的是它打在哪。

```text
破境(道, 品 N):

① 这一品要不要瓶颈？
   ├─ A 无瓶颈（p ≥ 1.00）        → 层级直接取 LvN，跳到 ③
   ├─ B 判定型瓶颈（0 ≤ p < 1）   → 进 ②
   └─ C 资格型瓶颈（世界认可 / 悟道）→ 有资格就跳到 ③，没有就卡死

② 瓶颈判定（本次事件掷一次骰）
   roll < p(道, 品, 属性)
   ├─ 命中「修改成功」→ 层级 LvN−1 → LvN，跳到 ③
   └─ 未命中         → **不突破**。层级不变、修为保留、门不消失，下次再来

③ 其余条件（只有养灵、修心设）
   ├─ 满足 → **突破成功**
   └─ 不满足 → **不突破**（层级保留，等属性；修为不清零）
```

**一句话读法**：**瓶颈管"你有没有资格进门"，其余条件管"你这个人够不够格"。两者都过才突破；任何一步失败，结果都是"不突破"——没有"半突破"，也没有"失败扣境界"这种惩罚。**

| 情形 | 结果 | 玩家看到什么 |
| --- | --- | --- |
| 修为满了，层级不到 | 按钮置灰 | 「此境的关窍你还没通」 |
| 层级到了，属性不够（养灵/修心） | 按钮置灰 | 「你的资质还撑不住这一品」 |
| 层级到了，修为没满 | 继续攒，攒满即过 | 「就差修为了」 |
| 层级到了，修为满了，属性够了 | **必成，一次过** | 「水到渠成」 |
| 层级超前拿到了 | 允许，只是还差修为 | **"早通窍"是实实在在的优势** |

#### 5.8.2 层级怎么涨：一次判定，不是事件链 `[定]` `[改]`

> 用户原话（r11）：「像法相这种突破，事件一个就够了，不需要设置事件链。」

**r11 废除"每品 3 环境链"，改为"每品一次瓶颈事件"。** 上一版为了"破境不是老虎机"，把随机性搬进了 66 个环；结果是**内容量炸了，而且判定反而更模糊**（玩家不知道还差什么）。现在回到单次判定——**一次事件、一个骰子、一个明确的成功率，失败就是"这次没抓住"。**

```text
层级 Lv(N−1) → LvN：
  触发一次对应主题的事件（见 §5.8.3 的名字表）
  → 掷骰 p
  → 命中：层级 +1（拿到就是永久，不会掉）
  → 未命中：什么都不发生，下一次遇到同类事件再试
```

**四道的 p 表（全部沿用旧成功率公式，只是挂到层级上）**：

| 道 | 层级 | 成功率 p | 备注 |
| --- | --- | --- | --- |
| **锻体** | Lv1 体魄 | `0.80 + (资质−40) × 0.02` | 资质 50 起 100% → **无瓶颈，直取** |
| | Lv2 脏腑 | `0.90 + (资质−60) × 0.01` | 资质 70 起 100% |
| | Lv3 调息 | `(资质−60) × 0.05` | 资质 80 起 100%；60 以下恒 0 |
| | Lv4 朝元 | `(资质−79) × 0.10` | 资质 90 起 100% |
| | Lv5 金身 | **资格：世界认可** | 不掷骰 |
| | Lv6 临虚 | **资格：悟道** | 不掷骰 |
| **炼气** | Lv1 感气 | `0.50 + (悟性−60) × 0.025` | 悟性 80 起 100%；**悟性<60 首次必败** |
| | Lv2 破胎 | `max(0.05, 0.30 + (悟性−60) × 0.035)` | 5% 下限不可省 |
| | Lv3 驭凡 | `(悟性−70) × 0.05` | 悟性 90 起 100% |
| | Lv4 法相 | `(悟性−89) × 0.10` | 悟性 100 → 100% |
| | Lv5 合一 | **资格：世界认可** | 不掷骰 |
| | Lv6 化朽 | **资格：悟道** | 不掷骰 |
| **养灵** | Lv1–6 | `0.35 + (资质+悟性−160) × 0.01 + 生死经历(0.10)` | 双 80 → 0.35，双 90 → 0.55；钳制 [0.05, 0.95] |
| **修心** | Lv1–4 | `0.30 + 0.05 × (心性−90)` | 90 → 30%，95 → 55%，100 → 80% |

**失败各自扣什么**（这是四道手感的分野）：

| 道 | 失败代价 | 为什么 |
| --- | --- | --- |
| 锻体 | **不扣修为**，只是这次没通 | 肉身的事，练了就在身上，试错成本只是时间 |
| 炼气 | **不扣修为**，但感气有"首次必败" | 开窍是一瞬间的事，失败不留疤 |
| 养灵 | **修为 −10%** | 门的失败是"看不透"，看错一次要退回来 |
| 修心 | **修为 −10 × 基数**，且 30% 再扣 1 点心性 | 心关失败会动摇你，这是修心独有的"人会退" |

**三条获取规则（继承上一版，未改）**：

1. **层级可以超前拿。** 在第 N−1 品时就能触发第 N 品的瓶颈事件——这是养灵"卡事件"的机制来源，也是"练到顶却动不了"的来源。
2. **不能跨大境界拿。** 炼气的时候碰不到养灵 Lv2–6 的门。**唯一例外是每道的 Lv1**，它是"入门门"，可以在前一道触发：

| 入门门 | 在哪一道时触发 | 说明 |
| --- | --- | --- |
| 锻体层级 Lv1（体魄） | 凡人 / 蒙学 | 蒙学卒业 |
| 炼气层级 Lv1（感气） | 锻体 | 蒙学气感课，**凡人也会**（凡人定义的一半就在这里） |
| 养灵层级 Lv1（见众生） | **炼气** | 入养灵的门（旧称"生命层级 Lv1"） |
| 修心层级 Lv1（我是谁） | **养灵** | 入修心的门（旧称"自我层级 Lv1"） |

3. **"法相"这类门槛品，一次事件就够。** 用户原话：「像法相这种突破，事件一个就够了，不需要设置事件链。」所以 `炼气层级 Lv4` 的获取就是**一次"立相"事件 + 一次 `(悟性−89)×0.10` 的判定**——不是三环、不是机缘布尔、不是明悟叠加。**先立相，才成相；立不起来，明年再立。**

#### 5.8.4 层级与属性门槛的分工

| 道 | 层级 | 属性门槛 |
| --- | --- | --- |
| 锻体 / 炼气 | 六品全要 | **不设**——资质/悟性只决定你走多快（修炼基数 + 层级成功率），不决定你能不能进门 |
| 养灵 | 六品全要 | **双 80**（`境界系统总纲.md` §5.1） |
| 修心 | 四品全要 | **心性 ≥90**（入门前必须满足；入门后不再自然衰减，见 §5.7.4） |

**一句话**：层级是"你走到哪一步"，属性是"你这个人够不够格"。锻体炼气只看前者（谁都能练，快慢不同）；养灵修心两者都要，而且要**同时满足**。

> **这解释了一件旧事**：锻体为什么"资质 50 是分水岭"？不是因为 50 以下不让练，是因为**资质决定修炼基数，也就决定"同样四年蒙学，你能不能攒满 470"**；而且它同时决定**层级成功率**——资质 50 的人，体魄无瓶颈、脏腑 90%、调息 0%。**门槛从来不在门口，在速度和判定上。**

### 5.9 两类基数：修炼基数与百艺基数 `[定]`

> 用户原话：「修炼收益受功法影响，功法又受品级和契合度影响，契合度又受资质、悟性影响，层层套娃想实现太难，所以这里简化一下，以境界受影响的属性与功法品级，本身境界加权总和做一个计算公式，结果呈正相关就行，这个计算出来的值就是修炼基数（锻体和炼气用）。」「百艺品阶与修炼差不多，其受到资质与悟性两项属性影响，是一个加权和，这个就是百艺的修炼基数。」

#### 5.9.1 修炼基数（锻体 / 炼气）

**放弃三层套娃**（契合度 → 功法品级 → 收益），压成一个加权和：

```text
修炼基数 = 主属性 × (0.70 + 0.15 × 功法品阶) + 境界品 × 2

  主属性    锻体 = 资质，炼气 = 悟性
  功法品阶  1–6（黄下=1 黄中=2 黄上=3 玄=4 地=5 天=6，见 战斗系统总纲 §6.2）
  境界品    当前小境界序号（1–6）

月修为 = 修炼基数 × 0.2 × 其他乘区（天赋、宝地、丹药）
```

**功法系数 `0.70 + 0.15 × 品阶`** 的来历：它在 1 阶给出 0.85、3 阶给出 1.15——正好接住旧文档里散落的 `0.83` 与 `1.2` 两个值，也就是说**旧的两个散例不是特例，是同一条直线的两个点**。

| 主属性 | 功法 | 境界品 | 基数 | 月修为 | 年修为 |
| --- | --- | --- | --- | --- | --- |
| 50（稍弱） | 1 阶（黄下） | 1 | 44.5 | 8.9 | **106.8** |
| 60（及格） | 3 阶（黄上） | 2 | 73.0 | 14.6 | **175.2** |
| 70（良好） | 4 阶（玄） | 3 | 97.0 | 19.4 | **232.8** |
| 80（优秀） | 5 阶（地） | 4 | 124.0 | 24.8 | **297.6** |
| 90（顶尖） | 6 阶（天） | 5 | 154.0 | 30.8 | **369.6** |

> **功法品阶被境界卡着**（天地玄黄梯：天阶要 5 品才能入门），所以"高资质 + 高功法 + 高境界"这三项天然共线——**强者恒强不是数值设计，是梯子本身的结构**。
>
> **这个数可以存。** 用户原话「修炼基数可以保存起来，不用每次计算」——它只在**破境、换功法、属性变化**这三个时机重算，其余时候直接读缓存。

#### 5.9.2 百艺基数

```text
百艺基数 = 资质 × w资 + 悟性 × w悟        (w资 + w悟 = 1)
百艺积累 += 百艺基数 × 0.2 / 月
```

| --- | --- | --- | --- |
| 丹道 | 0.4 | **0.6** | 火候靠悟，药性靠记 |
| 器道 | **0.6** | 0.4 | 手感与力道吃资质 |
| 符箓 | 0.4 | **0.6** | 一笔成符，差的是神意 |
| 阵道 | 0.3 | **0.7** | 纯脑力 |
| 堪舆 | 0.3 | **0.7** | 同上 |
| 灵植 | **0.6** | 0.4 | 农活，靠身子 |
| 灵膳 | 0.5 | 0.5 | 各半 |
| 医道 | 0.4 | **0.6** | 辨证靠悟 |

#### 5.9.3 术法基数：术法也吃同一套算法 `[定]` `[改]`

> 用户原话：「术法和百艺一样，也是需要修炼的，其和境界修炼一样，采用同样的计算。」

术法**不再用**"2 + 悟性 × 0.06"这种凭空的月熟练（旧口径作废）。它直接吃**修炼基数**——同一个公式、同一份缓存、同一套境界加权，只是再乘一个"这本术法有多难"：

```text
术法月熟练 = 修炼基数 × 0.2 ÷ 阶位系数 × 相性系数

  阶位系数   黄下 1 / 黄中 1.5 / 黄上 2 / 玄 3 / 地 5 / 天 8
  相性系数   相符 1.0（含中性）/ 错配 0.5（好人修恶术）
  熟练度     0–100，入门 ≥40 / 大成 ≥80 / 圆满 100
```

**以修炼基数 75（锻体、资质 60、黄上功法、品 3）为例**：

| 术法阶位 | 月熟练 | 入门（40） | 大成（80） | 圆满（100） |
| --- | --- | --- | --- | --- |
| 黄下（罗汉拳） | 15.0 | 2.7 月 | 5.3 月 | **6.7 月** |
| 黄中 | 10.0 | 4.0 月 | 8.0 月 | **10.0 月** |
| 黄上 | 7.5 | 5.3 月 | 10.7 月 | **13.3 月** |
| 玄 | 5.0 | 8.0 月 | 16.0 月 | **20.0 月** |
| 地 | 3.0 | 13.3 月 | 26.7 月 | **33.3 月** |
| 天 | 1.9 | 21.3 月 | 42.7 月 | **53.3 月** |

> **这个梯度是刻意做的**：黄下半月上手、半年圆满，天阶要四年半才圆满。而天阶本来要品 5 才能入门（天地玄黄梯），所以"天阶术法"的真实成本是**三十年起步的境界 + 三年苦练**——不是捡到就会。
>
> **术法与修为抢的是同一份时间。** 每月只能做一件事，练术法的月份不长修为——**"多学"的代价永远是境界**（`战斗系统总纲.md` §6.3 那条"没有携带上限"的平衡，就落在这个月数上，不需要额外限制）。
>
> **术法熟练也吃缓存重算**：换功法、资质悟性变化、进宝地，都会改修炼基数，进而改月熟练。这条并入 §5.9.1 的"三个重算时机"。

### 5.10 人口：基线回归 `[定]` `[改]`

> 用户原话：「人口这块成为养灵境界后才担心，到时候通过事件控制，例如天灾-10w人（城）；祥瑞出，+2w人（城）。城的人口是有一个基准线的，超出和缺失时，都会像这个基线靠拢，例如一年1w。」

**人口在养灵之前是背景数**（不模拟，只查表）；**养灵之后才进循环**——因为你开始读灵量了。

```text
基线 base = f(城等级)          # 小城 5 万 / 中城 20 万 / 大城 60 万 / 王城 150 万
每年：人口 += clamp(base − 人口, −1万, +1万)
事件：人口 += 事件值（天灾 −10 万 / 祥瑞 +2 万 / 战乱 −20 万）
```

| 情形 | 每年变化 | 恢复年限 |
| --- | --- | --- |
| 人口 = 基线 | 0 | — |
| 人口超基线 5 万 | −1 万/年 | 5 年回正 |
| 天灾 −10 万（大城 60 → 50） | +1 万/年 | **10 年才补回来** |
| 祥瑞 +2 万 | −1 万/年（超出部分自然回落） | 2 年 |

> **"天灾 −10 万"的真实重量**：不是掉一格数字，是**接下来十年灵量都在低谷**。城主的养灵增益 `1 + log10(灵量+1)/2` 会跟着掉——按大城 60 万算，掉到 50 万，增益从 3.89 掉到 3.85。看着不多，但**十年里每一年的月修为都少 1%**，累计就是"一场天灾偷走了你半年修为"。
>
> 这也是"人口为什么不给公式"的原因：**它不该是经济模拟，它该是事件的记分牌。** 玩家能做的只有"防灾、赈灾、多生"这三类事，全部走事件。

> **§5.10 只管"人口怎么变"，不管"人口里有多少修士"。** 后者（一个城同时有几个养灵、几个修心、灵量实际是多少）见 **`世界人口与境界分布.md`**——那里给出了存量 = 流量 × 存留期的算法，结论是**一城 9 个养灵、2 个修心**，与本节的人口基线互不干涉。

### 5.11 伤病：两种来源，两套规则 `[定]`

> 用户原话：「伤病分两种，一种是命格、天赋带的，一种是战斗时的临时状态。这些你可以先编一点。」

**分野很清楚**：前者是**你这具身体的初始设定**（跟着命格/天赋走，一般终身），后者是**战斗的账单**（会好，也可能好不了）。

#### 5.11.1 先天伤病（命格 / 天赋附带）

| 伤病 | 来源 | 效果 | 能不能好 |
| --- | --- | --- | --- |
| **胎弱** | 命格·早夭 | 资质 **−10**、血量 −10% | **洗髓可愈**（一次性，成功率 70%） |
| **心疾** | 命格·心病 | 心性 **−8**；每场战斗精神上限 −10% | 不可愈，只能压（清心丹长期服用） |
| **断脉** | 天赋·残脉 | **修炼基数 ×0.85**（全道通用） | 不可愈 |
| **天盲** | 天赋·天盲 | 命中 −15%、看破类判定 −20% | 医道 3 阶（**50 金**）可治 |
| **寒骨** | 命格·寒骨 | **每年寿元 −1**（终身累加） | 在火属性宝地连住 3 年可解 |

> **先天伤病的意义**：它让"命格"不只是加成，也有代价。`品阶命格寿元.md` 里那些"看起来很强"的命格，很多都带着一条这样的暗线——**早夭给你 10 点资质，但你的身子撑不到成年**。

#### 5.11.2 战斗伤病（临时状态）

| 状态 | 怎么来的 | 效果 | 持续 |
| --- | --- | --- | --- |
| **流血** | 破甲 / 刀伤 / 撕裂 | 每回合 **−5% 血量** | 3 回合，或止血（凝血丹） |
| **断骨** | 单次伤害 > 血量上限 20% | 攻击 **−25%**、防御 **−40%** | **90 天**；医道 1 阶处理 → 30 天 |
| **内伤** | 法术伤害穿透（无盾硬吃） | 法力回复 **−50%** | 30 天 |
| **神魂震荡** | **精神归 0 但被叫停/救回** | 精神上限 −30%，一个月内不能出战 | 30 天 |
| **心创** | **神志值归 0 但被叫停/救回** | 人物心性 **−3**，三个月内不能修心 | 90 天 |
| **残** | 断肢（暴击且伤害溢出 50%，或剧情） | 对应功能永久丧失（手/眼/腿） | **永久**，除非 4 阶丹或传承器 |
| **中毒 / 中蛊** | 毒术、蛊术、阴险术 | 每回合 −3 血量，或某项属性 −10% | 解毒丹 / 医道，或事件 |

**三条规则**：

1. **非死亡比斗（危险线 10% 叫停）不会留下断骨、残这种重伤**——只可能流血、内伤。这条让"切磋"真的安全，也让"生死斗"真的危险。
2. **神魂震荡是"三条血条"设计的安全阀**：精神归 0 即死太狠，所以给一条"救回来但废一个月"的岔路。**能不能救，看有没有人在旁边**。
3. **心创是唯一能通过战斗扣真实心性的事**——但只在你心性被打穿、且活下来的时候。这仍然符合"心性只能被自己的怀疑打碎"：**被打穿本身就是一次怀疑**。

> 与战斗系统的分工：**这张表是权威数值，`战斗系统总纲.md` 只写"战后掷不掷伤病、什么条件下掷"**。掷法与概率见那份文档 §4.8。

## 6. 完整示例

**例一：寿命（事件折损 + 命格长寿）**

```text
基础值：随机 60–100 → 80
事件：折损 10%        [*0.9]
扩展：无              []
身份：无              []
天赋：无              []
命格·长寿：+20 年     [+20]

80[*0.9][][][][+20] = 92
```

**例二：修炼收益（天赋加成 + 气运取整）**

```text
基础值：修炼基数 = 60 × (0.70 + 0.15 × 3) + 2 × 2 = 73
        （资质 60、黄上功法、当前品 2；见 §5.9.1）
天赋·悟性惊人：+10%   [*1.1]

73[][][][*1.1][] = 80.3
取整：气运 50（k=1）→ 0.3×1 < 0.5 → 舍 → 80
      气运 80（k=1.6）→ 0.3×1.6 = 0.48 < 0.5 → 仍是 80
      气运 90（k=1.8）→ 0.3×1.8 = 0.54 ≥ 0.5 → 进位 → 81   ← 详见 气运系统.md §5
```

链的起点是「这个属性的基础值」。**修炼收益的不再是"悟性 × 功法系数"这种一次性乘法**，而是先算出可缓存的**修炼基数**（§5.9.1），再让天赋/身份/命格在这条链上依次作用于它。

**例三：身份压制（不进链）**

```text
身份·寒门（出身槽）      → 年收入 [身份段 +1 银]
身份·丧失双亲（家庭状态槽）→ 压制「出身」槽的现金流效果

结果：寒门标签仍在，但身份段视为 []，年收入不 +1
```

**例四：顺序会改变结果**

```text
基础值 100，事件 +10，命格 ×1.2

按定序（事件在前）：(100 + 10) × 1.2 = 132
若颠倒（命格在前）：(100 × 1.2) + 10 = 130
```

同段同类型时顺序无关；一旦跨类型（加与乘），顺序就开始产生差额。这就是五段必须写死、不能由内容层自由排列的原因。

**例五：同层多来源聚合（炼丹）**

```text
基础：一次出丹 10 颗
天赋·炼丹达人：数量 +10%     pct +0.10
天赋·炼丹妙手：每次 +1 颗     flat +1
天赋·丹道天赋：数量 +20%     pct +0.20

天赋层聚合 → mul = 1 + 0.10 + 0.20 = 1.30，add = 1
10[*1.3 +1] = 10×1.3 + 1 = 14 颗
```

**例六：抵消的两种形态**

```text
伤害：断腿 → 条目 d-broken-leg { 层:扩展, target:资质, kind:flat, value:-5 }
治好：事件删除该条目 → 资质回到未受伤时的值

身份：寒门 { 层:身份, target:年收入, kind:flat, value:+1 银,
             guard: 不含「丧失双亲」标签 }
丧失双亲 → guard 求值 false → 寒门条目跳过，但标签仍在
重新归族 → guard 恢复 true → +1 银自动回来，无需重新施加
```

**例七：中间值回写（金钱失窃）**

```text
存档：钱 = 1000
事件「失窃 −10%」：取当前值 1000 当基础值 → 链(1000) = 900 → 回写
存档：钱 = 900
再失窃一次：链(900) = 810
```

对比寿元：同样是 `*0.9`，寿元不回写，所以每次显示都用 80 重算，永远 92 起算。

**例八：同一条规则不能同时挂在两种值上**

```text
命格·来财：每次获得金钱 +20%

挂在钱（中间值）上 → 每次事件都乘 1.2，支出也被放大，余额复利膨胀
挂在 Δ（target:delta）上 → 只作用于本次收入，支出不受影响
```

| **旧"破境成功率"（锻体 §3.3 / 炼气 §4.3）** | ✅ **r11 改挂到层级判定**（§5.8.2）—— 公式一字未改，改的是"结果对象"：从"境界过不过"变成"层级涨不涨" |

### 9.6 标记类不需要公式（这是对的，不要补）

世界认可、悟道、学籍、入学方式、身份标签集、职位/组织——**开关不是数值**（§1.8）。别给他们编公式，一旦有了数值，就会有人拿它做乘法。**四道层级也算这一类**：它是开关（能不能破这一品），所以也不带进度点、不带小数。

### 9.7 还剩什么（按优先级）

| 优先级 | 缺口 | 为什么是这个优先级 |
| --- | --- | --- |
| **P0** | **修心窗口的"永久关闭"岁数** | 地板 60 低于门槛 90，**触了地板就再也补不回 90**。最高配置（出生 100）33 岁触地板，普通配置（出生 85）26 岁。所以"修心"本质上只对年轻人开放——若你要"老而悟道"的修心者，得允许心性事件突破 60 地板（§5.7.4） |
| **P0** | **心性事件额度要不要收紧** | r14 还原"基线=地板"后，出生 100 的人 20 岁 87、缺 3 点，**一次大彻大悟就够**。旧建议「一生 4–8 次」因此偏宽——不收紧则"命格好 + 等得到事件"的人几乎必然入道（§5.7.3） |
| **P0** | **「回心」事件给几个、抬多少** | r11 定"入修心后事件仍会扣、跌破 90 修为停摆"之后，这条从"开门条件"升级为**修心者唯一的自救手段**。给少了 = 一次目击杀戮（−5）就废掉一生修为，且此后再没有回到 90 的路 |
| **P1** | **心魔触发系数的那个 `0.03`** | `p(触发) = 0.03 × (40 − 心性)` 是我按"39 岁的人 33 年遇一次"给的。若要让心魔更密，改 0.05；更疏，改 0.02。**成活率（0.10 @39）是用户拍死的，触发频率没有** |

| **P2** | "路上"位置的月数消耗 | 位置系统已立，"从 A 城到 B 城走几个月"没有表 |
| **P2** | 心性提升事件的稀有度分档 | 与 P0 第一条同源，细化到"哪些城市/身份能遇到" |

> **r14 之后，"修心能不能走通"这个问题已经关了**——出生 80–90 + 事件补，一算就过。现在真正阻塞的只剩两条：**心性事件给几次**（决定修心者是"一个城一个"还是"一个城一百个"）与**「回心」给几次**（决定已经进去的人会不会被一次目击杀戮废掉）。其余要么是写作量，要么是 P2 细节。
