## 1. 核心原则（本次修正）

1. **身份只对养灵境界有增益**。一个居民身份凭什么加修炼进度？他手下不管人。
2. **增益来源是「治下生灵数」，不是身份本身**。
3. **身份不叠加**：城主有 100 万人口，再给个将军的 1 万人口，提升微乎其微。
4. **不往人堆里凑也能修**：自己种草管草（草也是生灵），有加成，但很低。

## 2. 养灵修炼 = 生灵的「质量 × 数量」

### 2.1 核心公式（按你的例子修正）

不是简单数人头，而是**按境界折算成的「灵量」**：

```text
灵量 = Σ (该境界人数 × 境界权重)

境界权重：
  凡人（未修炼）    0.2
  锻体境            1
  炼气境            2
  养灵境            5
```

你的例子：

| 构成 | 计算 | 灵量 |
| --- | --- | --- |
| 城：100 万（9 万锻体 + 55 万炼气 + 7 万凡人 + 100 养灵） | 9万×1 + 55万×2 + 7万×0.2 + 100×5 | **119.3 万** |
| 将军：10 万炼气 | 10万×2 | **20 万** |
| 宗门：1 万（多为炼气） | 1万×2 | **2 万** |
| 大家族：一千人（多为凡人+少量锻体） | 900×0.2 + 100×1 | **280** |
| 散修：自己 1 人（炼气） | 1×2 | **2** |
| 种草：100 株灵草 | 100×0.05 | **5** |

### 2.2 灵量 → 修炼增益

```text
增益 = 1 + log10(灵量 + 1) / 2

  灵量 2（散修）      → ×1.15
  灵量 5（种草）      → ×1.35
  灵量 280（小家）    → ×2.22
  灵量 2 万（宗门）    → ×3.15
  灵量 20 万（将军）   → ×3.65
  灵量 119 万（大城）  → ×4.04
```

**自然解决「不叠加」**：城主 119 万 + 将军 20 万 = 139 万 → ×4.07，只多了 0.03。
所以「给城主再加个将军头衔」在数值上毫无意义，不需要专门禁止。

### 2.3 灵量会波动

- 人口增长（治理好）→ 灵量升
- 战乱、瘟疫、灾荒 → 灵量降
- 被夺城 → 直接归零
- 手下叛离 → 按比例减少

所以城主的养灵修炼是**会掉下来的**，不是一劳永逸。

### 2.4 治下生灵从哪来

| 身份 | 灵量范围 | 说明 |
| --- | --- | --- |
| 无身份散修 | 2–10 | 自己与家人 |
| 种草者 | 5–50 | 灵草、灵植、灵兽，极慢 |
| **家主** | 200–2,000 | 一族之人（凡人为主） |
| **宗门弟子** | **0** | 不借宗门生灵（宗门不会让你借） |
| **宗门宗主** | 10,000–50,000 | 门人（多为炼气） |
| **将军** | 100,000–400,000 | 麾下军士（炼气为主） |
| **城主** | 1,000,000–3,000,000 | 一城之民 |
| **附庸（有实职）** | 按职务 | 见 2.5 |

### 2.5 附庸也要有「管的人」

城主招一个东城门总管，他管东城门，手下就有人：

```text
城主（119 万灵量）
 └─ 东城门总管（管 3,000 人，多为锻体 → 灵量约 4,000）
     └─ 城门卫兵（管 50 人 → 灵量约 60）
         └─ 无
```

- **只有「有实职」的附庸才有治下生灵**。
- 挂名客卿、清客、闲散供奉 → 灵量仍是个位数，不涨。
- 「投靠强者」不等于「自动变强」，必须拿到实职。

### 2.6 身份只影响养灵

| 境界 | 身份是否影响修炼 |
| --- | --- |
| 锻体 | ❌ 只看资质 |
| 炼气 | ❌ 只看悟性 + 宝物 |
| **养灵** | ✅ **只看灵量** |
| 修心 | ❌ 只认认知与经历 |

## 3. 身份清单（不叠加）

### 3.1 可招募附庸的身份（「有人」的）

| 身份 | 获得条件 | 治下生灵 | 强制事件 | 主要事件池 |
| --- | --- | --- | --- | --- |
| **家主** | 一族之长（出身或继承） | 100–1,000 | 族中事务 | 家族、田产、婚丧 |
| **宗门宗主** | 养灵 + 自建宗门 | 1,000–10,000 | 护山、调解 | 收徒、争地盘 |
| **将军** | 记功 + 破胎 + 心性 | 10,000–100,000 | **出征（必去）** | 打仗、军务 |
| **城主** | 记功极高 + 心性 ≥90 + 养灵 | 500,000–1,500,000 | 朝会、赈灾 | 政务、税收、政敌 |
| **附庸·有实职** | 被上述身份招募 | 按职务 | 主公差遣 | 职务相关 |

### 3.2 不招募附庸的身份

| 身份 | 灵量 | 强制事件 | 特点 |
| --- | --- | --- | --- |
| **城中居民** | 个位数 | 缴税 | 安全，但无增益 |
| **城卫** | 数十–数百 | 城防调动 | 有微薄增益 |
| **宗门弟子** | **0** | 差遣 | 无增益（宗门不会让你借） |
| **太学生** | 个位数 | 季考 | 无增益 |
| **种草者 / 散修** | 5–50 | 无 | 自由，但极慢 |
| **邪修** | 掠夺来的 | 仙司围剿 | 快，但心性崩 |

### 3.3 晋升路径

```text
太学卒业
 ├─ 直招 + 心性优良 → 城池权力机构历练 → 城主
 ├─ 直招 + 心性一般 → 军中任职 → 将军
 ├─ 特招 → 资源较少 → 多为中层实职（总管/队正/执事）
 └─ 无培养价值 → 自力更生（居民/散修/种草）

旁支：
  拜入宗门 → 弟子 → 执事 → 宗主
  被招募为附庸 → 有实职 → 治下生灵 ↑
  走邪路 → 邪修
```

## 4. 太学选拔（修正）

### 4.1 学制

| 阶段 | 年龄 | 年限 |
| --- | --- | --- |
| 蒙学 | 7–10 | 4 年 |
| 府学 | 11–14 | 4 年 |
| 大考 | **15 岁** | — （只考，不判入学） |
| **空窗** | **15** | **1 年**（奇遇 / 家庭 / 冲炼气·破胎） |
| **入学判定** | **16 岁** | — （看当时有没有破胎） |
| 太学 | **16–19** | 4 年 |
| 卒业 | 20 | 分配 |

> **关键修正**：15 岁只考不判。**入学判定放在 16 岁**，看那一刻你有没有炼气·破胎。
> 所以 15 岁那一年就是最后的冲刺窗口——冲不破胎，大考考得再好也进不了直招。

### 4.2 直招（四项全中）

```text
1. 大考成绩达标
2. 境界 ≥ 炼气·破胎（2 阶 2 品）
3. 资质 > 80   ← 可配置
4. 悟性 > 80   ← 可配置
```

### 4.3 特招

```text
条件：境界 ≥ 炼气·破胎 + 大考成绩达标（不看资质悟性）
名额：每城 5–10 人（可配置）

特招与直招的区别：
  - 培养方式不同（直招进权力机构，特招多做实务）
  - 但目的相同：都是为了培养养灵人才
  - 与养灵修炼速度无关
```

### 4.4 太学的作用（修正）

> 太学只是提前知道养灵境界，知道朝那个方向努力，可以在满足特定条件下提前（不用锻体、炼气修炼到第四境界）进入养灵。

| 作用 | 说明 |
| --- | --- |
| 提前知情 | 获得 `spirit_known`，知道养灵是什么、往哪努力 |
| 提前入门 | 满足 **资质 > 80 且 悟性 > 80**（同一组通用阈值）即可提前尝试感悟生命 |
| 不给修为 | 太学不发养灵修为，也不加养灵速度 |

两条进入养灵的路径：

```text
常规：锻体·朝元(1,4) 且 炼气·法相(2,4) → 可尝试「感悟生命」
提前：太学在读 且 资质 > 80 且 悟性 > 80 → 可尝试「感悟生命」
      （仍需判定通过，不是必成）
```

命名不再用「北国/南国」这种方位词，改用有意象的国名。

| 方位 | 国名 | 意象 | 特点 | 与大曜关系 |
| --- | --- | --- | --- | --- |
| **本作** | **大曜** | 日光 | 国办学，七国中最重制度 | — |
| 北 | **玄朔** | 幽暗的北方 | 苦寒、骑兵、崇武、尚黑色 | 世仇，北关常战 |
| 南 | **朱崖** | 南方赤色崖岸 | 湿热、灵植丰盛、商路发达 | 通商，偶有摩擦 |

| 远北 | **玄冥** | 极北幽寒 | 邪修聚集，传为鬼域 | 传说之地 |
| 远南 | **赤离** | 火 | 火山群岛，火系功法 | 商队带火晶 |
| 远东 | **沧屿** | 苍茫海岛 | 海岛诸城，以船为家 | 远航罕至 |
