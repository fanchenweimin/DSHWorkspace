# 大曜问仙录

网页文字修仙游戏。首页是一张地图：**断天山脉横在大陆正中（妖族之地），七国绕着它排成一圈，大曜在东**。你从大曜的长明城出发，七岁入蒙学，一路走到寿数尽头或死在路上。

**打开游戏：http://127.0.0.1:8787**

> 本文件只写**项目与开发信息**：怎么跑、目录怎么分、约定是什么、现在做到哪。
> **需求与设计不在本文件**，全部在 `docs/`（见文末）。
> 续做请看 **[PROGRESS.md](PROGRESS.md)**——那里是断点。

---

## 立即运行

只需要 **Node.js 22 以上**（用到内置 `node:sqlite`）。零第三方依赖，`npm install` 不需要，没有构建步骤。

```powershell
cd C:\Work\DSHWorkspace
node src/index.js
```

- 后台启动：`node start.js`，或双击 `start-game.cmd`
- 停止：`node stop.js`，或双击 `stop-game.cmd`
- 换端口：`$env:PORT=8899; node src/index.js`

> 这三个命令与端口是**约定**，不要改。`start.js` 会检查 `/api/health` 再拉起进程，`stop.js` 靠 `data/server.pid`。

## 页面

| 路径 | 说明 |
| --- | --- |
| `/` | 首页 = 地图。**没有顶部菜单栏**：填个名字（不填就叫沈砚）→「开始新游戏」；有活局时多一个「继续这一世」 |
| `/game.html` | 游戏页：左人物 + 法术/百艺进度 + 囊中·钱，中六块，右纪事。**卡上的选项直接点，点完即结算，不弹抽屉、不弹确认** |
| `/login.html` | 登录（只有管理账号需要） |
| `/admin.html` | 配置。**服务端拦截**，非 sysadmin 直接 302。**表格 / 表单**，不是整块 JSON |

游戏页中栏是**六块**，各管一件事：

| 块 | 内容 | 什么时候出现 |
| --- | --- | --- |
| 今年的事 | **一年只有一件**主事件；上面描述、下面整行可点的选项 | 有事件就出现，办完这一年就不再有 |

> **开局四属性（资质 / 悟性 / 心性 / 气运）每局随机**：前三个 45–90（两次平均），气运 30–80。
| 修为 | 四道合一：**修为没满 = 修炼，满了 = 突破** | 有得修或有得冲才出现 |
| 法术 | 学过的能练（一次修到升档）；**四档：入门 / 小成 / 大成 / 圆满**，入门还不能打；来路三选一：**学堂授 / 坊市买 / 城主府换军功** | 有可练可学的才出现 |
| 百艺 | 十四岁先选一门（免费），其余 **120 文**求学；档次写「**2 阶 · 黄上**」；**门槛没到的灰着写原因**；升一档出一件成品进囊中 | 十四岁以后，**十二门全画出来** |
| 营生 | 逛坊市 / 委托 / **切磋** / 出战 / 闲居 | 不是强制事件挡着就有 |
| 坊市 | 逛过之后摆摊：**能买也能卖**（卖是半价） | 在城里点一次「逛坊市」（1 月），当年有效 |

> **入品是一道门，不是一条进度条**：七岁入学那天先判一次体魄的门——没墙就直接站在体魄，有墙就停在门口（界面写「→ 体魄」，**没有进度条**）。
> **修为条属于站着的这一品**：站在体魄练满 140 才准破脏腑。
> **两种瓶颈两种破法**：概率瓶颈只点一次，判定成功后同一动作直接进品；**事件瓶颈先把那一件事办掉来通层级，再手动点击真实境界突破**。品内真实突破一年一次，入门关不算。
> **炼气先学后修**：11 岁府学炼气学习强制事件完成后才开放感气入门与炼气修炼；学习事件不直接进品，也**不要求锻体·脏腑**。
> **画出来的一定点得动**：月数不够、境界不够、钱不够、门槛没过、到上限的，一律不渲染。
> 买下的东西进左栏「囊中」，**钱也在左栏**（吸底，左栏再长也看得见）。
> 左栏的「法术 / 百艺 / 囊中」三段**可以折起来**，每一条进度只有一行——学到十几门也不会拖到看不见底。

## 战斗：一屏定死，逐帧放

战斗是**独立一屏**，`720 × 620` 定死（`height`，不是 `max-height`），中间的**战报自己滚**：

```
切磋        同辈
沈砚                        第 2 回合                        同辈
血    ▬▬▬▬▬▬▬▬  92/100      对       ▬▬▬▬▬▬▬  79/98  血
精神  ▬▬▬▬▬▬▬▬  30/30                ▬▬▬▬▬▬▬  30/30  精神
神志  ▬▬▬▬▬▬▬▬  62/62                ▬▬▬▬▬▬▬  43/43  神志
─────────────────────────────────────────────────
「罗汉拳」你欺身进招「罗汉拳」，同辈掉血 10。
「刀」    同辈欺身进招「刀」，你掉血 8。
─────────────────────────────────────────────────
                                    跳过
```

- **两边的条随每一拍跳**：血 / **法力盾** / 法力 / 精神 / 神志（`bb-board`），名字后面跟「闪避 12%」；
  服务端把整场算成 `frames[]`，每帧带双方快照。
- **每一拍都有招式名与品阶**：术法带 `means`（物理 / 法力）、`kind`（攻 / 运功）、`tier`（黄中 / 玄下…），
  手段层对不上就用不出来；法力不继时改动手，招式名也跟着变。
- **法力 ≠ 法力盾**：法力是放法术的油（施法扣、每回合回 5%）；**法力盾只从法器与防御术法来**——
  没练过防御术法、身上没法器，血条就是光着的。
- **闪避**：挨打之前先掷，闪开了这一下**全免**（灵术三段也一样）；道伤躲不开。
- **拳头砸得开气墙**：物理穿透护盾 55%，凡人三境打炼气系数 0.55（法术只有 0.12）——低阶修士有活路。
- **以力驭法**：境界高于术法阶品时，按自身阶品算，威力打 0.75 折——旧术法不会变废纸。
- **符箓**：身上有符（雷火符 80 文），开打前自动甩一张先炸一下。
- **认输**：切磋血量跌破 15% 就收手，判负但不死；死斗没有认输，只有打、跑、死。
- **数值全查表**（`rules.BATTLE.tables`，就是 `设计/30` §4.3 的基准表）：血/攻/防看锻体品，法力看炼气品，灵力与精神看养灵品，神志 = 自身心性 ×1。
- **修为进度也进公式**：站在这一品练了多少，往下一品插 15%。

### 阶 + 品：世界上只有一套刻度

| 品 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 名 | 黄下 | 黄中 | 黄上 | 玄 | 地 | 天 |

**影响等级 `L = 阶 + 品`**（品 ≤ 4 时成立）：3 阶 2 品够得着 2 阶 3 品、1 阶 4 品；2 阶 2 品够不着 2 阶 3 品，**威力只剩一成**。
品 5 / 6（地 / 天）不做这个换算，只能同阶比品。

- **法术**：阶由手段层给（法力 = 2 阶），品 = 品阶 ± 熟练偏移（小成 −1 / 大成 0 / 圆满 +1）。
  所以「黄上 小成」= **2 阶 2 品**，打 2 阶 3 品的人就几乎打不动。
- **百艺**：从门艺的入门阶起算——符道 1 档就是 **2 阶 2 品**（没有 2 阶 1 品），产出低一品 = **2 阶 1 品**，
  只影响 1 阶 1 / 2 品。
- **耗时**（`rules/time.js`）：`base × 品阶系数 × ref / 属性分`——资质 90 的人破同一关只要 ⅔ 时间。

| 分级 | 怎么结束 | 会不会死 |
| --- | --- | --- |
| **切磋** `spar` | 任一条血条到 **10% 危险线**即叫停，判负 | 不会；也不掷伤病 |
| **死斗** `death` | 没有危险线，血条归 0 就是死 | **会**。死了 `state.dead = true`，这一世当场结束 |

> 切磋在「营生」里（城中，12 岁以上，1 月）；出战（军职）与劫匪、妖物、城战、国战都是死斗。
> 城战 16 岁以下不上城墙、国战 18 岁以下不在征召册上——只能弃城或避役。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/health` | 存活检查（`start.js` 也用它判断是否已在跑） |
| GET | `/api/world` | 七国地图数据（已裁剪内部注释） |
| GET | `/api/hand` | 今年桌上的东西：`{state, main, breaks, train, arts, actions, bag, locked, canWait}`；没开局返回 `{empty:true}` |
| GET | `/api/has` | 有没有活着的一局（首页用它决定给不给「继续这一世」） |
| POST | `/api/act` | **结算一次动作** `{kind, id, choice, dao, tier, mode}`；kind 见下 |
| POST | `/api/new` | 开新局（body 里可带 `{name}`，不填用默认名） |
| POST | `/api/save` | 立刻落一次档（平时每一步结算后都会自动存，这是手动/兜底） |
| POST | `/api/forget` | 把这一局（内存 + 存档）一起删掉 |
| GET/POST | `/api/me` `/api/login` `/api/logout` | 会话 |
| GET/PUT/DELETE | `/api/config[/<file>]` | 配置读写（仅 sysadmin） |
| GET | `/api/schema` | **配置字典**（字段中文名 / 列宽 / 只读路径），配置页只读它（仅 sysadmin） |

`kind` 一共十一种：`event`（事件选项）、`action`（营生）、`train`（修炼）、`break`（突破 / 求学）、`art`（练百艺）、`learnArt`（求学一门手艺）、`spell`（练法术）、`learnSpell`（学术法）、`use`（吃药）、`buy` / `sell`（坊市买卖）、`wait`（把这一年过完）。

`/api/act` 是「零弹窗」的关键：点一下就是一次请求，**返回包里直接带着下一步要显示的整张桌子**，前端不需要二次确认或再拉一次。
一次结算的顺序写死在 `src/model/systems/turn.js`：**查月 → 扣钱 → 耗月 / 纪事 → 跑效果 → 满 12 月翻年 → 算寿元**；效果本身由 `systems/effects.js` 按 `do` 一条条执行。
主事件由 `systems/draw.js` 掷：**时间窗 → 条件 → 额度（`quota`）→ `ttl`** 四步入池，再取最小优先批、批内按 `weight` 归一化抽一张。
突破不走事件池：`systems/hand.js#breakCards()` 看**修为条满没满**，满了就生成一张常驻卡，门槛读 `rules.BREAK_GATE`。
`kind:'wait'` 是兜底：这一年还有月却一件也做不成时，把剩下的月过掉（`canWait` 为真时前端才给这一格）。

一局的状态存在 **`saves` 表**里（`src/model/state/running.js` 负责"内存缓存 + 库"两层），
**游客也能连续玩，重启服务或关掉浏览器再回来还在**——连"今年桌上那张牌"都不会变。

- 存的是**整份 state**（`wall / study / arts / mods / pending / turn.mainId / flags` 全在里面），
  不做字段挑选：漏存任何一个都能读档刷数值。
- 版本号在 `repository/saves.js#VERSION`；改了 state 结构就 +1，**旧档直接丢**（下次进游戏等于新开一局），
  开发期不写迁移脚本。
- 登录状态也落库了（`sessions` 表），重启服务不用重新登录。
- 想清档：`POST /api/forget`，或者停服务删 `data/` 整个目录。

## 配置（sysadmin）

- 配置的**磁盘原值**在 `src/seed/*.json`（**17 份**，就是数据层）。
- 在 `/admin.html` 里保存，写的是 **sqlite 覆盖层**（`config_overrides` 表），**不动磁盘文件**。
- 运行时读的是 `repository/config.js` 的 `get()`：**覆盖层优先，否则磁盘**。
  所以「保存 → 刷新页面」就生效，不用重启。
- 「还原」会删掉覆盖层，回到磁盘原值。
- 直接改 `src/seed/*.json` 也会生效：种子按 **mtime** 自动失效。

### 配置页怎么变成"人能看懂"的

`src/seed/schema.json` 是**配置字典**，配置页完全由它驱动（代码里不写中文表）：

| 段 | 管什么 |
| --- | --- |
| `fields` | 221 个字段的中文名、列宽、能不能改（`edit:false`） |
| `files` | 17 份文件的中文名、左右分组、整份是否只读、**哪些路径只读** |
| `hints` | 打开某份文件时顶部那句人话说明 |

规则：

1. **列头写中文名，下面小字写英文名**——程序认 `id`，人看中文。
2. **机器生成的值一律锁死**：`land`、`plateau.path`、`borders`、`countries.*.label`、`cities.*.at` 这些是算出来的坐标，改了地图就歪；`id` / `no` / `source` 是程序调用的，改了就对不上。
3. **只读路径用段数组 + `*` 通配**（`*` 只吃一层）。键里带点也没事（`cond.break_ready`）。
4. 只读只是**格子不让改**，值照样显示——先让人看懂，再谈能不能改。
5. 算子列后面跟 `ops.json` 里的中文释义（`gte` → 大于等于），和校验用的是同一份。

## 开发约定

1. **顺序**：需求 → 设计 → 前端 → 后端 → 数据库。跳步要回头补。
2. **冲突**：代码与 `docs/` 不一致时，**以 `docs/` 为准**，改代码并更新本文件。
3. **零依赖**：只用 Node 内置模块；前端不引框架、不打包。
4. **裁剪在服务端**：任何"该不该让玩家看见"的判断，只能写在 `controller/serialize.js`。
5. **配置只读一次出口**：运行时读配置一律走 `repository/config.js`，不要直接 `seed.raw()`。
6. **启动/停止命令与端口不动**（见上文）。
7. **新页面先想权限**：是 guest / user / sysadmin 中的哪一档。
8. **公式只有一处**：月修为、出现率、破境概率都在 `model/rules/realm.js`，配置只能引用（`rate.month.body` 这种），不许在 JSON 里写算式。
9. **新效果 = 新算子**：`do` 里要加一种玩法，在 `effects.js` 的 `OPS` 注册一个函数，数据层立刻可用；**不要**在业务代码里手写特例。
10. **修改变的数值只走 `mods.write()`**：否则 `rev` 不变、`.eff` 不重算，面板和判定会对不上。

**r39 新接通的三条链**：

- **年龄就是日程表**：7 进蒙学 → 10 毕业 → 11 府学炼气学习 → 14 学百艺 → 15 大考 → 16 判太学 → 19 卒业，
  **每个节点都是强制事件**，除了"进不进太学"没有别的岔路。
- **东西有保质期**：物品写「2 阶黄上级」，**只对 2 阶 3 品及以下有用**；
  高一小品打一折，**跨大阶直接无效**。罗汉拳到了调息就是废纸——所以术法要换代。
- **委托挂到每一门百艺上**：12 门各一条线，出城的单子会在路上遇上人。

**r36 新接通的两条链**：

- **层级 ≠ 境界**：`lv`（门通到第几层）与 `level`（站在第几品）分开。
  事件办成只**通层级**，境界要**玩家自己点突破**——所以"能突破但先不突破"是合法玩法。
- **界面按"有没有"隐藏**：没入品的境界行整块不画（不是画成灰条）。

- **心性**：定时衰减（只到 60）/ 事件扣减 / 心关失败扣减 → 跌破 40 才掷**心魔**
